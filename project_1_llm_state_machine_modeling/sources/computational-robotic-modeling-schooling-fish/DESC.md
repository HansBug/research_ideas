# 鱼群机器人双状态控制论文 / Computational and robotic modeling reveal parsimonious combinations of interactions between individuals in schooling fish

## 论文在讲什么

这篇论文整体上是在研究鱼群中个体如何整合邻居信息来形成集体运动，因此它的主学术问题偏向生物行为建模。作者同时使用了计算模型和机器人平台来比较不同交互假设，其中机器人实验部分不是简单动画复现，而是把行为模型真正嵌入到实体机器人控制系统中。

对我们来说，真正值得收录的部分正是这套机器人控制实现。论文把单机器人如何周期性做决策、如何朝目标移动、如何处理目标无效和邻居阻挡这些问题，明确落实成一个两态有限状态机，并且给出了双时间尺度、超时与回退策略，因此它并不是只有“生物启发”而没有工程控制细节。

## 控制系统在文中的位置

这里的控制系统描述不是论文的终极研究目标，但它是机器人实验能成立的核心载体。换句话说，作者最终想回答的是“鱼群交互规则是否足够简洁”，而为了让这个问题在机器人平台上可验证，他们不得不构建一套清楚的单机器人控制状态机。这个状态机于是成为论文里一个相当扎实的控制子系统。

这也意味着文中控制逻辑不是随手一写的实验脚本。`COMPUTE` 和 `MOVE` 两个主状态、`Rotate / Move straight / Avoid obstacle` 这些运动子过程、`3 s` 超时和 `80 mm` 回退规则，都是为确保机器人在真实物理环境里可持续运行而设计的，已经具备可复用的状态机样本价值。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是 `⚙️ + FSM + T1` 的机器人控制样本，而且它和常见的工业顺序控制、交通灯或门控系统非常不同。它体现的是一种“模型驱动决策 + 实时运动执行 + 超时恢复”的双时间尺度状态机，这对后续研究 LLM 如何从自然语言中恢复控制层级和恢复链很有帮助。

它还有一个额外价值：这里的状态机不是为了流程推进，而是为了在动态邻居环境下持续生成新目标并执行运动。这类样本能扩展数据集的控制对象类型，让样本库里不只有设备工艺链，也有体现机器人局部决策与恢复机制的离散控制器。
