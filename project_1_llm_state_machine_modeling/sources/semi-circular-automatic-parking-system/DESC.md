# 半圆形自动停车系统原型 / Prototype Design and Application of a Semi-Circular Automatic Parking System

## 论文在讲什么

这篇论文提出的是一套面向停车位稀缺场景的半圆形多层自动停车系统原型。文章不仅给出了机械结构、传感器和单片机实现，还把真正的控制主线写成了一个可执行的停车监督流程：车辆进入 `acceptance/delivery lot` 后，系统先做车牌识别，再根据空位状态选择目标车位，最后由搬运单元完成停车或取车动作。

对我们最有价值的不是它的结构设计，而是它把控制程序写得比较工程化。作者把系统工作明确分成 `vehicle acceptance mode` 和 `vehicle delivery mode` 两个顶层模式，并进一步把最优车位选择 `OPLS`、位置控制 `POC` 以及若干执行子程序的作用关系写了出来，因此不是那种只有一张框图、却没有实际控制链的停车论文。

## 控制系统在文中的位置

这里的控制系统就是整篇原型能够工作的关键。车牌识别、空位检测、搬运机构和计费逻辑都围绕 PIC 微控制器中的控制程序组织起来，系统到底停在哪个车位、怎么把车送进去、怎么按原路径取出来，都由这个程序决定。换句话说，控制不是附属模块，而是把识别、选位、搬运和计费串成闭环的主线。

从状态机视角看，这篇论文的价值在于它既有清楚的顶层模式，也有明确的下层执行链。顶层是 `acceptance` 与 `delivery` 两个运行模式，底层则通过 `OPLS` 和 `POC` 继续分解成选位、前后移动、垂直移动和水平移动等子过程；再往下，执行动作还被 `SW1 / SW2`、红外空位传感器和固定运动时间参数约束。这样的描述强度足以稳定支持一个 `HSM + T1` 样本。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是 `🅿️` 方向里一种比较少见的“停车监督器 + 搬运执行链”样本。它不同于很多只停留在 FPGA 门禁或简单车位计数的停车稿，这里有真实的多层车位、搬运臂、取车回路和局部运动时间模型，状态机骨架更完整。

此外，它还有助于平衡当前文库中停车方向的样本形态。停车类文献很容易重复到“门禁 + 空位显示”这一路，而这篇论文把“最优车位选择 + 执行子程序调度 + 取车逆过程”都写出来了，能为后续做状态机建模、场景生成和缺陷修复提供更丰富的离散控制结构。

## 如果需要人工细读，建议怎么读

如果后续要人工复核 `STM.md`，建议先读第 3 页对 `vehicle acceptance mode / vehicle delivery mode` 的总述，先确认系统顶层模式和进入条件。然后直接跳到第 6-7 页的控制程序部分，把 `OPLS`、`POC`、`5.2 sec / 2.75 sec`、`SW1 / SW2` 这些真正决定状态切换和动作触发的内容抓出来。

至于机械结构尺寸、步进电机选型和模糊折扣计费，可以放到第二轮再看。它们对理解整套原型当然有用，但如果目标是抽取离散控制链，第一轮最值得保住的仍然是“何时进入哪个模式、如何选位、如何通过子程序完成停车/取车”这条主链。
