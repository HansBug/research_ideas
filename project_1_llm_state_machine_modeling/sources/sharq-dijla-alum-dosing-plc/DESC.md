# Sharq Dijla 水厂明矾配制与投加控制 / Upgrading of Alum Preparation and Dosing Unit for Sharq Dijla Water Treatment Plant by Using Programmable Logic Controller System

## 论文在讲什么

这篇论文讨论的是伊拉克 `Sharq Dijla` 水厂化学加药单元的自动化升级。作者关注的不是整座水厂所有工艺，而是明矾溶液的配制、储存优先级、投加泵调节和相关监测点如何从纯人工操作改造成 `PLC + SCADA` 监督控制系统。

文章的价值在于它没有停留在“建议自动化”这一层，而是把需要接入的 `LIT / DIT / TIT / FIT / ALIT` 传感器、卸料阀、供水泵、鼓风机、变频投加泵和本地/远程操作方式逐项写出来，再进一步给出自动模式下的 basin priority、配制步骤和停机条件。

## 控制系统在文中的位置

我们关心的控制系统描述在文中是核心主体。论文前面虽然也介绍了水厂背景和 SCADA/PLC 基础概念，但真正展开的重点是“化学楼里这套加药单元该怎样自动运行”，包括如何确定优先使用哪座配制池、何时自动补配、以及怎样根据来水流量和水质实时修正投加量。

这使它和很多只给一张工艺图的水处理短稿不一样。这里的控制对象边界相当清楚，状态推进也比较完整：先判断模式与池优先级，再决定取用/补配，再进行按传感器融合的投加调节，最后在满池、低浊度、缺料或故障等条件下退出自动流程。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是一种很有代表性的过程控制样本，但又不只是简单的液位阈值启停。它把多个池之间的优先级切换、配制时序和多传感器闭环调节结合在一起，比普通水箱补液或单泵启停系统更适合支撑后续状态机建模任务。

它还保住了对后续抽取很关键的执行器和 guard 细节。比如不同模式下的 `OWS / LCP / PLC-CB` 权限关系、配制池年龄优先级、预设混合时段、以及 `FIT / DIT / ALIT / TIT` 对投加速度的共同约束，这些都能直接转成状态、条件和动作描述。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看第 4-6 页 `4.1` 和 `4.2`。先把三座 preparation basin、卸料 silo、水服务泵、鼓风机、进气阀和 dosing pump 的角色画清楚，再重点核对自动模式下的 basin priority、补配触发和“空池切换到下一池”的推进逻辑。

如果后续要补更细的 guard 或异常链，再回看摘要和结论对应的段落，重点核对 `FIT / DIT / TIT / ALIT` 分别在投加计算里扮演什么角色，以及自动流程在哪些条件下退出。相比之下，前部关于 SCADA/PLC 的一般背景说明不是第一次重做 `STM.md` 时最优先的内容，可以后看。
