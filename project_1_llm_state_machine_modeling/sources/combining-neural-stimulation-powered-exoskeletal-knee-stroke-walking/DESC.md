# 卒中步行辅助混合外骨骼四相位控制 / Combining neural stimulation and a powered exoskeletal knee to enhance walking after stroke

## 论文在讲什么

这篇论文讨论的是一套面向卒中后步行障碍患者的混合外骨骼。系统把非侵入式神经刺激和带电机的膝关节矫形器组合起来，希望同时利用患者残余肌力和外部助力，让 swing、push-off 和 stance 稳定性都得到改善。

论文的重点并不只是对比几种 walking condition 的效果，而是说明这台装置怎样根据 gait phase 切换控制模式。作者把控制器写成四相位 `FSM`，再在每个相位里分别挂接电机弹簧/阻尼参数和特定肌群刺激，因此整篇文章里的控制逻辑边界相当清楚。

## 控制系统在文中的位置

这里的控制系统是正文的核心实现对象，而不是为了做实验随便附带的控制框架。第 `Controller` 小节明确把装置写成 `early swing / late swing / early stance / push off` 四态 `FSM`，并进一步解释 `IMU`、`FSR`、电机参数和刺激通道如何跟这四个状态绑定。

当然，论文整体仍然带有明显的康复实验色彩，后半部分也会讨论受试者步态表现和多种 assistance condition 的差异。因此它不是那种纯粹只讲控制器设计的工程论文。但对 `sources/` 来说，它已经足够具体，能够稳定保留一条完整的 gait-phase 控制主链。

## 对我们为什么有用

这篇论文的价值在于它补进了一条“神经刺激 + 外骨骼电机”联合调度的 gait-phase 控制样本。库里已有不少外骨骼和神经假体条目，但这里的控制链比较干净：四个状态、明确的 `IMU/FSR` 相位触发、相位内的电机阻抗设定，以及对应肌群的刺激输出。

它之所以被放在降采样池，不是因为质量不够，而是因为步态外骨骼这一簇现在已经积累了不少高质量近邻样本。后续如果要做主训练集采样，这篇更适合拿来提供表述差异和实现风格差异，而不是继续堆同类型主力样本。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `6-8` 页，把 `Controller` 段和 Figure `5` 周边的内容完整读一遍，优先圈出四个 gait phase 名称、`IMU/FSR` 触发条件、电机助力参数和神经刺激对应关系。这几块就是恢复 `STM.md` 的核心证据。

第 `1-5` 页关于装置机械结构、传动比、受试者背景和试验条件的内容可以放在第二轮再看。第一次复核时，只要先把“哪四个状态、如何切换、每个状态输出什么 assistance”这条主控制链读稳，就已经足够支持单篇样本重建。
