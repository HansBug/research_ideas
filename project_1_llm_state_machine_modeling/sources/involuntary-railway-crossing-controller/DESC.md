# 双红外道口门控与异常报警 / Involuntary Railway Crossing Controller

## 论文在讲什么

这篇论文讲的是一个用 ATMEGA328 和双 IR 传感器构成的铁路平交口自动门控系统。它的目标很直接：用传感器代替人工道口值守，让栏杆在列车接近时自动关闭、在列车通过后重新开启，并在异常时触发报警。

从状态机样本角度看，这篇文章的价值在于它把一个极简但闭环完整的道口控制对象写清楚了。虽然篇幅只有三页，但输入是两个方向传感器，输出是栏杆电机的正反转和报警，控制器中间还有微控制器与 H-bridge 的方向切换逻辑，因此并不是一句“自动关门”式的背景描述。

## 控制系统在文中的位置

铁路道口控制器就是论文唯一的核心对象。作者围绕工作原理、框图、H-bridge、电机和硬件单元展开说明，所有章节都服务于“如何自动开关栏杆”这条主线。

这对 `sources/` 来说很合适，因为我们不需要从复杂联锁或大系统架构里裁剪子逻辑。传感器布置、信号输入、电机方向控制和异常报警都集中在几页正文内，阅读和回溯成本都比较低。

## 对我们为什么有用

这篇样本补的是 `🚆` 方向里一种更贴近工程实现的道口门控控制器，而不是轨道联锁表、形式化 route establishment 或协议验证。它能够给文库提供一类非常直接的“到达检测 -> 关门 -> 通过后检测 -> 开门”控制叙事。

它虽然与库内已有一些传感器式道口控制样本存在邻近相似，但仍然有自己的表达差异：作者把双红外传感器的前后布置、H-bridge 正反转以及报警逻辑写得比较集中，适合后续做轻量级门控状态机、异常告警和守卫条件抽取。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看第 1 页 的摘要和 `Working of Involuntary Railway Crossing Controller & Results`，快速抓住两个传感器的功能分工和道口开关逻辑；然后看第 1-3 页 的 block diagram、H-bridge 和 hardware unit 段落，把信号流和电机方向控制对应起来。

这篇文章几乎没有需要第二轮才读的复杂理论区块，真正值得反复核对的是几个具体动作：前方传感器触发关门、后方传感器触发开门、H-bridge 正反转如何实现、异常报警何时介入。只要把这四处读稳，就足以重新抽出高质量的 `STM.md`。
