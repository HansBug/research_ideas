# 动作感知与金属检测自动门控制 / Design and Construction of a Motion-Based Automatic Door Opener with Metal Detector

## 论文在讲什么

这篇论文设计的是一个以 `PIC16F877A` 为核心的自动门系统：`PIR` 负责检测人体接近，金属探测器负责安全筛查，伺服电机负责门体开闭，`LCD` 和蜂鸣器负责状态提示与报警。论文篇幅不长，但从摘要到程序代码都围绕同一个控制问题展开，即“门什么时候允许打开、什么时候必须保持关闭、什么时候应该报警”。

它不是复杂的楼宇系统论文，而是一个比较紧凑的单门控制案例。即便如此，原文仍把控制链写得很直白：人体检测成立还不够，必须同时满足“未检测到金属”才开门；若检测到金属，则门保持关闭并触发蜂鸣器。程序代码、仿真截图和实物测试三者对同一套 guard 条件形成了互相印证。

## 控制系统在文中的位置

控制系统是论文的主体，不是简单硬件拼装说明。文章前半部分介绍 `PIR`、金属探测器、伺服电机和单片机，但这些并不是孤立器件说明，而是为后续程序流程服务。到 `3.4 Programming`、仿真模型和附录代码时，门控逻辑已经被明确写成输入组合到输出动作的程序分支。

对我们来说，这一点比“系统高级不高级”更重要。它意味着该论文虽然对象简单，却非常适合做状态机描述样本，因为每个输入组合对应的门状态、报警动作和显示状态都很容易追溯，不需要再从图里猜转移。

## 对我们为什么有用

这篇论文提供的是一个典型的 guard-driven 自动门样本。它非常适合补充“简单但可追溯”的门控控制链，因为原文明确区分了 `PIR high + metal low`、`PIR high + metal high`、`PIR low` 等分支，并写清楚伺服电机、蜂鸣器和 `LCD` 如何响应。这种样本对后续训练很有价值，因为它能提供干净的 `if-then-else` 风格状态切换语言。

它也能补充楼宇机电方向中“门禁安全筛查”这一子类。相比只谈距离阈值或普通开门按钮的自动门论文，这篇文章多了金属筛查的拒绝分支和报警输出，使它在语义上更接近真实入口控制而不是单纯便利性自动门。

## 如果需要人工细读，建议怎么读

人工细读时，先看第 `1-3` 页摘要和 conceptual framework，确认系统边界、输入输出器件以及“必须同时满足 `PIR=1` 且 `metal=0` 才开门”的核心 guard。然后直接跳到第 `14-15` 页的 programming 与 simulation 结果，把四种输入组合下的门状态先读清楚。之后再看第 `19` 页程序代码，尤其是 `if(PORTB.B1==0 && PORTB.B0==0)` 和 `if(PORTB.B1==0 && PORTB.B0==1)` 两个分支，它们是最直接的控制证据。

电源设计、晶振、电阻电容计算和器件原理部分可以放到第二轮再看。这些段落对复现实物有帮助，但对重新抽取状态机主链不是最高优先级；如果 `STM.md` 需要返工，最该回看的仍是摘要、framework、programming、simulation 和代码分支。
