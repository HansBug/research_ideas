# 自动滑门开闭与防夹 PLC 控制 / PLC Based Automatic Door Opening & Closing System

## 论文在讲什么

这篇论文讨论的是面向公共建筑入口的自动滑门控制系统，而不是一般性的楼宇自动化综述。作者围绕 `PLC + 频率变换器 + 驱动电机 + 传感器` 搭建了一套完整门控方案，重点放在“人到门开、门口有人就保持、无人后延时关门、关门时遇障回开”这条主控制链上。

它不像一些只展示接线图的短文，而是把自动控制和手动控制都纳入同一个系统设计里，同时补上了防夹、安全格栅、限位与报警复位逻辑。这使它比单纯的“门电机驱动示意”更像一个可直接抽成状态机的楼宇机电控制样本。

## 控制系统在文中的位置

自动门控制器就是全文核心对象。摘要、系统设计、软件设计、流程图和梯形图都围绕门体本身的开关动作展开，输入是感应器、红外与按钮，输出是门机和报警信号，没有把焦点转移到楼宇平台或管理系统上。

对 `sources/` 来说，这意味着我们能够直接从原文恢复控制系统边界：哪几个输入决定门是否打开，什么时候进入延时关门，什么时候触发防夹回开，什么情况下整套系统会进入故障停机和复位流程。这种边界清晰度很适合拿来做 `STM.md`。

## 对我们为什么有用

楼宇机电方向里当前已有一些电梯与自动门样本，但这篇补的是更完整的“滑门开闭 + 安全格栅 + 手动/自动双模式 + 报警复位”控制器。它既保留了 nominal open-hold-close 链，也保留了异常与人工干预分支，因此比只有一条顺序链的门控文更有训练价值。

它的另一个优点是时间语义清楚：`8 s` 保持、`6 s` 关门、`0.2 s` 防夹延迟都在原文里明说。对后续要做 `FSM/EFSM + T1` 的数据集来说，这种“局部工程定时 + 异常回退”样本比单纯的门位切换更有辨识度。

## 如果需要人工细读，建议怎么读

建议先看第 `1-4` 页的 `Introduction`、`System Design` 和 `System Software Design`，先把感应开门、保持、延时关门、防夹回开、报警复位和手动/自动模式这几条线读顺。第一次人工复核时，重点是确认“门为何保持开启、何时开始倒计时关门、关门时遇障怎样回到开门分支”。

第二轮再去看流程图和梯形图部分，把 `I0.4 / I0.6 / I0.7 / I1.0 / I1.3` 等输入和 `Q0.1 / Q0.4 / Q0.5 / Q1.1` 等输出对回具体功能。后面的泛文献综述可以后看，因为恢复控制状态机时，真正关键的是系统设计与软件逻辑，不是 PLC 技术背景综述。
