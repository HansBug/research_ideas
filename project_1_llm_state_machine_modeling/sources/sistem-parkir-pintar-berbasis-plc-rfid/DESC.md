# 基于 RFID 的多层停车位分配与入库控制 / RANCANG BANGUN SISTEM PARKIR PINTAR BERBASIS PLC (PROGRAMMABLE LOGIC CONTROLLER)

## 论文在讲什么

这篇论文讨论的是一个多层智能停车样机，目标是用 PLC、RFID、光电传感和数据库前端把车辆入库和出库流程做成自动化控制系统。作者不是只做门禁展示，而是让系统在读取身份后自动选择空车位、驱动平台与闸门动作，并把入库结果回写到控制界面中。

从系统边界上看，它包含 RFID 识别、Visual Studio 与 MySQL 前端、PLC 梯形图、房间空位检测、平台机械动作和闸门放行。这使它比“只有计数器或只会开关门”的停车稿更接近完整停车控制对象。

## 控制系统在文中的位置

控制系统是文章主线。前半部分用 `Visual Studio 2010`、`MYSQL` 和 `CX-Supervisor` 解释数据如何从 RFID 读入并传到 PLC，后半部分用 `mode masuk / mode keluar` 流程和实际测试说明车辆是怎样被分配到具体房间的。

我们关注的不是数据库实现本身，而是它服务于一个离散控制链：识别车辆身份、判断是否属于进入流程、挑选空房间、打开对应 PLC memory、确认目标房间没有车、把平台降到地面、再让闸门变成桥面把车送进样机。这个控制主链在文中是明确可追溯的。

## 对我们为什么有用

这篇样本对 `sources/` 的价值在于它补的是“带身份识别和空位分配的停车系统”，而不是单纯的入口闸门。相比库里已有一些停车门禁条目，它更强调房间选择、数据库状态和平台动作的耦合，因此在停车方向上有一定增量。

同时，它仍然保持了足够清晰的工程离散语义：空位是变量条件，`mode masuk` 是模式入口，`memory 220.02` 之类的位是动作触发，平台到地面和闸门下放则是后续执行效果。这样整理后，很适合作为 `EFSM + T0` 的停车控制样本。

## 如果需要人工细读，建议怎么读

人工回原文时，先看 `2.5 Perancangan Visual Studio 2010`，先把 RFID、数据库和空房间选择这条前端链读清楚；接着直接看 `2.6 Flowchart` 和 `3.2 Pengujian Sistem Secara Keseluruhan`，重点抽取 `mode masuk`、目标房间 memory、光电传感器空位判断、平台下降和闸门桥接这几个关键动作。

如果还要补边界信息，再看 `3.3 Hasil Pengujian Sistem Keseluruhan` 与结论部分，确认满位指示灯如何禁止继续入库，以及系统是否已经完成从 RFID 读取到车辆入库/出库的闭环验证。大量器件级测试和电压表格可以放在第二轮，因为它们对状态机主链帮助有限。
