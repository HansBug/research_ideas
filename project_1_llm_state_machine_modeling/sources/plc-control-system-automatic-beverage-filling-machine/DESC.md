# 自动饮料灌装机 PLC 控制系统分析与设计 / Analysis and Design of PLC-based Control System for Automatic Beverage Filling Machine

## 论文在讲什么

这篇论文讲的是一台自动饮料灌装机如何用 `PLC + 伺服计量泵 + HMI` 做控制。系统被拆成送瓶、灌装和封盖三部分，空瓶先被送入灌装位，通过称重和位置检测确认后执行定量注液，随后把已灌装的瓶子送入封盖区。

文章虽然篇幅不长，但并不是只停留在“PLC 很适合工业自动化”这一层。作者把瓶到位、称重确认、伺服计量、输送速度协调、封盖移交和自动/手动子程序都写进了控制结构里，因此能够形成一条比较完整的离散制造主控制链。

## 控制系统在文中的位置

这里的控制系统是论文主体。硬件部分介绍了 PLC、称重、传感器、伺服灌装和输送机构如何协同，软件部分则明确给出 `automatic/manual`、`drive`、`filling servo`、`capping` 这几个子程序各自负责什么，以及它们如何围绕灌装流程组织。

从 `sources/` 的角度看，这篇论文的价值不在复杂算法，而在一个典型灌装单元怎样把“空瓶确认 -> 参数设定 -> 灌装 -> 送往封盖区”写成工程上能落地的 PLC 顺序控制。它属于制造方向里比较典型、但仍然足够具体的 `EFSM + T1` 工程样本。

## 对我们为什么有用

这篇论文能补的是“以产线节拍和定量灌装为核心”的制造型控制样本。它与只给器件清单或总流程框图的短文不同，已经明确到哪些传感器负责确认空瓶、哪些子程序负责速度协调、灌装结束后如何切换到封盖区，这些信息足以支持后续构造状态、guard 和动作描述。

另一个价值是它保留了工程实现里的关键约束。比如灌装量通过 HMI 参数进入系统、伺服泵通过位置/速度控制保证计量、输送速度要和灌装速度匹配，这使它不只是“先做 A 再做 B”的极简流程，而是更接近真实产线控制器的样子。

## 如果需要人工细读，建议怎么读

如果后续需要人工重做 `STM.md`，建议先看第 1-2 页的 `Principle of automatic filling system` 和各部件功能说明，先把空瓶确认、称重、伺服灌装、输送和封盖之间的边界弄清楚。随后直接看第 3-4 页的软件框图和 `Flow of filling program`，把 `automatic/manual`、`drive`、`filling servo`、`capping` 四个子程序与主流程关系补齐。

文中关于 PLC 优势、背景比较和一般性灌装产业需求可以放到第二轮再看。第一轮真正需要抓住的是“什么输入确认瓶子到位、谁触发灌装、灌装结束后如何移交给封盖”这条主链；只要抓住这部分，这篇短文就足够支撑高质量样本提取。
