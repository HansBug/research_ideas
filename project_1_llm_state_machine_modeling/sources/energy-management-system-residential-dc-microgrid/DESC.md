# 直流微电网全局能量管理控制器 / Design and Implementation of an Energy-Management System for a Grid-Connected Residential DC Microgrid

## 论文在讲什么

这篇论文研究的是一个并网住宅 `DC microgrid` 的能量管理系统。系统由 `PV array`、`battery bank`、`supercapacitor`、双向 `DC-AC` 变换器和直流母线组成，作者的核心目标是设计一个 centralized `EMS`，在不同负载和供能情形下维持母线电压稳定，同时尽量利用光伏、减少对主网的依赖。

对 `sources/` 来说，最关键的是论文没有把 `EMS` 只写成“优先用 PV，再用电池/主网”的口头规则，而是进一步把它落实成 `GMC` 十状态状态机，并给出大表格形式的转移条件和输出模式。也正因为如此，这篇材料能稳定沉淀为一条强 `EFSM + T0` 样本。

## 控制系统在文中的位置

这里的控制系统描述是文章主轴。论文不仅给出了 `Figure 7` 的 GMC 状态机图，还在 `Tables 3-7` 里把每个状态的输入条件、下一状态以及 `PV / DC-DC / DC-AC / Loads` 输出模式全部列出。实验和实现部分也是围绕验证这套全局控制器的切换行为展开。

它和很多只讲优化目标或能量流仿真的论文不同。作者明确关注的是“控制器如何决定谁供电、谁充电、谁退出”，所以状态机承担的是系统调度骨架，而不是结果图背后的隐含逻辑。

## 对我们为什么有用

这篇论文补的是 `🌡️` 方向里“条件表非常完整的微电网 supervisor”样本。相比只给模式名或流程图的能量管理稿，这篇的优势在于输入、状态和输出三者被直接对齐，后续不需要大量二次猜测就能把控制链还原出来。

它也有助于补齐“连续功率变量驱动的 EFSM”这类表述。这里的状态切换依赖 `Vbus` 电压区间、`PV Power` 是否高于 `800 W`、`MG` 可用性和电池状态，而输出又直接映射到变换器的 `VC / MPPT / BOOST / BUCK / RECTIFIER / INVERTER` 模式，因此很适合作为连续条件驱动离散监督控制的代表样本。

## 如果需要人工细读，建议怎么读

人工重读时，建议先从第 `9-13` 页入手，顺序读 `Figure 7`、`Tables 3-7` 和紧随其后的状态解释。第一轮重点只回答四个问题：有多少状态、哪些输入变量驱动转移、每个状态输出哪些变换器模式、`START` 和低压异常时是如何分流的。

第二轮再回看前面的系统组成和后面的局部控制器章节，确认 `PV`、`battery`、`MG`、`DC bus` 各自在控制链中的位置，以及局部 `VC / MPPT` 控制如何接住 `GMC` 发出的模式命令。这样读最不容易被整篇论文的大量硬件和功率电子实现细节淹没。
