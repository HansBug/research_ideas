# 主支路分级与左转跳过交通灯 / Conceptual Design of Intelligent Traffic Light Controller

## 论文在讲什么

这篇论文讨论的是一个面向简单路口的智能交通灯控制方案。作者把一个两条道路相交的路口抽象成主干道 `North-South` 与支路 `East-West`，并明确给主干道更长的放行周期。系统不是只做固定红黄绿轮转，而是把左转车道也纳入考虑，并假定左转车道下方有感应线圈来判断当前周期里是否真的需要给左转绿灯。

论文的实现重点放在离散状态机设计上。作者把控制器写成 `12` 个状态的 Moore 机，输出灯色只由当前状态决定，而感应线圈输入只影响下一个状态怎么选。后文又把几个方向灯在什么状态下为绿灯写成布尔逻辑和电路实现，因此它不是泛泛讲“有一个交通灯系统”，而是把状态机编码和相位控制骨架都明确展开了。

## 控制系统在文中的位置

这里的交通灯控制器就是论文主体本身。文中没有把状态机当作附带例子，而是直接把“如何给主支路和左转相位排状态、怎样让输入只影响下一状态、如何把状态编码成输出电路”作为主要内容来写。

对 `sources/` 而言，这篇文献的重要性在于它提供了一类比较干净的 `FSM + T0` 交通控制样本。它和那些强调定时器常数、车流密度计算或模糊控制的交通灯论文不一样，更多是在做结构化相位设计，因此适合补“状态主导、输出纯由状态决定”的交通灯状态机表述。

## 对我们为什么有用

这篇论文最有价值的地方，是它把主干道优先、支路切换、左转跳过和状态编码放在同一套控制叙述里。后续如果要做自然语言到状态机的建模任务，这种样本很适合作为“状态驱动输出、输入驱动下一状态”的标准 Moore 机对照。

此外，它还能补足交通灯方向上的结构差异。文库里已有不少 `T1` 型交通灯控制器，常常强调固定秒数、倒计时、应急优先或传感器阈值；而这篇更突出状态集合本身和方向灯输出映射，对建立更平衡的交通灯样本簇有帮助。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看第 1 页 `2. Traffic Light Model`，先把主干道/支路设定、左转处理方案和感应线圈跳过规则读稳。然后直接看第 2 页 `3. Controlling the Lights According to the States`，这里是理解这篇论文的关键，因为作者明确说了这是 Moore 机、输入只影响下一状态、状态总数是 `12` 个。

之后再看第 3-7 页各方向灯的实现说明，重点核对 `East-South`、`North-East`、`West-East`、`West-North` 等方向分别在哪些状态下点亮。反过来，那些更偏 Karnaugh 图和门级实现细节的部分可以放在第二轮再看；第一次人工回读只要先把“主支路分级 + 左转跳过 + 12 状态 Moore 机”这条主控制链抓住就够了。
