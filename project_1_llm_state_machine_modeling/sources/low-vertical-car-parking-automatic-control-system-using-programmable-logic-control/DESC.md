# 六槽位立体停车 setpoint 定位控制 / Low Vertical Car Parking Automatic Control System Using Programmable Logic Control

## 论文在讲什么

这篇论文围绕六槽位立体停车 setpoint 定位控制展开，当前 `STM.md` 抽到的核心对象是“六槽位立体停车原型的槽位定位与呼叫控制器”。如果只抓一句话理解它的主体，可以先把它看成：这是智慧停车与车位管理领域里一个更偏“平台定位”而不是“门禁放行”的 PLC 样本，用按钮给出目标车位、用 rotary encoder 反馈当前位置，再驱动平台旋转到目标槽位。

从现有条目看，文中的离散控制链主要以 `EFSM（扩展状态机）` 的方式出现，时间语义属于 `T0（无关键时间语义）`。和库里已有的停车门禁/空位分配条目相比，这篇更像一个“位置闭环 + 槽位 setpoint 调度”的设备级控制样本，因此能补足停车方向里不那么依赖入口闸机的另一类控制对象。

## 控制系统在文中的位置

它是论文的主案例，不是附带说明。作者做整篇设计，就是为了实现一个可容纳 6 辆车的立体停车原型，并验证 PLC 是否能根据按钮命令和编码器反馈把平台转到目标位置。

更具体地说，这篇论文里我们关心的控制系统描述，承担的是“把停车位编号、当前位置反馈和电机执行链落成具体控制环”的角色。它没有停留在一般性硬件介绍，而是把 `button -> PLC -> relay -> inverter -> motor -> encoder -> PLC` 这条链直接串起来了。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补进的是一个 `停车位 setpoint + encoder feedback` 样本。后续如果要比较“停车门禁 / 车位分配”与“立体停车平台定位”两类离散控制链，这篇非常适合做后者的代表。

做数据集时，第一轮最值得盯住的是 six-slot 结构、button 命令、encoder 角度反馈、slot position 变量以及 PLC 输出到 inverter 的执行链。至于机械结构装配、电压电流测试细节和一般性停车背景，可以放到第二轮再看。

## 如果需要人工细读，建议怎么读

如果后续需要人工细读，建议先看第 1 页摘要与引言，把“6 个车位、button 命令、rotary encoder、set point 时间”这几个对象和目标读稳；然后直接看第 2 页 `Method`，重点圈出 PLC 输入/输出、relay/inverter、电机和 encoder 的因果链；最后看第 3-5 页 `Result and Discussion / Conclusion`，确认 setpoint 测试、slot 编号和 nominal 响应时间。

像第 2-3 页里更偏机械安装、电源连接和一般性实验装配说明的内容，可以放到第二轮再看。除非你是在追电机驱动规格，否则第一次人工复核只需要先把槽位 setpoint 控制链读稳；即使 `STM.md` 之后需要重做，这条阅读路线也足够支撑人工重新把案例抽出来。
