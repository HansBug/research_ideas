# 三模式停车场门禁与占位监督控制 / PLC Based Automatic Intelligent Car Parking System

## 论文在讲什么

这篇论文提出的是一个基于 PLC 的智能停车场控制系统，目标是用较低成本的 IR、LDR 和太阳能供电部件，完成入口车辆检测、出口放行、空位统计和紧急闭锁。论文并不是复杂的塔式停车机械设计，而是面向地面停车场门禁与占位管理的监督控制。

对 `sources/` 有价值的地方在于，作者没有只停留在“有传感器、有显示器”的介绍，而是明确给出系统运行的三种模式：`ON`、`OFF`、`EMERGENCY`。再往下又把入口 gate、出口 gate、LDR 车位检测和应急按钮如何共同决定控制动作写清楚了。

## 控制系统在文中的位置

控制系统就是这篇论文的核心对象。作者把 PLC 视为整套停车场逻辑的中央控制器，IR 传感器和 LDR 是输入，入口门和出口门是输出，紧急按钮则触发全局安全模式。也就是说，论文不是以图像识别、云端平台或支付系统为主体，而是在讲一条具体的停车监督控制链。

虽然文中也花了一些篇幅介绍传感器和太阳能供电原理，但这些内容主要是为实现服务。真正可提炼成状态机自然语言的部分集中在 `Methodology` 和 `Process Description`：三模式切换、空位判定、入口放行、满位拒绝、出口放行和应急全闭锁。

## 对我们为什么有用

这篇论文补的是 `🅿️` 方向里比较实用的 `EFSM + T0` 停车门禁样本。库里已经有一些停车场导引、密码门禁、计费和 FPGA 方案，但这篇的特点是把“全局模式 + gate guard + occupancy sensing”结合得很直接，且原文足以支撑双 A 级描述。

它还提供了一个很适合数据集的写法：上层是 `ON / OFF / EMERGENCY` 模式，底层是 entry/exit gate guard 和 vacancy check。对于后续 LLM 建模，这类样本比单纯车位计数器更像真实 supervisor，也比只写硬件电路的短文更容易恢复成状态机。

## 如果需要人工细读，建议怎么读

人工重读时，建议先读第 `2-3` 页的 `III. Methodology` 和 `IV. Process Description`。先把三种模式、六个 `LDR`、入口/出口 `IR`、紧急按钮和 gate 开闭条件全部抓出来，再确认哪些条件对应正常放行、满位拒绝和全局闭锁。这样能最快重建状态机主体。

之后如果需要补硬件和部署边界，再回看第 `1` 页摘要和第 `3-4` 页的模块说明，确认 PLC 型号、输入输出模块和太阳能供电角色。较长的传感器原理说明可以放到最后，因为它们对恢复门禁监督逻辑帮助有限。
