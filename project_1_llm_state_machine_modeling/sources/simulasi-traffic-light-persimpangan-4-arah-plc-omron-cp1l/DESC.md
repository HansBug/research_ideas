# 四向路口 PLC 交通灯仿真 / Simulasi Traffic Light Persimpangan 4 Arah untuk Optimasi Alur Kendaraan Menggunakan Programmable Logic Controller (PLC) Omron CP1L

## 论文在讲什么

这篇论文名义上是在讨论“四向路口交通灯优化”，但真正最有价值的部分不是复杂自适应策略，而是一条非常完整的 `PLC Omron CP1L` 定时交通灯顺序控制链。正文把四个方向的绿灯轮转、黄灯过渡、初始全红和循环复位都写成了可执行的 ladder 逻辑。

因此，它更适合被当成“定时信号相位控制样本”来读，而不是“密度自适应优化算法论文”。摘要虽然提到了车流密度，但文中最明确、最可追溯的控制证据，仍然是固定顺序的 timed cycle。

## 控制系统在文中的位置

控制系统设计是这篇论文的核心内容。第 6-11 页依次给出流程图、`CX-Programmer` 中的 ladder 描述、初始状态、黄灯过渡和循环复位逻辑，控制器并不是论文里的辅助示例，而是主角。

对样本库来说，这篇论文的价值在于它把“简单但完整”的路口相位控制说得很清楚。很多交通灯论文会把重点放在图像检测、优化指标或硬件平台展示上，而这里真正留下的是 `all-red -> green_i -> yellow_i -> next` 的顺序控制骨架。

## 对我们为什么有用

这篇论文提供了一条很干净的 `FSM + T1 + 显式时钟` 交通灯样本。它的状态并不复杂，但状态之间的顺序、互斥和时间语义都很明确，适合做“定时相位循环”这一类基线控制器的训练样本。

另外，它还能作为一个很好的“标题与正文重心不完全一致”案例。也就是说，后续做扩样时，不能只因为标题里有 `optimasi`、`kepadatan` 就把它当成自适应信号控制论文；真正可收录的还是正文中那条明确的离散状态链。

## 如果需要人工细读，建议怎么读

人工重读时，建议先从第 6-8 页的流程图和文字说明入手，先把 `all red`、四个方向各 `6 detik` 绿灯和循环回到起点的骨架确认下来。然后再看第 8-11 页 ladder 说明，把 `timer 1`、`timer 2`、`timer 8` 这些定时器在控制链中的作用补齐，尤其要确认黄灯是如何充当过渡状态的。

如果只是为了重建状态机，不必花太多时间在前面的背景与拥堵论证，也不必把后面关于车流观察的统计部分看得很深。第一次阅读最值得抓住的是：相位顺序、每相持续时间、单方向放行互斥，以及最终如何通过定时器复位进入下一轮循环。
