# 自动滑门与房间照明联合控制系统 / A Digital Automatic Sliding Door with a Room Light Control System

## 论文在讲什么

这篇论文研究的是一个比较典型但在样本库里并不算多的楼宇机电控制对象：自动滑门。作者不是只做机械结构介绍，而是把自动滑门和房间照明控制放在同一套电子控制系统里，用红外发射/接收对管、比较器、单稳态、计数器、异或门、继电器和直流电机做出一套可以实际运行的入口控制器。

论文最有价值的部分在于它把门控逻辑写得很工程化。系统既要在有人接近时开门，又要保证通过后自动关门，还要避免同一次通过被重复计数，同时还把室内人数计数和灯光开关接到同一条传感逻辑上。这让它不只是“自动门电路设计”，而是一条完整的离散控制链。

## 控制系统在文中的位置

我们关心的控制系统在文中是主体。第 3 节之后，论文基本都围绕传感器如何触发、单稳态如何定时、计数器如何记人流、继电器如何切换电机极性展开。也就是说，这篇文章不是用自动门举例说明某个通用方法，而是在直接构造自动门控制器本身。

和现有 `sources/` 里那篇 PLC 自动门论文相比，这篇文章的实现手段更偏硬件逻辑与定时电路，而不是 PLC I/O 和程序位。它因此补到了同一个楼宇子对象上的另一种实现画像：不是 PLC 程序驱动，而是比较器 + 单稳态 + 继电器切换驱动的门控链，这对样本多样性是有帮助的。

## 对我们为什么有用

对 `🏢` 领域来说，这篇论文的价值首先在于补子类型。当前楼宇机电方向主要还是电梯样本，自动门虽然已有个别条目，但还远没到饱和。这篇文章把自动门对象写得非常细，尤其是 `5 s / 10 s` 两级定时、第二传感器屏蔽窗口、反向极性关门和人数计数联动，都很适合抽成带时间 guard 的状态机语料。

其次，它的语言形态很适合做自然语言到状态机数据。原文虽然不是直接画传统状态图，但控制链非常明确：传感器断光 -> 启动双定时 -> 开门 -> 计数/通过 -> 反向关门 -> 灯光按人数计数开闭。这类样本能帮助后续模型学会从硬件逻辑叙述中恢复出离散状态，而不是只会处理软件式显式 FSM。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `5-6` 页关于系统工作原理的段落，把两个核心事实抓住：一是开门和关门由哪两个时间常数驱动，二是电机为什么能在同一套机构里实现开/关两个方向。只要这两点抓住，自动门的主状态链已经很清楚。

然后再看第 `7-10` 页的 `Sensor Control Stage`、`Counter Stage` 和 `Driver Control Stage`。这里要重点确认第二个传感器被屏蔽 `10 s` 的原因、人数计数是怎么跟 entry/exit 方向绑定的，以及继电器如何在后半段切换极性执行关门。至于前两页关于自动化背景的长引言，可以放到最后再看，因为它对 `STM.md` 的首轮抽取帮助不大。
