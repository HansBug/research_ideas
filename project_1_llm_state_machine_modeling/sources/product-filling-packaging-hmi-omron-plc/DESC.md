# HMI 可设定计数的灌装包装控制 / Control and Monitor of Product Filling Automation System in PLC-Based Packaging Using HMI Omron NB7W-TW00B

## 论文在讲什么

这篇论文讲的是一套基于 `Omron PLC + HMI` 的产品灌装包装自动化系统。作者用钢球作为被灌装产品，把输送带、容器到位检测、落料电机和计数传感器组合成一个重复执行的装填循环，并把“每包需要装多少个产品”交给操作员在 `HMI` 上配置。

论文的核心不是单纯展示 `HMI` 界面，而是解决“包装规格可变”这个控制问题。与只能固定装填数量的设备不同，这套系统把目标计数作为一个可修改的数据变量带入控制逻辑，因此容器到位、开始落料、传感器脉冲计数、达到设定值后停料再放行下一包，形成了一条很完整的 `EFSM` 主链。

## 控制系统在文中的位置

这里的包装控制器是全文主体。摘要、装置设计、工作过程、`I/O` 地址、时序图、梯形图和传感器测试都直接服务于这套灌装系统，没有偏向泛化的人机界面介绍或教学化原型展示。

从样本角度看，这篇论文的好处是把“变量化配方”写得很直接。`HMI` 设置值不是附带说明，而是决定何时停止落料、何时重新启动输送带的核心条件，因此这篇论文能提供的不只是简单顺序控制，还包含了一个很清楚的计数型 guard 变量。

## 对我们为什么有用

这篇论文对 `sources/` 的价值，在于它补进了制造/包装方向里一种比较典型的“可配置批量计数”控制案例。相比只依赖固定时间或固定位置切换的灌装短文，这里多了一个由操作员输入的目标计数，使得状态推进与内部变量更新关系更明确。

它也很适合后续做自然语言到模型元素的提取。按钮、光电传感器、电感接近传感器、输送带电机、落料电机以及 `00.00-00.03 / 100.00-100.01` 这些地址映射都写得比较直白，后续如果要核对输入输出、事件和 guard，这篇论文的可追溯性会比很多装置型文章更好。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `1` 页摘要和 `2. Device Design`，先确认控制对象、输入输出和 `HMI` 在文中的职责。之后直接读第 `2` 页 `2.1 Work Description` 和 `2.2/2.3/2.4`，把“设定计数值后按下 Start、输送带送入容器、光电传感器到位停带、落料电机启动、接近传感器脉冲累计、达到设定值后停料并再次放行”这条主线重新整理一遍。

如果后续需要补界面细节或验证计数变量怎样在 `HMI` 上呈现，再看第 `3-5` 页对传感器和界面的说明。第一次人工回读时，不必在包装背景和一般 `PLC/HMI` 介绍上停太久；最值得优先锁定的，是目标计数这个变量怎样驱动整条灌装循环的进入、保持和退出。
