# 新能源汽车起步状态机控制 / Research on Starting Control Method of New-Energy Vehicle Based on State Machine

## 论文在讲什么

这篇论文研究的是纯电或部分混动新能源汽车在低速起步阶段怎样兼顾驾驶意图、平顺性和坡道防溜坡的问题。作者把起步工况先按平路、缓坡和陡坡拆开，再把控制器写成一个显式状态机，核心输入包括挡位、坡度、制动踏板开度、加速踏板开度、车速和电机转速，核心输出则是不同起步阶段应当给出的电机扭矩。

论文不是停留在“用了状态机”这一句，而是把 `default / torque preload / anti-rollback / pedal control / PI creep` 五个状态、它们之间的切换条件，以及各状态对应的扭矩计算模块都画出来并逐条解释。除了状态机之外，正文也给了车辆和车轮模型、制动模型与若干公式，但这些低层模型主要是在支撑状态机里的 guard 与 torque law，而不是替代离散控制链本身。

## 控制系统在文中的位置

这里的状态机就是论文主角之一。作者明确把起步控制策略拆成 `enabling condition + state machine + torque calculation` 三部分，说明它是整套起步控制的骨架，而不是在某个局部顺手加一个流程图。五个状态分别承担零扭矩待机、短时预加载、防溜坡保持、制动踏板驱动的起步扭矩调节，以及无踏板 creeping 调速。

更重要的是，论文把转移条件写得比较工程化和可执行，例如 `brake > 95%`、`speed < 0.2 km/h`、`brake < 70%`、`speed < 3 km/h`、`brake = 0`、`speed < 9 km/h`，并把 `0.5 s` 预加载和 `8 km/h` 爬行目标也嵌入控制链里。这使它对 `sources/` 很有价值，因为后续要整理成自然语言状态机时，不需要靠图意猜测，很多 guard 和 mode intent 在正文里就能直接对齐出来。

## 对我们为什么有用

对 `project_1` 的样本库来说，这篇论文补的是“车辆低速起步 / 坡道保持 / creep 模式管理”这一类比较具体的车载离散控制对象。与库里已有的换道、编队、AEB 一类行为决策样本相比，这篇更贴近底层驱动与人车交互边界处的模式切换控制，差异位比较明显，不属于简单重复。

它的另一个价值是把“状态名 + 阈值 + 状态内扭矩 law”放在了一起。很多车辆控制论文虽然也谈 launch 或 hill-hold，但正文常常更偏连续控制性能；这篇则相反，五态切换链非常明确，因此可以直接作为 `EFSM + T1` 的工程型双 A 样本。后续如果做数据集清洗，优先可保留 `preload -> anti-rollback -> pedal -> PI creep` 这条主链，而把更长的动力学推导放到第二层。

## 如果需要人工细读，建议怎么读

如果后续要人工复核 `STM.md` 或二次抽样，建议先看摘要和 `2.4 Starting Control Strategy`，先锁定五个状态、状态图和逐条 conversion criteria；这一轮阅读的目标是确认状态集合、进入条件、退出条件、速度阈值和踏板阈值，不必一开始就陷入整套车辆动力学公式。

随后再看 `2.4.3 Torque Calculation` 和结果分析部分，重点核对 `0.5 N·m / 0.5 s` 的 preload、anti-rollback 的制动扭矩映射、pedal control 的无回溜起步逻辑，以及 PI creep 对 `8 km/h` 目标速度的保持效果。像前面的车辆/车轮数学模型、参数表和完整仿真平台配置，则更适合在第二轮需要追问某个 torque law 来源时再回去读。
