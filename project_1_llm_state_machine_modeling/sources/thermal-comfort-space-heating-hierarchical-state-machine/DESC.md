# 面向热舒适的分层空间采暖控制 / Thermal comfort driven space heating control via hierarchical state machine strategy interacting with multiphysics simulation

## 论文在讲什么

这篇论文研究的是储热式电暖器如何不再只盯着固定位置温度传感器，而是围绕 occupant 周围的温度体验来做空间采暖控制。作者用一个三维多物理场模型实时估计人员所在位置附近的温度，再把控制器写成三层层次状态机，用来在开关机、不同功率模式和快热/常规热状态之间切换。

这篇文章的价值不只是“有个 HSM 图”。它把 `Mode 1/2/3`、每个 mode 内的 `FH/NH`、舒适区 `22-23 C` 和实时闭环更新都写清楚了，因此不是泛泛的舒适控制概念稿，而是一条能直接转为 `HSM + T1` 样本的离散监督控制链。

## 控制系统在文中的位置

这里的控制系统就是论文主轴。多物理场模型、COMSOL-SIMULINK 联动平台和 PMV-PPD 模型都在服务于一件事：让状态机控制器能够根据 occupant 周围的热环境动态切换加热功率和放热方式。没有这套控制逻辑，论文就只是一个热场仿真研究。

状态机部分也写得比较完整。顶层先决定 `ON/OFF`，第二层再选 `1 kW / 2 kW / 3 kW` 三个模式，第三层在每个模式内决定 `fast heating` 还是 `normal heating`。再加上控制步长和舒适区阈值，这条链已经足够支撑较高质量的建模与验证语料。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是 `🌡️` 方向里一种很有代表性的“舒适驱动型采暖监督器”样本。它和文库中常见的液位、泵阀、灌装等过程控制不同，控制对象是建筑热环境与储热式电暖器，但离散骨架仍然非常明确，因此能显著拓宽过程与环境控制领域的样本类型。

它还有一个重要作用：把层次状态机和连续热场仿真明确耦合起来。这种“离散模式切换 + 连续物理反馈”的结构，对后续博士研究中的 LLM 建模、性质生成和验证剖面设计都很有参考价值。

## 如果需要人工细读，建议怎么读

如果后续要人工重写 `STM.md`，建议先读第 4-5 页中对 HSM 总体结构的说明，把 `ON/OFF`、`Mode 1/2/3`、`FH/NH` 和 `22-23 C` 这些最关键的状态骨架和阈值先锁定。随后再回看 co-simulation 平台部分，理解状态机是怎样拿到 occupant 温度反馈的。

至于更底层的多物理场建模、房间几何、网格和 PMV-PPD 推导，可以放到第二轮再看。它们对验证控制效果当然重要，但对第一轮离散状态机抽取来说，真正必须保住的是层次结构、状态名和触发阈值。
