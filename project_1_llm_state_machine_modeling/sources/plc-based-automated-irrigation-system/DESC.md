# 土壤湿度阈值分区灌溉控制 / PLC Based Automated Irrigation System

## 论文在讲什么

这篇论文围绕自动灌溉系统展开，核心对象是一套由 `SIEMENS LOGO 230 RC` 控制的多分区灌溉装置。系统用四路土壤湿度传感器作为输入，PLC 根据湿度阈值控制总阀、四个分区阀以及水泵，让不同区域在需要时自动获得供水。

它的重点不是复杂的水文模型，而是一个很直接的阈值控制器：文中明确给出湿度 `22` 作为开启阈值、`55` 作为关闭阈值，并把 `I1-I4` 到 `Q1-Q6` 的输入输出映射表列出来。随后又用五条规则说明每一路传感器触发时哪些阀门会被打开，这对状态机抽取非常友好。

## 控制系统在文中的位置

这里的控制系统就是论文主体，作者不是把灌溉逻辑当成一个附属实验。结果讨论部分把 PLC 程序如何控制总阀、分区阀和水泵写成了主叙述对象，输入输出表和五种触发情形都是为了说明实际控制流程怎样工作。

从 `sources/` 的角度看，这篇论文提供的是一种典型的“多输入 + 共享资源 + 分区输出”控制结构。虽然它没有复杂时钟约束，但它把共享主阀与局部分区阀的联动关系讲得很明确，因此依然是一个质量很高的 `EFSM + T0` 样本。

## 对我们为什么有用

这篇论文对文库的价值在于补了一类环境过程控制样本，而且不是只说“湿度低就浇水”。它保住了四路输入、一个共享主阀、四个区域阀和一个水泵之间的组合关系，能很好地支撑后续把自然语言控制描述转写成状态机。

后续若做数据集清洗，第一优先级应是保住“阈值判断、共享主阀、对应分区阀和全开场景”这四类事实。相比之下，控制器尺寸、供电模块和一般性的农业背景不属于这篇论文最值得抽的部分。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 5 页结果段，把 `22 / 55` 阈值、`I1-I4` 与 `Q1-Q6` 的映射先抄稳，因为这部分决定了状态变量、输入和输出集合。然后继续看第 6-7 页五条“sensor initiated”规则，把每种触发情形下总阀和分区阀的动作关系补齐。

如果还需要核系统边界，再回看前文对 PLC 与阀门部件的说明即可。第一次复核时不需要把综述性农业背景读得很细，关键是先保住控制器对阀门和水泵的动作条件，以及多区同时请求时如何扩展到全开状态。
