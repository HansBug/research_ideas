# 喷洒无人机混合供能能量管理状态机 / Energy Management Strategy Based on Fuzzy Logic and State Machine for Spraying UAV Hybrid Power System

## 论文在讲什么

这篇论文讨论的是农业喷洒无人机在长航时任务里如何协调燃料电池和电池供能。作者面对的核心问题不是机体姿态控制，而是喷洒飞行里典型的起飞、悬停、巡航和作业负载变化会让功率需求大幅波动，单靠电池会明显限制续航，因此需要一套高层 `EMS` 去决定什么时候由燃料电池独供、什么时候让电池补峰、什么时候趁负载合适给电池回充。

论文把这件事写成“状态机 + 模糊控制”的组合。状态机负责确定当前处于哪类供能工况，模糊控制则在高负载情况下给出电池功率的方向和幅值，因此系统整体既保留了清晰的离散模式链，也保留了和连续功率需求紧耦合的能量分配逻辑。

## 控制系统在文中的位置

这里的控制系统不是附带案例，而是全文真正的主角。摘要、引言和第 `4.3` 节都直接把贡献落在喷洒无人机混合供能 `EMS` 的设计上，后续仿真也是围绕这套 `EMS` 在不同飞行阶段如何切换供能来源来展开。

更具体地说，文中最值得保留的不是一般性的燃料电池或电池模型，而是四个离散状态本身。`State 1`、`State 2`、`State 3`、`State 4` 分别对应低于悬停功率、fuzzy 控制介入、回充补能和放电补峰等不同供能工况，这些状态与 `hovering` 阈值、功率缺口和 `replenish/discharge` 信号有直接映射关系，因此很适合转成状态机自然语言描述。

## 对我们为什么有用

这篇论文对 `sources/` 的价值主要在于它补进了一条 `✈️` 方向里较少见的“任务功率驱动的混合供能监督器”样本。库里已经有一些无人机任务管理、降落管理和故障模式管理条目，但把喷洒作业功率剖面直接写成四态供能链的样本并不多。

同时，它也属于那种很适合做“离散状态骨架 + 连续变量 guard”对照的材料。后续如果要研究 LLM 如何从自然语言恢复 `EFSM`，这篇能提供比较明确的状态名、进入条件和状态内动作；如果要进一步研究和连续变量耦合的 supervisor 写法，它又比只有模式名没有动作分工的能量管理论文更实用。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `1-2` 页的摘要和引言，只确认系统边界、供能构成以及作者为什么需要一套喷洒无人机 `EMS`。随后直接跳到第 `8` 页的 `4.3 State Machine`，把四个状态、各自进入时机和燃料电池/电池分工先完整抄出来；这是恢复 `STM.md` 主链最关键的部分。

在主链稳定之后，再回头看第 `4.2` 附近关于 fuzzy 规则和功率转换器的描述，以及第 `5` 节仿真结果。那些内容更适合拿来确认 `Pb` 的正负含义、回充与放电的控制意图，以及状态切换在典型喷洒任务曲线中怎样出现，而不是第一次阅读时就把所有连续控制细节一并展开。
