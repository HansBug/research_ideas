# 液位定时与三阶段洗涤顺序控制器 / PLC Based Washing Machine

## 论文在讲什么

这篇论文讲的是一个基于 PLC 的自动洗衣机顺序控制原型。作者要解决的问题并不复杂，就是把日常洗衣机最核心的几步离散过程固定成一条可执行的控制程序：用户启动设备、选择水位、进水到设定液位、在门锁闭合的条件下完成浸泡/洗涤、漂洗和脱水三个阶段，最后停机并触发告警。

原文最大的特点是把控制顺序写得非常直白。它没有绕到电机设计、结构优化或洗净度评价上，而是直接给出三阶段算法：第一阶段如何正反转交替运行多久、第二阶段如何重新进水并完成漂洗、第三阶段如何无水甩干以及何时鸣笛结束。对于一个想从自然语言恢复顺序控制状态机的人来说，这种写法比很多只给硬件框图的工程稿更有用。

## 控制系统在文中的位置

这里的洗衣机控制器就是文章主体。摘要、系统框图、算法、流程图和梯形图都在服务同一个对象，也就是这台 PLC 洗衣机的控制流程。即便文章同时包含硬件选型和原型实现照片，那些内容也只是为了支撑控制程序落地，而不是把洗衣机当成附带的演示平台。

这使它在 `sources/` 里很容易定位。我们不是因为它“用了 PLC”就收录，而是因为它确实把一个日常但完整的离散控制对象写成了明确的状态推进链。进水、门锁联锁、电机正反转序列、排水、漂洗、脱水、结束告警，这些环节都直接出现在正文里，因此它比许多只谈家电自动化概念的论文更适合沉淀为样本。

## 对我们为什么有用

对当前文库来说，这篇文章补的是 `🏭` 方向里很典型的一类 `EFSM + T1` 工程顺序控制样本。它的价值不在于系统复杂，而在于结构规整、定时条件充分，而且动作链闭环完整。现有工业控制样本里，有些更偏包装线、瓶装线或输送分拣，这篇洗衣机材料则提供了一个非常标准的“多阶段定时工艺控制”对象。

后续若要做状态机自动生成或验证场景生成，这类样本很适合作为基础训练材料。它有清晰的阶段边界，有水位定时与门锁 guard，也有重复交替动作和最终告警，既不是只有一个线性步骤表，也没有复杂到需要大量领域知识才能理解。对于构造 `start -> fill -> wash -> rinse -> spin -> alarm` 这一类工业顺序控制链，它是很好的原始来源。

## 如果需要人工细读，建议怎么读

如果后续要人工重读，建议先看第 `1-2` 页的 `Abstract`、`System Block Diagram`、`Algorithm` 和 `Flow Chart`。第一次阅读时重点只盯四件事：用户输入有哪些、门锁在主控制链中的联锁作用是什么、三个阶段各自的主要动作顺序是什么、每个阶段涉及哪些定时值。把这几件事读清楚，就已经足够恢复出可靠的 STM 主链。

后面的梯形图页、硬件实物图和元件说明可以第二轮再看，用来核对控制程序与执行部件之间的映射是否一致。它们有助于理解实现细节，但不是重建状态机的第一信息源。若后续发现 `STM.md` 还要补充更细的 guard 或 timer，优先仍应回到算法与流程图对应的正文段落，而不是从硬件介绍部分倒推控制语义。
