# 半自动闸门水位监督控制 / Rancang Bangun Sistem Kendali Semi Otomatis Pintu Air Bendungan dengan Mini Hoist PA200 Berbasis PLC Omron CP1E-E20SDR-A

## 论文在讲什么

这篇论文讨论的是一个值守型水闸门控制系统，目标不是做完全无人自动化，而是用 PLC、float switch、tower light 和 mini hoist 把“人工值守开关门”这件事变得有层级、有告警、有边界保护。系统会根据水位从低到高切换不同告警等级，并在高水位时提示操作员执行开门动作。

它的设计很有工程感。作者没有只停在“达到某个阈值就开闸”的简单表述，而是把三级水位、颜色信号、蜂鸣器、上下限位、自动按钮、手动按钮和 emergency switch 串成一条完整的控制链，因此这篇论文更像一个监督控制器而不是纯传感器报警器。

## 控制系统在文中的位置

我们关心的控制系统是这篇论文的核心对象。引言就说明 level 1、level 2、level 3 各自的意义，第 8-9 页的流程图继续把“告警 -> 操作员确认 -> 开门 -> 水位回落 -> 关门”的顺序写全，第 12-14 页的黑盒测试则把每一步是否真的被执行又核了一遍。

对 `sources/` 而言，这篇论文的特别之处在于它保留了“人仍在环”的控制结构。也就是说，水位状态是自动感知和自动显示的，但真正的 `AUTO UP / AUTO DOWN` 仍然是经过值守人员确认才执行，这比全自动开关型水位控制更适合补半自动监督控制样本。

## 对我们为什么有用

`🌡️` 方向里，很多样本都集中在水箱、泵和阀门启停，而这篇论文补的是另一类对象：闸门式水工设施。它同样是离散控制，但状态语义不再只是“高于阈值就开、低于阈值就关”，而是“三级水位监督 + 人工确认 + 上下限位保护 + 手动维护旁路”。

这让它对 project 1 很有价值，因为它提供了一种更接近真实运维流程的状态机描述。后续如果要让模型理解“自动感知、人工触发、设备执行、限位停机、维护旁路”这类链条，这篇论文就是很合适的训练素材。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看引言和摘要，把三档水位、对应颜色和 buzzer 的意义先理清。然后直接跳到第 8-9 页的流程图，把 `Emergency Switch`、`AUTO UP`、`AUTO DOWN`、上下限位和 `Manual Up / Manual Down` 在整条顺控链中的位置摘出来。

之后再看第 12-14 页的黑盒测试，把 level 1 到 level 3 的上升过程、开门后回落到 level 2 和 level 1 的过程、以及手动分支逐条核对。电气图和元件说明适合作为第二轮补证材料，不是首轮抽取状态机主链的重点。
