# 自动门开闭定时与方向联锁 / Automatic Door Control Using PLC

## 论文在讲什么

这篇论文讨论的是一套面向楼宇入口的 PLC 自动门系统。作者把对象定义得比较直接：入口侧的 IR 或接近传感器负责检测来人，PLC 读取检测信号后驱动电机和继电器开门，门体到达全开位后保持一段预设时间，再按条件反转关门，最后由闭位限位开关把动作停住。

虽然篇幅不长，但它不是只罗列“自动门可以提高便利性”这类概述。文中至少把输入端、控制端和输出端拆开讲了：传感器属于输入，PLC 属于控制核心，电机、继电器、限位开关和机械门体属于输出执行链；随后又补上了开门、保持、关门和互锁保护的运行结果。

## 控制系统在文中的位置

这里的控制系统描述是论文主体，而不是随手附带的应用案例。摘要和引言已经把问题定义成“基于 PLC 的自动门开闭系统”，方法部分继续围绕传感输入、梯形图逻辑、限位开关和电机控制展开，结果部分则直接验证了开门、保持、关门和互锁是否按预期运行。

对 `sources/` 来说，这类文章的价值不在于复杂算法，而在于它把一个常见机电控制对象的主链压得很清楚：门的开闭不是连续优化问题，而是典型的事件触发加局部定时顺序控制。这种材料很适合保留成 `EFSM + T1` 的短而完整样本。

## 对我们为什么有用

这篇论文补的是 `🏢` 楼宇机电方向里较轻量但完整的一类门控样本。它同时保住了人到来时的触发条件、门到全开位后的保持时间、关门条件、闭位停机以及正反转互锁，所以不是只有“检测到人就开门”的薄链。

后续如果要把它放进状态机数据集，重点应放在 `closed / opening / hold-open / closing` 这条控制骨架，以及触发这些状态切换的传感输入、定时器和限位开关。相比之下，PLC 选型说明、红外传感器工作原理和泛化应用背景只需要作为辅助上下文即可。

## 如果需要人工细读，建议怎么读

人工回看时，建议先读第 1 页引言里关于“检测来人 -> PLC 开门 -> 预设延时 -> 自动关门 -> 互锁保护”的连续叙述，再跳到第 2 页方法部分的输入/控制/输出三段结构，确认传感器、PLC、电机、继电器和限位开关各自扮演什么角色。

之后直接看第 3 页结果段，把“开到全开位、启动定时器、反转关门、闭位限位停机、互锁防止双向同时动作”这条链重新核一遍。若只想重做 `STM.md`，优势最大的就是这两个位置；至于红外传感器工作原理和自动门应用场景，可以放到第二轮再看。
