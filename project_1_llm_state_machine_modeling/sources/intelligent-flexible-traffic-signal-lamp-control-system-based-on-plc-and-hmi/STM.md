### 2. 基于原文整理后的自然语言描述

The traffic controller runs a fixed phase order at the intersection: each cycle begins with north-south straight traffic and then turns to the corresponding left-turn phase before moving to the opposite direction and repeating. The PLC supports both manual and automatic operation, and in manual mode the operator can directly connect any signal-light group in response to special or emergency situations. Automatic control is divided into day and night modes: during daytime the controller compares the stranded-vehicle difference between the current direction and the opposite direction, extends the current straight or left-turn green by `T1` when the difference exceeds `δ`, shortens it by `T2` when the difference is below `-δ`, and immediately skips to the next phase when the current movement has no waiting vehicles. At night all external sensors are disabled and every direction flashes yellow to warn vehicles and save energy. Two ground induction coils per lane provide inlet/outlet counts for real-time stranded-vehicle estimation, while DB blocks and the HMI store vehicle counts, green times, and other control parameters so the operator can retune the scheme without rewriting the PLC logic.
