Abstract : This project presents the design and implementation of an efficient car parking system using Verilog for 
FPGA -based applications. The existing method addresses only a single car parking system. It does not address the issue of a 
multi parking slots. To overcome this problem, the proposed system is developed to streamline parking management by 
automating vehicle detection, and availability monitoring in real -time. Util izing finite state machines (FSMs) and modular 
design principles, the system ensures robust operation, scalability, and adaptability to varying parking lot sizes and 
configurations. This implementation is particularly suited for FPGA -based platforms, makin g it a viable choice for deployment 
in smart cities and intelligent infrastructure systems.  
 
The Verilog -based design is simulated and validated using the ISim Simulator, demonstrating accurate performance 
under different operational scenarios, including p eak and off -peak hours. The results highlight the system's capability to reduce 
human intervention, improve parking efficiency, and provide a cost -effective solution for modern automated parking 
requirements. This implementation is particularly suited for FPGA -based platforms, making it a viable choice for deployment in 
smart cities and intelligent infrastructure  systems.

I. INTRODUCTION  
 
 In rapidly developing countries like India, the rapid increase in population and vehicles has created significant parking and  
traffic challenges. The lack of sufficient parking spaces often forces drivers to park on roads, leading to congestion, slow traffic 
movement, and increased emissions from vehicles searching for parking. This not only wastes time but also harms the 
environment with CO2 and other harmful gases. To address these issues, advanced parking systems, like automated and smart 
parking solutio ns, can efficiently use land, reduce congestion, and minimize environmental impact by providing real -time 
information about available parking spaces. These systems use sensors to monitor occupancy and guide drivers to vacant spots,  
improving parking effici ency in crowded areas like hospitals, shopping centers, airports, and universities.  
 
 The implementation of a smart parking system using sensors and Web APIs offers a cost -effective solution to the growing 
parking problem. This system automatically tracks parking space availability, generates parking tokens, and records vehicle 
check -in times, which helps reduce the time spent searching for a space. Developed using technologies like Laravel, the web -
based application manages data related to vehicles, ensuri ng better monitoring and management of parking lots. By automating 
parking management and eliminating the need for manual supervision, this system not only saves time but also reduces the risk  
of theft and vandalism, offering a more efficient and eco -frien dly solution to urban parking  challenges.

III. EXISTING  METHOD  
 
Various methods have been explored for designing FPGA -based car parking systems using Verilog. One of the most 
common approaches is the *counter -based system*, which uses up/down counters and finite state machines (FSMs) to track the 
number of cars entering and leaving a parking area. This method is relatively simple and efficient for small parking faciliti es, 
using Verilog logic blocks to manage vehicle flow. Ho wever, it lacks detailed tracking of individual slot occupancy and doesn't 
scale well for larger or more dynamic environments.  
 
Another widely adopted method involves *sensor -integrated systems*, where infrared or ultrasonic sensors are placed in 
each park ing slot. These sensors send signals to the FPGA, which is programmed in Verilog to determine slot occupancy. 
Outputs are typically shown through LEDs or seven -segment displays. While this provides real -time status of each slot, the 
design complexity incre ases as the number of slots grows, especially due to the wiring and input/output pin limitations of 
FPGAs.  
 
Advanced systems include *FPGA interfacing with LCDs or LED matrices* for displaying parking information to users. 
Some implementations incorporate keypads or RFID -based vehicle identification for secure access and monitoring. In these 
systems, Verilog code handles both the logical operations and the interface control, providing a more interactive and user -
friendly experience. Although useful in publi c spaces like malls or hospitals, these systems may require more FPGA resources 
and optimized design to manage multiple peripherals effectively.  
 
More intelligent parking designs also leverage *priority -based allocation and wireless communication modules* like ZigBee 
or RF, integrated with the FPGA. These systems enable features such as reserving parking for specific vehicle types or remote ly 
accessing slot status. Verilog is used to implement encoding/decoding logic and decision -making algorithms. While th ese 
systems are more scalable and suited for smart cities, they introduce challenges in terms of real -time reliability, design 
complexity, and hardware  integration.

 The proposed methodology for designing and implementing an efficient car parking system using Verilog for FPGA -based 
applications is based on a structured, modular approach aimed at providing real -time monitoring and control of parking spaces. 
The system is conceptualized to automate the process of checking parking slot availability, controlling vehicle access, and 
displ aying real -time status updates. The architecture includes distinct modules for entry and exit control, slot monitoring, and 
visual output through LEDs or 7 -segment displays. These modules work together under the supervision of a central control 
logic desig ned using Finite State Machines (FSM), which ensures efficient operation and transition between system states.  
 
 The core of the system is the FSM -based controller, which governs the sequence of operations such as detecting vehicle 
presence, checking slot  availability, opening or closing the gate, and updating the slot counter. Each parking slot is simulated 
using sensor inputs (e.g., binary switches), and slot occupancy is tracked using registers and counters within the Verilog co de. 
The FSM transitions b etween various states like IDLE, CHECK_SLOT, ENTRY_GRANTED, ENTRY_DENIED, and 
UPDATE_DISPLAY, ensuring the system responds accurately to real -time events. This approach simplifies the complexity of 
control flow and enhances the maintainability of the syste m. 
 
 In the implementation phase, the design is written in Verilog HDL and tested using simulation tools like ModelSim or 
Xilinx Vivado. Each module is simulated with a set of test vectors representing various input scenarios, such as vehicle entr y, 
exit, and full occupancy. Once the individual modules pass functional verification, they are integrated and synthesized into a 
top-level design. The design is then deployed onto an FPGA board, where real hardware components such as buttons, switches, 
and display s are used to emulate sensors and system feedback, providing a tangible representation of the system’s behavior.  
 
 This FPGA -based approach offers several benefits including real -time performance, parallel processing capability, and 
reconfigurability. It a llows for high -speed execution of control logic and can be easily adapted to larger or more complex 
parking systems with minimal changes. Moreover, the low power consumption and cost -efficiency of FPGA platforms make 
this solution practical for integration  into smart city infrastructure. Future improvements could include the integration of 
advanced features such as license plate recognition, IoT connectivity, and mobile app interfaces for remote monitoring and 
reservation.

promptly and reliably under various parking scenarios.

applications.

V. CONCLUSION

caters to a wide range of issues. Device utilization was found to be much lower in comparison to the existing models. It is a safe
