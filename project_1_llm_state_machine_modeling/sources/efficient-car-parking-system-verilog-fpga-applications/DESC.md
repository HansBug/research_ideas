# 多车位认证式停车门禁控制 / Design and Implementation of an Efficient Car Parking System Using Verilog for FPGA-Based Applications

## 论文在讲什么

这篇论文围绕一个基于 Verilog 和 FPGA 的停车场控制器展开，关注的不是视觉识别或纯车位预测，而是入口/出口放行与车位状态更新这条离散控制链。作者把系统拆成入口控制、出口控制、车位监测和显示输出几个模块，再由中心 FSM 统一调度。

从 `sources/` 的视角看，它的核心价值在于论文没有停留在“有一个 smart parking 平台”的泛描述，而是把 `IR1 / IR2` 传感器、密码校验、开闸继电器、车位检查和显示更新写成了可追溯的状态序列。这使它更像一个真正的停车门禁控制器样本，而不是单纯的板级演示。

## 控制系统在文中的位置

我们关心的控制系统描述是这篇论文的主体。摘要直接把 `finite state machines (FSMs)`、自动化车检和车位监测列为主要方案，`Proposed Methodology` 里又继续展开入口检测、等待密码、密码匹配、入口/出口放行以及车位显示更新。

更具体地说，文中停车控制器承担的是“把车辆到达和车位状态转换成具体放行行为”的角色。它既不是验证用 toy model，也不是为了讲 Web API 或传感器平台才顺带提到状态机；状态机本身就是系统组织方式。

## 对我们为什么有用

这篇论文对 `sources/` 的直接价值，是补充了 `🅿️` 方向里一类比较稳定的“认证门禁 + 车位状态”样本。当前库里虽然已有若干停车控制案例，但不少样本更偏机械车位或 RFID 分配；这篇则把密码认证、入口/出口双传感器和车位检查放在同一条主链上，和现有样本形成互补。

后续做数据集时，最值得保留的是它对控制对象、触发条件和主状态名的明确交代：`IDLE`、等待密码、`CHECK_SLOT`、放行/拒绝和显示更新。图像化实验结果可以辅助理解，但真正有数据价值的是这些能直接转成自然语言状态机描述的控制句子。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1 页摘要和第 2-3 页 `Proposed Methodology`。第一轮先把 `IR1 / IR2` 的作用、密码等待逻辑、`3 nsec` 局部等待、状态名集合和车位检查链读稳，这些信息足以重构主控制器的骨架。

随后再看第 3-5 页的实现与结果部分，重点核对入口、出口和显示模块是如何在同一 FSM 下协同工作的。图中的仿真截图和硬件波形可以留到第二轮再看，因为它们更适合做一致性核对，而不是第一轮抽取 `STM.md` 时的主证据来源。
