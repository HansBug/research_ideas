# 倒计时交通灯与行人延时控制 / Traffic Light Controller Displaying Countdown using 7-segment Display

## 论文在讲什么

这篇论文讨论的是一个带倒计时显示的交通灯控制器，作者用 Verilog 和状态机把东西向、南北向两组信号灯以及 7 段数码管计时显示组织成一个完整系统。论文的直接动机是让路口使用者知道还要等待多久，因此与很多只做固定相位切换的简化交通灯稿相比，它额外保留了倒计时显示和行人过街延时这两块比较有辨识度的控制语义。

正文最核心的是状态推进链。作者明确说明系统从 `S0` 开始，在东西向绿灯持续 `7` 秒后转入黄色，再进入一个两方向全停的 `2` 秒窗口，用来给斑马线行人通行；随后系统切换到南北向并继续沿 `S3-S5` 推进。数码管的显示值由同一个计数器生成，这使状态、时间和输出之间的关系比较清楚。

## 控制系统在文中的位置

这里的控制系统就是论文的主体。虽然文中也解释了一些 Verilog、Xilinx 和交通灯背景，但这些内容都只是实现前置说明，真正被设计和验证的对象一直都是同一个交通灯控制器。状态图、输出编码、倒计时任务和实验波形都指向这一条主控制链，而不是某个更大系统里的一个小功能块。

从文库角度看，这篇论文的重要性在于它提供了一个很“干净”的交通信号控制样本。它没有过多依赖复杂交通感知、优先级通信或外部调度，而是把相位顺序、秒级定时和行人延时直接写成状态机，因此非常适合作为 `🚦` 方向的基础 T1 样本。

## 对我们为什么有用

这篇论文对 `🚦` 方向的直接价值，是补进一条结构非常标准的 `FSM + T1` 倒计时交通灯样本。现有交通灯条目里，已经有不少带密度感知、紧急车辆优先或更复杂模式切换的样本，而这篇更适合作为“定时相位 + 显式倒计时 + 行人全停窗口”的基准模板，便于后续和更复杂的交通控制器做对照。

它也让交通灯方向的输出语义更丰富一些。这里不仅有红黄绿灯状态，还有数码管倒计时和行人延时窗口，后续如果要做状态机自然语言生成或对比不同时间语义强度的样本，这篇比只给灯色轮转的短稿更有用。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看摘要和 `Road structure / State machine and state table`，把两条道路、两组信号灯、斑马线 `2` 秒窗口，以及 `S0-S5` 的相位推进顺序先确定下来。尤其要先抄出 `S0` 的 `7` 秒绿灯和之后的 `2` 秒全停窗口，因为这两类时间语义是这篇论文最关键的建模依据。

然后再读 `Logic Synthesis` 和实验波形，只做两件事：确认 `A[2:0]`、`B[2:0]` 确实对应灯色输出，确认同一个计数值也被送到了 7 段显示。Verilog/Xilinx 的一般介绍和更泛的交通背景可以放到第二轮再看；第一次人工复核只要把状态顺序、秒级计时、倒计时显示和重置行为读稳，就足以重做这篇样本。
