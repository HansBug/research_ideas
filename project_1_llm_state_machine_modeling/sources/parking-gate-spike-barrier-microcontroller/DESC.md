# 停车闸门与尖刺防闯控制 / Implementasi Sistem Kontrol pada Gerbang Parkir dan Spike Barrier Menggunakan Mikrokontroler

## 论文在讲什么

这篇论文讨论的是一个停车闸门原型，但它的重点不只是“车辆来了自动开门”，还额外加上了 `spike barrier` 安全装置。正常情况下，车辆经过前后传感器触发闸门开关；异常情况下，如果车辆强行冲撞处于关闭状态的闸门，尖刺障碍会自动抬起。

因此，这篇论文的系统对象比一般停车门禁稿更完整。它同时覆盖了 nominal passage 和 abnormal breakthrough 两条链，而且都落在同一套微控制器、继电器、限位开关和电机控制逻辑里。

## 控制系统在文中的位置

控制系统是论文中心，不是附属模块。第 3-5 页集中说明了系统流程、`flowchart`、前后传感器、限位开关位置以及 `spike barrier` 的触发和恢复方式，控制器如何决定开门、何时关门、何时进入异常安全支路都说得比较明确。

对 `sources/` 来说，这篇的意义在于它补了一条带显式异常恢复链的停车样本。很多停车论文只保留“有卡开闸”或“有空位显示”，而这里把“强闯 -> barrier 激活 -> 人工复位”这条更像工程安全控制的分支也保住了。

## 对我们为什么有用

这篇论文对数据集建设有两个直接价值。第一，它是一条比较完整的停车出入口控制器样本，具备传感触发、门控执行和位置反馈。第二，它把安全装置作为控制链正式分支写了进去，而不是只是附带一句“系统更安全”。

这意味着后续做状态机抽取时，可以不只收“前传感器开门、后传感器关门”这一条主链，还能把“非法突破 -> barrier 激活 -> 手动恢复”当成同一控制器里的异常状态迁移。这样的样本比普通停车门禁更有区分度。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 3 页 `Alur Kerja Sistem`，把前传感器、后传感器和开关门主链先钉住。然后立刻跳到第 4 页 `Flowchart Gerbang dan Spike Barrier`，这里是异常分支最清楚的地方，能直接确认 `kendaraan menabrak gerbang -> barrier aktif -> manual push button reset` 这条链。

第 5 页关于 `limit switch` 的说明则适合第二步细读，用来补齐闸门在 `A1/A2/A3`、`B1/B2/B3` 各位置上的状态语义。硬件尺寸、机械结构和功耗测试可以后看，它们对重建状态机帮助不大，不需要第一次阅读就深究。
