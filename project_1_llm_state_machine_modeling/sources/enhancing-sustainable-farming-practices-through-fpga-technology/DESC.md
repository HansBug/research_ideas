# 过程与环境控制 / Enhancing Sustainable Farming Practices through FPGA Technology

## 论文在讲什么

这篇论文讨论的是基于 FPGA 的智能灌溉控制系统，重点放在土壤湿度监测与水泵启停控制。文章虽然会先从可持续农业、实时处理和 FPGA 优势讲起，但真正落到控制层时，核心对象非常明确，就是 `soil_moisture_monitor` 模块：它持续读取湿度传感器数据，并根据土壤干湿状态决定是否开启灌溉泵。

它最有价值的地方，是作者没有只写“根据湿度自动灌溉”，而是把双阈值和双状态 FSM 明确展开。`DRY_THRESHOLD` 和 `WET_THRESHOLD` 给出了 guard，`DRY` 与 `WET` 给出了状态边界，复位后的默认状态、时钟沿更新和 RTL 结构也都交代出来了。这使它成为一个很完整的环境控制离散样本。

## 控制系统在文中的位置

我们关心的控制系统描述是论文核心实现的一部分，而不是背景里的附带例子。第 4.2 节专门围绕 `soil_moisture_monitor` 模块介绍输入输出、阈值、FSM 和状态转移逻辑，后面的结果章节又进一步给出 RTL 与仿真结果，因此控制器本身在全文中拥有清楚、稳定的边界。

对于 `sources/` 来说，这意味着这篇论文不是一般性的“农业物联网平台”材料。它真正提供的是一个可独立识别的控制子系统：输入是 `moisture_level`，输出是 `water_pump`，状态是 `DRY/WET`，guard 是两个阈值，复位与时钟更新规则也明确。这种材料非常适合转成 `EFSM + T0` 风格的自然语言样本。

## 对我们为什么有用

这篇论文对 `sources/` 的价值，在于它补的是 `🌡️` 领域中双 A 数量相对偏少的一类农业环境控制样本，而且和已有的 PLC 水箱、头水箱阀门或灌溉时序样本相比，它突出的是“湿度阈值驱动的双状态 supervisory FSM”。这有助于平衡当前过程与环境控制方向的对象分布。

另外，它的文本非常适合做最小而完整的状态机样本。状态数虽然只有两个，但输入、输出、guard、复位和 RTL 对应关系都很清楚。后续若要构造轻量级建模样本，这类“状态少但证据链完整”的材料通常比篇幅很长但控制链分散的论文更稳定。

## 如果需要人工细读，建议怎么读

如果后续需要人工细读，建议直接从第 4-7 页的 `4.2 Soil Moisture Monitoring` 和 `5.1 Irrigation Control System` 开始。先把输入输出和双阈值读清，再顺着 `DRY -> WET -> DRY` 的状态转移逻辑去看 Figure 3、RTL comparators、MUX 和 `state_reg` 的说明；这几段连起来基本就能恢复完整控制链。

农业背景、FPGA 通用优势和前面一些 LED/PWM 展示模块可以放到第二轮再看。第一次回原文时，更该优先固定的是 `DRY_THRESHOLD / WET_THRESHOLD` 的 guard、`water_pump` 的输出语义、复位默认值和时钟更新方式，因为这些才是后续建模和重写 `STM` 时最需要保住的控制事实。
