# 城市自动驾驶 NMPC 模式监督 / Deterministic Operating Strategy for Multi-objective NMPC for Safe Autonomous Driving in Urban Traffic

## 论文在讲什么

这篇论文讨论的是城市交通场景下的自动驾驶 `NMPC` 运行策略。作者不是只研究一条轨迹优化公式，而是试图给出一个确定性的 operating strategy，让车辆在停车区驶出、道路跟驰、慢速跟停、完全静止、入停车区和任务结束之间，用一套有限状态机来切换不同的优化目标和约束。

全文的关键点在于，作者把模式管理写成了非常明确的 `XP / PF / PU / SS / NP / ND` 六状态机，并为 `t1-t7` 每个转移都给出了条件。像停车区出口阈值、接近终点阈值、慢车跟随触发、`v <= 0.5 m/s` 的 standstill 进入条件，以及 `srel >= sSF + sSF;h` 的恢复条件，都直接进入了监督逻辑，因此这不是泛泛的自动驾驶框架文，而是一个很具体的模式切换控制器。

## 控制系统在文中的位置

这里的 FSM 是整篇方法的离散骨架。虽然论文标题里有 `NMPC`，但作者非常明确地用 FSM 去决定当前采用哪一类 driving sequence，以及应该怎样调节目标函数权重、曲率限制、速度限制和安全约束。换句话说，连续优化器负责求控制量，FSM 决定“此刻该解哪一种问题”。

这种写法对 `sources/` 很有价值，因为它把自动驾驶中的高层 mode supervisor 写得足够可追溯：状态、优先级、guard、与连续优化的耦合关系都清楚存在。相较于许多只写“behavior planner”但不给具体转移条件的自动驾驶论文，这篇更适合直接转成状态机自然语言数据。

## 对我们为什么有用

对文库平衡来说，它补的是 `🚗` 方向里很需要的一类“城市自动驾驶 mode supervisor”样本，而且不是纯层次架构介绍，也不是只有简单 `cruise/stop` 两态切换。这里的状态集合同时覆盖停车区进出、低速跟停、交通灯/前车建模、完全静止缓冲和终点停车，层次比一般驾驶样本更细。

它的另一个价值，是把离散监督器和连续优化器之间的接口写得比较清楚。后续做数据集时，不仅可以保留 `EFSM + T0` 的状态链本身，还可以把它作为“离散模式决定优化问题配置”的代表样本，用来补充自动驾驶文献里常见但不易抽稳的 mode-selection 语义。

## 如果需要人工细读，建议怎么读

如果需要人工重读，建议直接从第 `6-8` 页的 `Figure 8`、`Table 1` 以及 `Exit Parking / Path Following / Pulling Up / Standstill / Enter Parking` 这些子节读起，先把 `6` 个状态和 `t1-t7` 条件完整抽出来。读状态时要特别注意优先级关系，例如 `PF` 里 `t2` 高于 `t3`，以及 `PU` 里 `t4` 高于 `t5`，这是后续重建监督器逻辑的关键。

像前面关于道路建模、代价函数和 `NMPC` 数学形式的推导，可以放到第二轮再看。第一次人工复核时，优先把“每个状态控制什么、在什么 guard 下切换、切换后连续优化器会被怎样改写”这条主链读清楚，比先深挖公式更有效。
