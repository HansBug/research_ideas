# 四向相位轮转与拥堵加时控制 / VHDL Based FPGA Implemented Advanced Traffic Light Controller System

## 论文在讲什么

这篇论文讨论用 VHDL 在 FPGA 上实现一个高级交通灯控制器，核心是四向路口的相位轮转、行人信号和基于传感器/计数器的拥堵加时。当前 `STM.md` 抽到的核心对象是“道路交通信号领域的 FPGA/VHDL 四向路口交通灯控制器”。

从现有条目看，文中的离散控制链属于 `FSM（有限状态机）`，时间语义属于 `T1（工程定时 / 局部定时）`。原文有 `TLC state diagram`，并明确解释 `cnt`、`dir`、reset、四个方向的绿灯/黄灯/行人相位，以及传感器如何调整状态间延时，因此原文细节和描述细节都可评为 `🟢 A`。

## 控制系统在文中的位置

控制系统描述集中在第 2-4 页的道路结构、拥堵/分流方案、状态图和硬件实现。论文虽然也讨论 TCC、GPS、SCADA 等外部概念，但真正可进入数据集的是 `cnt/dir` 相位状态机和传感器改变绿灯时长的那部分。

## 对我们为什么有用

该样本补进了一个非 PLC 的交通灯 FSM 表达方式。它把四个方向抽成 `dir`，把绿灯/黄灯/行人相位抽成 `cnt`，再用拥堵传感器调整状态延时，适合训练模型识别硬件描述语言论文里的状态变量和时序语义。

## 如果需要人工细读，建议怎么读

人工细读时先看第 2 页道路结构，理解 `SW1-SW4` 和 `L1-L8`；再重点读第 3 页 `State Diagram` 段，把 `cnt` 与 `dir` 的相位轮转抄清楚；最后看第 4 页硬件实现，确认传感器和计数器如何影响绿灯持续时间。外部交通控制中心与车辆分流内容可作为背景，不应替代状态图主链。
