# 过程与环境控制 / Design and Simulation of an Ozone Catalytic Oxidation System Based on Programmable Logic Controller

## 论文在讲什么

这篇论文面向工业废水的臭氧催化氧化处理系统，目标是把传统臭氧催化氧化中“自动化程度低、控制复杂”的问题收束到一套 `PLC + Kingview` 的上下位机方案里。作者先说明系统由沉降单元、臭氧发生单元、反应系统和尾气破坏单元构成，再把重点转到 `pH` 控制，说明为什么反应需要维持在偏碱性的 `pH ≈ 9`，以及怎样用三段非线性 `PID` 来调节过氧化氢泵的开度。

论文并不只是在讲一个连续控制器，而是把整个处理过程拆成带有模式和阶段的运行程序。它明确写出了手动首轮运行、自动运行、二次运行和停机请求四类分支，还给出进液、加药、臭氧反应、循环和排液的顺序与时间长度，所以我们看到的是“过程监督控制 + 局部连续调节”叠加在一起的系统。

## 控制系统在文中的位置

这里的控制系统是论文的主角，而不是附带示例。无论是硬件配置、信号链设计，还是主程序与 PID 子程序的说明，都是围绕这套废水处理控制器展开的，控制逻辑本身承担了整篇论文的核心叙述任务。

对 `sources/` 来说，最有价值的是它把离散阶段和连续调节连接得很清楚。很多过程控制论文要么只讲阀泵顺序，要么只讲 `PID` 或模糊控制，而这篇文章同时写出了 `manual / automatic / secondary / stop` 状态分支和 `pH` 闭环调节链，因此可以稳定落到 `EFSM + T1 + 连续耦合` 的样本类型。

## 对我们为什么有用

这篇论文的重要性在于，它补了 `🌡️` 方向里比较稀缺的一种结构画像：不是单纯液位阈值启停，也不是只有连续调节的化工控制，而是“带定时阶段的监督流程 + 连续变量闭环调节”的复合控制器。后续如果要训练 `NL -> 状态机`，它能提供模式切换、执行器联动、定时阶段和局部 PID 回路共存的自然语言样本。

它也有很强的可追溯性。原文直接给出 `15 min` 进液与同步阶段、`1 h` 反应阶段、`30 min` 自动模式保护阶段，以及 `I0.0` 在手动/自动间切换 PID 的方式，这些都能被明确映射回控制状态、guard 和动作，而不是只能靠图示猜测。

## 如果需要人工细读，建议怎么读

建议先看第 `3.1` 到 `3.3` 节，先把系统边界、`pH ≈ 9` 的控制目标，以及从传感器到过氧化氢泵的反馈链看清楚。接着直接跳到第 `3.6` 和 `3.7` 节，把主程序里的手动、自动、二次运行、停机分支，以及 PID 子程序中的模式切换条件和变量流读出来，这样就能把 `STM` 的主链完整重建出来。

至于前面的工艺背景、文献综述和更一般的 OCO 反应影响因素，可以放到第二轮再看。第一次人工复核时，真正需要优先确认的是：哪些设备构成了离散运行阶段、哪些条件触发模式切换、定时器在什么位置启动、`pH` 信号如何经过 PLC 最终作用到过氧化氢泵。
