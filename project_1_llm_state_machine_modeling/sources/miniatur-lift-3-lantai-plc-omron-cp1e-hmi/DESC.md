# 三层电梯微缩样机的呼梯与门控逻辑 / RANCANG BANGUN MINIATUR LIFT 3 LANTAI MENGGUNAKAN PLC OMRON CP1E DENGAN HMI

## 论文在讲什么

这篇本科毕业设计围绕一个三层电梯微缩样机展开，目标是用 `Omron CP1E` 系列 PLC、若干 `push button`、`limit switch`、步进电机和直流电机做出可运行的呼梯与门控控制系统。作者不是停留在硬件搭建，而是把样机的工作流程、楼层呼叫、到站门控和误操作保护都写进了正文。

论文的系统对象非常清楚：外部每层有上/下呼梯按钮，轿厢内有楼层选择与开关门按钮，每层和上下边界有位置/安全限位，门在到站后按定时器自动开闭。这样一来，它不仅是一个实验样机说明，也是一篇完整的离散控制链记录。

## 控制系统在文中的位置

控制系统就是全文主角。作者先在 `3.1.1 Pengoperasian Miniatur Lift` 里解释正常运行和故障边界，再用多页 `flow chart` 分开描述每层外呼、轿厢内选层和门控过程，之后又在输入输出表中把按钮、限位和各电机映射到 PLC 地址。

更重要的是，文末的场景分析没有只说“系统能运行”，而是把两个乘客连续呼梯、到站开门、再次选层、以及运行中误按开门键无效的过程写成了完整叙述。这让它对 `sources/` 来说不是普通课程报告，而是高质量楼宇电梯控制样本。

## 对我们为什么有用

这篇材料对样本库很有价值，因为它同时保住了三层电梯最关键的六类信息：控制对象、楼层状态、触发按钮、位置限位、门控动作和运行中禁开门保护。很多短稿只会给出“电梯上下行”或“门障碍检测”中的局部片段，这篇则把一条完整服务链写了出来。

另外，它虽然是学位论文来源，但正文完整度并不输很多短篇期刊稿。尤其是 `flow chart`、I/O 映射和情景分析三部分叠在一起后，已经足以支持一个可简单仿真的 `EFSM + T1` 电梯控制条目，而不需要大幅依赖外部脑补。

## 如果需要人工细读，建议怎么读

人工回原文时，先看 `3.1.1 Pengoperasian Miniatur Lift`，把样机在正常、误操作和故障情形下的总体边界读清楚；然后直接读 `3.2 Flow chart` 里的各层外呼和轿厢内选层流程，抓住“呼梯 -> 到站 -> 门开 -> 门关 -> 等待下一命令”的主链。

第二轮再看 `Tabel 4.1 / 4.2` 和 `4.4 Analisa Sistem`。前者用来确认 PLC 输入输出与安全限位的具体角色，后者用来核实两个乘客场景、同层直接开门和运行中禁开门保护。机械加工、装配照片和器件介绍可以放在最后看，因为它们对 `STM.md` 的主控制链帮助有限。
