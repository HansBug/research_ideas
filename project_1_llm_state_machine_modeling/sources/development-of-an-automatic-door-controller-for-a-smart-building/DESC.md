# 智能楼宇自动门控制器 / Development of an Automatic Door Controller for a Smart Building

## 论文在讲什么

这篇论文是一篇短篇工程实现稿，核心目标很明确，就是用 `ATmega 328P`、`PIR` 传感器、超声测距模块、继电器和 `DC` 电机做出一个面向智能楼宇的滑动自动门控制器。文章没有把重点放在宽泛的楼宇自动化愿景，而是直接落到“什么输入触发开门、什么条件下关门、输出如何驱动电机正反转”这条控制链上。

从正文能看出，作者把系统理解成一个典型的条件驱动门控装置：先感知是否有人接近，再测人与门之间的距离，然后根据 `10-60 cm` 的区间条件决定是否发出 `FMOTOR` 或 `RMOTOR` 信号。结果部分又用表格把不同距离对应的开闭结果列得很直接，因此这不是只会说“智能门会自动打开”的泛化描述，而是一篇可追溯到具体 guard 和动作输出的离散控制样本。

## 控制系统在文中的位置

这里的控制系统描述就是论文主体。传感器选型、引脚分配、`if/else` 逻辑、继电器接线、正反转驱动和结果表基本都在为自动门控制器本身服务，并不存在“论文主要讲别的，只顺手用了一个门控案例”的情况。

不过它也确实是一篇比较典型的轻量工程实现文，不属于大规模复杂系统设计。它的价值不在于层次结构复杂，而在于把一个小而完整的门控 `EFSM` 讲得足够直白，尤其适合在 `sources/` 里补“输入 guard 明确、输出动作明确、结果表明确”的基础楼宇门控样本。

## 对我们为什么有用

对 `sources/` 来说，这篇最有价值的地方是它能稳定提供一条干净的“传感器条件 -> 逻辑判断 -> 电机方向输出 -> 开闭状态结果”文本模板。类似模板很适合后续做 `project_1` 的自然语言到状态机建模，因为它把状态切换条件和执行动作都写得相当靠近工程口径，而不是抽象模式名堆叠。

它还补了 `🏢` 方向里比较稀缺的一类门控样本。库里虽然已有一些车库门、电梯门和楼宇机电控制条目，但这篇把 `PIR` 和数值测距区间直接组合成 guard 的写法很适合作为轻量 `EFSM` 基线，用来和那些更复杂、带权限认证或多部件互锁的门控控制器做对照。

## 如果需要人工细读，建议怎么读

人工回读时，建议先看第 `1` 页摘要，把 `PIR`、超声测距、`FMOTOR/RMOTOR`、继电器和 `12 V DC` 电机这组关键件先圈出来，确认这篇关注的是实际门控逻辑而不是楼宇概念介绍。然后直接跳到第 `2` 页 `Materials and Method` 和第 `5` 页 `Programming`，把输入引脚、真假分支、正反转驱动关系和 `if/else` 逻辑读稳。

第一次重读时，最值得再核对的是第 `7-8` 页结果表和结论，因为那里把“哪些距离会开、哪些距离会关、开门还要求有人运动”说得最清楚。背景性的智能建筑引言可以第二轮再看；如果目标只是重做 `STM.md` 或复核 `EFSM + T0` 判定，优先把条件区间、输入组合和开闭动作链确认即可。
