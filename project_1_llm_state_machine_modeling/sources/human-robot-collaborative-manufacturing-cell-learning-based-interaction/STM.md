### 2. 基于原文整理后的自然语言描述

The manufacturing cell uses a six-state robot supervisor to coordinate palletizing, safe human proximity, object handover, inspection, and object recovery inside one collaborative use case. After `Start`, the arm normally executes `Fast Object Manipulation`, but operator detection moves the controller into `Safe Object Manipulation`, where the same palletizing task continues with slower and more retracted motion. When the operator performs the `A` gesture and the robot already holds an object, the supervisor enters `Object Handover` and then `Wait for Interaction`, where `PUSH` rejects the object and returns to palletizing while `PULL` releases the object and sends the robot to `Wait to Recover Object`. Later, an `F` gesture from the operator requests recovery from the designated recovery area, causing the arm to enter `Recover Object` and then automatically return to the safe manipulation state. Because each state carries a specific motion, gripper, speed, and interaction policy, the paper provides a full manufacturing-cell FSM rather than a loose collection of perception modules.
