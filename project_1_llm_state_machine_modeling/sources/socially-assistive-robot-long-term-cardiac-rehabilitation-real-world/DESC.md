# 心脏康复训练中的社会辅助机器人监督器 / A Socially Assistive Robot for Long-Term Cardiac Rehabilitation in the Real World

## 论文在讲什么

这篇论文讨论的是社会辅助机器人如何长期进入真实 cardiac rehabilitation programme，并在门诊阶段持续陪伴、监测和反馈。作者不是只做短期实验，而是在真实临床合作环境中部署机器人 `2.5` 年，用它跟随患者完成多次训练会话，比较有无机器人的依从性和康复效果差异。

从状态机样本角度看，真正重要的是文中的 `Robot Module`。作者把康复会话写成三种交互状态：`Motivational support`、`Performance monitoring` 和 `Online feedback`。机器人不是一直机械播报，而是先宣布训练强度，再在训练过程中按固定节律鼓励、按固定间隔询问 Borg scale，并在心率、姿态或用力等级异常时切到不同的反馈/告警分支。这使它成为一个相当完整的 session supervisor，而不只是“会说话的陪练机器人”。

## 控制系统在文中的位置

控制系统描述在文中处于核心实现地位。论文的实验目标虽然是验证长期康复效果，但所有效果都建立在这套监督控制器的持续运行之上：机器人必须知道何时鼓励、何时监测、何时反馈、何时呼叫医护，才能形成稳定干预。也正因为如此，作者专门把 monitoring phase 的 finite state machine、阈值和 cooldown 写了出来。

这篇论文与常见临床评估稿的不同点，也正在这里。它不是只报告“机器人提高了依从性”，而是给出了一套可追溯的会话监督逻辑，包括 `5 min` 鼓励、`7 min` Borg 请求、`3 min` cooldown、心率 warning/critical threshold、姿态纠正和医护告警分支。对 `sources/` 来说，真正值得保留的不是效果统计，而是这条明确的干预状态链。

## 对我们为什么有用

它对 `🩺` 方向的价值，在于补进了一个很不一样的医疗监督器样本。库里已有起搏器、输液泵、外骨骼、义肢和步态控制，但这篇条目关注的是“康复训练会话监督”而不是执行器轨迹控制。它把生理阈值、问询反馈、姿态纠正和人工介入触发统一到一个状态机里，能扩展医疗样本的对象类型。

它也很适合作为 `EFSM + T1` 双 A 样本。这里不仅有离散状态，还有明确 guard 和局部定时：心率阈值、Borg scale `> 12`、姿态偏差、`5 min / 7 min / 3 min` 周期。对自然语言建模任务来说，这种“连续监测驱动的离散干预监督器”比单纯的设备模式切换样本更能覆盖医疗场景里的会话级控制逻辑。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `5-6` 页的 `3.2 Robot Module` 与 Figure `4`。先把三状态结构、`5 min / 7 min / 3 min` 的局部时间逻辑和 monitoring-to-feedback 的切换关系读出来，再往下读 heart-rate、Borg scale 和 cervical posture 三种反馈分支。

第二轮再回到更前面的 patient-robot interface 章节，确认心率、倾角、速度和 tablet 输入是如何进入监督器的。至于后面的长期实验统计、依从性变化和临床结果可以后读，因为那部分主要告诉你“这套监督器效果怎样”，而不是先恢复它的状态机本体。
