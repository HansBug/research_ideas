# 车位感知与双闸门停车控制 / Automated Parking System Using PLC Technology

## 论文在讲什么

这篇论文围绕一个带入口闸门、出口闸门、空位监测和 HMI/SCADA 显示的停车场原型展开。作者不是只做“空位识别”，而是把停车场当成一个完整的离散控制对象来写：车辆来到闸门前会被光电传感器检测到，PLC 再结合车位传感器的空闲结果决定是否开门，同时把当前空位状态显示到外部界面上。

从我们最关心的状态机样本角度看，这篇文章最有价值的部分不在“用了 PLC”这一点，而在它把双闸门、电机正反转、继电器、限位停机和满位锁闭这些典型工程控制细节串成了一个可追溯的控制链。它没有强调复杂优化或路径规划，而是把停车场门禁控制写成了很典型的离散 I/O 监督逻辑。

## 控制系统在文中的位置

这里的控制系统就是论文主体，而不是为了展示某个算法顺带给出的演示案例。文章从硬件组成、传感器与继电器、原型实现、HMI 画面、输入接线和电机输出控制一路往下写，核心关注点始终是“PLC 如何接收停车场输入并驱动门禁动作”。

对 `sources/` 来说，这种位置非常重要，因为它意味着我们后续回看原文时，不需要先穿过长篇方法论或验证框架才能找到控制对象。停车场控制器本身就是作者实际设计和实现的主对象，入口/出口门、空位判断和满位处理都直接落在正文主线里。

## 对我们为什么有用

这篇样本补的是 `🅿️` 方向里相对稳定、可复用的 PLC 停车门禁控制链。当前停车样本里，连续轨迹型自动泊车和车位分配型样本并不少，但像这样把“车位传感 + 入口判定 + 闸门动作 + 限位停机”写得比较工程化、而且原文和提取文本都比较顺的文章，更适合直接转成状态机自然语言样本。

它对后续自动建模也很友好，因为输入、guard 和输出的边界很清楚：车辆到门、车位是否空闲、继电器正反转、门开闭到位、HMI 更新，这些都能稳定落到 `EFSM + T0` 的离散建模框架里。虽然它和库内已有的若干停车门禁样本存在邻近相似，但双闸门和限位停机链仍然提供了值得保留的工程表达差异。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1-2 页 的摘要和 `Material and Methods`，只确认系统边界、输入/输出器件和作者要解决的问题；然后直接跳到第 5-10 页 的 `Practical Implementation`、`Entry and Exit Gates`、`Parking Spaces`、`HMI Programming`、`Wiring Diagram`，把入口/出口门、车辆检测、空位检测、继电器正反转和限位停机几段控制链读透。

第 11 页 的 `Results and Discussion` 与 `Conclusion` 也值得快速回看，因为它会把“空位则开门、满位则关门/锁闭”的高层逻辑再次压缩总结出来。相对而言，前面更偏元件介绍和一般背景的段落只需要在第一次阅读时确认设备角色，不必把注意力耗在器件通论上。
