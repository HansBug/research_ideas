> The FSM has 6 states as shown in figure 1. State transitions take place according to the timing control signals generated by the timer block and inputs given to a particular state. ... It has following states: IDLE, READY, SOAK, WASH, RINSE, SPIN. Initially the FSM is in the idle state. Once the coin is inserted, the FSM will go to the READY state. Once in ready state, any of the 3 modes for washing can be selected. The selected mode decides the timing allocated to each state. If no mode is selected, it will remain in the READY state itself. In case the process is cancelled now, the coin is returned as the washing process has not yet started and the FSM returns to the IDLE state. ### 2. 基于原文整理后的自然语言描述

The washing-machine controller is an `EFSM` that begins in `IDLE`, moves to `READY` after coin insertion, waits for one of `mode1`, `mode2`, or `mode3`, and then executes the fixed cycle `SOAK -> WASH -> RINSE -> SPIN -> IDLE`. Its transitions are not purely symbolic because the paper explicitly adds a timer block whose elapsed signals determine when each phase completes and how long each washing mode lasts. During operation, `water_inlet` is asserted in both `SOAK` and `RINSE`, `Cancel` returns the coin only before washing actually starts, and opening the lid pauses the process for safety while the current-state outputs remain visible on the FPGA board LEDs. Because the state order, guards, timer dependency, and named outputs are all explicit, this is a strong `EFSM + T1` appliance-sequencing sample with clear engineering timing semantics.
