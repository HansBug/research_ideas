# 模式可选的洗衣机顺序控制 / An Implementation of Automatic Washing Machine Control System Using Verilog HDL

## 论文在讲什么

这篇论文讨论的是一个用 `Verilog HDL` 实现的自动洗衣机控制系统。作者没有把重点放在家电外形或机械结构，而是直接把洗衣机的控制逻辑抽象成一套有限状态机，由 `IDLE`、`READY`、`SOAK`、`WASH`、`RINSE`、`SPIN` 六个状态和一个 timer block 共同协调整机流程。再加上 `Coin`、`Cancel`、`Lid` 和 `mode1/2/3` 这些输入，整篇实际上就是一个比较完整的顺序控制器设计说明。

正文最有价值的部分在 `System Design`。它不仅列出了状态，还把输入输出表和控制块职责写清楚了，例如 `ready_op`、`soak_op`、`wash_op`、`rinse_op`、`spin_op`、`coin_rtrn`、`water_inlet` 这些输出信号分别承担什么作用，以及 timer block 如何在不同模式下生成对应的时间控制信号。对于样本库来说，这篇论文的重点不在 FPGA 板卡，而在它把一个日常家电流程写成了非常典型的“模式选择 + 顺序阶段推进 + 安全暂停”的离散控制链。

## 控制系统在文中的位置

这里的控制系统不是附带案例，而是论文主体。作者的目标就是借洗衣机这个对象说明 Verilog HDL 和有限状态机设计能力，因此状态集合、输入输出接口、定时块和状态转移是正文的中心内容。即使文章篇幅不长，它也没有把状态机语义藏到代码片段深处，而是直接在正文里把状态图、模式选择和转移顺序说了出来。

这意味着我们关心的控制系统描述在文中的位置非常集中。`READY -> SOAK -> WASH -> RINSE -> SPIN -> IDLE` 的推进顺序、模式对定时的影响、未开始时取消返币与开始后取消不返币、开盖暂停这些规则，都是作者为了说明洗衣机控制器而主动写出的核心内容，而不是从图缝或实验表述里勉强拼出来的。这类材料非常适合进入 `sources/`。

## 对我们为什么有用

这篇论文对样本库最直接的价值，是为 `⚙️` 方向补进一个非常标准的 `EFSM + T1` 家电顺序控制样本。当前库里虽然已经有部分洗衣机、灌装、包装和流程式设备控制样本，但这篇洗衣机论文在“状态集合、模式选择、计时块、暂停条件、输出信号”五个要素上都比较齐，适合作为顺序机电控制的代表性轻量样本。

它也很适合作为从自然语言恢复状态机结构的训练材料，因为状态和 guard 的关系非常直观。`Coin` 决定是否进入 `READY`，模式选择决定定时配置，timer 决定阶段推进，`Lid` 触发安全暂停，`Cancel` 在不同阶段有不同效果，这些都属于典型的扩展状态机语义。后续如果要构造“模式可选的周期型设备控制”子类数据，这篇会是比较稳的一条基线。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1-3 页 `System Design`，尤其是状态说明、输入输出表和状态图。第一步先把 `IDLE / READY / SOAK / WASH / RINSE / SPIN` 六个状态抄出来，再把 `mode1/2/3`、`Cancel`、`Lid`、`water_inlet` 和 timer block 的作用挂到这些状态上。只要这一步读清楚，整篇论文的控制系统边界和主链已经足够稳定。

第二步再看第 3-4 页的结果部分，把 FPGA 板上的 LED 状态映射和状态图一一对起来，确认每个状态都有清楚的板级表示。相比之下，Verilog 工具链背景和 HDL 推广性说明可以放在后面看；第一次人工复核只需要把状态顺序、模式与定时关系、以及暂停/取消规则抓稳即可。
