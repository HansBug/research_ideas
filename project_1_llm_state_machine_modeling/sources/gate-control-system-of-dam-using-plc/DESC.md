# 双浮球闸门开停闭环控制 / Gate Control System of Dam using Programmable Logic Controller

## 论文在讲什么

这篇论文实现了一个基于 PLC 的小型水坝闸门控制系统，用两个浮球传感器检测水位，并通过继电器和 DC 电机控制闸门开闭。当前 `STM.md` 抽到的核心对象是“过程与环境控制领域的水坝闸门 PLC 水位监督控制器”。

从现有条目看，文中的控制链属于 `EFSM（扩展状态机）`，时间语义属于 `T1（工程定时 / 局部定时）`。原文明确写出 `X000/X001`、`Y000/Y001/Y002` 与 `T0/T1/T2/T3`，并给出两段开门、等待和关门的具体秒数，因此原文细节和描述细节都可评为 `🟢 A`。

## 控制系统在文中的位置

控制系统是全文主体，而不是附带例子。论文从硬件连接、浮球传感器、PLC 梯形图、仿真结果到模型照片都围绕同一条闸门开闭链展开。历史失败记录中曾因下载路径不稳而未获得原文；这次找到稳定 PDF 后，正文细节可以支撑入库。

## 对我们为什么有用

它提供了一个很清晰的“水位触发 + 定时动作序列”样本：高水位触发报警与两段开闸，低水位触发反转关闸。该样本可用于训练模型把 PLC 叙述中的输入、输出线圈、定时器和动作阶段转化为状态机。

## 如果需要人工细读，建议怎么读

人工细读时先看摘要和第 1 页介绍，确认传感器、PLC、继电器和 DC 电机的边界；然后重点读第 3 页 `Operation of Ladder Diagram`，把 `X001 -> T0 -> T1 -> T2` 和 `X000 -> T3` 两条链抽出来；后面的仿真和模型照片只用于验证动作序列是否与文字一致。
