# FPGA 水箱自动控制 / Intelligent Water Tank Automation System using FPGA for Efficient Water Management

## 论文在讲什么

这篇论文讨论的是一个水箱液位自动控制系统，目标是用 `FPGA` 替代手工值守或简单单片机方案，实时采集水位并控制补水泵启停。系统本身由 `DE10-Nano`、水位传感器、`MCP3208 ADC`、继电器、直流泵、LED 和人工复位开关组成，整体定位是一个面向家庭和工业环境的嵌入式资源管理控制器。

从我们关心的控制逻辑来看，文中最有价值的是一个很明确的阈值型三态控制框架：低于 `25%` 时开泵，高于 `90%` 时关泵，中间区间保持当前状态；同时用三种 LED 编码分别表示低、中、高液位，并允许通过人工复位把系统拉回 `Idle`。这使它不只是一个“测水位”的硬件演示，而是一套完整的离散控制器。

## 控制系统在文中的位置

控制系统是正文主体。作者没有把它当作某个更大平台里的小部件，而是围绕硬件组成、控制逻辑、阈值算法、FSM、仿真、综合和硬件原型逐段展开，因此输入、状态、输出和测试行为都能在主文中直接定位。

对 `sources/` 来说，这很重要，因为我们关心的不是“FPGA 很快”这类泛泛结论，而是“在什么阈值下切换到什么状态、泵和 LED 如何响应、手动复位怎么打断控制链”。这篇论文恰好把这些控制事实集中在一起，比较适合抽成过程控制方向的状态机样本。

## 对我们为什么有用

这篇论文对当前文库的价值，在于它补的是 `🌡️` 方向里一种比较清晰的 `EFSM + T0` 阈值控制器。现有过程控制样本里已经有 PLC 浮球式水位控制和喷灌控制，但这篇把模拟量采集、ADC 阈值、继电器泵输出和 LED 状态反馈绑得更紧，能补上“传感器量化值直接驱动离散状态”的表达方式。

另外，它虽然结构不复杂，但对做数据集反而有好处。`25% / 90%` 两个阈值、三态 FSM、三种 LED 编码和人工复位条件都足够明确，后续无论是训练自然语言到状态机生成，还是做同类控制器对照，这篇都能提供相对标准化的输入-guard-输出样本。

## 如果需要人工细读，建议怎么读

建议先读第 `5-6` 页 `Hardware Components`、`Control Logic Design`、`Threshold-Based Algorithm` 和 `FSM Design`，第一轮只抓四件事：系统由哪些硬件构成、ADC 值如何进入 FPGA、`25% / 90%` 阈值分别触发什么、`Idle / Pump ON / Pump OFF` 三个状态之间如何切换。

第二轮再看第 `7-8` 页的仿真和硬件测试，重点确认 `VADC = 500 / 2000 / 4000` 三种场景下泵和 LED 的反应，以及 `10` 升水箱里 `2.5` 升开泵、`9` 升关泵、手动复位回 `Idle` 的实验结果。像文前对 FPGA 优势和未来 IoT/AI 扩展的叙述，可以放在最后浏览。
