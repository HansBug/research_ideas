# 立体仓库三轴存取与复位控制 / Design of stereoscopic warehouse control system based on PLC

## 论文在讲什么

这篇论文讨论的是一套用 PLC 控制的小型立体仓库系统，核心设备是可以沿 `X / Y / Z` 三轴运动的堆垛机。作者把仓库看成一个自动存取系统：输入端选择货位，控制器根据传感器和限位信息驱动水平、垂直与叉取动作，把货物送入指定货格，然后再回到原点。

文中不仅给出电机、驱动器、输出端口和限位开关的硬件映射，还把软件层拆成 `delivery / pick up / reset / fault protection` 四个子系统。其中 delivery 子流程最关键，因为它直接把“判断目标货位是否空闲、沿 X 轴和 Y 轴定位、叉入货物、放货、缩回并回零”写成了顺序链。

## 控制系统在文中的位置

控制系统是论文真正的主角。文章的机械结构部分只是为了界定仓储设备边界，真正的论证重点放在电气控制和软件流程：哪些输出控制 X/Y/Z 轴，哪些输入来自光电传感器和限位开关，以及当系统接到 delivery 信号后具体按什么顺序推进。

对 `sources/` 来说，这篇论文的价值在于它是一个典型的仓储式离散事件控制对象，而不是泛泛的物流平台综述。它保留了实际驱动链、错误分支、回零操作和联锁保护，因此能很自然地转成 `EFSM` 形式的控制描述。

## 对我们为什么有用

这篇论文补的是 `🏭` 制造/物流方向里较高质量的一类样本。和只描述“仓库由哪些部件组成”的文献不同，它至少给出了一条完整的入库控制链和相应的异常分支，这让后续做状态机建模时可以直接抽出正常路径和错误回退路径。

后续做数据集时，最重要的不是仓库设备外形，而是 `目标货位检测 -> X 轴定位 -> Y 轴定位 -> Z 轴送叉/缩叉 -> 回零` 这条主链，以及限位开关、故障灯和切电保护如何作为 guard 或动作嵌入其中。这些内容足以支撑状态、条件和动作三级结构化提取。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 2-4 页电气控制部分，把 `Y0-Y5` 对三轴电机的作用、`X16-X35` 的传感器/限位分工和 `KM1/KM2` 的互锁保护先记下来。这样能先确定状态机中的执行器和关键输入是什么。

然后直接读第 4 页 delivery 子流程，把“是否缺货位、如何报错、如何依次走 X 轴、Y 轴和 Z 轴、何时缩叉并回到 0 位”这条链核实一遍。若只是为了重做 `STM.md`，优先级最高的就是这一页；机械结构和物流背景可以放在第二轮再看。
