# 四状态门禁密码锁 / An FPGA application of home security code using verilog

## 论文在讲什么

这篇论文讨论的是一个在 `Altera DE2-115` 板上实现的家庭门禁密码锁。作者的目标比较聚焦，不是做完整的智能家居总控，而是做一个可重构的 home security code lock，用按键按钮和矩阵键盘两种方式开门，并用 `7-segment` 和 LED 把锁定或解锁状态显示出来。与很多泛泛而谈“智能门锁”的短文相比，这篇的优势是门禁本体足够简单，状态机主链反而写得很直接。

论文正文围绕数字硬件设计、仿真和板级验证展开。它先给出键盘矩阵和 top module，然后把密码锁在 `FSM` 小节中明确写成 `IDLE / S1 / S2 / S3` 四状态序列，密码顺序是 `2 -> 6 -> C`。后面的仿真与硬件验证进一步把这个状态推进链具象化成 `L2`、`L6` 和 `UC` 的显示结果，因此整篇更像一个小而完整的门禁状态机工程样本。

## 控制系统在文中的位置

这里的控制系统描述就是论文的中心对象。虽然文章也花了一些篇幅解释 FPGA 相对 ASIC 的优点，但控制语义并没有散掉，而是集中落在 `Finite state machine` 小节和紧随其后的验证小节里。换句话说，这不是“先写很多安全系统背景，再顺便提一下状态机”的论文，而是确实拿密码锁状态机做了设计、仿真和板上验证。

从 `sources/` 的使用视角看，这篇样本的价值在于它非常纯粹。我们关心的是门锁如何从锁定走到解锁、错误输入如何回退、reset 如何回到默认状态，这几件事在文中都处于主线位置，没有被其他感知、联网或平台堆料稀释。它不是复杂系统级样本，但作为离散门禁子系统样本，表达非常整齐。

## 对我们为什么有用

这篇论文对样本库最直接的贡献，是补进一个非常标准的 `FSM + T0` 门禁控制器。当前 `🏢` 方向虽然已经有一些家居安防和智能门控样本，但不少是多模块组合控制，或者把门禁和其他环境功能揉在一起。这篇恰好提供了一个“状态少、密码链清楚、回退规则清楚、输出显示清楚”的轻量型门禁基线，适合做更纯的离散状态机训练样本。

它还适合拿来做“短状态链 + 符号输入序列”这一类训练切片。因为 `IDLE -> S1 -> S2 -> S3` 的推进条件就是 `2`、`6`、`C` 三个符号，错误输入回 reset，最终输出再反映到 LED 和数码管上，所以很适合后续构造“从简短控制描述恢复状态迁移图”的子任务数据。它不承担复杂控制，但在有限状态机样本库里正好能补一个很干净的基础类型。

## 如果需要人工细读，建议怎么读

人工重读时，建议直接从第 5 页 `Finite state machine` 小节开始，把四个状态和三次正确输入的推进关系先抄出来，再去看第 6-8 页的仿真与板级验证，把 `L2`、`L6`、`UC` 对应到状态推进过程。只要把这两部分读稳，这篇论文的核心控制链基本就已经完整了。第一页摘要只需要拿来确认系统边界和双解锁模式，不必作为主要证据来源。

如果还要进一步核对实现层细节，可以回看第 2-4 页的 flowchart、矩阵键盘表和 top module，确认按键输入是如何解码到状态机上的。但这属于第二层实现阅读；第一次人工核验时，优先抓 `IDLE / S1 / S2 / S3`、密码序列 `2 / 6 / C`、reset 回退和解锁显示逻辑即可，不必被过多硬件平台介绍分散注意力。
