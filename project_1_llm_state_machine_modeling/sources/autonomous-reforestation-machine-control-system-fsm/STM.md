### 2. 基于原文整理后的自然语言描述

The AutoPlant mission supervisor is a ROS/SMACH finite-state machine with parallel state execution that sits at the top of the control chain and coordinates the move, transfer, planner, and planter action clients from their completion and failure outcomes. Its top-level flow starts in `Standby`, executes the `Move` submachine to reach a working area, sets `new_site=True`, and then enters the `Transfer & map generation` submachine to initialize a new staging area. If the system still has a new site to process, it continues into the `Select plant position` submachine and then the `Plant` submachine; if no new site remains it executes `Set no new site` with `new_site=False` and proceeds toward mission completion. The explicit top-level transitions are triggered by returned outcomes such as `transfer`, `plantlocation done`, `done`, `stop`, and `end reached`, so the supervisor routes execution according to subsystem results rather than monolithic scripts. To keep the graph readable, the controller is decomposed into superstates and carries system-status variables such as `has_seedling` and `new_site` outside the action states, yielding a hierarchical mission loop that coordinates movement, workspace preparation, plant-location selection, planting, stopping, and end-of-mission handling.
