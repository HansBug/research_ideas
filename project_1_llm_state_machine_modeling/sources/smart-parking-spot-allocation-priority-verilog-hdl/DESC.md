# 优先级停车位分配与道闸控制 / Development and Implementation of a Smart Parking Spot Allocation System Based on the User's Category and Priority using Verilog HDL

## 论文在讲什么

这篇论文研究的是一个面向单层停车场的智能停车位分配系统，重点不是车位监测平台或支付系统，而是“车辆到达第二入口后，系统如何根据用户类别给出最近可用车位，并联动入口道闸”。作者把场景限定为 `12` 个车位的小型原型，用户类别分成 `OKU`、`pregnant women/elderly`、`women` 和 `normal` 四类，并明确规定离商场入口最近的车位优先留给高优先级类别。

系统实现上采用 `Verilog HDL` 和 `FPGA DE2-115`。文中给出了按钮输入、`IR` 车位检测、LCD 提示、七段数码管车位显示、蜂鸣器与道闸电机的整体链路，因此读者能看到它不是单独的显示模块，而是一套从“检测到来车”到“车位分配”再到“道闸开闭”的完整控制器。

## 控制系统在文中的位置

这里的控制系统描述就是论文主体。摘要和方法部分先定义了类别优先级、每一类对应的车位分区与入口面板，随后在 `Fig. 5` 把主流程明确写成 LCD 提示、读取空位、等待类别选择、分配车位和控制自动道闸的顺序链。也就是说，论文并不是把停车系统当作某个通信平台的附属 demo，而是在讲一个实际的停车分配控制器该如何组织输入、状态判断和输出动作。

对 `sources/` 来说，它的价值还在于保留了“同类车位不足时如何处理”的分支。很多停车短文只会写“空位检测 + 放行”，但这篇把 `OKU`、孕妇/老人、女性和普通用户之间的优先级与 fallback 逻辑写了出来，例如高优先级类别满位时转入普通停车位，而不是直接拒绝进入，这让样本更接近真实停车策略而不只是门禁控制。

## 对我们为什么有用

这篇论文补进的是 `🅿️` 方向里比较难得的一类“系统级分配器”样本。它不是只看某个超声/红外模块的局部有限状态机，而是把入口感知、类别输入、最近空位搜索、七段显示和道闸控制串成了一条主控制链，因此适合归到 `EFSM + T0` 的双 A 停车样本。

后续做状态机自动生成数据集时，这篇尤其适合用来训练“有优先级约束的资源分配控制”这一类文本。因为它同时给出了用户类别、资源可用性判断、从近到远的搜索规则、类别满位时的回退策略，以及成功分配后的放行动作；这些信息组合起来，比只写“停车位已满/未满”的简单门禁论文更有建模价值。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `1` 页摘要和第 `3-4` 页系统设计，把四类用户、`12` 个车位的分布以及两道闸的角色先锁定下来。然后直接跳到第 `5-7` 页的 `Fig. 5` 和对应文字，把 LCD 从 `Welcome to VIXX Mall` 到 `Sorry No Parking` / `Choose Type of Parking` 的切换、类别按钮分支、最近空位搜索和道闸开闭链条一次读顺。

如果还需要补证，再去看第 `11-13` 页的原型验证图片与说明，重点核对三类事实：同类车位可用时如何给出编号、同类满位时如何回退到普通车位，以及分配完成后道闸与 `IR` 传感器怎样配合完成放行。第一次细读时不必陷在 `FPGA` 工具链或板级实现细节里；真正关键的是把“类别优先资源分配 + 成功分配后的入口执行链”这条主控制链读稳。
