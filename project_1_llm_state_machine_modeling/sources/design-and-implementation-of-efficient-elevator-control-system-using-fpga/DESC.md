# 三层电梯 FPGA 状态机控制 / Design and Implementation of Efficient Elevator Control System using FPGA

## 论文在讲什么

这篇论文研究的是一个三层电梯控制器的 FPGA 实现。作者使用 `Xilinx StateCAD` 和 `Verilog HDL`，把电梯的楼层驻留、上行和下行行为写成一个七状态有限状态机，然后再映射到 FPGA 上验证。它不是从建筑调度角度谈“多电梯群控”，而是聚焦单台三层电梯在不同按键请求和楼层传感器触发下如何完成楼层间迁移。

论文的技术表达相当直接：先给出状态集合，再说明 `PB1/PB2/PB3` 和 `S1/S2/S3` 分别代表什么，最后逐条解释从 `F1` 到 `MU2/MU3`、从 `F2` 到其他楼层、以及从 `F3` 向下回落的迁移逻辑。它因此不是一个“电梯系统概览”，而是一篇标准的状态机控制器说明文。

## 控制系统在文中的位置

控制器是论文的主体对象，而不是实验附件。正文专门解释为什么电梯控制系统适合用有限状态机建模，并用一个完整的三层案例展示 `F1/F2/F3`、`MU2/MU3`、`MD1/MD2` 之间的关系。状态图、状态解释、输入输出含义和若干典型迁移都服务于这个控制器本身。

这对 `sources/` 很重要，因为它意味着我们不需要从系统架构或电路连接里反推控制逻辑。原文已经把楼层驻留、向上运行、向下运行和基于传感器停靠的规则拆得很清楚，天然适合整理成一个 `FSM + T0` 的电梯控制样本。

## 对我们为什么有用

这篇论文补的是 `🏢` 方向里比较标准、但可追溯性很高的单电梯控制器样本。它没有把大量篇幅放在接口电路或外设展示，而是明确把楼层状态和迁移条件写出来，使得后续模型生成任务可以稳定恢复一个“状态名明确、输入明晰、输出直白”的 elevator FSM。

它对样本库的意义还在于，它提供了一个很适合做基线训练或验证的简单控制器。和一些更复杂的电梯论文相比，这篇更容易人工核对，也更容易在后续做状态机抽取、错误注入或验证属性构造时充当基准案例。

## 如果需要人工细读，建议怎么读

建议先看状态说明和 `WORKING MECHANISM`，先把七个状态各自代表什么弄清楚，再顺着 `F1 -> MU2 -> F2`、`F1 -> MU3 -> F3` 这些例子把迁移语义读透。第一轮不用急着看实现工具，重点是把“哪些输入触发、哪些输出控制电机、哪个传感器负责停车”三件事确认下来。

第二轮再回到输入输出表和实现章节，核对 `HBRG` 的编码、`FLOOR` 显示如何更新，以及不同楼层是否真的共用同一套对称迁移规则。像工具链说明、RTL 视图和参考文献可以放到最后再看，它们对恢复状态机主链帮助不如状态图和迁移解释直接。
