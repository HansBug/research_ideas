### 2. 基于原文整理后的自然语言描述

The elevator controller is explicitly organized as a seven-state machine for a three-floor system, where `F1/F2/F3` denote floor-resident states, `MU2/MU3` denote upward-travel states, and `MD1/MD2` denote downward-travel states. Its input side is split between call buttons `PB1/PB2/PB3` and floor sensors `S1/S2/S3`, while the output `HBRG` drives motor direction and `FLOOR` drives the current-floor display. From `F1`, pressing `PB2` moves the controller into `MU2`, generates `HBRG="01"` to rotate upward, and waits for `S2` before switching to `F2` with `HBRG="00"` to stop the motor; pressing `PB3` similarly produces the `F1 -> MU3 -> F3` path. The paper states that the same transition pattern is reused from the other floors, so the controller gives a complete floor-to-floor FSM rather than a loose verbal description of elevator motion.
