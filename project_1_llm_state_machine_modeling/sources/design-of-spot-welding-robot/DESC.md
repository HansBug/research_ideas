# 点焊机器人多模式顺序控制 / Design of Spot Welding Robot

## 论文在讲什么

这篇论文设计的是一个三自由度点焊机器人，硬件由机械系统、控制测量系统和 PLC 控制器构成，目标是在危险、高温和高重复场景里替代人工完成定位点焊。就我们最关心的控制语义而言，论文并没有停留在“机器人由 PLC 控制”这句泛话，而是把顶层模式、动作顺序和主要输入输出都写了出来。

作者把整套控制分成手动和自动两大模式。手动模式用于调试和回原点，自动模式用于生产；而自动模式内部又分单步、单循环和连续运行三种子模式。再加上完整的动作顺序和 `2.4` 秒焊接周期，这篇论文天然就是一个层次状态机样本。

## 控制系统在文中的位置

控制系统是全文的中心，不是实现细枝末节。机械部分负责说明自由度、传动方式和焊枪机构，控制部分则给出初始位、启动后动作序列、限位开关和时间继电器，以及不同自动运行模式的停机与恢复规则。读者几乎可以直接把这些描述翻译成 HSM。

这也是它和很多工业机器人论文的差别所在。很多机器人稿件会把篇幅主要花在轨迹规划、视觉跟踪或机械设计上，而这里只要围绕 PLC 顺序控制去读，就能提取出相当清晰的模式链条和动作阶段。

## 对我们为什么有用

它为工业自动化方向补进了一个比较少见的“多模式机器人顺序控制”样本。现有库里有不少包装线、灌装线、洗车机和输送带控制器，但像这种既有顶层模式分裂、又有固定焊接动作链、还带运行子模式的机器人监督控制器并不多。

这类样本对后续状态机自动生成很有价值，因为它不只是单层顺序流程，而是明显带有层次结构。模型如果能把“manual / automatic”与“single-step / single-cycle / continuous”两层关系一起恢复出来，就比只会平铺动作顺序更接近真实工程控制需求。

## 如果需要人工细读，建议怎么读

人工细读时，先看摘要和 `2.2 Mechanical Systems Design Scheme`，确认机器人自由度、动作能力和 `2.4` 秒焊接周期；然后重点读 `4.1 The Workflow`，把 `dextral -> backspin -> elongation -> welding -> contraction -> topspin -> sinistral` 这条主链抄出来，再把 manual、single-step、single-cycle、continuous 四种运行方式对应到顶层和子层模式。最后看 `I/O Address Assignment` 与 `PLC Programming`，确认这些模式切换在程序层面确实有独立输入。

夹具结构、丝杠机构和机器人一般性背景介绍可以放到第二轮阅读。这些部分能帮助理解设备，但不是抽取层次状态机的第一入口。
