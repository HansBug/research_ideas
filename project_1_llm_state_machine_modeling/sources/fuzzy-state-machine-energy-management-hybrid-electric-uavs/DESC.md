# 面向混合电动无人机的模糊状态机能量管理 / Fuzzy State Machine Energy Management Strategy for Hybrid Electric UAVs with PV/Fuel Cell/Battery Power System

## 论文在讲什么

这篇论文研究的是 `PV + fuel cell + battery` 三源混合电动无人机的在线能量管理问题。作者关心的不是某一个电源模型本身，而是飞行过程中三类能源如何协同满足母线功率需求，并尽量节约燃料、保持电池在合理区间内工作。为此，论文提出了一个 `fuzzy state machine`，把离散状态机和模糊功率分配结合起来。

它的写法很适合我们做状态机样本：前面先交代 `PV` 优先、`battery` 负责补偿、`fuel cell` 尽量后用的总原则，后面再把五个离散状态逐一展开，并说明 `SOC` 与 `Pd` 怎样进入模糊逻辑层产生期望的燃料电池输出。因此这不是宽泛的“规则策略”概述，而是一条有 guard、有动作、有连续执行量的 `EFSM` 控制链。

## 控制系统在文中的位置

这里的控制系统是论文方法本体。混合动力系统模型、无人机模型和仿真平台都是为了验证这个能量管理器能否在真实飞行功率需求下稳定分配能源。没有这个控制器，论文就只剩电源组件和飞行平台的拼接，无法体现三源协同的核心价值。

从控制结构上看，顶层离散状态机负责决定当前属于哪一种供能工况，模糊逻辑层则在状态 `4/5` 中进一步细化燃料电池输出。也就是说，这不是纯粹的连续优化器，也不是只给几个模式名的流程图；它明确保留了 `PpvMax / PD / Pd / Pchrg / SOC` 这些变量与具体动作之间的映射关系，因此很适合进入 `sources/`。

## 对我们为什么有用

对文库来说，这篇论文补的是 `✈️` 方向里相对稀缺的“飞行平台能源管理状态机”样本。相比航迹规划、姿态控制或任务管理类无人机论文，它直接给出了混合动力供能控制的离散骨架，能显著增加航空方向样本的类型多样性。

它还有一个额外价值：这里的状态不是传统机动阶段，而是能源分配工况。这种“离散状态决定连续功率分配”的表达方式，对后续做 LLM 状态机建模很有帮助，因为它逼着模型同时保留状态名、阈值变量和动作输出，而不是只记住表面的模式标签。

## 如果需要人工细读，建议怎么读

如果后续需要人工重做 `STM.md`，建议先读第 3-4 页对能量管理原则的说明，把 `PV`、`battery`、`fuel cell` 的优先级和职责关系确认下来。然后直接读第 4-5 页 `Implementation of Fuzzy State Machine`，把五个状态、对应 guard 和每个状态的功率输出关系梳理清楚。

在此之后再回头看模糊逻辑部分，重点抓 `SOC` 的三段区间和 `Pd` 作为输入变量如何得到 `PF`。至于更底层的电池、燃料电池和推进系统模型，可以放到第二轮再看；它们更适合支持性能分析，而不是第一轮抽离散控制骨架。
