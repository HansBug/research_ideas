# 自动门 PLC 控制系统设计 / Design of PLC Control System for Automatic Door

## 论文在讲什么

这篇论文讨论的是公共场所自动滑门的 PLC 控制系统。作者把常见商场、酒店出入口的自动门作为对象，围绕“有人接近时开门、无人后定时关门、关门时防夹、异常时停机报警”这条主线，设计了一套基于 PLC、变频器、电机和多种传感器的控制方案。

论文不是单纯介绍硬件组成，而是明确把系统拆成控制流程、硬件设计和软件逻辑三部分。它既说明了传感器和执行机构如何连接，也说明了自动模式和手动模式如何切换，以及故障和急停时系统如何停下来、如何报警和如何复位。

## 控制系统在文中的位置

我们关心的控制系统在这篇论文里是核心对象。第 2 节给出总体控制流程，第 3 节给出硬件与 I/O 规模，第 4 节把关门、防夹、故障和急停逻辑写成 PLC 软件功能，第 5 节再用验证段总结系统运行结果。也就是说，这篇论文不是用自动门举例说明某种方法，而是在直接设计和说明自动门控制器本身。

对 `sources/` 来说，这篇论文的价值在于它把建筑机电控制里常见但容易被忽略的一类对象补了进来。相比大量电梯样本，这个自动门控制器的对象更轻量、流程更短，但安全逻辑很完整：等待、关门、防夹、故障灯、急停和复位都在文中明确出现，所以很适合作为 `EFSM + T1` 的楼宇机电补样。

## 对我们为什么有用

当前 `🏢` 领域虽然已有不少电梯样本，但双 A 的比例仍不高，而且对象较为集中。自动门这种门禁/出入口执行机构控制器能为建筑机电方向补一个新的子类型，也能让数据集不再只围绕轿厢调度和门控延时打转。

更具体地说，这篇论文很适合做状态机语料，因为它的控制链天然是离散的：传感器触发、等待计时、低速关门、防夹回开、故障停机、急停报警、按钮复位。后续如果要训练模型识别“带计时 guard 的机电控制流程”，这类样本会比只有概念性流程图的文章更有用。

## 如果需要人工细读，建议怎么读

人工细读时，建议先读第 2 节和第 4 节。第 2 节先把对象边界和控制流程看清：到底哪些传感器负责开门，哪些传感器负责安全保护；第 4 节再把 `I0.4`、`I0.6/I0.7/I1.0`、`T37`、`Q0.1/M0/V0`、`Q1.1`、`I1.3`、`I0.1` 这些具体信号和动作串起来。

硬件选型、三相异步电机结构和变频器原理可以放到第二轮再看。它们有助于理解实现背景，但对 `STM.md` 的首轮提取而言，优先级低于控制模式、定时量、防夹逻辑和故障/急停分支。如果后续需要补更细的实现性备注，再回第 3 节核对即可。
