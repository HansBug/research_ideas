# 基于 PLC 的船舶供水自动控制系统设计 / The Design of Water Supply Automatic Control System of Ship Based on PLC

## 论文在讲什么

这篇论文讨论的是一套面向船舶集中供水系统的自动控制方案。作者把柴油机废热、太阳能、混水箱、电加热和 PLC 集中控制结合起来，希望在节能背景下完成船上生活与机务用热水的稳定供应。

文章外层是节能与环保，但真正落地的是一套明确的供水控制链。它不仅区分了不同水箱和不同温度等级，还解释了温度探头、阀门、加热器、流量开关和循环泵如何共同维持供水温度与启停逻辑。

## 控制系统在文中的位置

我们关心的控制系统在这篇论文里是主对象，而不是背景。前面几节说明热源与系统结构，第 IV 节明确给出低温和高温两种调节路径，第 V 节则把 PLC 输入输出、启动条件、停机和紧急停机写成集中控制流程。

这意味着论文虽然带有较强的能源利用背景，但控制系统并没有被淹没在热工原理里。对 `sources/` 来说，它提供的是一条真实船舶过程控制链，而不是泛泛的节能方案说明。

## 对我们为什么有用

这篇论文补的是 `🌡️` 方向里比较实用的一类样本：阈值驱动的供水温度调节与启停控制。它不像很多过程控制论文那样主要落在连续调节或控制性能指标上，而是保住了离散分支语义，例如“温度低于设计值时怎样关阀并加热”“温度高于设计值时怎样开阀加冷水并停止加热”。

它还补上了 start-work-stop-emergency 这一层设备运行逻辑。正文明确给出循环泵总开关、流量开关、单系统停机和整机紧急停机，因此很适合作为过程/环境控制方向里的 `EFSM + T0` 样本。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看温度调节部分和 PLC 控制部分。先抓第 IV 节里“低于设计值”和“高于设计值”两条调节链，把温度探头、阀门、温度开关和加热器的动作顺序读顺；再看第 V 节确认 PLC 的输入输出、流量触发、水泵启动和 stop/emergency 分支。

关于废热与太阳能的利用背景、蓄电池补能和节能意义，可以放在第二轮再看。它们有助于理解系统目标，但对首轮 `STM.md` 而言，更重要的是温度判据、动作分支以及启停控制本身。
