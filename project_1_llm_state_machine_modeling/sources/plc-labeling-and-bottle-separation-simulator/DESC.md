# 瓶体贴标与颜色分流控制链 / Sistem Tertanam Berbasis PLC pada Simulator Pemberian Label dan Pemisahan Botol

## 论文在讲什么

这篇论文讲的是一条小型输送带瓶体处理线的后段控制：瓶子在前序工位完成灌装和封盖后，进入当前系统，先贴标，再按颜色做分流。作者用 `PLC Omron`、`photoelectric sensor`、`RGB fiberoptic`、气动贴标机构和侧向 `gate` 组成了一套完整的顺序控制装置。

最有价值的是，原文没有只停留在硬件搭建，而是把“什么时候贴标、什么时候识别颜色、什么时候分流、红瓶和绿瓶各去哪里”写成了可追溯的控制链，再配上输入输出地址和自动/手动两种模式。这使它明显强于只给设备图和实验台照片的薄制造样本。

## 控制系统在文中的位置

控制系统是文中的主对象。论文虽然介绍了输送带、气缸、面板和传感器布置，但这些内容都直接服务于那条 `PLC` 控制链本身，也就是传感器如何触发贴标和分流动作。

我们关心的不是“做了一个瓶子处理实验台”，而是这条线怎样根据 `photoelectric` 与 `fiberoptic` 两类输入，驱动电机、贴标气缸和分流 `gate`，把贴标和分拣两个阶段串成一个完整顺序。原文在这一点上写得很具体，后面的结果表也能反向验证这条链真的在跑。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是一个比较少见的“贴标 + 颜色分流”制造控制样本。它和常见的单纯灌装、单纯计数或单纯包装不一样，因为这里有两段不同功能的顺序子任务，而且传感器和执行器的角色区分很清楚，特别适合抽出状态、guard 和动作。

它还和本轮其它瓶装线样本形成了天然的前后工位关系。后续如果要做“跨工位但仍可拆分成单状态机”的数据集整理，这篇可以很好地代表制造线里的一个局部控制单元，而不是泛泛的整线总览。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看摘要和第 2.1 节，把系统边界固定为“前序灌装封盖完成后的贴标与分流子系统”，同时记住红瓶直行、绿瓶侧分流这条主链。然后直接读第 8-10 页的输入输出映射、算法与 `manual / automatic` 说明，把 `photoelectric -> label`、`fiberoptic -> gate` 两个触发关系抽稳。

最后再看第 10-11 页的结果表和结论，确认控制链不是纸面设想，而是确实通过三十次观测运行过。硬件尺寸、面板布线和品牌参数可以放到第二轮再看，不影响先恢复状态机主链。
