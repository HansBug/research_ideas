# 营养液制备模块分层控制 / A Mathematical Model to Enable the Virtual Commissioning Simulation of Wick Soilless Cultivations

## 论文在讲什么

这篇论文研究的是面向 wick soilless cultivation 灵活试验台的虚拟调试与控制软件验证问题。它的主线虽然表面上是“用数学模型支撑 virtual commissioning”，但真正落到工程对象上时，作者给出了一个相当具体的营养液制备与灌溉试验台，其中 `NSM` 负责制备设定 `pH/EC` 的营养液，`FM` 负责加热和分配给不同作物样本。

对我们最有价值的是 `NSM` 这一块。论文详细列出了过滤单元、酸液与 A/B 营养液储罐、混合罐、液位/`pH/EC` 传感器、空气压缩机和蠕动泵等执行部件，并没有把控制逻辑停留在“有一个模型”这一层，而是进一步给出它如何先后完成蓄水、过滤、送入混合罐、设定不同植物样本所需的 `EC/pH`、以及何时进入报警停机。

## 控制系统在文中的位置

这里的控制系统描述不是配角。作者之所以要做离散事件数学模型，就是因为试验台本身的控制软件已经足够复杂，必须同时管理多个营养液策略、更多的传感器与执行器，以及一套可在虚拟调试中验证的顺序控制逻辑。换句话说，虚拟调试方法服务的是这套控制器，而不是反过来。

尤其重要的是，文中没有停留在普通顺序图，而是把 `NSM` 先概念化成 state machine diagram，再转换成 `Structured Text PLC` 代码，并明确说明了 `composite state`、`alarm state` 以及 `region/state/substate` 三层层次实现。这使得它对 `sources/` 来说不是一篇泛方法论文，而是一篇带有真实过程控制对象和分层状态机实现的样本。

## 对我们为什么有用

这篇论文补的是 `🌡️` 方向里比较稀缺的一类“过程控制 HSM”样本。很多过程控制论文要么只讲连续调节，要么只讲设备结构和优化目标；这篇则把营养液制备模块写成了一个清楚的离散监督器，里面既有顺序推进，又有复合状态，还有异常停机分支，因此很适合作为 `HSM + T0 + 层次` 的代表样本。

后续做状态机自动生成数据集时，这篇尤其适合补“工艺准备类 supervisor”这类文本。它不仅给出状态机的名字，还给出复合状态为什么存在、哪些动作在多个步骤间共享、报警从哪些传感器或 HMI 条件触发、以及 PLC 代码怎样保留层次结构。相比只给图不讲实现的文章，这篇更容易抽成可追溯的自然语言描述。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `8-9` 页，把 `NSM` 和 `FM` 两个模块的边界分开，只先盯住 `NSM`。重点读过滤单元、配方制备单元、`T240` 混合罐、`Q240/I240/A240` 这些传感器和 `P210/P220/P230/C200` 这些执行器，从而先建立“这套控制器到底在控制哪些物理部件”的直觉。

然后直接跳到第 `11-12` 页，把 state machine diagram、`nutrient solution generation` 复合状态、`alarm` 状态以及 `region/state/substate` 三层 PLC 实现连起来读。第一次细读这篇时，不必把所有数学方程和 Simulink actor 细节都读完；最关键的是先把“顺序填充与配液主链 + 共享动作的复合状态 + 由 HMI/液位/补料触发的报警链”这三部分读稳。
