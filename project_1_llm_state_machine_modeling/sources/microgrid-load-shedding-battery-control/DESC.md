# 微电网负荷切除与电池控制 / Microgrid Operation With Load Shedding and Battery Control

## 论文在讲什么

这篇论文讨论的是一个带水电机组和电池储能的微电网在欠压风险下怎样通过负荷切除维持稳定运行。作者的目标不是提出泛泛的能源管理框架，而是做一个真正能在 `RSCAD` 上跑起来的 load-shedding controller，用它去监视 bus 电压、按优先级切除负载、延时后再测、并在条件恢复时重连 breaker。

论文最重要的设计决定，是把这套控制器明确实现成 `Moore FSM`。作者说明了为什么不用简单位掩码，而选用 `FSM` 作为可移植到实时系统的软件骨架，并给出 truth table、next-state/output logic、外部 clock、resettable flip-flop、`state zero`、breaker close/open 控制等实现细节。也就是说，这篇论文提供的不是“微电网可能会 shed load”的概念，而是一个明确离散化后的保护/恢复控制器。

## 控制系统在文中的位置

控制系统描述在文中是绝对主角。前三章交代微电网背景之后，第四章和第五章基本都在围绕 load-shedding controller 的软件开发、I/O 设计、参数化、delay 机制和 RSCAD 实现展开。作者明确说明控制器的输入包括欠压类信号、`LOADSHED`、`CLK`、`reset` 和 breaker close 相关量，输出则直接去驱动 breaker controllers，这使得它非常适合当作控制系统状态机样本，而不是当成一般电力系统背景文献。

同时，论文还把这套控制器放进实际仿真中，说明负载按优先级逐步切除、高优先级负载尽量保留、`0.90 p.u.` 触发切除、`0.93 p.u.` 允许重连等工程参数。对 `sources/` 来说，这种带明确阈值、延时和 idle/reset 行为的微电网控制器，比只给 `EMS mode` 名称的 energy-management 论文强得多。

## 对我们为什么有用

这篇论文对文库的价值，在于它补进了一个 `🌡️` 方向相对少见的 `FSM + T1` 样本。这里的状态机不是门控、相位或任务管理，而是电力系统里的欠压保护和重连控制；它既保住了离散逻辑的清晰边界，又保住了电气工程里很重要的 delay、priority 和 reconnect threshold。这种对象对扩展文库的领域多样性很有帮助。

此外，这篇论文也适合后续继续延伸到验证或修复任务。因为它的状态切换条件、输出动作、重连阈值和“最高优先级负载永不切除”的政策都很明确，后续无论是抽取性质、构造场景还是检查恢复链一致性，都比面对一般性的微电网优化论文更直接。它因此是一个非常合适的“电力保护式状态机”代表样本。

## 如果需要人工细读，建议怎么读

人工重读时，建议先从第 26-31 页开始，连续读 `FSM` 设计、Simulink 实现、`RSCAD` I/O 端口和参数说明，把控制器到底接了什么输入、发什么输出、何时由 `CLK` 触发执行先读清楚。然后重点圈出 `state zero`、priority list、delay、`LOADSHED`、`Close_BRK_Rg` 以及 reconnect 的相关段落，先还原出控制器的 nominal / protection / recovery 主链。

第一次人工复核时，不必把太多时间花在整套微电网电路结构或仿真平台介绍上。真正决定 `STM` 提取质量的，是“什么时候欠压、切哪个负载、切完等多久、什么时候允许重连、最高优先级负载怎么保住”这几处离散控制语义；只要把这些段落读稳，这篇论文就已经足够支撑高质量的微电网状态机样本。
