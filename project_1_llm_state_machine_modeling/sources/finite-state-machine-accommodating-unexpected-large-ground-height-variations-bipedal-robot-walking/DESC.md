# 双足机器人未知地形切换控制 / A Finite-State Machine for Accommodating Unexpected Large Ground-Height Variations in Bipedal Robot Walking

## 论文在讲什么

这篇论文研究 `MABEL` 双足机器人在不知道台阶位置和高度的情况下，如何通过高层有限状态机在平地行走、上台阶、下台阶和绊倒反射控制器之间切换。论文不是只做连续步态稳定性分析，而是把未知地形扰动显式落到 `RW / SD / SU / TR` 四个离散控制相位，并把接触开关、关节几何高度估计和绊倒早晚分类接入转移判断。

系统实现上，机器人通过脚端和胫部接触开关检测正常落地、提前触地和撞击障碍物；若一步正常完成，就用腿长和关节角估计当前高度变化并选择 step-up 或 step-down 控制器；若 swing leg 撞到障碍或过早触地，就进入 tripping-reflex 逻辑。后文还用仿真和 MABEL 实验验证 12.5 cm 上台阶、18.5 cm 下台阶以及连续升降平台场景。

## 控制系统在文中的位置

我们关心的状态机是论文的主控制对象，而不是背景例子。连续动力学、虚拟约束和控制律设计都服务于这个有限状态机：状态机决定何时调用平地、上台阶、下台阶或绊倒控制器，而每个状态内的低层控制器负责实际关节输出。

这篇论文的价值在于它把“真实机器人遇到未知地形”写成了可追溯的状态切换问题。状态名、触发条件、输入传感器、连续几何估计、状态内控制动作和实验场景都很明确，因此适合作为机器人任务监督 FSM 的高质量样本。

## 对我们为什么有用

对 `sources/` 来说，它补进的是 `⚙️` 通用控制与机器人任务方向里的真实机器人状态机，而不是常见的 PLC 课堂流程或抽象形式化方法。它能够帮助数据集覆盖“离散模式切换 + 连续运动控制器调用 + 传感器触发异常恢复”的组合。

后续建模时，第一层应抽 `RW / SD / SU / TR` 与正常高度扰动、step-up、step-down、tripping 的转移；第二层再根据需要展开 tripping-reflex 内部的 rapid-lowering、rapid-elevation 和 recovery 逻辑。不要把全文的虚拟约束推导全部压进主状态机描述，只需保留它们作为状态动作和连续耦合依据。

## 如果需要人工细读，建议怎么读

人工复核时先读第 1-2 页确认问题设定、传感器和实验目标，再跳到 Section IV 看 step-down、step-up、early/late tripping 的控制动作，随后重点读 Section V 的四相 FSM 与转移条件。最后用 Section VI-VII 的仿真和实验证据核对这些状态是否真的在完整平台场景中被触发。

若只是为了重写 `STM.md`，不必先细抠全部动力学公式和优化参数。那些内容主要解释低层控制器如何稳定步态；真正用于状态机样本的核心信息在 Abstract、Section IV 的反射动作、Section V 的状态集合与转移条件，以及实验图中的状态激活时段。
