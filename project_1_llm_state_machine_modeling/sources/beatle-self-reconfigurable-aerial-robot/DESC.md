# BEATLE 空中重构规划 / BEATLE -- Self-Reconfigurable Aerial Robot: Design, Control and Experimental Validation

## 论文在讲什么

这篇论文围绕一种可在飞行中完成对接与分离的模块化空中机器人 `BEATLE` 展开。作者一方面介绍了机械对接结构和多模块飞行控制框架，另一方面把真正承载“如何完成空中重构动作”的部分落实到一个分层运动规划器上，使原型不仅能稳定飞行，还能执行模块间的重构动作。

从 `sources/` 的角度看，最值得保留的不是一般性的多旋翼控制，而是它把重构过程拆成了带恢复语义的 `FSM / Sub-FSM` 结构。正文明确说整体规划由多个 `Sub-FSM` 串接而成，而每个单元动作又细分为对齐、接触、装配这类阶段，并且在误差超限时回退重试，这让它很适合做“带异常回退的层次状态机”样本。

## 控制系统在文中的位置

这套状态机规划器在文中属于核心系统设计，而不是附带的小模块。论文的主张之一就是：空中自重构如果只靠连续位姿控制很容易在接触阶段失稳，因此需要一种能够显式插入恢复动作的离散规划骨架。状态机因此不是展示性配角，而是重构动作能否安全完成的主控制骨架。

更具体地说，论文把多模块飞行控制、推力分配和接触力补偿都放在连续控制层，而把“什么时候进入下一阶段、什么时候回退、什么时候更新连接拓扑”交给分层 `FSM`。这种分工非常清楚，也正是后续建模时最有价值的地方。

## 对我们为什么有用

这篇论文补入的是一个质量很高的空中机器人层次状态机样本。仓库里已有不少飞行器模式管理与任务监督条目，但 BEATLE 的独特价值在于它不是任务模式切换，而是更细粒度的“物理重构动作监督”：相对位姿满足后才接近、接近阶段误差超限则回退、对接成功后才更新结构参数。

对于状态机数据集来说，这类样本能够补足“连续控制包裹下的离散重构监督器”表达方式。它既保住了明确状态名和回退逻辑，又没有退化成单纯的轨迹规划论文，因此非常适合作为 `HSM + T0` 的核心保留样本。

## 如果需要人工细读，建议怎么读

如果后续要人工重读，建议先看第 1 页摘要，把 `merging / separating in-flight`、`motion planner based on a finite state machine` 这些总纲读稳；然后直接跳到第 5-6 页的 `IV. Reconfiguration Motion Planning` 与 `Figure 6`，这里是状态机抽取的核心位置，已经覆盖了层次结构、单元动作划分、相对位姿约束、误差回退和装配完成后的参数更新。

像第 2-4 页的机械设计、接触力补偿和推力分配细节，可以作为第二轮阅读来补系统背景。若以后需要重做 `STM.md`，最优先保住的仍然是 `Sub-FSM` 层级、三阶段动作链、误差超限回退和逆序拆解这四类事实。
