# RFID 车库门禁与车位分配控制 / Control system of automatic garage using programmable logic controller

## 论文在讲什么

这篇论文讨论的是一个自动车库控制系统，核心部件包括 `Siemens S7-1200 PLC`、入口/出口 `RFID`、车位 `IR` 传感器、烟雾传感器、步进电机门机以及 `SCADA` 监控界面。它不是只说“做一个停车场系统”，而是把识别车辆、判定空位、分配车位、控制闸门开闭、记录停车时长和显示费用这些动作都串成了一个完整的工程控制流程。

原文比较有价值的一点是把逻辑显式拆成 `main logic / RFID logic / motor logic / car parking` 四部分，同时给出 `timer`、`counter`、比较器区间和门机驱动条件。这使它不只是一个模糊的“门禁系统”，而是一个变量和 guard 都比较清楚的 `PLC + SCADA` 车库控制样本。

## 控制系统在文中的位置

这里的自动车库系统就是论文的主系统设计对象。作者从硬件构成、RFID 数值换算、步进电机开闸方向、硬件接线、软件实现到主逻辑图，几乎所有章节都围绕这套控制器本身展开，因此它在文中承担的是“被实现和被说明的核心工程系统”角色。

对 `sources/` 来说，这种论文非常实用，因为控制链本身就写在工程实现细节里。后续做 `STM.md` 时，不需要从方法论文里四处拼控制规则，而是可以直接从“哪些输入触发哪种门机动作、哪些变量决定能否入场、哪些计时逻辑负责费用与关门”这条主线往下抽。

## 对我们为什么有用

当前停车领域里高质量双 A 样本仍然偏少，而这篇论文补的是一类和轨迹规划、模糊泊车完全不同的“停车场基础设施控制”样本。它的重点不在车辆连续运动学，而在 `RFID + 空位检测 + 闸门动作 + 计费计时 + 满位阻断` 这类离散控制链，因此能显著丰富 `EFSM + T1` 的停车子类样本。

它对后续数据集尤其有用的一点，是把 guard 和变量都写得比较工程化：有车位空满、有车牌识别、有计时和计费、有入口和出口两条对称逻辑，还有烟雾告警这类安全输入。即使以后不保留所有硬件说明，这些控制语义本身也足够支撑状态机建模。

## 如果需要人工细读，建议怎么读

建议先看第 1-3 页的摘要和 `2. PROPOSED AUTOMATIC GARAGE CONTROL SYSTEM`，先确认系统边界、传感器和执行器；然后直接跳到第 5-8 页的 `6. HARDWARE IMPLEMENTATION` 与 `7. SOFTWARE IMPLEMENTATION`，把“何时开闸、何时不准入场、RFID 如何授权、空位如何判定、计时/计费如何接入”这几条控制主线读清楚。

`3. PROGRAMMABLE LOGIC CONTROLLER [PLC]` 和 `4. RFID` 里较多原理性说明、器件背景和数值换算，可作为第二轮补证材料。第一次人工复核时，重点应放在主逻辑、门机驱动条件和车位分配链，而不是把所有 PLC 背景知识都读一遍。
