# 五车位升降横移立体车库控制 / Design of Five Parking Lifting Stereo Garage Based on S7-200

## 论文在讲什么

这篇论文讨论的是一个两层五车位升降横移立体车库控制系统。作者选择的不是抽象停车优化模型，而是典型的 `lift-sliding stereo garage` 工程对象：上层只能升降、下层只能横移，利用一个空位通道完成上层车盘的让位与降落。全文重点放在 `S7-200 PLC` 如何驱动升降和横移动作，以及如何借助限位、光电和防坠机构保证存车取车过程的安全。

论文虽然篇幅不长，但它把结构、模式和程序主链都交代出来了。尤其关键的是，上层车位不是简单“直接取车”，而是要先判断正下方是否有空位；如果没有空位，就先横移释放位置，再把车盘降下来。这个“判空-让位-降盘-复位”的链条使它不只是一个停车装置简介，而是一篇可以直接抽出状态机主线的停车控制样本。

## 控制系统在文中的位置

控制系统是这篇论文的核心内容。摘要就写明目标是实现 `automatic access vehicle, operation monitoring and fault alarm`，第 `2.1` 节进一步把运行模式分成自动和手动两类，第 `3.3` 节则明确说 PLC 程序由初始化、主控和故障报警模块组成，存车/取车逻辑主要由主控模块完成。这说明文中真正想讲的是“车库怎么自动运行”，而不是车库机构设计本身。

同时，这篇论文没有把安全只写成泛泛的“可靠”。正文明确点名了 `travel switch`、`photoelectric switch`、`anti-falling electromagnet` 和 `safety hook system`，并在故障程序里规定超长、超重或其他风险出现时要声光报警并停掉所有动作。这让论文里的控制对象同时覆盖了 nominal path 和安全停机分支，对样本库很有价值。

## 对我们为什么有用

对 `sources/` 来说，它补的是停车方向里一种比较典型、但又不只是门禁计数的立体车库存取控制器。和很多只剩“入口检测 + 满位提示”的停车短文不同，这篇论文真正保住了上下层协同、空位让位、托盘降落和复位等待这些系统级动作，因此更适合被整理成 `EFSM + T0` 的多步存取控制样本。

另外，它还能帮助我们维持停车领域内部的样本差异。库里已有一些门禁型、泊车辅助型和优先级分配型样本，而这篇论文的代表性在于“机械停车结构约束直接塑造了控制流程”。后续如果要比较停车文献里不同的状态机来源，这篇就是很好的“由设备拓扑决定状态迁移”的代表。

## 如果需要人工细读，建议怎么读

人工细读时，建议先抓第 `1` 页 `23-26` 行和第 `4` 页 `112-124` 行。前者把两层结构和空位通道机制说清楚，后者把真正的程序主链写得最明白：一层直进直出，二层先判下层空位，不空就先横移，再降盘，完成后自动复位。理解这两段后，再读第 `2.1` 节确认自动/手动模式边界。

随后再补读第 `3` 页 `88-101` 行，确认限位、光电、防坠和安全钩分别承担什么约束作用。至于前言里对立体车库市场前景的描述、机械结构宏观优点和泛化的控制器优点，都可以放到第二轮再看。重做 `STM.md` 时，真正不能漏掉的是“上层请求必须先判断下层空位”和“风险触发后全部动作停机报警”这两块。
