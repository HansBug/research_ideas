# SEVA3D 并联泊车有限状态自动机 / SEVA3D: Autonomous Vehicles Parking Simulator in a three-dimensional environment

## 论文在讲什么

这篇论文讨论的是一个三维仿真环境里的自动并联泊车控制系统。作者开发 `SEVA3D` 的目标，不是做一个泛化的图形仿真器，而是围绕一个非常明确的任务来建系统：让车辆在接近真实的三维街道环境里，依靠声呐传感器输入自动寻找车位、倒车入位、完成对齐，并在需要时自动驶出车位。

论文的系统背景确实带有仿真平台色彩，但核心控制链非常具体。作者给出了车辆周围五个声呐传感器的布置、车速和转向控制方式、停车自动机的状态集合，以及 pull-out 自动机的状态集合，最后还用多组不同初始位置和场景做了稳定性验证。换句话说，它不是“做了个 simulator 顺带提了个控制器”，而是“为了验证自动泊车控制器，做了一个三维仿真平台”。

## 控制系统在文中的位置

我们关心的控制系统描述在这篇论文里是主线之一，而且比平台实现更值得优先看。无论是摘要、系统模块图、传感器模型、`FSA Control - Parking`、`FSA Control - Pullout`，还是实验结果，真正串起全文的都是这套泊车监督器如何依据传感器输入切换状态并输出转向/速度命令。

更具体地说，这篇论文里的控制器不是只有一个抽象“park”动作，而是展开成了 `Stopped`、`Searching for parking space`、`Positioning outside`、`Entering`、`Positioning inside`、`Aligning` 以及出库时的 `Preparing pull out / Pull out / Returning`。对样本库来说，这种把完整停车过程写成离散阶段链的论文，明显比只给一条轨迹曲线或连续控制律的停车论文更有价值。

## 对我们为什么有用

对 `sources/` 来说，这篇论文最重要的价值，是补进了一类“真正的自动泊车 maneuver controller”样本。当前停车方向里已有不少车位管理、门禁和立体车库控制器，但像这样直接围绕车辆本身的并联泊车阶段控制、并且把传感输入与状态转换写清楚的条目并不多。

它还提供了一个很适合后续建模的数据形态。作者既给了状态名和切换条件，也给了声呐传感器、路缘检测、障碍距离阈值和实验结果，这让样本既有明确的离散骨架，又能保留少量与真实车辆运动相关的上下文信息。后续如果要比较“停车场设备控制”和“车辆自主泊车控制”这两类停车语料，这篇会很有区分度。

## 如果需要人工细读，建议怎么读

如果后续需要人工重读，建议先看摘要和第 3 节开头，把系统目标先锁定在“并联泊车与出库控制”而不是一般仿真平台；然后直接读 `3.2 Sensors Model`、`3.4 Vehicle Control`、`3.5 FSA Control - Parking` 和 `3.6 FSA control - pullout`，优先把五个声呐传感器怎样参与判定、停车自动机的状态序列是什么、哪些传感事件触发状态切换、出库自动机又如何补上闭环读稳。

前面的 related work、Ackerman 运动学推导以及 SimRob3D 的平台细节可以放到第二轮再看。第一次人工复核时，最该先抓住的仍然是停车/出库两个自动机本身和实验结果，因为它们足以支撑后续重新整理 `STM`；即使之后需要重写单篇提取物，也不必先陷进连续运动方程里。
