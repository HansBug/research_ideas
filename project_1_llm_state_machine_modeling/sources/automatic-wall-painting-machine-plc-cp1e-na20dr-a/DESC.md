# 自动墙面喷涂机 PLC 顺序控制 / Rancang Bangun Mesin Pengecat Dinding Otomatis Berbasis PLC CP1E-NA20DR-A

## 论文在讲什么

这篇论文设计了一台基于 `Omron CP1E-NA20DR-A` 的自动墙面喷涂机。系统用两个 `PG28` 直流电机分别承担垂直与水平运动，使用限位开关感知运动边界，使用编码器脉冲记录位移，再由 PLC 梯形图和 HMI 实现整机的往复喷涂控制。作者关心的不是喷漆工艺优化，而是怎样让设备在 `x-y` 两个轴上按固定轨迹完成整面墙的自动涂刷。

论文的核心工程点在于把这种二维机械运动整理成状态图和 PLC 程序。设备从初始点出发，先反复上下喷涂，再按既定脉冲阈值横向移动一个喷涂宽度，循环多次之后返回原点停机。由于同时给出了 `limit switch`、`counter`、`D100`、`D200` 这些具体切换条件，整篇文章很适合抽取为工业顺序控制样本。

## 控制系统在文中的位置

控制系统是论文的主线之一。文中虽然也讲电机、耦合器、传感器和 HMI，但这些内容都服务于第 `2.2.2` 节的软件状态图和 PLC 算法。作者明确把“程序状态”与“传感器触发转移”对应起来：`Keadaan 1`、`Keadaan 2`、`Keadaan 3`、`Keadaan 4` 和 `Stop` 构成了完整的控制骨架。

这意味着它不是一篇“硬件结构为主、控制流程顺带一提”的论文。对 `sources/` 来说，这类文章的价值在于，状态图与实际执行机构之间的映射非常直接，后续既可以抽离出抽象控制链，也能保留与工业设备动作相关的细粒度 guard。

## 对我们为什么有用

这篇论文补充的是一个很典型但又不常见的离散制造样本：不是输送带、灌装、包装或车库，而是带二维轨迹和位置计数的自动喷涂设备。它保留了工业控制里非常重要的“往复动作 + 计数阈值 + 回到起点”这一类语义，对后续状态机建模有明显帮助。

它的另一个优势，是 guard 不仅有传感器，也有位置计数。`limit switch 1/2/3`、`counter`、`D100=1380 ppr`、`D200=5520 ppr` 共同决定何时上移、下移、左移、右移和停机，这使它比只靠定时器驱动的简单顺序机更有工程味道，也更能训练模型理解“位置量触发离散切换”。

## 如果需要人工细读，建议怎么读

人工细读时，先看第 `1` 页摘要和第 `5-6` 页 `Desain Algoritma Program`，先把系统对象、两个运动轴和 `Keadaan 1-4 + Stop` 的状态集合确认下来。接着重点读第 `6` 页 `Gambar 7` 下方对状态图的解释，把 `start -> 上行 -> 下行 -> 左移 -> 再次上行循环 -> 右移回零` 这条主链，以及 `limit switch 3 / PB stop` 的提前停机分支记清楚。然后再看第 `7-11` 页编码器脉冲读数与 `1380 ppr / 5520 ppr` 的标定说明，确认水平步长和最终停止条件。

机械尺寸、RPM 误差分析和喷涂前后效果图可以放到第二轮再看。这些内容能帮助理解设备是否工作良好，但对重建控制状态链不是最短路径；若只是为了重写 `STM.md`，优先级应低于状态图解释、限位逻辑和编码器阈值。
