# 速度阈值驱动的混合无人机模式切换控制 / Flight control of hybrid drones towards enabling parcel relay manoeuvres

## 论文在讲什么

这篇论文研究的是一种用于 parcel relay manoeuvres 的混合无人机控制问题。对象是 `Convergence` 倾转三旋翼平台，它既能像多旋翼那样悬停，也能像固定翼那样高效前飞，因此作者需要同时处理 rotary-wing、fixed-wing 和两者之间的过渡控制，而不是只做某一种飞行模式下的轨迹跟踪。

文中前半部分分别建立了模型、旋翼模式控制器、固定翼模式控制器和 control allocation，真正把它串起来的是后面的 hybrid autopilot controller。作者明确说要把三套控制方案统一到一个 FSM 下面，使飞行模式切换由系统根据参考轨迹和实时速度自行决定，而不是由人工或写死的 waypoint 逻辑直接切换。

## 控制系统在文中的位置

这里的控制系统不是一个点缀式“状态机模块”，而是论文的核心集成层。前面的建模和连续控制器设计，最终都是为了让这套混合平台能够在悬停、前飞和过渡阶段之间自动切换；如果没有最后这个 FSM，前面那些控制器就仍然只是分散的局部解。

尤其对 `sources/` 来说，这篇论文的价值在于它没有把模式切换含糊地留在图示里，而是把模式管理写成了一个带输入变量和事件表的控制器：输入是 `||vref||`、`vair` 和旋翼倾角 `ā`，状态是 `S1/S2/S3`，切换条件则由速度阈值和倾角终值共同决定。这使它比只说“有 transition mode”的混合飞控论文更适合提取为 `EFSM + T0 + 连续耦合` 样本。

## 对我们为什么有用

这篇论文补的是 `✈️` 方向里非常典型的一类“连续控制器之上的离散模式管理器”样本。它不像普通固定翼或多旋翼论文那样只有一个模式，而是把 flight mode switching 明确变成了高层控制问题；同时它又不像纯架构稿那样停留在概念层，而是给出了具体状态、输入、guard 和仿真结果。

后续做状态机自动生成数据集时，这篇特别适合补“离散状态和连续阈值耦合”的语言模式。它提供的不是简单的 `idle / run / stop` 链，而是 `fixed-wing / rotary-wing / transitional` 这类物理构型模式，加上 `vrt / vvt / vht` 速度阈值和 `ā = π/2 / 0` 的完成条件，因此很适合训练 LLM 如何从混合系统描述中恢复一个合理的高层状态机。

## 如果需要人工细读，建议怎么读

人工重读时，建议先快速浏览第 `1-5` 页，只确认平台结构、两类飞行模式和前面连续控制器各自负责什么。然后直接跳到第 `6` 页的 `V. Hybrid Autopilot Controller`，把三件事先读稳：一是三套控制方案如何被统一；二是 `||vref||`、`vair` 和 `ā` 为什么被选作 FSM 输入；三是 `S1/S2/S3` 与事件表里的阈值条件如何对应。

第二轮再看第 `6-7` 页的正向和反向过渡仿真，重点核对速度跨阈值时何时进入过渡态、倾角达到终值时何时结束过渡，以及“只给预定义参考轨迹，模式切换由控制器自己做决定”这一点是否被仿真支撑。第一次细读这篇时，不必深陷所有动力学推导；最关键的是先把“连续飞控之上那层离散模式管理器”读清楚。
