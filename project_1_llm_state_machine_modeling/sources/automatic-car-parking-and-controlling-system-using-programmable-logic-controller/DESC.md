# 计数式停车场入口/出口门禁控制 / Automatic Car Parking and Controlling System Using Programmable Logic Controller (PLC)

## 论文在讲什么

这篇论文讲的是一个相对朴素但很完整的自动停车场控制系统：`LOGO! PLC` 负责读取入口/出口 `IR` 传感器、控制两侧闸门电机、维护车辆计数，并通过 `LED` 显示当前是否满位或空位。和很多偏轨迹规划的停车论文不同，它关注的不是车辆如何转向入位，而是停车场“能不能进、什么时候开门、什么时候关门、计数怎么更新”这条基础设施控制链。

原文把系统设计压缩得比较直接，核心就在两条逻辑：入口侧检查车位是否已满，若未满则开门、启动定时并递增计数；出口侧在满足离场条件后开门、启动定时并递减计数。虽然系统不复杂，但关键 guard、输出、计数器和定时器都出现了，因此非常适合做一个结构清晰的 `EFSM + T1` 基线样本。

## 控制系统在文中的位置

停车场控制器本身是论文的主角，不是为了验证别的方法而顺手带的例子。系统架构、硬件、软件设计和运行状态都围绕这套 PLC 门禁控制展开，因此后续回看时，不需要先把无关方法章节剥离掉，直接顺着控制器逻辑读就行。

不过这篇论文也比较典型地属于“工程实现型”论文：很多价值不在复杂理论，而在把一个完整门禁系统的输入、输出、计数和定时动作交代清楚。对样本库来说，这类文献适合作为基础控制链样本，也适合作为与更复杂 RFID/SCADA 停车系统对照的简洁版本。

## 对我们为什么有用

它对 `sources/` 的价值，在于补进了一类非常容易映射成状态机的停车门禁样本：容量 guard 明确、入口/出口流程对称、定时关门清楚、`Full / Empty` 指示明确。这类样本对于训练或评估“从自然语言恢复一个简单但完整的离散控制器”尤其有帮助。

同时，它也能作为停车子领域里的一个低复杂度参考点。后续如果需要比较“简单门禁计数型停车系统”和“包含 RFID、SCADA、车位分配、费用计算的停车系统”之间的语义层级差异，这篇论文正好能提供一个非常干净的基线。

## 如果需要人工细读，建议怎么读

建议先读第 1 页摘要，先把入口/出口、满位判断、开关门和计数更新这条总线抓住；然后看第 2-3 页的 `A. System Design`、`B. Hardware Equipment` 和 `C. Software Design`，重点圈出哪些输入是 guard、哪些输出是门机/LED、哪个地方启动定时器、哪个地方更新计数器。

第 3-5 页更多安装图和运行图可以放到第二轮再看。第一次人工复核时，真正重要的是把两条门禁逻辑和容量/计数语义读清楚；只要这部分抓稳，后续重做 `STM.md` 时就不会丢掉这篇论文最核心的控制价值。
