# 基于 PLC M221 的多区域停车原型 SCADA 系统 / SCADA for Prototype of Multi Area Parking System Based on PLC M221

## 论文在讲什么

这篇论文讨论的是一个双区域停车原型系统如何通过 `PLC M221 + SCADA/HMI + loop sensor` 做在线管理。系统不仅显示当前停车数量和当日收入，还直接控制入口与出口栏杆、红绿满位指示灯，以及两块区域的实时状态展示。

它的重点不是复杂路径规划，而是停车管理链最基础也最关键的部分：检测车辆、判断是否已满、控制栏杆开闭、统计当前占用数量，并在出口放车后恢复可进入状态。对 `sources/` 来说，这种“门禁 + 满位联锁 + 计数回写”的停车控制器是非常标准的离散控制客体。

## 控制系统在文中的位置

我们关心的控制系统描述在文中属于主角。虽然论文用了 `SCADA` 和 `HMI` 这些词，但它不是只展示监控界面；文章真正描述的是 loop sensor 信号如何进入 PLC、PLC 如何驱动闸杆电机和指示灯，以及计数和收入数据怎样同步更新到 HMI。

因此它并不是“停车管理平台论文里顺手带一个原型图”。相反，原型行为本身就是文章验证对象。入口不开门、满位关门、出口减计数、绿红灯切换这些控制动作都写得比较明确，能够直接转成状态机样本。

## 对我们为什么有用

这篇论文的直接价值，是补了一类相对轻量但完整的停车控制链。文库里已有一些停车系统更偏多层机械搬运、托盘/车板调度或轨迹控制，而本文更像典型停车场入口控制器，强调“检测-开杆-计数-满位联锁-恢复”的运营主链，因此在对象层面还是有补充意义。

另一个价值是它保留了双区域管理这个小变体。虽然每个区域的主链相似，但作者明确说明了两块区域都通过同一类 PLC/SCADA 逻辑在线管理，这让它比单入口的极简停车 demo 稍微更像真实场景里的停车管理单元。

## 如果需要人工细读，建议怎么读

如果后续需要人工重做 `STM.md`，建议先读英文摘要和第 2 页关于 loop sensor 与 PLC 行为的段落，先把“检测到车 -> 开杆/亮灯 -> HMI 更新”的核心链抓出来。然后直接读第 5-7 页的实验描述和 `Tabel 2 / Tabel 3`，因为这里最清楚地写出了初始状态、车辆进入、满位禁止进入、车辆离开后恢复可进入等具体行为。

一般性的 SCADA 介绍、PLC 选择理由和原型硬件清单可以放到第二轮再看。第一轮真正要抓住的是入口与出口两个栏杆在不同占用状态下的切换逻辑，以及红绿灯和计数器怎样跟着车辆事件变化；只要抓住这部分，就能稳定复原这篇论文的主控制链。
