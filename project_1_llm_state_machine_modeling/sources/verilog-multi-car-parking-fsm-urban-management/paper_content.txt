Abstrac t: The increasing vehicle population in ur ban areas has intensified parking challenges, leading to traffic congestion 
and inefficient space utilization. This paper presents a Verilog -based multi -car parking system designed using Finite State 
Machines (FSMs) to automate parking slot allocation and mana gement. Implemented on an FPGA  using  Xilinx Vivado 20.1 
and simulated in Model Sim, the system supports multiple slots with real -time vehicle tracking via sensors and password -
based authentication. By leveraging FSMs, the proposed design achieves low area utilization and scalability, offering an 
efficient solution for smart parking in urban environments.  
 
Keywords: Verilog, Finite State Machines, Smart Parking, Xilinx Vivado, ModelSim, Urban Parking Management  
I. INTRODUCTION  
        The rapid growth of vehicle ownership in urban centers, particularly in densely populated areas like shopping malls and 
residential complexes, has exacerbated parking challenges. Limited parking spaces result in traffic congestion, illegal parki ng, and 
increased operational costs due to manual management. Traditional parking systems rely on human intervention for slot allocation  
and access control, leading to inefficiencies and delays. This necessitates automated systems to optimize park ing space util ization 
and enhance user experience. In India, cities such as New Delhi, Hyderabad, In cities like New Delhi and Bangalore, parking s hortages 
are acute, with vehicle ownership out pacing infrastructure development. The economic impact is significant, as parking  spaces 
increase construction costs, affecting urban planning. Poor parking management also contributes to environ mental issues thro ugh 
increased fuel consumption and emissions from drivers searching for slots. Smart parking systems, implemented using har d ware 
description  languages like Verilog, offer a solution by providing real -time slot availability and automated access control. This paper 
proposes a multi -car parking system designed in Verilog using an FSM architecture, implemented on an FPGA with Xil inx Vivado 
2023.1 and simulated in ModelSim. The system uses sensors for vehicle detection and a password -based authentication mechanism 
to manage entry and exit, supporting up to four slots with scalability for larger setups. It minimizes manual intervent ion, reduces area 
utilization, and enhances efficiency, making it suitable for urban parking applications. The paper is organized as follows: S ection II 
reviews related work, Section III details the system design and FSM architecture, Section IV discusses the existing method’s 
limitations, Section V presents the proposed method, Section VI provides simulation results, Section VII concludes with futur e scope, 
and Section VIII lists references.

The FSM flow, depicted in Figure 1, illustrates state transitions driven by sensor inputs and authentication outcomes. The co re of 
the system revolves around a carcount register, which is used to monitor and maintain the count of occupied slots in the park ing 
space. This register plays a critical role in enabling efficient parking management by keeping an up -to- date count of vehicles currently 
parked in the slot.  The system  works  as follows:  
 When a vehicle approaches the entry point, the entry sensor detec ts its presence.  
 The FSM checks the current value in the carcount register to determine if a slot is available.  
 If a slot is available (i.e., carcount < maximum slot capacity), the system:  
o Authenticates  the vehicle  if required (e.g.,  RFID,  QR code,  number  plate recognition).  
o Triggers  the gate to open  for entry.  
o Increments the carcount register by 1  to reflect  the newly  occupied  slot. 
o Updates a display unit or LED indicator  to show  the updated  status (e.g., “1 Slot Occupied”).  
 If no slots are available, the system displays a “Parking Full” message and access is  automatically denied.”

V.PROPOSED  METHOD  
The proposed multi -car parking system overcomes single -slot limitations scalable Verilog -based by implementing a FSM 
architecture. The proposed system enhances the traditional single -slot parking approach  by introducing  a multi -slot symmetric  FSM - 
based in telligent urban parking system that tracks multiple vehicles, handles real -time slot allocation dynamically,  and offers  
scalability  to multi -level architecture. The method is centered around a robust Finite  State  Machine  (FSM)  controller  integrated  with 
smart sensors  and optimized logic  for effective  traffic management and resource utilization.  
The core of the proposed system is the enhanced car count register logic, now extended to manage multiple parking slots. 
Each slot is represented as a separate state  or a state group within the FSM, allowing for concurrent monitoring of entry/exit 
events and dynamic updates to availability  
A. Key Features  of the Proposed  Method  
• Multi -Slot Support : Unlike  the existing single -slot system, the proposed method supports multiple slots (N -slots). Each  
slot's  availability  is tracked  using  a slot status array, updated in real -time as vehicles enter or exit. 
• Advanced FSM Controller : The FSM manages multiple concur rent transitions and determines slot assignments 
dynamically. It handles state transitions based on sensor inputs, slot availability, and vehicle authentication status.  
• Symmetric Entry/Exit Handling : The entry and exit mechanisms are designed symmetrically  with their own  
IR/PIR/Ultrasonic  sensors  transitions  occur independently  for each sensor,  reducing  wait time and enabling bidirectional 
flow.  
• Slot Allocation Logic : Upon detecting a vehicle at the entry, the FSM checks for the nearest available slot using  a 
priority encoder -based logic. Once verified, it opens  the entry  gate and updates  the car count  and slot status.  
• Display and Notification System : A dynamic display module is integrated to show real -time availability (e.g., “3 Slots 
Free”) at the entrance . Optional IoT extension can provide mobile notifications or remote monitoring via apps or web 
dashboard.  
• Security and Authentication : Vehicles can be authenticated using RFID, QR codes, or license plate recognition to 
ensure authorized access. FSM  integrates this logic as a verification stage before allowing entry.  
• Scalability:  The system is designed to be scalable for larger  facilities  including  multi -level  or zoned  parking areas. Slot 
allocation can be localized to zones, with each having a sub -FSM module reporting to a central controller.  
The Verilog implementation  flow,  depicted  in Figure 4, outlines the design process: defining FSM states, coding control logic 
and sensor interfacing, synthesizing  with Xilinx  Vivado  20.1,  and simulating in  ModelSim.  The Mealy  FSM  minimizes  states,  with 
outputs updated based on state and inputs. The RTL design uses multiplexers for compact logic, validated through simulations for 
correct/incorrect passwords and full/empty conditions.  
The FSM is implemented in  Xilinx Vivado with a clock -driven state register for synchronized transitions.  The authentication  
module  compares  user inputs against predefined values (username: 01, password: 10),  ensuring  secure  access.  Synthesis  results  
confirm low resource usage, wit h multiplexers reducing gate count. This design provides scalability, automation, and efficiency, 
surpassing single -slot systems for urban parking applications.

The FSM -based  multi -car parking  system operates  through  a structured  digital  control  logic  that integrates  
authentication  and parking  slot management using  a Moore  finite  state machine  (FSM).  The system receives  three  main  inputs:  an 
8-bit username,  an 8-bit password,  and a 3-bit signal  car_in,  which  uniquely identifies  each incoming  vehicle.  These  inputs  
are handled by the Input Module, which passes the data directly to the FSM Controller for logical processing. Upon  receiving  
input,  the FSM  transitions  from  the initial IDLE state to th e AUTH (authentication) state, where  it compares  the provided  
username  and password  against  pre-configured  valid  credentials stored  in the design.  The FSM  architecture  is based  on Moore 
principles, meaning that outputs are governed strictly  by the current  state rather  than the instantaneous  input.  If the 
input  credentials  are verified,  the FSM  enters  the SUCCESS  state, activating  a green  LED to  indicate  successful login. 
The system  then transitions  into the ALLOCATE  state, where  the 3-bit car_in  input  is decoded  to activate  one of  eight  available  
parking  slots.  Each  slot (from  Slot_1 to Slot_8) is represented as a separate output signal, and only one slot is  asserted high at a 
time to indicate that the slot is occupied by the current car.  
If authentication  fails,  the FSM  transitions  to the FAIL state, triggering the red LED to alert the user of the unsuccessful login 
attempt. No slots are activated in this  condition,  and the system  eventually  returns  to the IDLE state awaiting the next user input. This 
strict state -driven behavior ensures that the parking system follows  a deterministic  and predictable  control  flow,  avoiding conflicts 
in slot allocation and ensuring secure access management.  
The entire logic is implemented in Verilog HDL and verified  through  simulation  in Xilinx  Vivado,  ensuring the design is 
synthesizable and testable in an FPGA environment. The absence of sensors or external peripherals allows the system to be use d 
purely in simulation mode, making it particularly suited for educational use,  prototyping, and academic research. The modular nature 
of the FSM also allows easy scalability, enabling the system to be expanded for more users or parking slots in future develop ments.

VII.  CONCLUSION  
The proposed Verilog -based multi -car parking  system, utilizing  FSMs,  effectively  addresses urban parking challenges. 
Its multi -slot support, low area utilization, and automated operation mark a significant improvement over single -slot system. 
Implemented on Xilinx Vivado 20.1 and simulated in ModelSim, the system ensures reliable perfo rmance through  accurate  state 
transitions  and sensor -based  slot tracking. The Mealy FSM optimizes hardware resources, making it suitable for FPGA 
deployment.  Future  enhancements  could  include  dynamic authentication  mechanisms,  such as RFID  or database - driven 
passwords,  to improve  security.  Integrating  IoT for real -time slot updates via mobile applications would enhance user 
convenience. Testing with larger parking configurations and physical sensors (e.g., ultrasonic) could validate real -world 
performance,  ensuring adaptability to diverse urban settings.  
Additionally, incorporating machine learning for predictive slot allocation could optimize efficiency in high -traffic scenarios. 
Exploring hybrid FSM models (Mealy  and Moore)  enhance performance. Continued research into advanced sensor integration and 
scalability will position the system  as a comprehensive  solution  for smart  parking in smart cities.
