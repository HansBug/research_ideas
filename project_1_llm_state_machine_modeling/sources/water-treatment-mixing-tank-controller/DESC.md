# Modelling and Verification of an Automatic Controller for a Water Treatment Mixing Tank

## 论文在讲什么

这篇论文讨论一个工业水处理混合槽的 PLC 顺序控制器。系统需要按固定工艺完成两种化学品进液、液位检测、搅拌、定时混合、排液和循环重复，并用 Petri net 对顺序控制链做建模与验证。

最有价值的是第 2 节的 `Control system specification` 与后续 Petri net 模型描述。原文不仅列出传感器与执行器，还直接给出 `S0-S10` 状态和 `T0-T9` 迁移链，足以恢复一个完整的 `EFSM + T1` 过程控制样本。

## 控制系统在文中的位置

控制系统是论文主对象。`LS1 / LS2` 负责液位反馈，`V1 / V2 / V3` 分别控制进液与排液，`lamp1-lamp4` 表示运行阶段，on-delay timer 控制搅拌保持时间。论文随后把这些设备耦合到 PLC 输出与 Petri net 状态迁移中，说明这不是背景例子，而是全文建模与验证的核心案例。

## 对我们为什么有用

这篇补进 `🌡️` 过程与环境控制方向的高质量样本。它比常见水位阈值启停样本更复杂，因为除了液位上下限，还包含两路进液、搅拌泵、定时器和排液阀的顺序耦合，能给 `NL -> 状态机` 数据集提供更完整的工艺循环描述。

## 如果需要人工细读，建议怎么读

先读摘要与第 2.2 节，固定系统边界和设备名；然后读第 2.3 节中 `S0-S10 / T0-T9` 的段落，按迁移顺序整理状态链；最后再看第 2.4 节的模块耦合和第 3 节验证结果，用来确认模型是否无 deadlock、bounded、safe。
