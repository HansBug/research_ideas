# PLC/SCADA 配方驱动液体灌装线 / PLC ve SCADA Kontrol Yöntemleri ile Sıvı Dolum Otomasyonu

## 论文在讲什么

这篇论文讨论的是一条原型级的 PLC/SCADA 液体灌装线，重点并不是单个阀门如何开关，而是让用户可以从 HMI 输入产品组合、目标重量和生产数量，然后让整条产线按这些输入自动完成灌装、封盖、贴标和出料。它既有典型的工业自动化结构，又保留了不少实际工位级细节。

从样本价值看，本文最大的特点是链路比较完整。很多灌装论文只给“瓶到位 -> 开阀 -> 关阀 -> 走带”，但这里除了重量闭环灌装，还多了 HMI 配方入口、封盖五步工序、纯/混合标签分支，以及编码器闭环监控传送带故障。

## 控制系统在文中的位置

控制系统描述就是论文的主线。文章前面会解释 PLC、SCADA、HMI 和相关工业背景，但这些不是为了做概念综述，而是直接服务于后面的原型产线实现。因此我们关心的控制系统并不是“附带案例”，而是作者真正要落地展示的对象。

此外，它也不是那种只停留在界面截图或接线说明的短文。论文把各主工序和辅助工序写成了有先后关系的控制链，所以对 `sources/` 来说，它更像一篇可以直接抽状态机描述的工程样本，而不是泛泛工业自动化介绍。

## 对我们为什么有用

它对当前文库的意义，在于补了一类更完整的 `🏭` 方向灌装样本。现有文库里已经有若干 bottle filling 条目，但很多偏短流程或单站控制；这篇则把配方输入、重量闭环、封盖、标签和闭环传送带都写进了一套原型里，层次更丰富。

后续做数据集时，这篇尤其适合作为“用户配置驱动的顺序产线控制”样本。它既能提供常规的灌装动作，也能提供异常重启、标签分支和输送故障检测等更细的控制语义，有助于把工业自动化样本从单一阀控短链拉向更完整的工艺链。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看英文摘要，先把整条系统链条建立起来：HMI 选配方和数量，按重量灌装，然后封盖、贴标、出料。接着直接读 `2.1.2 SCADA` 和 `2.2.1-2.2.4`，这里集中给出 HMI 限制、液位和称重检测、封盖步骤、标签分支以及传送带闭环控制，是重做 `STM.md` 时最核心的证据段。

`3.1 Akış Diyagramı` 和 `3.2 Sistem Mimarisi` 可以作为结构补充再看，用来核对工位先后关系。前面的 PLC/SCADA 基础介绍和后面的总结部分第一次不必细抠；真正最值得保住的是工艺段中的工位顺序和异常重启条件。
