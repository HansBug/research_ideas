# 5G-V2X 条件下的双层驾驶决策 HFSM / Modeling and TOPSIS-GRA Algorithm for Autonomous Driving Decision-Making Under 5G-V2X Infrastructure

## 论文在讲什么

这篇论文试图把 5G-V2X 时代的智能网联车自主驾驶决策写成一个“像人脑一样分层思考”的离散系统。作者不是单纯讨论某个局部换道器或某条轨迹，而是从整车逻辑出发，把全局场景理解、局部行为决策、局部路径规划和后续执行链连成一个完整的决策框架。

论文最核心的建模动作，是提出一个 `global FSM + local FSM` 的双层 HFSM。全局层负责把当前道路场景识别成 `start / on road / approaching an intersection / intersection / field driving / U-Turn / stop` 等宏观状态，局部层再把这种场景细化成更具体的驾驶行为，例如跟车、加减速、避障转向、各种 lane change 以及多种 stop 行为。之后 TOPSIS-GRA 算法不是悬空存在，而是直接用来给这些候选状态排序。

## 控制系统在文中的位置

我们关心的控制系统描述就是这篇论文的主线。摘要已经明确说 HFSM 由全局 FSM 和局部 FSM 组成，后面整整两节都在定义状态集、事件集、状态转移和候选目标点，不是方法论文里常见的“借车辆案例略示一下”。

更重要的是，这篇文章不只是把状态列出来，还解释了这两层状态机之间的输入输出关系。全局层的输出成为局部层的一部分输入，局部层的结果再送去路径规划模块，同时向上反馈刷新全局数据。这种“层间耦合但职责分明”的组织方式，对后续做状态机自动生成和层次状态机 benchmark 都很有价值。

## 对我们为什么有用

从 `sources/` 的角度看，这篇论文补的是 `🚗` 领域里更偏系统级的双层驾驶行为机，而不是单个 maneuver 的局部 supervisor。它和已有一些自动驾驶样本的差异，不在于又多了一篇 lane change 论文，而在于它把宏观交通场景和局部驾驶动作之间的层次映射写得更完整。

此外，这篇论文的条目价值还来自它给出了很丰富的局部状态集。像 `vehicle following`、`overtaking vehicles`、左右避障转向、带/不带减速的换道、`stop at intersection`、`stop at parking lots` 这些局部驾驶态，对后续做自然语言状态机输出很有帮助，因为它们比泛泛的“safe driving mode”更具体、更可落地。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1 页摘要和第 5-8 页 `Global FSM Model` 与 `Local FSM Model` 两节。第一轮重点是把两层状态机的职责边界读出来：全局层在做什么、局部层在做什么、局部层为什么还要带 `V` 这个候选目标点集合。只要这条链读稳，`STM.md` 的主骨架就已经足够明确。

第二轮再看第 10 页以后的 TOPSIS-GRA 状态转移排序过程，以及后面的仿真实验。那些部分对于理解“为什么选这个状态”当然很重要，但在首轮抽样时，优先级还是稍低于状态集合本身与层间输入输出关系。换句话说，先把 HFSM 结构抽稳，再回头补排序算法细节，会更高效。
