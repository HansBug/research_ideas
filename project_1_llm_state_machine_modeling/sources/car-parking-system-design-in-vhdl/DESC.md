# VHDL 停车门禁控制 / CAR PARKING SYSTEM DESIGN IN VHDL

## 论文在讲什么

这篇论文是一份本科毕业设计，讨论的是一个基于 `VHDL` 的停车场入口门禁控制器，而不是轨迹规划意义上的自动泊车。作者把问题收缩到停车入口这一条工程主链：车辆接近、前后传感器检测、密码输入、门禁开关、红绿灯提示以及车位显示，并用 `Quartus II` 和 `Altera` 平台去实现这条离散控制流程。

论文整体带有比较明显的课程项目和硬件实现色彩，前半部分包含停车系统背景、软件工具和原型说明，但它并没有只停留在平台介绍层。中段开始，作者把控制逻辑明确落到 `FSM` 上，给出了输入输出端子、命名状态、等待周期和状态图，这使得它在 `sources/` 里并不是“只有硬件、没有控制链”的弱停车样本。

## 控制系统在文中的位置

我们关心的控制系统描述在文中就是核心实现对象。作者不是把状态机当作附带的小模块，而是直接把“停车入口怎么根据传感器和密码工作”写成了 `State Diagram of Car Parking System`，并围绕这个状态图去组织接口、流程图和后续 `VHDL` 编码。

这类写法对 `project_1` 很有利，因为控制器的边界非常清楚。它不是泛化的“智慧停车平台”，也不是只讨论计费或车位显示，而是一个入口门禁控制器：检测来车后进入等待密码，密码正确则放行，密码错误则阻塞重试，当前车尚未停妥时还会把后车挡在 `STOP` 状态之外。

## 对我们为什么有用

对 `sources/` 来说，这篇论文的价值在于它补的是 `🅿️` 方向里较为干净的一类“密码门禁 + 跟车阻塞”样本。文中把 `Clock / Reset / Front Sensor / Back Sensor / Password` 这些输入和 `Green/Red LED` 这些输出集中写在一起，又把 `WAIT_PASSWORD` 的 `4` 周期约束写得很明确，适合作为 `FSM + T1` 停车控制样本入库。

它还提供了一个比“仅有开门/关门两态”更完整的主链。除正常放行外，文中还有密码错误重试、后车阻塞、前车通过后复位这几个关键环节，因此后续若要把它转成状态机自然语言样本，能够保留比普通门禁短文更完整的 guard 和动作语义。

## 如果需要人工细读，建议怎么读

人工细读时，建议直接从第 `28-30` 页开始，先看 `3.3 Developing Diagram and Interface Signal` 和 `3.4 State Diagram of Car Parking System`。第一轮重点只抓四件事：系统有哪些输入输出、命名状态有哪些、`WAIT_PASSWORD` 的 `4` 周期约束是什么、密码错误和后车到来分别如何改变状态。

然后再看第 `32-33` 页 `The Gate / The Exit / Implementation in VHDL`，把“密码正确开门、车辆进入、关门、等待前车停妥后重启”这条工程动作链补完整。至于前面的停车背景、文献综述和软件工具介绍，可以放到第二轮再看；它们有助于理解项目上下文，但对重做 `STM.md` 的贡献明显低于状态图、输入输出表和门禁流程描述。
