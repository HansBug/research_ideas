# Implementation of Automatic Car Parking System Using Verilog HDL

## 论文在讲什么

这篇论文讨论的是一个停车场入口控制与车位信息显示系统。它不是做车辆轨迹级自动泊车，而是做比较典型的“车来了 -> 请求密码 -> 决定开不开门 -> 输出空位信息”的停车场门禁控制逻辑，并把这个逻辑用 Verilog/FPGA 方式实现出来。

从控制对象来看，这篇论文更像“停车场运行控制”而不是“车体自动泊车控制”。作者关心的是入口传感器、密码校验、门禁锁闭、车位数/最近空位提示，以及入口和出口流程的协调，这类内容都很适合转写成离散状态机样本。

## 控制系统在文中的位置

控制系统描述在文中是主线之一。虽然前半部分有不少停车背景和相关工作综述，但 `Proposed System` 与 `Car Parking System` 两节已经把真正有价值的状态链写出来了：入口传感器触发、`idle`、`wait password`、`parking`、两次密码机会，以及密码正确才开门的规则都直接出现在正文里。

这让它和那种只给 RTL 图或波形截图的 FPGA 短文不一样。它至少保住了门禁控制本体的主状态和回退逻辑，因此不是“标题写了 FSM、正文只剩硬件实现”的弱稿。

## 对我们为什么有用

对 `sources/` 来说，这篇论文的价值在于它补的是 `🅿️` 方向里偏“门禁/准入控制”的 EFSM 样本。当前停车方向虽然已经有一些门禁和安全类条目，但这篇把 `idle / wait password / parking` 明说出来，又把两次密码失败回退保住了，适合做较干净的离散控制条目。

它还有一个额外价值，就是把停车状态和停车信息输出绑在一起。除了开门放行，它还输出最近空位距离、空位总数和已停车数量，这种“状态 + 扩展变量/显示输出”的组合正好符合 EFSM 样本的需求。

## 如果需要人工细读，建议怎么读

人工细读时，建议先跳到第 6-7 页，直接看 `Proposed System` 和 `Car Parking System`。第一轮只抓三件事：入口传感器怎样触发、密码错误怎样回退、密码正确后系统怎样进入 `parking` 并开门。把这三步读顺以后，再回头看空位提示和超声测距的输出逻辑。

第 1-5 页的大段背景综述可以晚点再看。那些内容能解释停车问题为什么常见，但对恢复这套门禁状态机本身来说，优先级明显低于状态名、条件判断和门禁执行链。
