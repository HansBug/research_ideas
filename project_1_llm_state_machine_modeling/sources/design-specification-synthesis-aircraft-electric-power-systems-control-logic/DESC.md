# 飞机电气分配系统重配置控制 / Design, Specification, and Synthesis of Aircraft Electric Power Systems Control Logic

## 论文在讲什么

这是一篇围绕 aircraft electric power system 控制逻辑设计、形式化规格和自动合成展开的博士论文。它的背景是现代飞机电气系统里有多台发电机、多个高低压 AC/DC 母线、整流器、变压器和一组接触器；当发电机故障、供电路径变化或关键母线需要保障时，系统必须通过切换接触器来重配置供电拓扑，同时又不能让 AC 源并联、也不能让关键母线掉电太久。

论文的主体确实包含方法论，但它不是空泛谈方法，而是始终把一个具体的 aircraft EPS 当成主应用对象来展开。它给出了组件拓扑、变量划分、母线供电规则、接触器开闭延迟、关键母线掉电容忍窗口，以及中央/分布式控制器合成后的仿真结果。对 `sources/` 来说，我们关心的正是这条“根据 generator/bus/contactor 状态选择下一步重配置命令”的离散控制链。

## 控制系统在文中的位置

这套控制逻辑是全文的核心对象之一。作者不是把 aircraft EPS 当成随手举的形式化案例，而是围绕它来定义环境变量、受控变量、依赖变量和时钟变量，并用这些对象来描述应当如何安全地控制接触器。特别是在简化 case study 里，`4` 个 generators、`4` 个 buses 和 `7` 个 contactors 的关系被写得很清楚，方便后续把它还原成 EFSM。

更具体地说，论文里的控制系统并不是一个简单的 if-else 列表，而是一个带时钟的重配置自动机。它既要考虑 generator health、bus power status 和 contactor intent / state 之间的组合关系，也要处理 `50 ms` 级别的关键母线供电限制和 `10 ms` 级别的接触器动作 tick。这样一来，它在文中的角色更接近“受约束的离散电源重配置 supervisor”，而不是单纯验证对象。

## 对我们为什么有用

这篇材料对 `sources/` 的意义很大，因为它补的是一类在航空领域里很少见但对状态机建模很有价值的样本：不是飞行任务管理，也不是航迹切换，而是机载电源分配系统的离散重配置控制。它能把 `EFSM + T1 + 显式时钟 + 资源互斥` 这些要素同时落到一个具体工程对象上。

从数据集角度看，这篇论文的优势在于控制语义密度很高。除了状态空间和动作外，它还保住了关键的时序与安全语义，比如“关键母线最多掉电 50 ms”“每个 tick 代表 10 ms”“接触器意图与物理状态分离”“不能并联 AC 源”。这些内容非常适合后续做时序需求、异常恢复链和受约束配置切换的文本建模。

## 如果需要人工细读，建议怎么读

如果后续需要人工重读，建议先看第 1-2 章里系统拓扑和组件说明，只确认 generator、bus、contactor、battery、APU 各自扮演什么角色；然后直接跳到第 3 章的 specification 和 case study 部分，把安全约束、时钟变量、接触器延迟和简化拓扑的变量定义先抓稳。第一次细读的目标，不是通读全部合成算法，而是先把“控制器到底在决定什么、受哪些时间约束、通过哪些变量观察环境”这件事读清。

在第二轮阅读时，再看合成结果图和仿真页，用具体 step 去核对重配置序列怎样响应 generator failure、怎样维持 bus power status、怎样避免 source paralleling。这样读能最大化保住控制对象的离散核心，而不会在一开始就被大量时序逻辑或工具细节分散注意力。
