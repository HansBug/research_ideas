# 多层自动停车 PLC 控制器 / PLC Based Automatic Multistoried Car Parking System

## 论文在讲什么

这篇论文讨论的是一个半圆形多层自动停车原型怎样用 PLC 做成完整的停车机构。作者面对的核心问题很直接：城市停车空间紧张，人工停车既占地又容易出错，因此他们设计了一套四栋、每栋三层的停车装置，通过垂直升降、圆周旋转和托盘推进来把车辆送到目标车位。整篇论文虽然篇幅不长，但系统组成写得并不含糊，包含了光电接近传感器、DC 齿轮电机、限位开关、三只气缸和 PLC I/O 扩展模块等关键部件。

从控制角度看，它最有价值的地方是把“车进入升降台后发生什么”写成了连续的工程链条，而不是只给一张设备照片。论文说明了空位检测来自各层传感器，停车目标由 PLC 根据预设优先级选定，升降与旋转运动通过电机和限位开关精确停止，最后再由气缸把托盘送入车位，停车成功后系统再回到原点。这种输入、决策、动作、确认、复位俱全的写法，正好适合我们抽取状态机样本。

## 控制系统在文中的位置

这里的停车控制器不是论文里的陪衬，而就是论文的主体。作者当然也介绍了机械结构，但这些结构说明的目的，是为了支撑 PLC 控制逻辑为什么要分成垂直运动、旋转定位和气动推送这几段。换句话说，机械部分与控制部分是绑在一起的，控制器负责把一辆车从入口托盘送到指定楼层和楼栋，再把机构退回待机位。

对 `sources/` 来说，这类论文和很多只有“HMI 监控 + 车位显示”的停车短文不同。它不是只在入口做一个开闸或计数，而是明确涉及 lift、pallet、building/floor selection、completion acknowledgement 和 return-to-home 这样的系统级控制主链。因此它能补进停车领域里更像真实设备控制器的一类样本，而不仅是管理界面或门禁逻辑。

## 对我们为什么有用

这篇论文对样本库最有用的地方，在于它把停车系统写成了一个相当典型的 `EFSM + T0` 控制对象。它既有离散模式切换，也有足够清晰的 guard 和动作输出：入口光电传感器确认车辆进入、各层传感器回报空位、PLC 决定目标楼层、限位开关保证精确对位、DCV 驱动三只气缸把车推出、停车完成传感器再触发回原点。这样的链条写出来后，后续既能做人类可读的状态机自然语言，也能转成更结构化的数据条目。

另一个价值是它能帮助停车领域的样本不再只围绕“入口控制”和“空位显示”。文库里如果长期只有门禁、密码、RFID 或 HMI 这类近题，就会把停车方向收窄成管理系统；而这篇样本提供的是设备本体的运控语义。对于后续要研究“自然语言需求如何生成状态机”的任务，这类设备级控制链明显比界面型短文更适合。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1-2 页的摘要、引言和 escalator mechanism 部分，先把系统边界弄清楚：它到底有几栋、几层、什么传感器、什么执行器，垂直运动和圆周运动分别靠谁完成。接着直接跳到第 3-5 页，看气动机构和 `4.2 Role of PLC`、`VI. Overall working` 这几段，把“车进入后如何选位、如何送达、如何确认完成、如何复位”的主链抽出来。第一次读不需要被原型结构细节拖住，关键是先把控制闭环读顺。

第二轮如果要重写更细的 `STM.md`，再回头核对限位开关、楼层传感器和三只气缸的具体作用分工，必要时结合图 2.2、图 3.x 和图 6.1 看运动关系。机械尺寸、元件选型和手动模式部分可以放到后看；对我们最重要的仍然是 PLC 怎样把感知、定位、推送和回原点串成一条稳定的离散控制链。
