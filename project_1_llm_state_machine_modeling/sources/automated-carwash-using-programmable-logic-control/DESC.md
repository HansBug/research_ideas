# 自动洗车 PLC 控制系统 / Automated Carwash Using Programmable Logic Control (PLC)

## 论文在讲什么

这篇论文讨论的是一个小型自动洗车设备如何用 `OMRON SYSMAC CPM2A PLC` 做顺序控制。系统把车辆通过输送带送过多个工位，依次完成进场准备、喷水、喷洗涤剂、刷洗、漂洗、吹干和出场停机。输入侧主要是 `Start/Stop` 按钮、`Sensor 1-6` 和定时器，输出侧则是 conveyor、三路 pump、brush motor、fan 以及红绿指示灯。

论文不是只说“做了一个洗车原型”，而是把控制链分得比较细。正文既有总流程说明，也有 ladder diagram 运行解释和结果页的逐工位测试叙述，所以可以把它读成一条比较完整的工业顺序控制器叙事：什么条件下进入下一工位、哪个执行件什么时候打开、旧工位输出何时关闭、系统何时回到 ready 状态，都有明确线索。

## 控制系统在文中的位置

这里的控制系统就是论文主体本身。文章的方法、仿真和结果几乎都围绕这一套自动洗车 `PLC` 程序展开，没有明显把状态机控制退化成附属实现细节。对于 `sources/` 来说，它属于典型的“具体设备 + 传感器 + 执行件 + 局部定时 + 顺序阶段”样本。

更具体地说，文中的状态机价值不只在于“有一个 flowchart”。作者把 `Sensor 1-6` 与各个工位的 actuator 绑定起来，还补充了 `TIM000` 与最终停机延时如何驱动 ready/running 切换和回初态，因此我们关心的控制系统描述在这里是主角，而不是方法论文中的随手示例。

## 对我们为什么有用

对 `project_1` 的样本库而言，这篇论文的价值在于它提供了非常标准、同时又足够细的 `EFSM + T1` 工业控制链。它既保留了状态推进的主顺序，也保留了触发输入、局部定时、输出动作与停机回环，非常适合做“从工程论文抽自然语言状态机描述”的正样本。

另外，这篇论文还能帮助平衡当前文库中的领域分布。工业自动化方向虽然已有不少 `PLC` 样本，但真正能同时把输入传感器、工位动作和回初态链写到双 A 级别的原文并不算过多。相比那些只给原理图或短流程图的弱样本，这篇文献更容易稳定抽出高质量 `STM`。

## 如果需要人工细读，建议怎么读

如果后续需要人工复核 `STM.md` 或重新抽样，建议先看第 2-3 页的 `Methodology`，先确认系统边界和 `Sensor 1-6` 对应的六个工位顺序。随后直接跳到第 5-6 页的 `Simulation of the System`，这里最适合核对 `TIM000`、各传感器输入、各执行件输出和停机延时。最后再看第 8-10 页的 `Results and Discussion`，用实测叙述确认各工位切换时旧输出何时关闭、新输出何时打开。

相对而言，硬件外观图和器件布局图可以放到第二轮再看。它们有助于理解原型实现，但不是抽状态机描述的主证据。只要先抓住“进场延时 -> 六传感器顺序工位 -> 出场延时停机回初态”这条主链，后续人工重读时就不容易被原型细节带偏。
