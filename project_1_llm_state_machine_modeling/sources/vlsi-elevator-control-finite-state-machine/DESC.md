# 三层电梯 Mealy 状态机控制器 / A VLSI implementation of elevator control based on finite state machine using Verilog HDL

## 论文在讲什么

这篇论文研究的是一个三层电梯控制器的 Verilog / VLSI 实现。文章整体不复杂，重点在于把电梯控制问题明确建成一个 Mealy 有限状态机，再用二进制状态编码实现到数字电路设计工具链里。相比很多只画梯形图或只讲 PLC 接线的电梯论文，这篇文章从一开始就直说“elevator control system is a Mealy finite state machine”，因此样本边界非常清楚。

论文把每一层都映射成状态变量，再用 `EIDENTIFY`、`B1/B2/B3`、`S1/S2/S3` 等控制变量去描述电梯是在当前楼层、正在上行还是正在下行。更关键的是，它没有只给一个抽象框图，而是把 `1 -> 2`、`1 -> 3`、`2 -> 3`、`2 -> 1`、`3 -> 2` 等迁移在状态表和设计规则里逐项写出来，所以这篇文章虽然工程层次不高，但状态机信息非常密集。

## 控制系统在文中的位置

这里的控制系统描述就是论文主体。作者不是借电梯举一个例子来说明 Verilog，而是把“如何用有限状态机实现电梯控制”作为主要研究内容。状态表、状态图、方向编码和各楼层间的迁移条件，共同构成了整篇论文最核心的技术内容。

这也使它和当前文库中那些 `PLC + door timer + 同向优先调度` 的电梯样本不太一样。那些论文通常更接近 `EFSM + T1` 的楼宇执行控制，而这篇文章更像一个简洁、纯粹、可直接枚举转移表的 `FSM + T0` 电梯控制器。两者都属于电梯控制，但在状态机画像上差异很明显。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是 `🏢` 领域里较少见的 plain `FSM` 样本。现有楼宇机电条目多数都带门控延时、障碍重开门、自动/手动模式等工程化附加逻辑，而这篇文章更接近一个教学但完整的“楼层状态 + 方向编码 + 请求触发迁移”电梯控制器，非常适合用来平衡电梯领域内部的状态机类型分布。

它还有一个实际好处，就是文本非常适合做离散控制链数据集。输入和输出变量简单，状态集合小，转移规则直接写在表里，不需要从大段背景说明里硬抠状态。这类样本对于训练模型识别“状态表型控制逻辑”很有帮助，也适合作为更复杂电梯样本的对照基线。

## 如果需要人工细读，建议怎么读

人工细读时，建议直接看第 `2` 页。第一轮优先读 `Section 2 Algorithms`、状态表和设计规则，把三件事先钉住：`EIDENTIFY` 三种编码各表示什么；楼层状态如何表示；每一条从某楼层到另一楼层的迁移由哪些控制变量组合触发。只要这三件事确认了，这篇论文的主状态机就已经非常完整。

第 `1` 页的背景介绍只需要快速浏览即可，用来确认作者的实现目标和为何选 Mealy FSM。第 `3` 页开始的器件利用率、时序分析、RTL schematic 和综合结果可以放到第二轮再看；除非你要追实现资源占用，否则这些内容对抽取状态机主链的帮助不如第 `2` 页直接。
