# 飞机电气分配系统有限状态重构控制 / Finite state machine control for aircraft electrical distribution system

## 论文在讲什么

这篇论文讨论的是更电飞机 `MEA` 背景下，机载电气分配系统在复杂供电条件和故障条件下应如何自动重构。作者关注的不是单个控制回路，而是整个 `EPS` 网络在发电机、蓄电池、除冰负载和 avionics 负载之间怎样切换功率路径，才能既维持关键负载供电，又避免电网进入危险工况。论文因此把问题建模成一种反应式控制逻辑，而不是单纯的电力系统计算。

文中最关键的系统是一个用 `Stateflow` 实现的有限状态控制器。它接收负载功率需求、蓄电池 `SOC` 等输入，输出 `PowerInj`、`Shedding`、`NoEssential` 之类控制量，决定由发电机单独供电、发电机与电池联合供电、还是在供电同时切除非关键负载。换句话说，这篇论文虽然场景在航空供电网络，但它真正有用的部分是“负载需求与 `SOC` 驱动的离散重构监督器”。

## 控制系统在文中的位置

控制系统描述在文中是主线，不是背景。论文前半部分先交代传统知识库方法和 `LTL` 方法的局限，然后明确提出把 `EPS` 视为 reactive system，并把 `FSM` 作为新的管理逻辑来处理电力路径重构。到了建模部分，作者直接把 civil aircraft 的 de-icing 与 avionics 子系统写进同一个模型，配上 vital / non-essential loads、接触器与双向电池变换器，再用状态机来决定系统配置。

更重要的是，文中不是只说“有五个状态”，而是给出了每个状态的工程语义。`STATE 1` 是发电机供负载并给电池充电，`STATE 2` 是电池断开，`STATE 3` 是发电机和电池联合供电，`STATE 4` 是带 shedding 的充电态，`STATE 5` 是带 shedding 的联合供电态。对 `sources/` 来说，这种“状态名 + 输入条件 + 输出行为 + 故障后切换路径”写法非常适合作为高质量 EFSM 样本。

## 对我们为什么有用

这篇论文对文库的意义在于，它补进了一种与传统交通灯、电梯、停车控制很不一样的航空电源管理样本。这里的状态不是简单的动作顺序，而是面向系统重构的配置态；转移 guard 也不是门磁、红外或按钮，而是 `PL` 与 `SOC` 这类电力系统变量。这样的样本有助于把 `FSM/EFSM` 的覆盖面扩展到“离散逻辑 + 连续电气量耦合”的工程控制器。

同时，这篇论文也非常适合后续做验证与修复相关研究。因为它本身就把 `FSM` 和 `LTL` 放在同一问题语境中讨论，又给出了 generator fault 下如何进入 `STATE 3/5/4` 的重构主链。后续如果要从自然语言描述继续抽验证性质、故障恢复链或配电策略一致性条件，这篇论文能提供比一般“能源管理框图稿”更扎实的入口。

## 如果需要人工细读，建议怎么读

人工重读时，建议先跳到第 3 页的 `4 Logic description` 和 `5 From the theory to the model`，先把控制器输入输出、受控对象范围和 `Stateflow` 在文中的角色读稳。然后马上看第 4-5 页的 `Table 1` 和仿真说明，把 `STATE 1-5` 的含义、`PL` 与 `SOC` 的分段关系、以及 generator fault 后状态如何演化按顺序重新抄一遍。

第一次人工复核时，不需要把更多篇幅放在 `MEA` 背景综述或电力系统一般介绍上。真正值得优先看的，是“故障后先进入哪个状态、什么时候启用电池、什么时候触发 shedding、低 `SOC` 时如何回退”这几处；只要把这条离散重构链读清楚，这篇论文就足够支撑一个高质量航空 `EFSM` 样本。
