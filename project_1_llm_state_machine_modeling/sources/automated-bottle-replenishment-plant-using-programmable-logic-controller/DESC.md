# 瓶型判别、缺陷剔除与灌装封盖控制 / Automated Bottle Replenishment Plant using Programmable Logic Controller

## 论文在讲什么

这篇论文讨论的是一条 `PLC` 驱动的瓶装生产线。系统不只是做单瓶灌装，而是把瓶体检测、大小瓶区分、质量判别、灌装、封盖、缺陷瓶剔除、crusher 回收和末端分拣一起并入同一条自动控制链。

文章虽然篇幅不长，但给出的结构明显比普通“瓶子到位后定时灌装”的短稿更丰富。前半部分说明了输入模块、输出模块和 tank-level 传感器，后半部分则把 bottle detection、filling、user-defined volume 和 capping 这些子流程按顺序展开，便于直接抽成状态机描述。

## 控制系统在文中的位置

我们关心的控制系统描述在文中是主角。作者确实介绍了 PLC、继电器驱动和模块划分，但这些内容最终都是为了回答一个更具体的问题：不同瓶型、不同质量状态和不同位置上的瓶子，怎样被同一套控制器分流到对应的灌装、剔除、封盖和包装路径。

它和很多单纯的教学型灌装例子不一样，因为这里有明确的分支和并行感。大瓶/小瓶切换、缺陷瓶 reject、process tank 的 `LLS/HLS/MLS` 补液逻辑，以及“当前一批封盖时下一批开始灌装”的链路，都让系统结构更完整。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是离散制造方向里更复杂的一类瓶装控制样本。它不是只有一条短定时链，而是把质量检测、大小瓶分路和回收支路也保住了，因此对后续训练“带条件分支的 `EFSM`”会更有区分度。

另一个价值在于，它保留了不少具体 guard 和动作：`IR` 检测、大小瓶开关、质量传感器、预设 timer、三组 actuator、box level sensor 和第三 conveyor 分流。这种“输入信号明确、执行器明确、分支明确”的工程材料，对后续自动建模很有帮助。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看第 2-4 页的 `Methodology`、`Input Module`、`Series of Operations`。先把前端检测、填充位停止、process tank 补液、用户设定体积和封盖位停止这几段主链连接起来，再单独核对缺陷瓶 reject 和末端大/小瓶分流支路。

如果后续需要补更细的状态边界，再回看输入与输出模块部分，把四组 `IR` 传感器、七个液位传感器、五台泵和三组 actuator 的职责一一对应好。相比之下，前面对 PLC 一般性的背景介绍不是重做 `STM.md` 时最优先的材料，可以后看。
