# 左心室压容环有限状态机建模与控制 / Finite state machine implementation for left ventricle modeling and control

## 论文在讲什么

这篇论文研究的不是一般意义上的心脏生理分析，而是怎样把左心室压力-容积循环写成一套可在确定性实验平台上运行的有限状态机控制结构。作者希望用它来驱动一个液压 `mock circulatory system`，从而在体外复现实验对象的 preload、afterload 和 contractility 变化，并支撑后续心室辅助装置或个体化治疗方案的验证。

它的技术主体是把典型左心室压容环拆成四个相位，再用 `Simulink/Stateflow` 实现逻辑式相位治理。这样做的意义在于，相比只用连续方程求解，`FSM` 写法更便于固定采样率执行，也更适合部署到需要确定性处理的实验控制平台上。

## 控制系统在文中的位置

这里的控制系统是全文的中心对象之一，而不是辅助案例。摘要就直接把贡献写成“finite-state machine governance of a left ventricle model”，方法部分进一步展开 `Mealy machine`、状态图、输入变量和输出力，结果部分则围绕这套控制器在不同 preload / afterload / contractility 变化下的仿真表现来验证它是否可用。

对 `sources/` 来说，最重要的是它把“医学对象 + 明确相位状态 + 固定采样执行 + 物理执行输出”这几件事放在了一起。也就是说，这不是单纯的生理相位描述，而是一套真正驱动实验左心室装置的相位控制器。

## 对我们为什么有用

这篇论文补的是 `🩺` 方向里相对少见的“实验心室执行控制”样本。库里已有不少起搏器、外骨骼和假肢控制器，但把心动周期压容环显式写成 `Mealy` 状态机并直接输出执行力的条目并不多，因此它对扩展医疗控制对象边界很有价值。

另外，它还提供了一种很适合做 `EFSM + T1` 对照的素材。状态名本身来自生理相位，但转移依赖的却是 `LVESP / LVESV / LVEDV / LVEIRP / P / V / t` 这组连续变量和固定采样更新，因此非常适合用于研究“领域相位语义如何落成工程状态机”。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `1` 页摘要与方法概述，只确认系统边界、应用目标和为什么作者要把左心室模型写成 `FSM`。随后直接跳到第 `10-11` 页，把 `Mealy machine` 状态转移图、输入变量、输出 `Force` 和 `1024 Hz` 执行方式完整读出来；再回到第 `4` 页附近的压容相位说明，把 `filling / isovolumetric contraction / ejection / isovolumetric relaxation` 四个状态与图中的关键点对上。

像更早章节中的生理背景、数据提取和曲线拟合细节，以及后面的多组仿真曲线，可以放到第二轮再看。第一次阅读最关键的是先把“哪四个状态、用什么量切换、输出什么执行量、以什么采样方式运行”这条控制主链稳定下来。
