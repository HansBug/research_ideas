# 复杂场景下基于层次状态机的自动驾驶行为决策框架 / Decision Making Framework for Autonomous Vehicles Driving Behavior in Complex Scenarios via Hierarchical State Machine

## 论文在讲什么

这篇论文研究的是复杂直道路况下自动驾驶车辆的行为决策。作者把问题表述为一个分层有限状态机决策系统：先判断当前场景，再评价候选驾驶行为，最后把选中的行为落实为具体执行动作。论文关注的不是底层横纵向控制，而是“车辆下一步到底应该自由行驶、跟驰还是换道”的高层决策逻辑。

方法上，这篇论文把传统规则式驾驶决策和连续安全距离建模结合起来。一方面，它保留了有限状态机的可解释层次结构；另一方面，它又用能效函数、车道空闲率和安全距离模型去评价不同动作，因此整篇论文既有明确的离散模式，又保留了实际道路决策里常见的约束计算。更重要的是，作者没有停在抽象框架层，而是明确写出了 `30` 个顶层子场景、四类候选动作节点，以及下层动作转移表/矩阵怎样从当前节点推到下一节点。

## 控制系统在文中的位置

我们关心的控制系统描述在这篇论文里是主角。标题、摘要、第 2 节的 `FSM mission planning model`、`Top layer scenario decision` 和 `Middle layer energy efficiency assessment`，都在直接解释这个自动驾驶行为决策器如何分层、每层负责什么、各层之间怎么传递结果。

对 `sources/` 来说，这篇论文的重要性在于它提供了一个比较典型的道路车辆高层监督器样本。与单纯写轨迹优化或连续控制性能的道路车辆论文不同，这篇论文明确区分了场景分类层、行为评价层和执行层，并把 `free driving / lane change / following` 三类主要行为以及下层 `acceleration / right lane change / left lane change / deceleration` 动作节点都写成了可追溯的离散结构，因此适合拿来做 `HSM + T0` 的道路车辆语料。

## 对我们为什么有用

当前 `🚗` 领域里能同时落到 `FSM/EFSM/HSM + T0/T1 + 双 A` 的样本一直偏少，尤其缺这种不是 `Hybrid/T2/T3` 的高层行为监督器。这篇论文虽然带有较多评价函数和安全距离推导，但真正承载系统逻辑的仍然是分层状态机，这使它比很多只写连续控制器的道路车辆论文更适合进入 `project_1` 的样本库。

它还有一个额外价值，就是帮助我们覆盖“场景识别 + 行为选择 + 执行落地”这种三段式决策结构。后续如果要做自动驾驶行为监督器的自然语言到状态机建模，这类条目能提供比单层状态机更丰富的层次信息，也能让模型学到“上层做场景划分，中层做评价筛选，下层再用动作转移表落实下一步”的组织方式。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看摘要，再直接读第 `2.2`、`2.3`、`2.4`、`2.5` 节。第一轮阅读只抓五件事：三层状态机分别干什么；顶层场景分成哪些主类与子场景；中层候选行为有哪些；这些行为分别受什么安全约束；下层动作转移表怎样把当前节点推到下一动作。只要把这五件事抓住，就能较快还原出一个比较清晰的高层 HSM 轮廓。

后面的安全距离公式、换道最小距离推导和仿真结果可以放到第二轮再看。那些内容对于理解作者如何量化“安全换道”和“跟驰”很重要，但对我们当前的 `STM` 提取来说，优先级仍低于层次结构、状态集合、动作节点和状态转移输入。如果后续需要补 guard 细节，再回第 5-8 页对应公式、表 1 和图 3 核对即可。
