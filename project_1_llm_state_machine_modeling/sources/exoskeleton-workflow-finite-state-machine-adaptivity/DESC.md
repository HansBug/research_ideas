# 工业外骨骼工作流监督器 / Adaptation of the support of an industrial exoskeleton based on the workflow – Finite-State-Machine based exoskeleton adaptivity

## 论文在讲什么

这篇论文讨论的是工业外骨骼在装配流程中的自适应支持问题。作者不是只从肌电或关节角度做连续控制，而是提出在现有外骨骼控制器之上再加一层工作流状态机，用作“上层工序监督器”，让外骨骼支持策略随着具体工位任务而切换。

文中用一个简单但非常具体的板件更换流程来说明方法：准备、拧松螺钉、搬运板件、重新拧紧。每个阶段对应不同的手腕支持方式，有的允许自由运动，有的只加强某个方向的屈伸，有的直接锁止手腕以帮助稳定。

## 控制系统在文中的位置

这里的状态机不是背景概念，而是论文主方法本身。作者的核心主张就是：仅靠底层外骨骼控制不足以覆盖工序变化，必须把“当前处于哪个作业步骤、该切什么支持策略”显式建模出来。因此，状态机在文中承担的是上层监督控制职责。

这点对样本库非常关键，因为我们拿到的不只是“外骨骼可以自适应”的结论，而是一套能落回状态、事件、支持动作和层次控制关系的完整描述。它比一般的康复步态分相论文更贴近工业任务状态机。

## 对我们为什么有用

这篇论文为 `sources/` 补入了一个比较少见的工业外骨骼监督控制样本。它既不是传统 PLC 顺序控制，也不是医疗康复里的 gait phase FSM，而是把装配流程知识、工具识别、螺钉数量统计和扭矩事件组合成了一个上层任务状态机。

做数据集时，这类样本很有价值，因为它体现了一种非常典型的“上层工作流监督器 + 下层执行控制器”的层次表达。后续如果要训练模型识别上层任务状态、下层执行方式和事件驱动转移，这篇论文提供了很稳的自然语言素材。

## 如果需要人工细读，建议怎么读

如果要人工重读，建议先看第 1 页摘要，先把 `superordinate controller`、`state machine describes the workflow` 这些总纲读清楚；然后重点读第 4-5 页的 `3.2 Praktische Anwendung`，这里直接给出了四个状态、各状态的支持方式，以及按钮、RFID、螺钉计数和扭矩事件如何触发转移。

第 2-3 页关于一般方法和相关背景的部分可以放到第二轮再看，它们主要解释为什么状态机适合建模工业工作流。若将来需要重写 `STM.md`，最优先保住的仍然是四个工序状态、各状态的支持策略，以及 `Taster / RFID / Anzahl_Moment / Moment > 12 Nm` 这些转移触发依据。
