# REBot 瞬时动态避障四足机器人 / REBot: Reflexive Evasion Robot for Instantaneous Dynamic Obstacle Avoidance

## 论文在讲什么

这篇论文讨论的是四足机器人在极短反应时间下如何对高速动态障碍做出“反射式”规避，而不是依赖常规导航重规划。作者指出，当障碍逼近时间小于约 `1.5 s` 时，很多基于轨迹重规划的避障方法已经来不及，机器人需要像动物脊髓反射那样，先做快速闪避，再在事后恢复稳定。围绕这个目标，论文提出了一个叫 `REBot` 的控制框架。

系统核心不是单一策略网络，而是一个把 `Normal`、`Avoidance` 和 `Recovery` 三个阶段组织起来的 FSM。正常阶段执行本职动作，探测到接近障碍后切换到避障阶段，由 RL 策略产生快速规避动作；如果规避后姿态、关节速度或底盘高度表明机器人不稳，则再进入恢复阶段，把姿态拉回到默认稳定状态。整篇论文后半部分又用仿真、消融和真机实验去验证这条控制链，而不是只给一个算法框图。

## 控制系统在文中的位置

我们关心的控制系统描述在文中就是主角。论文虽然也讲了奖励函数、curriculum 和 sim2real，但这些内容本质上都是围绕“这个三态 FSM 怎样才能真正稳定工作”展开的。换句话说，控制系统不是“用来展示学习方法的载体”，而是学习方法服务的对象；离散阶段划分、转移判据和恢复机制都是方法成立的前提。

尤其值得保留的是它把恢复阶段单独立起来，而且明确给出进入恢复的三条不稳定判据：姿态角超阈、关节速度超阈、底盘高度跌破阈值。随后论文又用 ablation 说明，去掉 recovery stage 后，在 reflex 区间成功率会下降约 20%。这就让 `Recovery` 不再只是“也许可以加一个后处理”，而是实打实的控制链组成部分。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是通用机器人控制方向里一种非常有辨识度的样本：高速动态障碍规避不是靠单一连续控制律，而是靠“正常-避障-恢复”三态 supervisor 去管理。当前文库里虽然也有一些移动机器人、无人机或车辆避障样本，但像这样把恢复链和成功率消融一起说清楚的四足机器人安全控制器并不多。

它也非常适合作为双 A 正例，因为原文同时保住了状态名、触发 guard、恢复条件、阶段内动作目标和实验上的功能性验证。后续若要让模型从自然语言恢复状态机，或者在验证失败后回原文补“什么时候应该回退到 Recovery”，这篇论文都能提供比普通避障算法文更扎实的离散控制语义。

## 如果需要人工细读，建议怎么读

如果要人工重做 `STM.md`，建议先看第 1-2 页摘要和引言，只确认应用场景、`< 1.5 s` 的反应时间问题以及为什么导航重规划不够快。然后直接跳到第 3-4 页的 `IV-A` 到 `IV-C` 和 Figure 3，把 `Normal / Avoidance / Recovery` 三个阶段、从障碍接近到进入 `Avoidance` 的条件、以及由姿态角/关节速度/底盘高度阈值触发 `Recovery` 的条件完整标出来。接着再看第 5-7 页实验和 ablation，把 `ASR`、`RSR` 以及“去掉 recovery stage 成功率下降约 20%”这几个结果补回来。

关于奖励函数的每一项、curriculum 学习细节和模拟器训练设置，可以放到第二轮再读。它们有助于理解为什么策略学得好，但若当前目标是提取状态机样本，第一轮更重要的是先固定离散阶段、转移判据、恢复逻辑和实验上对恢复阶段必要性的验证。
