# 自动仓储站的 FIFO 入库-出库顺序控制 / Creating Programmable Logic Control Program for a Storing Station

## 论文在讲什么

这篇论文讨论的是一个自动仓储站如何用 Siemens PLC、TIA Portal 和 PLCSIM 建立完整的入库与出库顺序程序。对象并不是泛化的自动化教材例子，而是带有传送带、机械臂、气缸、夹爪、坐标传感器和库存位置映射的仓储站模型，目标是让物料按 `1 -> 20` 顺序入库，并按 `20 -> 1` 顺序离库。

它最有价值的地方，在于把“顺序控制”真正写到了变量和功能块级别。文中不仅给出 `C0/C1/C2`、`A0-A4/B0-B3/K0`、`M3/M4`、`FC1/FC2/FC3/FC5` 这些离散控制元素，还把取料、放料、计数和位置选择过程逐步写了出来，因此很容易抽成一条细粒度 EFSM。

## 控制系统在文中的位置

我们关心的控制系统描述就是论文主体。第 7 章先给出 storing/leaving 两条顺序流程，后面又用 PLC 变量表、传感器位置、功能块和梯形图结果逐步解释机械臂如何执行这些流程，所以这不是“讲 PLC 语法时顺手带一个 demo”，而是完整的自动仓储控制程序。

这类样本对 `sources/` 很重要，因为它兼顾了离散制造场景里的计数、顺序、坐标、执行器与局部定时。很多制造类论文会漂向单个输送带、单个瓶装模块或只剩硬件搭建，而这篇保住的是从入口输送到货位映射再到逆序离库的主控制链。

## 对我们为什么有用

它补进了一类比较典型但文库里还不算密集的自动仓储控制样本。和瓶装灌装、颜色分拣、贴标拒收这些线型顺序控制相比，仓储站样本更强调“库存位置映射 + 机械臂坐标动作 + FIFO 规则”三者的联动，因此对象画像更完整，也更适合训练复杂一点的离散控制建模。

另外，这篇论文非常适合做 `T1` 样本。虽然整套系统主要靠事件和位置推进，但 `Z` 置位后的 `2` 秒放料延时、传送带暂停、抓取/放置切换这些局部工程时间语义都写得比较清楚，能有效区分它和纯 `T0` 的静态顺序控制器。

## 如果需要人工细读，建议怎么读

建议先从第 26-28 页读起，把 storing flow 和 leaving flow 的主链先抓住，尤其是 `C0 -> C1 -> 计数 -> 目标位 -> 抓取 -> 放置` 与 `station full + LEA -> 20 -> 1` 这两条链。接着读第 34-45 页，把变量表、机械臂电机状态、`M3/M4`、`FC3/FC5` 和 `2` 秒放料延时对上。

第一次回原文时，不需要先把整本论文的 PLC 和 TIA Portal 背景都看完。真正有价值的是：哪些传感器定义了状态推进、哪个内存字代表货位、抓取和放料怎样通过功能块串起来、离库为什么从 `20` 逆向回到 `1`。这几部分读稳后，这篇论文就足以稳定支撑一个双 A 制造控制样本。
