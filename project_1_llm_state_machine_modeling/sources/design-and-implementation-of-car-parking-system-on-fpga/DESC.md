# FPGA 车库管理状态机 / Design and Implementation of Car Parking System on FPGA

## 论文在讲什么

这篇论文研究的是停车场入口控制与车位分配系统，不过它不是做传统摄像头路径规划，而是做一个比较典型的“门禁 + 身份识别 + 车位状态判定”离散控制器。作者把停车系统实现到 FPGA 上，用状态机建模身份识别和车位分配模块，再通过 LCD、步进电机、RF 模块和 LED 做出一个可运行原型。

从系统形态上看，这篇论文更像停车场运营控制，而不是自动驾驶泊车轨迹控制。它关心的是车进门时有没有空位、门该不该开、来车是不是已注册用户、新用户是否发临时卡、哪个车位是空的/已满/已预留，这些都非常适合转写成离散状态机描述。

## 控制系统在文中的位置

控制系统描述在这篇论文里就是核心。作者专门单列 `Finite state machine for the operation of the system` 和 `Designing of parking system with State Machine Diagram` 两节，明确说系统由 `Identification` 和 `Slot Selection` 两个模块组成，并给出 ASMD 图、步进电机开门、身份识别仿真、车位分配仿真以及整合后的 RTL 结果。

这意味着它不是那种“硬件实现附带提一句用了 FSM”的文章，而是真的把停车管理流程组织成一条状态机式工作流。对 `sources/` 来说，这种条目能补到 `🅿️` 领域里相对稀缺的 `EFSM + T0` 停车管理样本，与现有更偏 `Hybrid / T3` 的自动泊车轨迹类样本形成明显差异。

## 对我们为什么有用

这篇论文最有用的地方，是它补的是“停车管理控制链”而不是“停车运动轨迹控制链”。当前 `🅿️` 领域虽然样本不少，但很多集中在模糊控制并联泊车、轨迹修正或车位搜索。这里则是入口门禁、身份判定、车位分配和车位状态维护，更贴近停车场控制系统本身。

另外，它的原文很适合做状态机数据。ASMD 图把入口状态展示、门控、身份识别、车位判定和结果输出串得很直，仿真里又补了 `idle`、`slot 15 available`、`Identified / new_member`、`led_filled / led_reserv` 这些实现级信号。对训练模型识别“从硬件控制叙述恢复状态机”很有价值。

## 如果需要人工细读，建议怎么读

人工细读时，建议先读第 `4-5` 页关于 `state diagram` 和 `ASMD chart` 的段落，先把停车系统的四步主链抓出来：入口是否有空位、是否开门、来车是谁、最后怎么分配车位。第一轮不需要马上理解全部 HDL 信号，先把业务状态链读顺就够了。

之后再去看第 `6-8` 页的仿真结果，重点看三件事：步进电机开门是如何触发的，身份识别模块的 `current_state / next_state` 怎样区分已识别用户和新用户，以及车位分配模块如何输出 `slotallot`、`led_filled`、`led_reserv`。这些内容最能帮助后续把停车管理状态机写成高质量自然语言描述。至于前两节关于停车拥堵背景和相关工作，可以放到最后再补。
