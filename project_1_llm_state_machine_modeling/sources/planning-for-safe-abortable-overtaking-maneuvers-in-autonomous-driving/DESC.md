# 可中止超车行为规划器 / Planning for Safe Abortable Overtaking Maneuvers in Autonomous Driving

## 论文在讲什么

这篇论文研究的是双向道路上的自动驾驶超车问题。作者关注的不是静态场景里那种“看见前车就换道再换回来”的简化版超车，而是更接近真实道路的情况：前方有慢车，对向车道可能突然出现来车，系统必须在超车过程中判断是否继续前进，还是立即中止并安全并回原车道。

论文的系统结构很清楚。上层用一个行为状态机选择当前机动，下层用安全/可达区域与非线性模型预测控制去生成轨迹，因此这篇文章既不是纯连续轨迹优化，也不是只给概念流程图。它把离散机动链和连续轨迹规划耦合在一起，是一种很典型的“状态机管机动、优化器管轨迹”的自动驾驶控制写法。

## 控制系统在文中的位置

我们关心的控制系统描述在这篇论文里就是主体。论文的核心贡献之一就是这条四态行为规划链：`Lane Keeping / Follow Lead Vehicle / Overtaking / Aborting`。状态机不是辅助例子，而是整个超车方法的入口，因为后面的安全集生成、可达集求交、参考点选取和 MPC 轨迹求解，都要跟着当前状态走。

更重要的是，作者没有只写“支持 abort”这种高层口号，而是把状态集合、事件触发和一次完整的“跟车 -> 发起超车 -> 因潜在碰撞中止 -> 回到跟车 -> 再次超车 -> 恢复巡航”的运行链写进了正文。这一点让它非常适合 `sources/`，因为它能直接提供可追溯的状态机自然语言样本，而不是需要我们从图里硬猜。

## 对我们为什么有用

对 `sources/` 来说，这篇论文的价值主要在 `🚗` 领域补了一种当前仍然不算饱和的离散行为样本。现有汽车方向里已经有车队协议、城市任务管理和个别换道控制，但“超车可中止”这种以风险回退为中心的行为链仍然比较少，而且这里的状态机和安全约束耦合关系写得比很多自动驾驶论文更直接。

它还补到了一类对后续数据集很有价值的语言模式：状态不仅是动作阶段名，还对应不同的参考位姿与参考速度；转移条件也不是抽象的“满足安全性”，而是“检测到前车”“超车条件允许”“预测到碰撞风险”“完成并回到前车后方”这类可以直接转成 guard 的自然语言。这种写法很适合用来训练模型识别带回退分支的机动状态机。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `3-4` 页的 `Rule-Based Finite State Machines` 段和 `Fig. 4`。第一轮先把四个状态分别负责什么、`σ1-σ5` 五个事件各触发什么转移、各状态如何定义参考位姿与参考速度这三件事抓住。只要这三件事抓稳，`STM.md` 的主链已经足够完整。

第二轮再去看实验章节，尤其是第 `6` 页对 `t = 9.9 s` 发起超车、`t = 12.8 s` 中止、之后重新尝试的描述。这部分最适合补“状态机如何在真实运行中切换”的证据。至于安全集、可达集、多边形约束和 MPC 细节，可以作为后续补充理解来看，但它们对第一轮抽离离散状态机骨架不是最高优先级。
