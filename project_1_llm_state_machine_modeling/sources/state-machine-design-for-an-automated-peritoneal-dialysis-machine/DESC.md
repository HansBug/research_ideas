# 腹膜透析 FSM 与冲洗/排液监督控制 / State machine design for an automated peritoneal dialysis machine

## 论文在讲什么

这篇论文围绕自动腹膜透析机的有限状态机设计展开，目标是通过状态机、冲洗阶段和浊度传感器改进传统 APD 流程。当前 `STM.md` 抽到的核心对象是“医疗设备领域的自动腹膜透析机流程监督控制器”。

从现有条目看，文中的离散控制链属于 `EFSM（扩展状态机）`，时间语义属于 `T1（工程定时 / 局部定时）`。原文给出了状态图、`S0-S17`、16 个输入、18 个输出、状态转移表、故障报警 `11111`、浊度传感器和排液/冲洗条件，因此原文细节和描述细节都可评为 `🟢 A`。

## 控制系统在文中的位置

控制系统是全文的核心贡献。前半部分解释 APD 设备背景和系统组成，后半部分直接给出 FSM 定义、I/O 表、状态图、状态转移表和触发条件。与一般医疗综述不同，这篇论文的状态机证据非常集中且可追溯。

## 对我们为什么有用

它提供了一个医疗设备方向的强 EFSM 样本：用户模式选择、加热准备、灌注、排液、阀门控制、冲洗、浊度回路与错误报警都写成了可复用的状态转移。虽然医疗设备方向当前 A 级数量不低，但这篇论文的 FSM 显式性和原文质量都很高，适合作为严格筛选轮次中替代低位领域失败候选的强样本。

## 如果需要人工细读，建议怎么读

人工细读时先看摘要和第 7 页监控界面说明，确认流程包含准备、灌注、驻留、排液和冲洗；然后重点读第 8-12 页的 `Finite state machine`、I/O 表、状态图与状态转移表；最后用第 13 页之后的布尔方程和结论确认状态表不是抽象示意，而是面向控制实现的完整 FSM。
