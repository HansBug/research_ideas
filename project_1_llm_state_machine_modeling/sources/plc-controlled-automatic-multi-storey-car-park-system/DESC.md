# 多层停车仓升降与托盘顺序控制 / A PLC Controlled Automatic Multi-Storey Car Park System

## 论文在讲什么

这篇论文讨论的是一个用于教学和原型验证的三层自动停车库。系统不是只在入口统计余位，而是把车辆放到一个带有升降和横移能力的机械舱里，再由 `PLC` 控制主升降机构、托盘电机、限位开关和传感器，把车送到目标层和目标列。

论文的正文同时保留了英文摘要和比较完整的土耳其文实现说明，所以能看到比较清楚的控制客体轮廓：三层、三列、总共九个车位；用户要输入目标层密码；`PLC` 根据边界开关和传感器确定轿厢位置；再通过主电机和各层托盘电机把车送入或取出。它本质上是一个停车仓搬运控制器，而不是计费、导航或车位推荐系统。

## 控制系统在文中的位置

这里的控制系统描述属于论文的主对象。作者先用摘要和原型介绍说明停车设备的机械组成，再把真正的控制主链放到程序流程图和梯形图网络里。也就是说，我们关心的不是外围背景，而是“密码输入后，设备如何横移、升降、等待、推送和回初态”这条离散控制链。

论文最有用的部分是第 7-9 页。那里把传感器、边界开关、主升降机构和托盘电机的动作顺序写到了同一个流程图里，甚至明确给出了多次 `2sn` 等待。这让它不只是一个“多层停车概念原型”，而是能直接回译成 `EFSM + T1` 描述的工程控制样本。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是停车方向里相对少见的“机械搬运型多层停车仓”样本。现有停车条目中有不少入口门禁、密码校验和余位统计，但这篇更强调停车舱本体的横移、升降、托盘转运与回位过程，因此能把停车域样本从入口控制扩展到仓储式搬运控制。

它的另一个价值是原文与提取文本都比较能打。虽然流程图里的部分文字带有轻微提取空格噪声，但密码、目标层、主电机、托盘电机、边界开关和 `2` 秒等待这些关键件都保留下来了，后续重写数据集样本时不需要再去猜“动作顺序到底是什么”。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1 页摘要，先锁定系统边界：这是三层九车位的自动停车仓，`PLC` 通过密码、操作请求和边界开关控制车辆入库和出库。确认这一点后，直接跳到第 7-9 页，优先重读程序流程图和梯形图说明，把“密码输入 -> 主电机横移 -> `2` 秒等待 -> 托盘送车 -> 轿厢升降 -> 回初态”这条主链按步骤重新抄出来。

第 3-5 页关于自动停车库背景、`PLC` 一般介绍和机械总体优势的内容，可以放到第二轮再看。第一次人工复核最值得盯住的是：哪些传感器负责位置判定，哪些动作由主升降机构完成，哪些动作由托盘电机完成，`2sn` 等待插在什么节点上，以及入库和取车两条链是否共用同一套位置判断逻辑。
