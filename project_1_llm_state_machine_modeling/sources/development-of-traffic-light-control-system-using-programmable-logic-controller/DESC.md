# 四路口双传感 PLC 交通灯控制 / Development of Traffic Light Control System Using Programmable Logic Controller

## 论文在讲什么

这篇论文是一个围绕四向路口交通灯模型展开的本科项目，核心目标是用 Omron PLC 把传统固定配时交通灯改成“只给有车车道放行、并根据排队长度调整绿灯时间”的控制系统。文中把整套实现分成硬件和软件两部分：硬件是四车道红黄绿灯模型与每车道两只限位开关，软件则是在 `CX-Programmer` 里把车道切换逻辑翻译成梯形图。

从样本价值看，它不是那种只给一张框图和几个器件名的薄稿，而是把传感器放置方式、车道优先策略、每个相位的秒级停留时间，以及与常规固定配时方案的对比都写了出来。我们关心的控制链条在这篇论文里是主体内容，而不是顺手带过的演示。

## 控制系统在文中的位置

控制系统就是全文的主角。摘要、硬件章节、流程图章节和实验比较章节都在围绕同一件事展开：PLC 如何根据每个车道的 `sensor 1 / sensor 2` 决定当前谁先放行、绿灯是维持 `10` 秒还是 `20` 秒、何时转黄、何时切回全红并把下一条车道切成绿灯。

这使它非常适合被整理成状态机样本。相较于很多“交通灯 + PLC”近题只停留在器件连接或固定轮转时间，这篇论文把 `guard`、`timer` 和 `signal output` 的关系写得更明确，尤其是“先到优先”和“第二传感器决定绿灯延长”的部分，足以直接支撑 EFSM 化描述。

## 对我们为什么有用

这篇论文对 `sources/` 的直接价值在于，它补的是低位领域里的一个高细节交通信号控制样本，而且不是图像识别、模糊控制或大而化之的智能交通框架，而是很具体的 PLC 相位控制逻辑。对后续数据集构造来说，它能提供“多输入车道竞争 + 局部定时器 + 安全过渡相位”这一类非常典型的离散控制模式。

另一个价值是它提供了一个容易泛化的模板：每车道至少两类检测输入，第一类决定是否请求服务，第二类决定是否延长绿灯。这个模板对后续从自然语言恢复状态机时很有帮助，因为它天然对应“状态 + guard + timer + action”的组合。

## 如果需要人工细读，建议怎么读

人工重读时，先看摘要和硬件说明，确认四车道、双传感器和红黄绿输出的系统边界；然后直接跳到 `Traffic phase flowchart` 与 `Program flowchart`，把“`sensor 1` 抢占绿灯”“`sensor 2` 触发 `20s` 绿灯”“黄灯 `2s`”“安全等待 `2s` 后切下一车道”这条主链完整抄出来。最后再回到对比表，把新系统与固定配时系统的差别核一遍，确认这些时间规则确实是论文主张的一部分。

文中关于 PLC 一般原理、模块化硬件、I/O 卡和 Omron 手册的大段介绍可以后看。这些部分有助于理解实现背景，但不是重建状态机所必需的核心证据。
