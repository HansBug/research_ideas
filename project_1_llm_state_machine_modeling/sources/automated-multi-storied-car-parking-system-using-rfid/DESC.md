# RFID 门禁与升降机回位立体停车 / Automated Multi-storied Car Parking System Using RFID

## 论文在讲什么

这篇论文讲的是一个多层立体停车控制系统，核心由 RFID 门禁、车位信息显示、升降机搬运和楼层内入位构成。作者不是只讨论“停车管理平台”这种软件概念，而是把入口处的鉴权、楼层容量、升降机忙闲状态、报警反馈以及升降机回到地面待命的动作链都落实到 PIC、RFID、IR 传感器和电机控制上。

对我们最有用的，是它把停车系统拆成了几个连续、可执行的离散阶段：刷卡识别、数据库校验、显示房间号/车位号、分配停车位、升降机移动、到位停止、车辆离开后回到地面。它不是传统自动泊车轨迹控制论文，而是一个典型的“门禁 + 资源分配 + 搬运执行”式立体停车样本。

## 控制系统在文中的位置

停车控制系统本身就是论文主体。作者花了大量篇幅解释 RFID 读写、PIC I/O、IR 传感器与升降机控制，并在中间穿插了工作流图、输入输出分配和实物测试结果，所以我们关心的控制逻辑不是边角料，而是整篇论文的实现骨架。

更具体地说，文中的控制描述承担的是“把一个合法车辆怎样进入系统、如何被分配到楼层、升降机如何搬运、何时报警和何时返回初始位”的主流程说明。虽然论文也包含硬件细节，但这些硬件并没有掩盖控制链，反而让每个状态转换更容易追溯到具体输入和执行动作。

## 对我们为什么有用

它对 `sources/` 的价值在于补入了一个停车领域里相对少见的“RFID 门禁 + 升降机资源分配”样本。现有不少停车论文会偏向路径规划、模糊控制或者占位检测，而这篇更适合抽出一个清晰的离散控制机：合法/非法、空闲/忙、满位/可分配、上行/停靠/回位。

这类样本对后续状态机建模尤其有用，因为它天然同时具备 guard 条件和执行动作。像“卡是否合法”“第一层是否已满”“升降机是否忙”“目标 IR 传感器是否触发”“车辆是否已从平台离开”，都能直接转成状态切换条件，而 LCD、LED、报警器、电机启停则可自然转成输出或动作语句。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 1-2 页 的摘要和系统总述，只锁定系统边界：它是一个三层、九车位的立体停车控制器，并确认 lift free / first floor full / lift busy / valid RFID 这些关键分支。然后直接跳到第 6-8 页，把 `Figure 6` 的 RFID 工作流、数据库校验、房间号显示和报警逻辑一口气读完，先把入口鉴权与车位分配链条抽稳。

第二阶段再跳到第 14 页 附近看实物测试与升降机动作，重点确认升降机初始在地面、到位后由 IR 传感器停机、车辆离开后自动回到底层待命这条执行链。至于中间大量 RFID 原理、电路和元器件介绍，可以第二轮再看；第一次人工复核只需围绕“鉴权-分配-搬运-回位”这条主控制链组织阅读即可。
