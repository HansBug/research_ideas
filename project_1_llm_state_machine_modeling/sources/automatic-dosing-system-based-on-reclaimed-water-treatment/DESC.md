# 再生水处理自动加药控制 / Automatic dosing system based on reclaimed water treatment

## 论文在讲什么

这篇论文讲的是一套用于河道再生水处理设备的自动加药系统。作者的目标是替换人工调药方式，把来水流量、在线水质、经验修正和投药装置联成一条 `PLC` 自动控制回路，从而让再生水处理过程更稳定地达标。

文章并不是单纯介绍某个计量泵或某种药剂，而是把自动加药系统拆成 dosing、稀释配制、调节控制三部分，并说明了电动阀、流量计、液位计、搅拌器、变频器、隔膜泵和上位机接口之间如何共同工作。`P1 / P2 / P3` 三个系数和 `Q = Q1 x P1 x P2 x P3` 的设定公式，是全文最关键的控制骨架。

## 控制系统在文中的位置

我们关心的控制系统描述在文中是主角，而不是某个附带案例。论文的大部分正文都在解释自动调药为什么需要前馈、反馈和修正三层机制，以及系统怎样在 `local control` 与 `PLC control` 之间切换。

它和普通“过程设备介绍”类文章不同的地方，在于控制链已经被明确写成了一个完整的自动化闭环：上位机先算设定值，再由 `PLC` 驱动变频器和计量泵执行，随后用流量计反馈和 `PID` 再把实际投加量拉回目标值；这对后续做状态机描述非常友好。

## 对我们为什么有用

这篇论文为 `sources/` 补入了一类偏过程控制但结构很清楚的样本。它不是只有阀门开关或单一液位阈值，而是把模式切换、流量反馈、水质反馈、修正系数和阀泵执行放在同一条控制链里，因此很适合拿来做“带扩展变量的 `EFSM`”样本。

此外，这篇文章还保留了设备层与控制层之间比较完整的映射。读者不只能看到“系统会自动投药”，还能看到自动稀释、液位驱动加水、比例设定、`PID` 闭环跟踪和本地优先控制这些更细的约束点，这使它对后续精确抽状态/guard 很有价值。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看第 2-3 页 `3.1` 和 `3.2`。先把自动加药系统的三大组成部分、`P1 / P2 / P3` 三个系数和 `Q` 的计算关系理顺，再确认上位机、PLC、流量计、频率转换器和隔膜泵之间的信号流。

随后跳到第 4-8 页 `4.1-4.3`，重点看阀门、储药箱、液位计、搅拌器和 `PLC control mode` 的自动动作细节，尤其是“local control 优先”“可选 flow proportional dosing 或 PID closed-loop”这两条。至于前面的河道污染背景和后面的处理效果数据，可以放到第二轮再看。
