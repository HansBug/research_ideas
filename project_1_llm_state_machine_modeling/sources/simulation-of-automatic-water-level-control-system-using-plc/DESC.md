# 八级水位 PLC 控制器 / Simulation of Automatic Water Level Control System by using Programmable Logic Controller

## 论文在讲什么

这篇论文围绕一个 PLC 水位控制系统的设计与仿真展开，目标是用较低成本的电子水位传感电路和 PLC 梯形图，把水箱液位维持在设定范围内。作者没有只写一个粗略的“低水位开泵、高水位停泵”故事，而是把液位划成八个等级，用 `S1-S8` 逐级表示水面上升过程，并把这些液位级别、泵启动条件和泵停止条件对应到 PLC 输入和输出。

除了自动控制主链之外，论文还给了较完整的实现上下文：传感电路使用 AND gate，控制器用的是 Siemens `S7-1200`，同时还有星三角启动相关的电机回路说明。自动部分通过流图、梯形图和 I/O 名单写得比较明确，因此它不仅是“水位传感器设计”，而是一套从传感、PLC 到泵执行机构联动起来的完整水位控制系统。

## 控制系统在文中的位置

水位控制系统是这篇论文绝对的主角。传感器电路、手动控制和自动控制三个部分虽然都出现了，但它们并不是平行展示的三个小实验，而是围绕同一个受控对象组织起来的：如何让水箱在缺水时补水、在满水时停泵，并且在液位回落后再次自动启动。作者把自动控制部分单独拉出来给出 flow chart、ladder diagram 和 connection diagram，这一点说明他们关心的正是控制逻辑的可执行实现。

对我们来说，这样的论文很适合作为“顺序型液位控制”的代表样本。它和只讲元件介绍、或者只给一张简单流程图的 PLC 练习稿不同，真正把感知级别、触发阈值和输出联锁整理成了可追溯的主链。即使它属于常见水位方向，这种八级细分也让样本的状态展开程度明显高于很多只分上下限两态的短文。

## 对我们为什么有用

它对 `sources/` 的价值主要体现在两个方面。第一，它把水位连续变化离散成了八级状态，这比许多只保留“低/高”两级的控制稿更适合抽成状态机自然语言。状态 `S1-S8` 之间的推进、`S7` 触发补水、`S8` 触发停泵、跌回 `S7` 以下再重启，这些都是非常标准、也很容易复核的状态转移链。

第二，它把 PLC 的实际输入输出列表一起给出来了。`I0.0-I1.0` 这一组输入不只是液位开关，还包含 system start、stop、emergency、fail safe 等控制信号；输出也不只是 pump start/stop，还有运行指示和接触器控制。这意味着后续整理时，我们既能保留“液位状态机”的主语义，也能保留一点工程落地层面的实现线索，让样本更接近真实控制器描述。

## 如果需要人工细读，建议怎么读

人工重读时，建议先读第 4 页 `Operation Of Water Level Indicator Control System`，把 `S1-S8` 每一级水位对应的 LED、继电器与泵动作先串起来。这一段已经足够把主状态链抽出来。之后直接跳到第 5-7 页，看 `Automatic water level control system by PLC`、PLC ladder diagram 和 input/output list，把自动控制信号与前面的八级液位状态对齐。

如果后续要补更细的控制语义，再回看手动控制与星三角启动部分，确认自动泵启动和电机执行机构之间的关系。需要注意的是，论文里有一部分是在解释硬件实现与手动兜底，所以第一次阅读时不要被这些内容带偏；对我们最关键的仍然是八级液位状态怎样驱动 PLC 发出启停泵动作。
