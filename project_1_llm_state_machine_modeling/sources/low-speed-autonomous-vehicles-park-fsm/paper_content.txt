Abstract — Park is an important population and industry
gathering area in a city, and a popular scene in theoretical
research and technical application of automatic driving.
Decision-making, path planning and control are the core
technologies. Due to cost and safety issues, automatic driving has
not been widely used for park applications. In this paper, a
decision-making model is devised based on finite state machine
(FSM), a local path planner is designed based on Bézier curve
and the lateral and longitudinal control method is realized on
GAC Aion LX. This decision-making system for low speed
automatic driving in the park is tested. Results demonstrate its
accuracy and reliability.
I. I NTRODUCTION
As an important scene to realize autonomous driving,
low-speed autonomous vehicles in the park have great
commercial application potential. Decision-making, path
planning and control system are the key technologies of
automatic driving, in which much research has been
performed.
Finite state machine (FSM) is widely used in
decision-making system. Boss’s FSM based decision-making
system [1] defines the highest level based on driving scenes,
and defines the bottom layer based on driving behaviors. Three
highest levels and their corresponding bottom layers are lane
driving (made up by lane selector, merge planner, current
scene reporter and distance keeper), intersection handling
(made up by precedence estimator, pan-head planner and
transition manager), and achieving a zone pose (made up by
state estimator and goal selector) respectively. Talos [3], which
is good at logical clarity, divides its decision-making system
into lane finding, navigator, motion planner, controller,
drivability map and obstacle detector by logical hierarchy. But
it also has poor adaptability to complex problems. Junior [4]
divides its decision system into lane changes, U-turns, parking,
and merging into moving traffic. AnnieWAY [5] which
includes all relevant maneuvers in DARPA Urban Challenge
devides its decision system into DriveStart, DriveOnLane,
LaneChange, DriveKTurn, DriveStop and DriveRecover.

This paper presents a new decision-making system with
path planning and control methods for application in the park.
The lane change path is manipulated by setting control points
based on Bézier curve. A lateral and longitudinal control
method is used for path tracking. The road test results of the
decision-making algorithm demonstrate its accuracy and
reliability.
This paper is organized as follows: Section II summarizes
the system architecture. Section III describes the design of the
decision-making system which includes planning and control
method. Section IV shows the experiments and results of path
tracking and lane changing. Section V provides the
conclusions and discusses the future work.
II. A RCHITECTURE
Figure 1 shows the overall system architecture of this paper
including the following subsystems.
Road-Paint Detection using image-processing method to fit
splines to lane based on cameras data provides lane boundry
for drivability area.
Obstacles Detector uses lidar and cameras data to detect the
position, velocity, moving direction, size and category of the
objects.
Fusion of Positioning reconciles Inertial measurement unit
(IMU) information, global positioning system (GPS) and
Real-time kinematic (RTK) integrated positioning information
and point cloud matching positioning information, and outputs
the real-time positioning results with high precision finally.
The high precision map uses lidar and positioning data to mark
the pre-defined path and the hazard which is hard to detect by
Obstacles Detector, like hollow on the road.
Drivability Area reconciles the lane detection and high
precision map, answering queries from Local Path Planner of
the validity of drivability path.
The Path Tracker tracks the pre-defined path based on high
precision positioning.
These modules are all running based on Robot Operating
System (ROS), which provides efficient communication, a set

III. D ECISION -MAKING SYSTEM BASED ON FSM
The FSM that is used to switch between different driving
states is shown in Figure 2. There are 7 individual states in the
FSM, which correspond to the following conditions.
StateEstimator: this state receives the vehicle’s position, lane
information, obstacles information and drivability area, andfilters out the useless information.
StopAndWait: this state enables the autonomous vehicle to
wait for pedestrians and other cars in the opposite lane passing
when lane changing.
DistanceKeeping: information provided by perception system
is used in this state to determine the necessary safety gaps
between two vehicles and adjust the speed of the autonomous
vehicle accordingly.
ConstantSpeed: in this state, the autonomous vehicle goes at
the default speed which is 3m/s.
LaneChoosing: this state uses the perceptual information to
determine the optimal lane to be in at any instant and evaluate
whether it is feasible.
LocalPlanner: path planning based on Bézier curve is used in
this state to merge into a lane proposed by lane choosing.
VehicleController: control system based on lateral and
longitudinal control is used for path tracking.

B. Lane Choosing
In this paper, overtaking other cars on the road isn’t
considered. Hence, Lane Changing is only considered when
avoiding static obstacles. Firstly, consider whether there are
incoming vehicles in the opposite lane when encountering
obstacles. If there are incoming vehicles in the opposite lane,
stop and wait until the vehicles pass. Secondly, return to the
original lane if passable, for staying in the opposite lane may
cause accident.
C. Local Planner
The following three problems are one of the most difficult
problems in path planning in order to reduce the probability of
traffic accidents in the park[9].
(1) The path should meet the constraints of vehicle
dynamics.
(2) The path should ensure driving comfort and safety.
(3) The path planner should be able to do path planning
adaptively under different circumstances.
To solve the problems above, a real-time local path planner
based on Bézier curve is proposed.
Nowadays, Bézier curves are widely used in computer
graphics and animation, for which it has the advantages of
continuous curvature, easily tracking and meeting vehicle
dynamics constraints. Therefore, Bézier curve is selected for
path planning in this paper.

B. The result of experiment
(1) Path tracking experiment
This paper did the automatic driving experiment in a
parking lot. Figure 10a showed the trajectory of tracking, in
which the dotted line is the tracking path and the solid line is
the original path. The tracking error is 0-13.51cm, and the
average error is 5.42cm. In conclusion, the path trackingalgorithm in this paper can track with high accuracy, especiallywhen turning.
The accuracy of tracking largely depended on the shortest
value of look-ahead distance
dl.dlshouldn’t be too small, for
which it might cause the oscillations of vehicle motion
although smalldlwould make tracking more accurate.
However,dlshouldn’t be too large, for which the vehicle
might have a tendency to understeer although large look-ahead
distance meant smooth tracking[10].
This paper chose 2m as the shortest look-ahead distance0l,
as a result of low speed driving in the park.

V. C ONCLUSION
In this paper, we proposed a decision-making system
including local path planner and control method used in thepark with high accuracy and safety. However, its practicabilitywas limited by the scene. In the future, more scenes should beconsidered, and universally applicable decision-making
system should be studied.
