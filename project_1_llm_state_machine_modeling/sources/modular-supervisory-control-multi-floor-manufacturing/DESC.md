# 多楼层制造流程的模块化监督控制 / Modular Supervisory Control for Multi-Floor Manufacturing Processes

## 论文在讲什么

这篇论文研究的是一个多楼层制造流程怎样把楼层内水平搬运和楼层间垂直转运统一进同一套离散事件监督控制框架。系统对象不是单台设备，而是一个由多层加工单元、每层移动机器人和一套中央电梯式垂直搬运系统组成的制造过程，目标是把产品按工艺路线在不同楼层之间稳定转运。

论文的主体是自动机建模和监督控制，而不是经验性的调度描述。它先给出每层水平搬运自动机，再给出垂直电梯自动机，随后把各自的期望行为写成形式化语言约束，最后讨论 modular supervisor 的构造和复杂度。这使得正文里对状态、事件和控制约束的描述非常集中，适合直接抽成状态机样本。

## 控制系统在文中的位置

我们关心的控制系统描述在文中是主角。论文虽然属于离散事件监督控制研究，但它并不是只停在抽象方法层，而是始终围绕一个具体的多楼层制造物料搬运系统展开，把水平机器人和垂直电梯都写成可执行的确定性自动机。

尤其值得注意的是，作者并没有只给“状态图骨架”。水平部分明确写出平台静止/运动与夹爪开低位/闭高位这组状态乘积，垂直部分明确写出楼层、门状态和电机高速/低速上下行状态；同时还补了门开时电机必须停、请求必须直达目标层、急停后必须锁住直到故障解除等工程约束，因此非常像一篇“方法论文中携带完整案例控制链”的强样本。

## 对我们为什么有用

对 `sources/` 来说，这篇论文的价值在于它补的是制造流程里少见的“模块化离散监督控制”样本。相比常见的单机 `PLC` 顺序控制，这篇论文更强调多个自动机的组合与约束传播，能帮助文库在 `FSM/EFSM/HSM` 之外进一步积累“明确自动机 + 明确语言约束”的工业控制写法。

它也有利于后续做跨文体样本整理。因为论文既有工程对象，又有非常形式化的状态和事件定义，后续无论是要做纯自然语言描述抽取，还是要研究从自动机定义逆向恢复状态机自然语言，都能从中拿到足够清晰的原始材料。

## 如果需要人工细读，建议怎么读

如果后续要人工复核 `STM.md` 或重做样本，建议先看描述楼层自动机和电梯自动机的部分，也就是水平搬运状态、事件字母表和转移函数，以及电梯 `Ql × Qr × Qd` 状态构造和 `Ee` 事件集合。第一轮阅读的目标是先确认两个控制对象分别有哪些状态变量、哪些事件能驱动转移。

随后再读 `4.2 Desired behavior of the vertical material handling system` 一节，专门提取门开停机、按钮屏蔽、直达目标层和急停恢复这类工程约束。至于后面的可控性证明、复杂度分析和 supervisor 构造证明，可以放到第二轮再看；它们对理解方法完整性重要，但不是抽取状态机自然语言样本时最优先的材料。
