# 工业自动化与离散制造 / Batch Process Control using AB1400 Programmable Logic Controller

## 论文在讲什么

这篇论文讲的是一个工业混料槽的批处理控制器。作者要做的不是泛泛介绍 PLC，而是拿一个实际的 mixing tank 场景，把两种液体按既定比例注入、混合、排放并循环重启的顺序控制过程写成 `AB1400` 的 ladder logic。控制对象很具体，就是带 `L1/L2/L3` 液位开关、三只电磁阀和搅拌电机的混料系统。

它之所以值得保留，不只是因为“用了 PLC”，而是因为正文把顺序链写得很完整。初始时排放阀打开、槽体为空；启动后先加水到 `L2`，再加酸到 `L3`，混合电机以 `3 mins` 为关键定时运行，之后打开排放阀把混合液排空，最后自动回到下一轮循环。这是一条很标准的离散制造 batch cycle。

## 控制系统在文中的位置

我们关心的控制系统描述是论文的核心案例，而不是背景说明。摘要、objective 和 observation 章节都直接围绕这个 industrial mixer 展开，作者主要想说明如何用 `AB1400` 和 ladder diagram 把这条混料顺序程序落地。

对于 `sources/` 来说，这一点很重要，因为文中并没有把控制逻辑藏在附录或只给一张流程图。相反，阀门顺序、液位阈值、`T:4` 以及 `3 mins` 的关键定时都在正文中出现，使它能够稳定支撑一条 `EFSM + T1` 样本，而不是只能抽出零散的工艺描述。

## 对我们为什么有用

这篇论文对 `sources/` 的价值，在于它补的是 `🏭` 领域里较少见的“液位 + 阀门 + mixer + timed drain”批处理控制样本。文库中已有灌装线、包装线和输送线，但这种以混料槽为中心、同时包含多段进料和定时搅拌的 batch process 并不多，因此能有效增加工业离散制造样本的对象多样性。

另外，它的状态边界非常适合做自然语言转状态机的数据。后续如果做数据清洗，可以先保留“空槽初始化、进水到 `L2`、进酸到 `L3`、定时混合、排放复位”这条主骨架；即使不去复刻所有 ladder rung 细节，样本本身依然具有清楚的阶段划分和 guard 条件。

## 如果需要人工细读，建议怎么读

如果后续需要人工细读，建议直接从第 2 页的 `II. OBJECTIVE` 和 `III. OBSERVATION` 开始。先把控制对象、三只液位传感器和三只电磁阀对应关系读清楚，再顺着“start -> close drain -> fill water -> mix -> fill acid -> mix -> drain -> restart”这条主链去看文字说明；这部分基本就够把 `STM` 重新抽出来。

PLC 背景、按钮开关的一般介绍和 Allen Bradley 设备概览可以放到第二轮再看。第一次回原文时，更该优先确认的是阶段顺序、液位触发点和 `3 mins` 定时，因为这些内容决定了这篇论文能否作为一个真正可用的 batch controller 样本。
