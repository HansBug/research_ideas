# 双色灌装与封盖顺序控制 / Simulator Proses Pengisian dan Pemasangan Tutup Botol Terkendali PLC Berbantuan Miniatur Konveyor

## 论文在讲什么

这篇论文讨论一条小型瓶装线中的灌装和封盖工位控制。系统基于 `PLC Omron`、迷你输送带、两路灌装泵、`fiberoptic` 颜色传感器、`photoelectric` 封盖传感器以及气动封盖/压盖机构构成，目标是让红瓶和绿瓶按不同配方灌装后自动完成上盖。

原文的可用度很高，因为它把“按颜色选泵”“灌装时停带”“封盖时再停带”“完成后重新放行”这条主链写得很明确，并且给出 I/O 地址、自动/手动模式和 `55 s / 45 s` 的程序时间参数。对于制造场景来说，这是很标准也很扎实的一类 `EFSM + T1` 样本。

## 控制系统在文中的位置

控制系统是这篇论文真正的主体。前文虽然也会讲 `PLC`、传感器和面板搭建，但这些并不是独立背景，而是为了说明灌装与封盖这条顺序控制链如何落地。

我们最关心的是：红瓶和绿瓶如何被识别，灌装泵怎样按颜色被选中，输送带为什么要在填充和封盖工位两次停住，封盖后如何重新放行。论文后面的观测表和结论都围绕这条主链展开，因此它不是简单的“设备实现说明”。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是一个很适合状态机数据集的制造控制样本。它比只做单一灌装或单一输送的论文更完整，因为这里同时保留了颜色分支、定时灌装、封盖和压盖四种关键要素。

它也和同批瓶装线样本形成了自然的工位互补关系。后续如果要研究“同一条生产线不同子工位的状态机写法”，这篇可以代表前序液体填充与封盖单元，而不是过于抽象的整线控制总览。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 2-3 页关于系统机制和 block diagram 的说明，把输入端的 `fiberoptic / photoelectric` 与输出端的 `pump / solenoid / conveyor` 先一一对应好。然后直接读第 5-8 页的 I/O 地址、自动/手动模式和观测过程，把“识别颜色 -> 选泵灌装 -> 停带封盖 -> 重新放行”这条链整理出来。

最后再看第 8-9 页的时间表和结论，确认 `55 s / 45 s` 灌装与封盖后重启输送带这些动作确实写进了系统行为，而不是只停留在示意图。设备尺寸、供电和面板布局可以放到第二轮再看，不影响先恢复状态机主链。
