# 6轴锁螺丝机器人有限状态自动机控制 / Implementation of Finite State Automata for 6-Axis Robot in the Screwing Process

## 论文在讲什么

这篇论文讨论的是一个真实装配工位里的锁螺丝顺序控制问题。作者把 `EPSON C4` 六轴机器人、`PLC`、`HMI`、光电与磁簧传感器、气动执行器和螺丝刀工具接成一个自动化单元，再用 `Mealy Machine` 形式的有限状态自动机来组织整条工作链。论文的重点不是“机器人能锁螺丝”这个结论本身，而是怎样把取工具、取螺丝、到达安全点、进入锁付工位等动作明确拆成离散状态和带反馈触发的转移。

从内容密度上看，这篇论文属于比较适合直接入 `sources/` 的工程短文。它没有把篇幅花在抽象方法综述，而是给了状态集合 `S0-S5`、输入/输出字母表、转移函数表、输出表，以及 safe-point 路径说明。虽然系统规模不大，但控制链条完整，足以支撑后续做状态机自然语言样本。

## 控制系统在文中的位置

我们关心的控制系统描述在文中就是主角。摘要先把 “state diagram + sensor-triggered transition + logical sequence” 讲清楚，随后方法部分用 block diagram 和 flowchart 说明输入、输出和动作路径，结果部分再把 `Q`、`Σ`、`δ`、起始/终止状态以及各状态的工程含义逐项展开。这种写法意味着，状态机不是附带的一张示意图，而是论文说明机器人锁付流程的主要组织方式。

更重要的是，它没有停留在“有一个状态图”这种浅层证据。表格里明写了 push button、photoelectric sensor、reed switch、robot arrival 等输入，也明写了 tool lock/unlock、vacuum、grip、screwdriver up/down、screwdriver on 这些输出动作。对 `project_1` 来说，这种“离散相位 + 传感触发 + 执行动作”三件套是非常典型、也非常可用的顺序控制样本。

## 对我们为什么有用

当前 `🏭` 方向虽然已经积累了不少 `PLC/SCADA` 工程控制样本，但不少样本更偏输送、灌装、包装和阀泵控制。这里补进来的是一个以工业机器人装配动作为核心的控制器，它把“安全点过渡 + 工具/螺丝获取 + 最终锁付”写成了比较干净的 Mealy 状态机，对扩充装配型离散控制样本很有帮助。

它的另一个价值在于，论文保留了足够多的实现性细节，却又没有把系统复杂度推得太高。对后续做数据集来说，这样的条目很适合作为 `FSM + T0` 的典型样本：状态名明确，输入输出稳定， nominal path 可直接复写，而且不需要额外推断复杂时钟或层级结构。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看摘要和第 3 页的系统与流程描述，先把 `Safe Point Tool -> Screwdriver Tool -> Screw Feeder -> Safe Point Screwing -> Screwing Station` 这条主路径记住。然后直接跳到第 5-7 页，优先读 `Table 1`、`Table 2`、`Figure 4`、`Table 3` 和 `Table 4`，把状态集合、输入/输出集合、转移条件和对应执行动作一一对齐。这几页已经足够恢复出核心状态机。

至于前面的行业背景、后面的实验截图和一般性结论，可以放到第二轮再看。它们有助于理解论文应用场景，但对当前要抽取的状态、guard、输出和相位顺序来说，优先级明显低于状态表、输入输出表和状态图解释段落。
