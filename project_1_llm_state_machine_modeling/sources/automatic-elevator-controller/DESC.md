# 自动电梯控制器 / Automatic Elevator Controller

## 论文在讲什么

这篇论文研究的是一个三层自动电梯控制器，重点不是楼宇调度理论，而是怎样把电梯的楼层状态、升降方向和复位逻辑写成有限状态机，并在 FPGA 上用 VHDL 实现。作者关心的是疫情背景下的自动电梯，也就是乘客进入和离开轿厢后，门传感器感知状态、门关闭、电梯按既定状态图自动运行，不依赖传统的人手按钮调度模式。

从论文结构看，真正有用的不是前面的历史综述，而是中间的算法和结果部分。正文把系统写成由楼层态 `F1/F2/F3` 和运动态 `MU2/MU3/MD1/MD2` 组成的 FSM，再用 `PS1/PS2/PS3`、`S1/S2/S3` 和 `hbrg` 输出解释不同楼层请求与到位检测如何驱动状态转移。这种表达方式非常适合转成状态机自然语言。

## 控制系统在文中的位置

这里的控制系统就是论文的核心对象。作者明确说算法建立在 finite-state machine 上，并且在结果分析里逐一解释 `F1 -> MU2 -> F2`、`F2 -> MU3 -> F3`、`F3 -> MD1 -> F1`、`F3 -> MD2 -> F2` 这类转移。也就是说，论文不是“用 FPGA 做点硬件实验”，而是用 FPGA 承载一个具体的电梯控制状态机。

另外，这篇文章的控制叙事比较完整：初始理想态是什么、上行和下行各怎么工作、到达目标层后如何停住并检查下一目标、复位时如何强制返回 floor 1。这些都让它比很多只展示代码框架的电梯实现文更适合作为 `sources/` 样本。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是 `🏢` 领域里相对稳定、易读、离散性很强的 `FSM + T0` 电梯控制样本。仓库里已经有一些 PLC 电梯、门控和多层控制器条目，但这篇把三层自动电梯的状态名、请求输入、到位传感和复位路径都压成了一个比较紧凑的 FSM 叙事，很适合作为简洁而完整的楼宇机电案例。

它还有一个额外价值：很多电梯论文会把重点放在综合、时序或硬件资源上，状态机本体反而写得很薄。这篇虽然不算长，但至少把关键状态和几组代表性跃迁写出来了，因此后续做数据集时，不需要从图里艰难猜测完整控制链。

## 如果需要人工细读，建议怎么读

人工重读时，建议先跳到第 `4-7` 页，也就是 `Algorithm` 和 `Result and Analysis` 相关部分，先抓状态空间和输入输出：理想态、上/下行两条主支路、`PS1/PS2/PS3`、`S1/S2/S3` 以及 `hbrg`。这一步完成后，电梯控制器的骨架基本就清楚了。

第二轮再看各张 transition figure 的文字解释，重点确认不同起始楼层下的具体跳转、到位后如何停止，以及 `rst=1` 如何让系统回到 floor 1。前面的历史介绍和 VLSI 背景可以放到最后补读，因为它们对重建状态机本体帮助不大。
