# 生物柴油批处理 PLC 状态图控制 / Desain Sistem Biodiesel Berbasis PLC Berdasarkan Diagram Keadaan

## 论文在讲什么

这篇论文讨论的是一个生物柴油生产过程的 PLC 顺序控制系统。作者把整个工艺拆成多个储罐、混合罐、阀门、加热器和搅拌器，并用状态图把进料、加热、搅拌、转移和最终出料过程表示成一串可执行的 `Kondisi` 和 `Transisi`。论文的重点不是化学机理，而是如何用状态图和梯形图把这条批处理流程编成一个结构清楚、便于检查错误的 PLC 程序。

对过程控制论文来说，这篇文章很难得地把“状态”和“转移条件”写得非常明白。文中不只给出工艺框图，还把 `Kondisi 1-13`、`T0-T30`、`TIM1-TIM3` 以及各类 `SA/SB` 传感器条件系统化列出，因此后续很容易把它抽成一条多阶段 timed EFSM，而不是只能得到一段泛泛流程描述。

## 控制系统在文中的位置

控制系统就是论文的核心内容。作者研究的不是上层优化，也不是某个局部执行器，而是直接围绕“如何用状态图设计生物柴油系统 PLC 程序”展开。状态图、转移方程、状态方程和梯形图转换构成了文章主体，工艺本身则是这个控制设计的承载对象。

这种角色定位对 `sources/` 特别合适，因为它保证了原文里的状态、传感器条件和输出动作不是附属说明，而是作者真正想表达的主要贡献。无论是为了写自然语言状态机描述，还是为了以后做形式化模型，都能直接从文中找到足够明确的证据。

## 对我们为什么有用

这篇论文补的是过程控制方向里很扎实的一类样本：不是简单液位启停，也不是模糊控制或 PID 论文，而是带多个阶段、多个容器、多个阀门和显式局部定时器的批处理顺序控制链。对于 `project_1` 而言，这类样本能显著丰富“工艺阶段推进”“多支路会合”“定时加热/搅拌后再转移”等语言模式。

它还保留了非常适合建模的数据形态。`SA1/SB1` 到 `SA5/SB5`、`TIM1-TIM3`、`Valve 1-8`、`Pemanas/Pengaduk` 这些元素都能自然转成 guard、动作和阶段名，不像很多过程控制论文那样只剩连续参数曲线或优化指标。也因此，它对于后续“从自然语言到状态机”的训练价值很高。

## 如果需要人工细读，建议怎么读

人工细读时，先看第 `1` 页摘要和第 `3` 页研究目标，确认这篇论文的核心就是“state diagram -> ladder diagram”的 PLC 顺序控制设计。接着直接读第 `5` 页 `Gambar 6` 下方对 `Kondisi 1-13` 的逐条解释，把每个状态对应的阀门、加热和搅拌动作先记下来。然后看第 `6` 页的 `T0-T30` 转移方程和 `Kondisi 1-13` 状态方程，确认哪些条件负责从一个工艺阶段跳到下一个阶段，哪些 `stop` 条件会中断整个流程。

输出方程、软件截图和一般 PLC 背景可以第二轮再看。它们对理解实现细节有帮助，但如果目标是重建状态机主链，最应该优先抓住的还是工艺状态、`TIM1-TIM3` 这些局部定时器，以及 `SA/SB` 传感器如何驱动批次推进。
