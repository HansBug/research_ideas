# 面向 LNG 船混合供能的状态转移逻辑设计 / State Transitions Logical Design for Hybrid Energy Generation with Renewable Energy Sources in LNG Ship

## 论文在讲什么
这篇论文解决的是LNG 船在可再生能源与热机并存条件下的供能调度问题。输入是负荷需求、光伏/风能出力、各热机最大功率和电池 SoC，方法是把 EMS 写成 12 状态有限状态机，输出是针对 LNG、DG1、DG2、电池与剩余功率的调度决策。
从论文的展开方式看，输入侧主要落在 `PL / Ppv / Pw / SoC / eng1_Pmax / eng2_Pmax / eng3_Pmax`，核心做法是 有限状态机 + 逻辑状态转移表 + Matlab 流程图实现，最终形成的则是 对 LNG 发电机、柴油机、电池充放电与 spare power 的请求量。 因此它不是只在某个局部环节顺手提到状态机，而是在用一套较完整的系统叙事把任务目标、控制分层和运行结果串起来。 对后续维护样本库的人来说，这一节读完后就应该能先建立系统边界、主要参与量以及大致控制思路的整体印象。

## 控制系统在文中的位置
这里的控制系统就是正文反复展开的核心对象之一，论文的主要篇幅都在说明它如何分阶段运行、如何在条件满足时切换，以及如何产生可执行控制行为。 论文不是只列出模式名，而是把状态切换明确依赖到一组变量守卫上，例如 `Ppv + Pw ≥ PL`、`Ppv + Pw < PL`、`eng3_Pmax > PL - Ppv - Pw`。
状态表至少覆盖了三类情况，例如 可再生能源足够供电：`State 1_1 / 1_2`、负荷超过 RES，需要逐步启用 LNG / DG1 / DG2：`State 2_1 ... 2_6`、零负荷或极端非法工况：`State 3_1 ... 3_3` 与 `State 2_7`。 也就是说，我们在这里看到的不是一句笼统的“有状态机控制”，而是一条能继续追溯到状态、触发条件、局部时间语义或阶段动作的控制链。

## 对我们为什么有用
对 `sources/` 来说，这篇论文提供了真实的船舶能量管理控制对象。 它把状态和变量守卫写得足够完整，适合直接抽成自然语言到状态机样本。 它补充了当前 `sources` 中较少见的船舶能源管理 EFSM 样本。
如果后续要把它继续清洗成数据集或训练样本，第一轮优先回看的通常是 “输入变量表 + 输出变量表 + 状态表”这种强结构化写法、按资源优先级递增启用执行单元的控制叙事、非法状态 `State 2_7` 这种边界场景表达方式 这些最容易直接转成状态机自然语言描述的部分。 时间语义更多体现在“随负荷变化的状态转移”，而不是显式局部计时器，所以更适合作为 `T0` 样本。 大量篇幅在做功率方程与稳定性分析，抽取时需要主动聚焦 EMS 状态表。 这些内容更适合放到第二轮核对时再展开，而不是在第一次整理时全部摊开。
