# 基于 PLC 的自动门控制系统设计 / Control System Design of Automatic Door Based on PLC

## 论文在讲什么

这篇论文讨论的是建筑出入口自动门的 PLC 控制系统设计。作者以 `S7-200` 为核心，把自动门拆成感应检测、门位检测、电机脉冲驱动、障碍防夹和软件流程几个部分，目标是让自动门在真实应用里实现更可靠的开门、保持、关门和安全保护。

和很多只停在“自动门可用 PLC 实现”的工程短文不同，这篇文章把工作原理和软件流程都讲了出来。它不仅交代有人靠近时如何开门、无人后如何延迟关门，还说明了限位开关、反夹中断和人工按钮分支，因此是比较完整的门控控制描述。

## 控制系统在文中的位置

这篇论文的主角就是自动门控制器本身。第 2 节讲工作原理，第 3 节讲检测与驱动硬件，第 4 节进一步把主程序、开门子程序和关门子程序写成 PLC 软件流程。也就是说，状态切换和动作链不是附属内容，而是全文展开的核心。

对 `sources/` 来说，这种论文的好处在于控制客体非常明确，而且正文里能直接读出触发条件和动作响应。人在门前、门完全开到位、门缝检测到障碍、人工按下开门或停止按钮，这些都可以自然转写成状态机里的事件和守卫。

## 对我们为什么有用

当前 `🏢` 方向虽然已经有不少电梯和自动门样本，但很多自动门文章只写一个很短的工作流程。这篇论文补的是更完整的版本：它把人体感应、门位限位、反夹回退、低速靠限位和人工按钮都拉进同一套 PLC 逻辑里，能形成更丰富的 `EFSM + T1` 描述。

从数据集角度看，它特别适合补“机电门控 + 安全回退”这一类样本。后续如果要训练模型从工程文本里恢复“正常路径 + 异常/保护路径”的控制结构，这篇论文会比只有 nominal open-close 的文章更有价值。

## 如果需要人工细读，建议怎么读

人工细读时，建议先按第 1 页的 `Working Principle` 和第 2-3 页的 `Hardware Components / Software Design` 顺序读。先把“开门、保持、延迟关门、障碍回开”这条主链串起来，再把 travel switch、anti-pinch interrupt、manual open/close、start/stop 这些附加分支挂到主链上。

如果后续想更精细地重写 `STM.md`，可以第二轮再看图 1-3 对应的主程序与子程序流程图。对首轮提取来说，优先级最高的是文字里已经给出的门位检测、反向驱动和障碍回退逻辑，而不是电机脉冲的实现细节。
