# 环形立体车库自动/手动分层控制 / Scale Model Parking Garage: Integrating Automation in Parking Facilities

## 论文在讲什么

这篇论文围绕一个环形立体车库比例模型展开，系统由 Beckhoff CX 系列 PLC、TwinCAT、伺服电机、步进电机、EtherCAT I/O 和 HMI 共同构成。它不是单纯介绍机械结构，而是把停车设施的自动停车、自动取车、手动调试、速度选择、故障停机和重启条件都写进了同一套控制系统实现里。

从样本库角度看，它最有价值的地方是程序组织足够清楚。作者把 `MAIN`、`AUTO_MODE`、`MAN_MODE` 和运动功能块分开写，并且在测试章节明确核查楼层定位、旋转方向、错误位置反馈和安全恢复，因此这不是“有界面没逻辑”的展示稿，而是一篇控制链完整的工程论文。

## 控制系统在文中的位置

这里的停车控制器是论文的绝对主角。第 5 章的软件实现负责说明程序层级、任务周期和 I/O 变量，第 6 章解释 HMI 如何在自动/手动之间切换并向 PLC 发命令，第 7-8 章则说明急停、故障停机和顺序验证，因此系统设计、实现和测试都围绕同一个控制对象展开。

对 `sources/` 来说，这篇论文的重要性还在于它提供了一个停车设施侧的层次化样本。它和只写闸门或空位分配的停车稿不同，控制对象是完整的机械车库平台，状态边界清晰地分成顶层模式和底层停车/取车序列，很适合和现有的停车基础设施样本做结构差异比较。

## 对我们为什么有用

当前停车方向虽然已经回补了不少双 A 样本，但很多还是 `EFSM` 风格的门禁、分配或局部执行链。这篇论文补的是 `HSM + T0` 角度的环形立体车库监督控制，能把“自动模式 vs 手动模式、停车 vs 取车、正常运行 vs 故障停机”这些层次关系补得更完整。

后续如果要从样本库里挑选代表性停车论文做数据集分层，这篇可以作为停车设施“分层监督 + 机械轴联动”一类的典型代表。它既有工程实现细节，又没有退化成薄弱的实验装置说明，适合作为高质量核心样本。

## 如果需要人工细读，建议怎么读

建议先看第 22-24 页的软件实现部分，把 `MAIN / AUTO_MODE / MAN_MODE`、变量映射和任务周期先读稳。接着跳到第 28-31 页的 HMI 与安全逻辑，把自动模式下的槽位输入、手动模式下的轴控制、模式互锁、急停和故障反馈串成一条完整的控制主线。

最后再读第 34-35 页的顺序测试和安全测试，重点看楼层范围选择、旋转方向选择、错误定位信号、故障停机与清故障后重启。像机械原理、滚珠丝杠和电机选型这些内容可以放到第二轮，因为第一次人工复核的关键是把分层监督关系和停车/取车顺序确认清楚。
