# 拉各斯大学多层停车门禁原型 / An Arduino-Based Automated Multi-Tiered Car Parking System for University of Lagos and Expected Financial Gains

## 论文在讲什么

这篇论文表面上同时讨论了校园停车空间紧张、立体停车的经济收益和原型实现，但对 `sources/` 真正有价值的是其中那套 Arduino 停车场入口/出口控制器。它的核心原型不是搬运式机器人停车系统，而是一个相对朴素但控制链完整的门禁原型：RFID 卡校验、入口/出口闸机舵机、每车位红外检测、LCD 余位显示和计数器更新。

从控制逻辑强度看，这篇的重点不在机械搬运，而在“谁能进、何时能进、满位时如何阻止、离场时如何恢复名额”。因此它更像智慧停车方向的门禁与容量管理样本，而不是复杂塔库调度样本。

## 控制系统在文中的位置

控制系统在本文里不是唯一主角，因为作者还花了不少篇幅做校园停车场调查、层数推算和收益分析。但只要进入 `2.0 IMPLEMENTATION` 和 `4.2 / 4.3`，可以看到论文确实给出了比较完整的控制器实现与测试，不是只停留在概念草图。

换句话说，这篇是“停车场规划/经济分析 + 具体门禁控制原型”混合型论文。对于我们的样本库，它的价值主要落在后半段 Arduino 原型，而不是前半段场地与收益论证。

## 对我们为什么有用

它补的是 `🅿️` 方向里比较实用的一类样本：不是轨迹规划停车，也不是视觉感知找车位，而是最直接的出入口授权和余位控制。当前库里停车样本虽然不算少，但很多论文会偏向塔库机械结构、门禁短链或感知平台；这篇把授权校验、满位禁止和进出计数更新连成了一条较完整的闭环。

后续做状态机数据集时，这篇尤其适合拿来做“授权通过/拒绝 + 容量约束 + 门禁动作 + 计数回写”一类文本样本。它的系统边界清楚，输入输出直观，适合作为门禁/停车类样本里的基础强样本。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第一页摘要，确认论文中真正值得抽取的是 Arduino 原型而不是校园停车收益分析；接着直接读 `2.1 Design of the Entry/Exit Point Control System` 和后面的 `Sensor Section`，把 RFID、LCD、舵机和 IR 车位传感器的角色分清楚。

然后跳到 `4.2 Test-running the System` 与 `4.3 Entry and Exit Sequences`，这里集中给出了 `Access Allowed / Access Denied`、`FULL`、入口计数加一、出口计数减一的完整动作链。停车场面积测算、层数推导和收益估算可以最后再看，它们对重做 `STM.md` 不是关键证据。
