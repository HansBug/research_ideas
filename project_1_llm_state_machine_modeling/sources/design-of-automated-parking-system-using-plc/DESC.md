# 起重机梳齿式立体停车顺序控制 / Design of Automated Parking System Using PLC

## 论文在讲什么

这篇论文讨论的是一个基于 `PLC` 的自动立体停车系统设计项目。作者选的是 `Crane type with Combs vehicle transfer system`，也就是用起重塔和梳齿机构完成车辆在入口位、停车位和取车位之间的搬运，而不是只做停车位统计或门禁开关。

论文虽然是项目报告而不是标准期刊论文，但控制链写得并不薄。摘要已经说明做了完整的 `SFC` 与 transition conditions，正文第 3 页又把停车链和取车链逐步展开成电机动作与限位开关联动，这使它在文库里仍然是一个质量很高的停车顺序控制样本。

## 控制系统在文中的位置

我们关心的控制系统描述在文中是绝对主角。机械结构说明只是用来交代系统边界，真正的正文核心是 `M1/M2/M3/M4` 四个电机怎样在 `PLC` 指令下按顺序带动车塔、梳齿与旋转机构完成停车、取车和复位。

尤其关键的是，这篇论文没有只停在“有一套流程图”这种泛泛表述上，而是把“停车前必须先回 home position”“哪一个 limit switch 停哪个 motor”“车主取车前要输入 security data 和车位号”“何时做 `180°` 旋转”都明确写了出来，所以后续抽取状态机主链时几乎不需要猜。

## 对我们为什么有用

对 `sources/` 来说，这篇论文补的是停车方向里比较典型但又足够工程化的一类机械搬运控制器。它和纯门禁停车、纯空位计数停车不一样，重点放在三维搬运、梳齿插入/回撤、车身旋转和送到交付位的全过程，因此能提供更完整的“执行机构驱动型”停车样本。

它还有一个价值是动作粒度比较细。很多停车短文只会说“电梯升降、平台旋转、车辆存取”，这篇则把每一步由谁触发、哪个开关结束、之后切到哪个电机写得较实，对后续做自然语言到状态机恢复非常友好。

## 如果需要人工细读，建议怎么读

人工细读时，建议先看第 1 页摘要，再直接跳到第 3 页 `Sequence of Operation` 和 `Car Calling Process`。第一轮只需要确认五件事：停车链的起点条件、`M1/M2/M4` 在停车链里的先后关系、取车前的安全数据输入、`M3` 的 `180°` 旋转处于哪一步、整套机构怎样回到 home position。

第 2 页的机械结构与第 5 页的消防设计可以放到第二轮再看。它们有助于补足系统背景，但对重做 `STM.md` 的主任务来说，优先级明显低于停车步骤、取车步骤、限位开关联动和车主认证这几条最直接的控制证据。
