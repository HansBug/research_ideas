# 智慧停车与车位管理 / Prototipe Sistem Parkir Gantung Berputar Ke Atas berbasis Programmable Logic Control Dilengkapi Human Machine Interface

## 论文在讲什么

这篇论文研究的是一个六车位悬挂旋转停车系统原型。系统包含 PLC、HMI、DC 电机、红外传感器和多组 limit switch，通过旋转机构把不同车位送到唯一的出入口位置。作者把问题分成三个典型场景：系统激活、车辆停车和车辆取车，并且分别在 HMI 设计、梯形图程序和测试表中给出了对应实现。

这篇论文的控制逻辑比一般“停车场计数+闸门”论文更丰富，因为它不只是判定车辆能不能进入，而是要在多个离散车位之间查找空槽、把指定车位转到取车口、维护当前停车数量，并用红绿灯指示满位状态。再加上 HMI 上的 `PIN` 安全入口和目标车位选择，它构成了一条比较完整的停车存取车控制链。

## 控制系统在文中的位置

这里的旋转停车控制器是全文的主体。文章先用 block diagram 解释硬件和车位搜索逻辑，再用 HMI 页面说明使用流程，然后在 `CX-Programmer` 梯形图部分给出停车、取车和计数三组核心程序，最后再用三张测试表验证“全部进场”“随机进出”“全部出场”三类场景。控制系统不是论文中的辅助实验，而就是论文要实现和验证的对象。

对 `sources/` 来说，这篇论文很有用，因为它保留了非常清楚的 slot-level 控制语义。很多停车类论文要么集中在门禁、车牌识别、空位展示，要么偏连续轨迹规划；而这篇则把“空槽搜索、目标车位召回、计数上限、PIN 认证”这些离散控制点直接写在正文里，非常适合转成状态机自然语言样本。

## 对我们为什么有用

这篇论文最直接的价值，是给 `🅿️` 方向补进了一类结构差异明显的样本。文库里已经有不少停车场门禁、停车塔和车位分配控制器，但这种“单入口+旋转车位+空槽搜索+指定车位召回”的控制结构并不多。它既不是简单的进出闸机，也不是连续轨迹泊车，而是更偏多工位顺序控制，非常适合平衡停车子域内部的样本形态。

另外，它的正文对 PLC 地址、`1:1 / 1:0` 空槽判定、`CMP 207` 计数比较和 HMI 输入关系写得比较细，这使它不仅可以补案例数量，还能补“地址级实现事实足够多”的样本类型。后续如果做文本到状态机元件抽取，这类稿子往往比只讲用户体验的智能停车论文更有训练价值。

## 如果需要人工细读，建议怎么读

如果后续需要人工重读，建议先按 `Blok diagram -> Hasil Desain HMI -> Program Sistem Parkir Gantung Berputar Ke Atas -> Hasil Pengujian` 的顺序看。第一轮阅读时，优先搞清楚三件事：空槽是怎样通过 `limit switch 7 + infrared` 判定出来的、取车时怎样通过 `W10.00-W10.05` 和 `L.S 1-6` 召回目标车位、以及停车数量怎样通过 `CMP 207` 和指示灯被维护。

像硬件安装图和材料说明可以放在第二轮再看。若要重写 `STM.md`，最值得优先核对的是 `PIN` 认证入口、停车和取车对应的 internal relay / output 地址、`1:1 / 1:0` 的空槽 guard，以及三张测试表对“满位”“随机进出”“全部出场”三类场景的叙述是否与程序逻辑一致。
