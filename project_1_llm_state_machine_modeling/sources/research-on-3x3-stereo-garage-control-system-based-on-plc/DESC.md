# 3x3 立体车库升降横移控制 / Research on 3*3 Stereo Garage Control System Based on PLC

## 论文在讲什么

这篇论文讨论的是一个 `3*3` 三层七车位升降横移式立体车库，用 `Siemens S7-200 PLC` 作为现场控制核心，并结合上位机按钮交互、光电检测和调度算法完成车辆存取。论文先给出立体车库的机械结构、提升机构和驱动选型，再进入 PLC 控制系统与上位机协作的总体方案，最后用一个“满载状态下提取 5 号车位车辆”的例子说明调度过程。

它的重点不是门禁计数或空位显示，而是“在有限机构和有限空位下，怎样通过升降与横移把目标车辆安全送到出口”。因此，文中的控制语义更偏资源受限的动作调度与位置确认，而不是简单开门关门式顺序控制。

## 控制系统在文中的位置

控制系统是这篇论文的主体之一。虽然文中包含不少机械尺寸和电机选型内容，但不是把 PLC 当作配件，而是明确把整个系统分为上位机人机交互层和下位 PLC 执行层，说明哪个层面负责按钮与车辆信息，哪个层面负责光电检测、驱动和实际的存取动作。

对我们而言，真正重要的是它把“车位状态、目标车位、可行路径、运动位置确认”这些事实写成了可追溯的控制边界。即便论文没有直接画出传统状态图，它依然提供了一个可组织成 EFSM 的控制客体：当收到取车请求后，PLC 依据传感器与路径调度结果，分阶段驱动升降横移动作，直到目标车位被送到出口。

## 对我们为什么有用

这篇论文在停车领域里补的是一种与普通入口门禁完全不同的样本。库里已经有不少“入口检测 + 满位指示 + 开杆放行”类停车控制，但升降横移式立体车库涉及的是另一层复杂度：不仅要判断有没有车，还要处理多个车位、载板、楼层和移动路径之间的相互制约。

它因此很适合放进“需要清洗但值得保留”的样本池。一方面，原文细节足够完整，尤其是 `17` 秒提升时间、光电传感器反馈和目标车位调度示例；另一方面，它也提醒我们停车领域里并不只有门禁控制，还有明显偏资源流动与位姿调度的控制对象。

## 如果需要人工细读，建议怎么读

人工细读时，先看摘要和第 `2` 节整体方案，确认这是三层七车位升降横移车库而不是普通停车计费系统；然后重点读 `2.3` 的提升机构说明与第 `3` 节硬件设计，把 `17` 秒提升约束、光电传感器反馈和 PLC 现场执行边界记下来。接着直接跳到第 `4` 节的软件设计与“提取 5 号车位”的示例，把目标车辆从三层左侧到出口的动作阶段和路径调度逻辑读清楚。

机械尺寸、混凝土框架和一般性的电机选型推导可以放到第二轮再看。这些内容对理解工程实现有帮助，但不是重建状态机主链的最短路径。
