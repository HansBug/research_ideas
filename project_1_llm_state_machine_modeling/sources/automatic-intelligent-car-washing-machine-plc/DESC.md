# 基于 PLC 的自动智能洗车机控制设计 / Control Design of Automatic Intelligent Car Washing Machine Based on PLC

## 论文在讲什么

这篇论文讨论的是一套自动智能洗车机控制系统。作者的关注点很工程化：传统洗车方式效率低、耗水高、自动化不足，因此希望用 `S7-200 SMART` PLC、三维运动机构和污水处理模块把整套洗车流程做成可复用的自动设备。

文章并不是只讲某个局部喷头或某段清洗工艺，而是把整机控制拆成硬件结构、分布式 PLC、运动机构和软件流程。入口放车、底喷、参数检测、正式洗车、泡沫、水蜡、风干、异常暂停/取消、污水回收和最终关机，都是连成一条主链来讲的。

## 控制系统在文中的位置

这套控制系统就是论文的核心。第 3 节先说明双 PLC 分布式架构、喷头运动机构和触摸屏 HMI，第 4 节再把自动/手动模式和完整洗车流程写成控制要求，因此洗车机不是方法验证载体，而是论文真正设计的对象。

对 `sources/` 来说，这类样本很有价值，因为它不是泛泛的“设备自动化”口号，而是把输入检测、执行器、用户交互和异常处理都放在同一条设备级控制链里。它同时覆盖了 nominal path 和人工干预路径。

## 对我们为什么有用

这篇论文补的是“服务型工业设备”的控制样本。和灌装、包装、输送等典型离散制造对象相比，洗车机的工艺环节更贴近用户交互和工序串联，因此能给数据集带来不同的动作词汇和模式表达。

它还保住了比较完整的辅助链。除了清洗主流程，文中还明确给出故障/过载检测、pause/cancel、显示/语音提示，以及车辆离开后启动污水回收与净化，这让它比许多只写洗车步骤示意图的论文更像一个真正可建模的控制系统。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 4 节的控制流程，再回到第 3.1 和 3.2 节核对硬件。第 4 节先把自动/手动模式、入口放行、底喷、异常检测、洗车阶段、pause/cancel 和收尾关机顺一遍；第 3.1 和 3.2 节再确认双 PLC 分工、X/Y/Z 运动机构和 HMI 在系统里各自扮演什么角色。

污水处理部分建议作为第二轮补读。它对理解系统闭环价值很重要，但对首轮 `STM.md` 来说，优先级仍低于模式边界、传感输入、执行器输出以及异常暂停/取消和关机顺序。
