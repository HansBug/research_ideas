# 瓶装产线 PLC/HMI 顺序控制 / Development and implementation of a programmable logic controller and human machine interface for control and monitoring of bottling operations

## 论文在讲什么

这篇论文研究的是一条小型瓶装饮料产线的自动化控制，包括灌装、封盖、贴标和成品计数四个主要工位。作者用 PLC 负责顺序控制，用 HMI 负责参数设定和实时监控，希望替代较僵硬的继电器逻辑，实现更容易调节的生产流程。

论文比较可贵的一点是，它没有只停留在“有一条灌装线”这种概括层面，而是把每个工位的传感器、气缸、电机、泵和定时参数都讲清楚了。尤其是 `S1-S4` 检测、`P1-P6` 气缸动作和 HMI 上的时间设置页面，使这篇文章非常适合转成状态机自然语言样本。

## 控制系统在文中的位置

这里的控制系统就是全文主体。灌装、封盖、贴标与计数不是实验附带动作，而是作者要设计并验证的核心对象。论文对每个工位都给出“检测到瓶子后做什么、保持多久、下一步如何继续”的控制描述，因此它本质上是一条顺序制造控制链。

HMI 在文中的角色也很明确：不是只做显示，而是负责各阶段 timer 的配置和过程监控。换句话说，PLC 提供离散控制骨架，HMI 提供参数化的时间调度接口，这让整条产线的顺序控制更像一个可调的 timed supervisor。

## 对我们为什么有用

这篇论文补的是 `🏭` 领域里很稳定的 `EFSM + T1` 制造样本，而且比单纯 bottle filling 稿件更完整，因为它把 filling、capping、labeling 和 counting 四段工序连成了一次完整循环。对于后续做自动建模，读者不需要从多篇文献拼凑整条链。

它的另一个价值是 timer 粒度很工程化。原文不只说“按顺序执行”，还把多个 solenoid、impact、pump 和 label motor 的延时与工作时长放进 HMI。对于训练模型恢复带局部定时的产线控制器，这类材料比只有工艺框图的文章要强得多。

## 如果需要人工细读，建议怎么读

人工重读时，建议先看第 `3-4` 页，也就是 `2.1 Prototype Design` 和 `2.2 Program Design of HMI`。先抓 `S1-S4`、`P1-P6`、泵、电机和三张 timer 配置页面，把四个工位的顺序链和时间参数读出来。这样最容易重建状态机的 nominal path。

接着再看第 `1` 页摘要和第 `5` 页处理时间、灌装误差、封盖/贴标成功率统计，确认这套控制链在实验中如何运行、一次完整循环耗时多少。硬件接线图和元件清单可以最后看，因为它们主要帮助实现复现，不是理解离散控制链的首要入口。
