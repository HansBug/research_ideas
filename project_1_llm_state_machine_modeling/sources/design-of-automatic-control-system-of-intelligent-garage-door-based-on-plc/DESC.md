# 基于 PLC 的智能车库门自动控制系统 / Design of Automatic Control System of Intelligent Garage Door Based on PLC

## 论文在讲什么

这篇论文研究的是一个基于 Mitsubishi `FX2N-16MR` PLC 的智能车库门控制系统。作者把无线遥控、内外传感器、限位、防夹光栅和高/中/低速门机输出整理到同一个 PLC 梯形图控制框架里，目标不是泛泛讨论智能家居，而是把“车库门怎么可靠地开、关、停、回开和复位”这条控制链讲清楚。

与很多只停留在部件选型或机械设计的自动门论文不同，这篇文章直接给了 `I/O` 端口分配表和动作结果表，所以读者可以明确看到输入条件和输出动作的对应关系。虽然篇幅不长，但控制链条是闭合的。

## 控制系统在文中的位置

控制系统在文中是核心实现对象。摘要、车辆进出流程、`I/O` 分配表和调试动作记录都围绕 PLC 门控逻辑展开，而不是把 PLC 只当成一个背景平台。对 `sources/` 来说，这意味着状态机样本的证据不需要从散乱叙述里硬拼，而是可以直接从模式开关、传感器、限位、防夹与输出执行之间的关系里抽出来。

尤其关键的是第 `4-5` 页两张表：`Table 1` 给出所有输入输出定义，`Table 2` 给出自动模式、手动模式、防夹回开、限位停机和异常复位的动作记录。这种写法对 `STM` 提取非常友好。

## 对我们为什么有用

这篇论文补的是 `🏢` 方向里“车库门自动/手动切换 + 防夹保护”的门控样本。库里已经有远程触发车库滑门和带授权判定的车库门禁，但这篇更强调 `mode switch`、内外传感器、分档速度和防夹回开，因此不是简单重复。它适合作为一个 `EFSM + T0` 样本，测试模型是否能把模式切换、传感 guard 和动作输出串成稳定的控制链。

从数据集角度看，这篇论文的价值不在复杂性，而在于工程词汇的完整性：`hand/automatic transfer switch`、`anti-pinch grating`、`open limit`、`lower limit`、`abnormal reset`、`medium/high/low speed` 都是建模时很有用的 guard 与 action 线索。

## 如果需要人工细读，建议怎么读

人工细读时，先读第 `2` 页的车辆进出流程，确认“遥控开门 + 门开后灯光切换”这条上层触发链。然后直接跳到第 `4-5` 页，重点看 `Table 1` 和 `Table 2`，把 `X1/X2/X3/X4/X5/X6/X11/X12/X14` 与 `Y12/Y13/Y3/Y4/Y5` 的对应关系读清楚。

如果只是为了生成或复核 `STM.md`，部件选型细节可以后看；最关键的是先确认这篇论文是否真的给出了自动/手动切换、防夹回开、限位停机和异常清除四类核心行为。答案是给了，而且证据比较直接。
