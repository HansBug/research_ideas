# 多水源灌溉与水位切换控制 / Conserving Water with A PLC Based Irrigation System

## 论文在讲什么

这篇论文设计并实现了一个 PLC 自动灌溉系统，通过田间水位传感器、蓄水池传感器、泵和电磁阀来减少定时灌溉造成的水浪费。当前 `STM.md` 抽到的核心对象是“过程与环境控制领域的 PLC 自动灌溉与双水源切换控制器”。

从现有条目看，文中的控制链属于 `EFSM（扩展状态机）`，时间语义属于 `T1（工程定时 / 局部定时）`。原文给出了 `START/STOP`、田间传感器 `S1-S4`、蓄水池输入 `I5`、`T0`、`Q1/Q2/Q3/Q5` 和电磁阀/泵动作，因此原文细节和描述细节都可评为 `🟢 A`。

## 控制系统在文中的位置

控制系统是全文主体。论文不仅解释了系统框图，还给出梯形图实现、指令表实现、WPLSoft 仿真和原型硬件组成。我们关心的不是农业背景本身，而是传感器需求、锁存继电器、水源切换、延时与输出动作之间的离散逻辑。

## 对我们为什么有用

这篇论文提供了一条典型但细节充足的 `sensor -> latch -> source selection -> valve/pump actuation -> demand clear` 控制链。它适合作为 `EFSM + T1` 的过程控制样本，尤其有利于训练模型把梯形图叙述转写成状态、guard、动作和定时器。

## 如果需要人工细读，建议怎么读

人工细读时建议先看第 2 页系统框图和工作原理，确认田间传感器与两类水源的控制边界；随后直接读第 5-6 页梯形图实现，逐个记录 `START/STOP`、`Q1`、`I5/T0`、`Q2/Q3/Q5` 和田间电磁阀的作用；最后再用第 7 页之后的仿真和原型部分核对该逻辑是否被完整实现。
