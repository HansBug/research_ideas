### 2. 基于原文整理后的自然语言描述

The autonomous electric bus behavior planner is organized as a two-layer hierarchical state machine whose upper layer distinguishes `general path` and `special path` according to marked entry and exit points on the global map. The lower layer refines driving behavior into six concrete states: `structured driving`, `unstructured driving`, `following`, `overtaking`, `buffer adjustment`, and `special path`, and it drives state transfer with explicit external events `E1` to `E10`. In structured driving, lane-recognition results provide the local reference points, while following is only allowed when lane detection is valid and the bus speed varies with the vehicle ahead. The overtaking state is not a vague label: the paper explicitly decomposes it into `lane change`, `overtake`, and `lane return`, and it requires the inter-vehicle distance `d1` to cross the safety threshold `dth` before lane shift and lane return. Around ramps and intersections, the controller first enters `buffer adjustment`, then moves into `special path`, while loss of lane lines diverts the bus into `unstructured driving`, where a manually defined check zone is used to detect threatening obstacles.
