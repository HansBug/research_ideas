# 四路口交通灯 PLC 定时轮换控制 / SISTEM KERJA PENGENDALI OTOMATIS LAMPU TRAFFIC LIGHT PADA PERSIMPANGAN 4 (EMPAT) JALAN RAYA MENGGUNAKAN PROGRAMMABLE LOGIC CONTROLLER (PLC)

## 论文在讲什么

这篇文章讨论的是一个四路口交通灯的 PLC 控制方案，核心目标是用更简单的数字逻辑、定时和继电器链替代早期不够灵活的人工或模拟式控制方式。作者把问题框定为典型十字路口的放行轮换，并强调 PLC 方案在程序修改、逻辑组织和实际运行上的便利性。

正文不是复杂的智能优化论文，而是偏工程实现说明：它先解释 PLC 为什么适合做交通灯控制，然后在结果部分把开机后哪个方向先绿、延时多久切黄、再经过多久换另一个方向的链条写出来。对于 `sources/` 来说，这种材料虽然结构上比较常规，但控制链条清晰，依然适合作为 `FSM + T1` 基础样本。

## 控制系统在文中的位置

交通灯控制器本身就是论文的主角，不是附带示例。文章围绕它的输入、输出、PLC 扫描逻辑和软件/硬件诊断展开，最终把最重要的控制语义压缩成几条直接可执行的灯色轮换规则。

我们关心的不是 PLC 基础介绍，而是结果部分已经明确写出的状态推进顺序：系统启动后先放行东西向，再经过 `05:00 s` 的 `On Delay` 进入黄灯过渡，然后保持另一方向红灯 `07:00 s`，最后切到南北向放行，并持续循环。这些正是可以抽成状态机自然语言描述的部分。

## 对我们为什么有用

这篇论文适合作为“经典 PLC 定时交通灯”样本保留，因为它的主链非常直白，几乎没有额外的变量或复杂模式嵌套，能够为后续模型提供一个干净的基线轮换控制例子。相比那些只有框图和硬件拼装的短稿，它至少把相位切换和定时长度讲清楚了。

不过它和库内已有不少四路口定时交通灯条目存在明显同构，因此更适合作为降采样保留，而不是继续扩大主训练集权重。它的价值在于补一个印尼语语境下的 PLC 定时实现版本，并为同类簇提供稳定、可追溯的对照条目。

## 如果需要人工细读，建议怎么读

人工回原文时，先看摘要和第一页末尾到第二页的引言，快速确认这是一篇把交通灯问题放到 PLC 数字控制框架下讨论的工程稿。随后直接跳到第 6 页 `Hasil` 段落，那里给出了最关键的控制顺序：`I1` 启动后的初始相位、`05:00 s` 黄灯过渡、`07:00 s` 对向红灯保持和循环重复关系。

如果需要补更多边界信息，再回看中段的 `Sistem operasi PLC` 与设备说明部分，确认输入/输出和软件运行方式即可。大量 PLC 常识性介绍、内存组织和接线概念可以放到第二轮看，因为它们对状态机抽取价值不高，真正重要的是结果部分那几条灯色与延时规则。
