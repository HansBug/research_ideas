# 方法类文献的模型代次时效性（L3 轨调研结论）

> **本文件是调研结论记录，⛔ 不是导师讨论记录。** ⭐ 它自包含：了解 paper1 但不了解 L3 这次工作的人，**不跳转任何链接**即可读完。⚠️ 每个承重数字都标了证据级别（**M** 机械可复算 / **S** 抽样人读 / **I** 推断）；⛔ 标 **I** 的一律不写成事实句。
>
> **执行摘要**：⭐ L3 轨调研 33 项外部工作后，此前把证据分了四档（受控对照 / 端到端 / 仅理由 / 单点），⛔ **却从未记录支撑论文用的是哪一代 LLM**。⭐ 补上这个轴之后：**九个设计决策点里只有 3 个有「同代」受控对照支撑，⛔ 而这 3 条全压在两篇 arXiv 预印本上**；⛔⛔ **「LLM 自评当裁决者收益近零」这条规律在代次约束下直接不成立** —— 它的全部支撑都是厂商家族最弱档（`-Mini` / `-mini`）、且无一来自近半年。⭐⭐ 由此**抬高**「拆掉两个自评 reviewer 跑同网格」的优先级：⛔ 文献两边都给不出证据，只能自己测。⭐⭐⭐ 另有两条实质发现：**一篇同代论文把自己的表读错了**（把 −0.3pp 的不显著均值读成「模型不需要中间表示」，⛔ 而中位数是 +2.3pp、12/18 模型为正）；**另一篇的标注错误意外产出一个方差地板**（⭐ 两格配置全同的臂相差 **9.4pp**）—— ⛔ 据此该表的**设计因子对照与代次跨越都不显著**（p = 0.763 / 0.164），⭐ **唯一显著的是跨厂商那条**（p = 0.0001），⭐ 而后者恰好背书我们的双厂商网格。⛔ **本轮我方撤回 9 条主张**（⭐ 其中 **4 条是本轮自己刚下的**），⛔ 另更正 **5 处**统计与可追溯性事实、⛔ 把 **6 个**数字标为无出处。
>
> ⛔⛔ **另有一处必须先解掉的差异（§10.1）**：⭐ paper1 的头条数字 `hit@1 = 355/588 = 60.4%` 与 `Δ = −15.82pp` **在仓库内不可独立复算**（⛔ 判定表不在库里），⛔ 而唯一可达的审计制品扣除边界剔除后给 **365/588** —— **差 10 位**。⭐ **本文全程不引用那两个数**，⛔ 且本文库 2026-08-12 的两篇实验记录引用了它们，应视为待复核。

## 1. 这次调研是干什么的，为什么要加这个轴

**L3 轨的问题**：近年学术工作里，LLM 具体是怎么被搭进针对行为类模型制品的流水线里的 —— 几个阶段 · 循环的裁决者是谁 · 中间表示什么形态 · 实验怎么做 · 有没有能拿来用的资产。⭐ **目的不是论文口径，是给方法重构攒素材。**

**为什么要加代次轴**：原本的证据分级只回答「对照是否受控」，⛔ **完全没回答「论文里用的 LLM 是哪一代」**。⭐ 这两件事独立，⛔ 而漏掉后者会系统性地把旧证据当新证据用。

⭐ 判据很直接：**一篇 2024 年用 `GPT-4` 的受控对照，方法学上无懈可击，⛔ 但它测的能力区间在 2026-08 已经不存在。** ⭐ 对我们（主臂 `gpt-5.5` 与 `claude-opus-4-7`）而言，它的参考价值**可能低于一篇 2026 年的、只讲设计理由没给数字的工作**。

## 2. 术语速查（⭐ 全部在本文内定义，⛔ 不依赖外部文档）

### 2.1 证据分档（回答「对照是否受控」）

| 档 | 定义 | 能支撑什么 |
| :-: | :-- | :-- |
| **①** 受控对照 | 论文**只改了一个设计因素**，其余不变，**并给出两侧的数** | ⭐ **可以支撑设计决策** |
| **②** 端到端对照 | 换了整套方法 vs 另一套（或 vs 无方法基线） | ⛔ 只能说「这套 vs 那套」，**不能归因到某个因素** |
| **③** 仅设计理由 | 作者讲了道理但**没有数字** | 只能当**假设** |
| **④** 单点观察 | 一个例子、一次运行、无对照 | ⛔ **不能推广** |

⛔ **另有一道用户裁定的硬门：只算纯自动的 LLM 方法。** ⭐ 若「决定要不要再来一轮」「修复」「接受产物」这三个动作中任何一个由人执行，该证据**不得进 ① 档**。⚠️ 注意区分：⭐ 人做标注 / 人做评测判定**不算**（那是评测装置）；⛔ **人参与方法的执行循环才算**。

### 2.3 ⭐⭐⭐ 最要紧的一对概念：**测能力** vs **测形态**

⭐ 这决定一条证据该打多少折：

| 类型 | 长相 | 代次影响 |
| :-- | :-- | :-- |
| ⛔ **测能力** | 「加了 X 之后从 `a%` 升到 `b%`」 —— ⭐ 而那个 `a%` **本身就是某一代模型的能力** | ⛔⛔ **会被代际吃掉**：新模型可能自己就到 `b%` |
| ⭐ **测形态** | 「结构性质孰优」，⭐ 或**由定义决定**的命题 | ⭐ **不需折扣**，⛔ 但「方向」与「量级」要拆开：⭐ 方向可给死，**量级仍是纯经验、仍要打折** |

### 2.5 其他术语

- **主结果模型** —— ⭐ 论文核心数字来自哪个模型，⛔ 不是它提过的所有模型。
- **最弱档** —— ⭐ 厂商家族里的 `-mini` / `-nano` / `Haiku` / distill 档。⛔ 用最弱档测出的**能力类**结论不得外推到旗舰。
- **snapshot** —— ⭐ 带日期的精确模型版本（如 `o3-mini-2025-01-31`）。⛔ 只给别名（`GPT-4`、`a GPT-4-class model`、`OpenAI's GPT models`）的**不可精确复现**。
- **`hit@k`** —— ⭐ 我方覆盖率口径。`hit@1` = 单轮命中率；`hit@3` = 三轮至少命中一次的条目比例；`hit@all` = 三轮全中。
- **格（cell）** —— ⭐ 我方实验的最小运行单位：**一个 pair × 一个模型 × 一轮**。⭐ 我方全网格 = 54 pair × 2 模型 × 3 轮 = **324 格**。⚠️ 本文引用的外部制品也用「格」指它自己的最小运行单位（⭐ 那份是 4 模型 × 8 变体 = 32 格 / 配置）。
- **位（position）** —— ⭐ 我方**判定的最小单位**：**一条台账条目 × 一个模型 × 一轮**。⭐ 与「格」的区别是：⭐ 一格里可能有多条台账条目要判，⛔ 所以位数 ≠ 格数。⭐ 我方 588 位 = 98 条台账 × 2 模型 × 3 轮。
- **台账（ledger）** —— ⭐ 人工事先写定的**期望缺陷清单**：每条记「这份模型在这条需求上应当有什么缺陷」。⭐⭐ **它是命中判定的分母**，⛔ 不是模型产出的东西。
- **臂（arm）** —— ⭐ 实验中的一个受控配置。⭐ 「主臂」= 我们的完整流水线；⭐ 「X1 臂」= 一次提示的朴素基线对照。
- **`Pass@1`** —— ⭐ 外部工作常用指标：每题只采一个样本，⭐ 该样本通过判据才算对。⛔ 与我方 `hit@1` 不是同一个量（⭐ 前者分母是题、后者分母是台账条目 × 轮次）。
- **`REPORTABLE`** —— ⭐ 我方代码里的一个常量，⭐ 即**进入正式统计的台账条目集合**（当前 **98** 条）。⭐ 它已扣除按范围裁定与逐条边界裁定剔除的条目。

## 4. 核心发现

### 4.1 ⛔⛔ 四条规律里，一条在代次约束下不成立

⭐ 原本从 ① 档证据里读出四条规律。按支撑论文的**主结果模型**对齐后：

| 规律 | 同代 ① | 裁定 |
| :-: | :-: | :-- |
| **1** 把可机械判定那一层的裁决权从 LLM 手里拿走交给确定性检查器 | **0** | ⭐ **站得住，⛔ 但理由须从经验换成解析** —— 见 §4.2 |
| **2** LLM 自评当裁决者时收益落在「几乎为零到小效应」区间，伴随可测误杀 | **0** | ⛔⛔ **在代次约束下不成立** —— 见 §4.3 |
| **3** 迭代收益在很早的轮次见底，见底位置由生成端质量决定 | **0** | ⭐⭐ **站得住，代次鲁棒性最强** —— 见 §4.4 |

### 4.2 ⭐ 规律 1：方向可以给死，量级要打折

⭐⭐ **正确的说法要把两件事拆开**：

- **方向是解析命题（⛔ 不需代次折扣）**：健全检查器在**自己的谓词上**假阴率**按构造恒为 0**；LLM 检查器在**任何模型档位**都 > 0。⭐⭐ **这不是靠对照测出来的，是定义决定的** —— ⭐ 所以它不随模型代次失效，⭐ 这也是本规律唯一能在同代 ① 为零的情况下存活的原因。
- **量级是纯经验（⛔ 同代 ① 为零）**：只剩 1 条干净 ①，来自落后 **23** 个月的模型。

⭐ **另有一层证据使方向更可信**：它的四条原始数字跨了 **2023-03 · 2024-05 · 2025-04 · 2025-08** 四代仍**全部同向**。⛔ 绝对数字要打折，⭐ **但方向不用** —— ⭐ 跨两代半仍成立的方向比只在一代上成立的更可信。

### 4.3 ⛔⛔ 规律 2 为什么不成立 —— 本文最要紧的一条

**规律 2 的全部三条支撑，主结果模型都是厂商家族里的最弱档**：

- 一篇用 GPT-4.1-**Mini** 与 O4-**Mini**（落后 **12** 个月）
- 另一篇主结果用 GPT-4o-**mini**（落后 **21** 个月），⭐ 且论文自己给了理由，逐字（M）：`GPT-4o-mini is selected as it is a lightweight, cost-efficient, and fast LLM`

⛔⛔ **没有一条来自 2025-11 之后，⛔ 也没有一条来自任何厂商的旗舰档。**

⭐⭐ **而其中一篇自己给了代次威胁的直接证据**，逐字（M）：

> `This is because the LLM's reasoning attempts a fine-grained evaluation, similar to the MCeT approach`

⭐ **即一个推理模型裸跑（无任何方法）的召回 50%，⛔ 而弱模型上整套方法是 68.1%（裸跑 34.1%，成本 6.7×）。** ⭐ 严格说：**一次代次跨越（2024-07 → 2025-01）吃掉了该方法 34.1pp 增益里的约 16pp（≈47%）**（M：三个百分数出自原文；⭐ 47% 是我方算术），⛔ **不是全部**。⚠️ **限定**：该对照只有 8 张图，⭐ 且是按主结果的 per-case precision 分层抽的。

⭐⭐⭐ **含义**：「LLM 自评当裁决者收益近零」是在最弱档模型上测的，⭐ 而我们用 frontier。**这条两个方向都说不通**：

- 可能 frontier 上自评**更有用**（⭐ 最弱档的评审能力本身就不够）
- 也可能 frontier 上**更没用**（⭐ 裸输出已经够好，没有 headroom）
