## 一、要向导师汇报的结论

### 1.1 可以写进论文的结果

第一，完整方法在四个固定的模型—提供方—运行配置上都提高了发现覆盖的点估计。E2 的同 backbone 配对结果如下：

| backbone | FULL hit@1：baseline → ours | Δ hit@1 | FULL hit@3：baseline → ours | Δ hit@3 | FULL hit@all：baseline → ours | Δ hit@all |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| GPT-5.6 Luna（v61 历史只读） | 51.72% → 74.25% | +22.53 pp | 72.41% → 89.66% | +17.24 pp | 32.41% → 56.55% | +24.14 pp |
| Claude Sonnet 5 | 55.40% → 66.90% | +11.49 pp | 75.86% → 84.14% | +8.28 pp | 33.10% → 47.59% | +14.48 pp |
| Qwen3.8-27B | 51.72% → 71.49% | +19.77 pp | 65.52% → 86.21% | +20.69 pp | 36.55% → 55.86% | +19.31 pp |
| Muse Glimmer-30B | 56.78% → 74.02% | +17.24 pp | 65.52% → 85.52% | +20.00 pp | 47.59% → 60.69% | +13.10 pp |

第二，precision 的提升不是只出现在一个模型上。三款本轮新增的 12-predicate 配置在普通和 strict 两种口径上都上升：

| backbone | 普通 precision：baseline → ours | Δ | strict precision：baseline → ours | Δ |
| --- | ---: | ---: | ---: | ---: |
| Claude Sonnet 5 | 68.67% → 87.36% | +18.69 pp | 53.43% → 78.98% | +25.55 pp |
| Qwen3.8-27B | 81.10% → 89.25% | +8.15 pp | 74.51% → 81.52% | +7.02 pp |
| Muse Glimmer-30B | 77.97% → 84.95% | +6.97 pp | 70.04% → 78.24% | +8.20 pp |

普通 precision 定义为 `(K+N)/(K+N+I)`。strict precision 沿用 A1 的既有敏感性口径：只把 `validity != INVALID` 且 `d_tier ∈ {D1,D2}` 的报告计入有效分子，分母仍是全部发布报告数。它不是新的主指标，也不是把 D0 从数据中删除后重新计算的精度。[A1 定义](../paper_stm_issue_discover/discover_matrix/docs/generations/a1_no_inspect_20260906/analyze_a1.py)

Luna 的普通 precision 仅从 83.40% 到 84.05%（+0.65 pp），strict precision 从 78.71% 降到 75.08%（−3.63 pp）。这两行来自 v61 的 19 predicates 历史运行，不能与三个 12-predicate 新配置合成同一排行榜。稳妥的总括是：**完整方法在四个固定配置上均显示正向的 hit 点差；在三个新配置上，普通和 strict precision 同时提高；precision 增益的幅度依赖模型配置。**

第三，precision 上升伴随报告量增加，而不是简单少报。以 ours 与 baseline 的报告数除以 162 个格计算：Sonnet 为 5.08 对 4.41，Qwen 为 5.91 对 2.81，Muse 为 5.62 对 4.20；对应的 INVALID 比例分别从 31.33% 降到 12.64%、从 18.90% 降到 10.75%、从 22.03% 降到 15.05%。这与“方法把更多候选都压掉了”不符，更接近“在扩大候选入口的同时，借助证据约束减少无效发布”。这里的 INVALID 是本项目冻结的独立 Luna judge 判定，不直接等同于一般意义上的 hallucination。

### 1.2 不能写成的结论

- 不能写成“Sonnet 天生比 GPT 更容易幻觉”或“Luna 天生低幻觉”。E2 比较的是固定的模型、provider、prompt、推理档位、serving 和 judge 组合。
- 不能把四款模型按报告条数、普通 precision 或 hit 做 SOTA 排名。Luna 是历史 19-predicate 参照，三个新增模型是 12-predicate 新运行；公开 benchmark 的 effort、harness 和日期也不一致。
- 不能把 E2 的整体差值拆成仿真、形式化验证、谓词定义和 backend 回执各自的因果贡献。A1 只隔离前置 inspection 信息，A2 尚未提供谓词机制的消融结果。
- 不能把“precision 提高”写成已经测量了人工确认工时下降。导师指出低 precision 会放大人工确认负担，但本轮没有用户研究或工时记录。
- 不能把带有证据缺口的格改写为所有义务均满足；这类状态保留在逐格裁定中。

## 二、实验问题与故事线

### 2.1 导师意见对应的研究问题

导师在 2026-09-05 的路线意见是：分别在商用和开放模型中选择两个 backbone，用 `LLMx + FCSTM + 谓词` 对比同一个 `LLMx`；论文要说明方法能提高不同大模型在规定状态机任务上的效果，而不是比较哪个 LLM 更新或更强。谓词的论文重点是降低无依据报告，成本叙事和 predicate subset 探索暂缓。原始讨论见[导师记录](./2026-09-05-导师-paper1多模型对照与谓词降幻觉.md)。

据此，E2 的结果型研究问题可组织为：

1. **RQ1：跨模型覆盖。** 在保持输入、方法语义、轮次和裁定协议不变的条件下，同一个 backbone 加入完整方法后，145 条 expected ledger item 的 `hit@1/@3/@all` 如何变化？
2. **RQ2：报告有效性。** 方法是否在保持或增加候选入口的同时提高普通 precision 和 strict precision？invalid、D0、D1/D2、K/N/I 的组成如何变化？
3. **RQ3：模型行为画像。** 不同模型在报告广度、有效产出、严格等级选择、台账外倾向和重复稳定性上是否呈现不同组合？这些差异能否解释 precision headroom 和 hit 增益的不同幅度？
4. **A1（单模型消融）。** 在 Luna 上撤掉确定性 inspection 信息，保留 FCSTM、谓词和其余协议，测量 inspection 信息的条件增量；这是独立于 E2 的单模型结果。
5. **A2（后续）。** 在完成 E2 后指定 Sonnet 5 作为低 baseline-precision stress configuration，关闭整个 predicate mechanism，保持其余因素固定，检验谓词机制的联合效应。Sonnet 的选择是后验的实验设计决策，不是对 Claude 家族的先验定性；A2 结果尚未产生。

### 2.2 E1、E2、A1 的分工

E1 是接入和模型选择阶段，不提供 hit 或 precision 结论。它核对四款优先模型的 profile、身份、结构化调用路径和上下文可用性；Gemini 3.7/3.8 保留为已接入但 schema 受限的后置候选，不能因为少量 API 探针就写成全面健康。

E2 是主多模型实验：Sonnet、Qwen、Muse 各完成 `ours`/`baseline` 54 pairs × 3 rounds = 324 格，全部由唯一 Luna judge 完成两读、必要仲裁和 expected 核销。Luna 不在 E2 重新生成，使用 v61 的 324 个历史裁定作为只读参照。

A1 是单独的 Luna inspection 消融。其结果显示撤掉 inspection 后整体 hit@1 从 74.25% 降到 53.56%（−20.69 pp），L2 hit@1 降低 40.17 pp；普通 precision 从 84.05% 降到 80.34%，strict precision 反而从 75.08% 升到 77.40%。由于两代 predicate、提供方和运行条件存在差异，A1 不能被写成纯单因素因果估计，但它说明检查信息对深层行为候选入口具有明显支持作用。[A1 完整报告](../paper_stm_issue_discover/reports/2026-09-06-19-49-18-a1-no-inspect-v61-results-cn.md)

## 三、E2 设计与指标

### 3.1 分析单位与控制

数据由 9 个自然语言簇、54 个 `<自然语言描述，固定 PlantUML 状态机>` 输入对和 145 条冻结 ledger item 构成。每个输入对运行三轮，因此每个 arm 有 435 个 expected-round，三模型每个 arm 有 162 个 cell；所有新模型合计 972 个 cell。统计单位是 expected-round、ledger item、pair 和自然语言簇的嵌套结构，不能把 972 个 cell 当成 972 个独立样本。

每个新模型使用同一模型做 baseline/ours 配对：

- `baseline` 只接收原有自然语言和状态机上下文，不接收 FCSTM、inspection facts、predicate registry、typed binding 或执行回执。
- `ours` 保留冻结的 method/prompt/validator/eligibility 语义，加入 FCSTM、确定性 inspection、12 条类型化谓词和可执行 backend。
- 两臂都由同一个 `semantic-judge.two-stage.v3.11` Luna judge 进行 validity、relation、必要仲裁和 closure；judge 不是候选模型。
- 新增生成和裁定沿用登记的统一协议；具体部署复现步骤留在 E2 报告，不在本 talk 展开。

### 3.2 指标定义

为了描述模型的决策倾向，而不是给模型排一个总名次，使用以下五组指标：

| 指标 | 定义 | 解释边界 |
| --- | --- | --- |
| 报告广度 `B` | 全部发布报告数 / 162 个 cell | 模型提出候选的倾向，不代表候选正确 |
| 接受产出 `V` | `(K+N)` / 162 个 cell | 每个 cell 产生的有效报告量；N 不是独立新缺陷数 |
| 普通 precision `P` | `(K+N)/(K+N+I)` | 报告级主口径；分母是全部发布报告 |
| strict precision `P_s` | `validity != INVALID ∧ d_tier ∈ {D1,D2}` 的报告数 / 全部报告数 | D1/D2-only 敏感性口径，分母不变 |
| strict gap `G` | `P - P_s` | 被接受但未达到严格 D1/D2 等级的报告比例 |
| novelty share `N_v` | `N/(K+N)` | 有效报告中台账外报告的比例，不等于去重后的新缺陷率 |
| `hit@1` | 435 个 expected-round 中被 `VALID_KNOWN` FULL 支持的比例 | 单轮发现覆盖，不是报告条数 |
| `hit@3` / `hit@all` | 145 条台账中至少一轮 / 三轮都 FULL 命中的比例 | 跨轮聚合，不是报告条数 |
| round stability `S` | `hit@all / hit@3` | 已经命中过的条目在三轮中持续命中的比例 |
| W2 share `E` | ours 发布报告中取得 W2 回执的比例 | 可执行证据承诺；不等于 validity 或 hit，baseline 无同口径值 |

其中 `B`、`V`、`N_v` 描述模型的输出决策，`P`、`P_s`、`G` 描述选择门槛，`hit` 与 `S` 描述覆盖和重复稳定性。模型响应方法的方式用 `ours - baseline` 的差值表示，不把这些维度压成一个综合分数。

E2 的普通和 strict precision、hit 及画像指标均可由 [E2 离线校验器](../paper_stm_issue_discover/discover_matrix/docs/generations/e2_20260907/analyze_e2.py) 从保存的裁定结果复算，不调用 provider。

### 3.3 统计边界

所有实际发布的报告都保留在 precision 分母中；正常零发现、证据不足和降级状态不被改写成成功，也不因报告较少而获得额外优势。`K/N/I`、strict precision 和 hit 只由冻结的 judge 结果与 expected 集合计算，报告数量不能替代缺陷数量。

结果诊断仍保留在 E2 归档中，用于说明结果边界；它们不在本 talk 中作为模型能力排名依据。

## 四、E2 结果

### 4.1 主结果与 cluster bootstrap

三款新增模型的普通 precision 差值均为正，9 个自然语言簇同步重采样 10,000 次得到的 95% 区间也不跨 0：

| backbone | 普通 precision Δ（pp） | cluster bootstrap 95% 区间 | strict precision Δ（pp） | cluster bootstrap 95% 区间 |
| --- | ---: | ---: | ---: | ---: |
| Sonnet 5 | +18.69 | [11.00, 24.79] | +25.55 | [17.08, 33.05] |
| Qwen3.8-27B | +8.15 | [3.40, 13.65] | +7.02 | [0.26, 13.84] |
| Muse Glimmer-30B | +6.97 | [1.35, 13.36] | +8.20 | [0.59, 16.80] |

这些区间是按自然语言簇成组的描述性不确定性区间，不是把报告或 cell 当独立样本后的传统显著性检验。Sonnet 的普通 hit@1 点差为 +11.49 pp，但其 cluster 区间为 [−1.67, 25.37]；Qwen 和 Muse 的普通 hit@1 区间分别为 [8.83, 30.70] 和 [3.63, 26.30]。因此论文应写“hit 点估计在四个配置上均提高，新增 Qwen/Muse 的整体 hit 区间支持正向差异，Sonnet 的 precision 差异最稳定”，不要把所有 hit 指标统称为统计显著。

| 模型 / arm | reports | K/N/I | 普通 precision | strict precision | invalid rate | reports / 162 cells |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |

| Sonnet baseline | 715 | 340/151/224 | 491/715 = 68.67% | 382/715 = 53.43% | 31.33% | 4.41 |
| Qwen ours | 958 | 599/256/103 | 855/958 = 89.25% | 781/958 = 81.52% | 10.75% | 5.91 |
| Qwen baseline | 455 | 247/122/86 | 369/455 = 81.10% | 339/455 = 74.51% | 18.90% | 2.81 |
| Muse ours | 910 | 544/229/137 | 773/910 = 84.95% | 712/910 = 78.24% | 15.05% | 5.62 |
| Muse baseline | 681 | 347/184/150 | 531/681 = 77.97% | 477/681 = 70.04% | 22.03% | 4.20 |

Sonnet 的现象最集中：方法让报告量由 715 增至 823，但 INVALID 从 224 降到 104，普通 precision 增加 18.69 pp，strict precision 增加 25.55 pp。Qwen 的方法报告量增加 503，仍把 INVALID 比例从 18.90% 降至 10.75%；Muse 的报告量增加 229，INVALID 比例从 22.03% 降至 15.05%。因此可把谓词和可执行回执的作用表述为“限制无证据报告的发布”，但不能从 E2 单独区分谓词定义提供的搜索引导与 backend 回执的后验拦截。

## 五、四个模型的决策画像

### 5.1 Luna：高选择性锚点，而不是“低幻觉真值”

Luna 的 X1v2 baseline 普通 precision 已达到 83.40%，strict precision 为 78.71%。完整方法主要带来 coverage 增益：hit@1 增加 22.53 pp，hit@all 增加 24.14 pp，而普通 precision 只增加 0.65 pp。这个组合说明在该历史配置中，baseline 已经有较小的普通 precision headroom，方法的可见收益更多落在问题入口和跨轮重复命中。

公开 AA v4.2 记录中，Luna 的 LCR/GPQA/HLE/SciCode 为 83.7/91.1/39.5/53.6，Terminal-Bench 80.9；AA-Omniscience 净分为 −10.2833。后者不是本任务的 hallucination rate，且没有 Luna 对应的官方模型卡或系统卡。因而应写“当前 Luna 配置在本任务中表现为高 baseline precision 与高 coverage 增益”，不能写“Luna 本身普遍更可靠”。

### 5.2 Sonnet：最大 precision headroom 与最明显的选择性变化

Sonnet 的 baseline precision 最低（68.67%），strict precision 更低（53.43%），但公开 AA v4.2 的 LCR 82.0、GPQA 91.1、HLE 41.3、SciCode 54.3、Omniscience +16.45 和 Terminal-Bench 80.5 均显示它不是通用能力弱的模型。它在本任务上呈现的是“通用能力强，但无外部证据约束时报告选择性较弱”的配置行为。

加入完整方法后，Sonnet 的报告广度只由 4.41 增至 5.08，但有效报告产出由 3.03 增至 4.44；普通 precision 提高 18.69 pp，strict precision 提高 25.55 pp，strict gap 由 15.24 pp 缩小到 8.38 pp。也就是说，方法没有让它简单地少报，而是让更多候选同时通过普通有效性和严格缺陷等级筛选。它最突出的特征是“高断言倾向对外部约束高度敏感”：候选入口变化有限，选择性变化最大。

Anthropic Sonnet 5 system card 记录了 factual question / information extraction 上的 excessive hedging、偶发 hallucination、工具不可用时寻找 workaround、over-refusal 等风险。这些定性材料与本轮“高能力、报告选择性不稳定、外部结构约束收益大”的画像相容，但没有测量当前 E2 的 INVALID 机制，也不能把 system card 当作 E2 因果证据。[Sonnet 5 system card](https://www-cdn.anthropic.com/9e6a1044980d8c4ed85669faf9c2a8342e2e9f1e/Claude%20Sonnet%205%20System%20Card.pdf)

因此，Sonnet 适合作为 A2 的 stress configuration：它有最大的 ordinary/strict precision headroom，关闭谓词后最容易观察到“覆盖—选择性”的权衡。论文中应写“基于 E2 观察选择的低 baseline-precision 压力配置”，不写“Claude 家族天然幻觉更大”。

### 5.3 Qwen：高探索量与明显的覆盖扩张

Qwen 的报告广度由 2.81 增至 5.91，增幅是三款新增模型中最大；有效报告产出由 2.28 增至 5.28，hit@1 提高 19.77 pp。与此同时，普通 precision 从 81.10% 提高到 89.25%，strict precision 从 74.51% 提高到 81.52%。这是一种“先扩大候选入口，再保持较高选择性”的行为，而不是用减少报告来换取 precision。

Qwen 的 strict gap 由 6.59 pp 增至 7.72 pp，说明大规模扩大候选入口后，普通有效性和严格缺陷等级之间的距离略有增加；但 strict precision 仍然上升。其有效报告中的 novelty share 为 29.94%，低于 baseline 的 33.06%，说明方法把一部分探索重新集中到冻结台账相关的可核对对象上。最终服务使用 chat-template `reasoning_effort=low`，而公开 AA xhigh 行的 LCR/GPQA/HLE 为 82.0/90.5/33.9；当前 low 行为 77.3/84.5/14.0，二者不能混写。Qwen 官方模型卡报告原生 262,144 context、RoPE/YaRN 可扩展到 1M；这些规格可以解释其长上下文取向，但不能直接推出当前任务中的决策质量。[Qwen3.8-27B model card](https://huggingface.co/Qwen/Qwen3.8-27B)

Qwen 的模型画像应写成“高探索、覆盖扩张明显，同时保留较高选择性”。它的差异主要体现在候选入口数量和 coverage headroom，而不是简单的“更容易出错”。

### 5.4 Muse：较强的重复稳定性与证据承诺

Muse 的报告广度由 4.20 增至 5.62，有效报告产出由 3.28 增至 4.77；普通 precision 提高 6.97 pp，strict precision 提高 8.20 pp，hit@1 提高 17.24 pp。它的 round stability 为 70.97%，三款新增模型中最高；ours 的 W2 share 也最高（30.88%）。这是一种“候选扩张适中、重复判断稳定、较愿意把主张落到可执行证据”的行为。

Muse 的公开 AA LCR/GPQA/HLE/SciCode 为 83.3/83.5/22.0/44.9，Terminal-Bench 51.7；作者卡报告 IFBench 77.0、MCP Atlas 75.5、DeepSearch QA 74.6、SWE-bench Verified 76.0。它在 agent/tool 取向指标上有针对性优势，但 HLE、Terminal-Bench 和 AA-Omniscience 净分（−32.8500）不能支持“通用事实推理很强”的说法。Meta 模型卡还提醒新颖场景中的多步推理风险，以及 agent 部署需要 guardrails 和不可逆操作的人工确认。[Muse Glimmer-30B model card](https://huggingface.co/meta-models/Muse-Glimmer-30B)

Muse 的 strict gap 由 7.93 pp 缩小到 6.70 pp，novelty share 由 34.65% 降到 29.62%，说明方法让候选更集中于可严格解释的报告。论文中应将 Muse 描述为“工具/agent 取向的开放模型，在本任务中重复稳定性和证据承诺较好”，而不是用发现条数给它排名。

## 六、为什么模型差异在本任务上会被放大

### 6.1 baseline precision headroom 只是部分解释

四个配置的 baseline ordinary precision 与 precision 增益为：

| 配置 | baseline precision | ours precision | Δ precision |
| --- | ---: | ---: | ---: |
| Sonnet 5 | 68.67% | 87.36% | +18.69 pp |
| Muse Glimmer-30B | 77.97% | 84.95% | +6.97 pp |
| Qwen3.8-27B | 81.10% | 89.25% | +8.15 pp |
| Luna v61 | 83.40% | 84.05% | +0.65 pp |

四个点的 baseline precision 与 Δ precision 呈负相关（Pearson `r≈−0.95`），但这个数字只能作为探索性描述：样本只有四个配置，Luna 还使用 19 predicates 历史运行，不能据此建立回归或普遍规律。Qwen 的 baseline precision 高于 Muse，却获得更大的 precision 增益（8.15 对 6.97 pp），说明初始 headroom 之外，还存在模型的候选生成倾向、严格等级选择和重复稳定性等交互。

因此不把 precision 增益解释为“越弱的模型提升越大”。Sonnet 的关键变化是 `G` 显著收窄，Qwen 的关键变化是 `B` 和 `V` 大幅扩张，Muse 的关键变化是高 `S` 与高 `E` 下仍保持 precision 提升，Luna 则是 coverage 增益大于 precision 增益。四个模型改变的是不同的决策环节。

### 6.2 方法不是单纯“少报”，而是改变候选到发布的路径

如果方法只是压低输出，报告量和 hit 应同步下降；E2 中三款新增模型的报告量、hit 和 precision 同时上升。更符合观测的机制链是：

1. FCSTM 和 inspection 把层级、迁移、可达性、终止和响应等状态机事实整理成可检索对象，减少模型必须从长文本重新构造结构的负担。
2. predicate 的定义给候选提供类型化的搜索方向，例如精确迁移、初始入口、守卫、路径或一步进展，而不是只要求模型“找问题”。
3. typed binding、后端执行和回执身份链把候选绑定到具体模型、义务和证据；不能闭合的候选继续保留为 W1/W0 或诊断，不直接升格为强报告。

E2 的结果支持这条机制链与观测数据一致，但不识别第 2 步与第 3 步各自的独立效应。导师提出的“谓词不仅形式化，也用于降低幻觉”的方向可以写成设计动机；“谓词定义和 backend 分别贡献多少”要等有对应消融后再写。

### 6.3 公开 benchmark 只能提供行为背景

E1 的 benchmark 矩阵显示四款模型并不沿单一能力轴排列：

| 模型 / 公开档位 | AA-LCR v1.1 | GPQA Diamond | HLE text | SciCode | AA-Omniscience 净分 | Terminal-Bench 2.1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| GPT-5.6 Luna max | 83.7 | 91.1 | 39.5 | 53.6 | −10.2833 | 80.9 |
| Claude Sonnet 5 adaptive/max | 82.0 | 91.1 | 41.3 | 54.3 | +16.4500 | 80.5 |
| Qwen3.8-27B xhigh | 82.0 | 90.5 | 33.9 | 46.6 | −9.9833 | 79.8 |
| Qwen3.8-27B low（当前 serving 近似档） | 77.3 | 84.5 | 14.0 | 40.0 | −26.6667 | 67.4 |
| Muse Glimmer high | 83.3 | 83.5 | 22.0 | 44.9 | −32.8500 | 51.7 |

AA 分数是独立评测背景，不能替代 Paper1 的状态机 issue discovery。Omniscience 净分同时奖励正确、惩罚错误并处理拒答；其 `hallucinationRate` 分母是 non-correct responses，不能当作本任务 precision。Qwen 的公开 xhigh 与本轮 low 也不是同一推理档位。

pane9 中补查的公开论文进一步说明，不同 benchmark 测到的不是同一个“模型好坏”变量：

- **SimpleQA**（Wei 等，2024）将 correct、incorrect 和 not attempted 分开；较早版本中 Claude 3.5 Sonnet 的 not attempted 明显高于 GPT-4o，而 GPT-4o 的 incorrect 也更高。它说明回答、拒答和事实正确性必须分开统计，不能直接把“更愿意回答”当成更可靠。
- **LongFact/SAFE** 的 factual precision 在 Claude 3.5 与 GPT-4 之间接近，说明不能从模型家族名推出固定的事实精度方向；长输出还会同时影响 precision 和 recall。
- **FACTS Grounding** 与 **τ-bench** 显示 grounding 和重复工具交互的排序会随 judge、harness、重复次数变化；一次工具调用成功不等于多阶段流程稳定。
- **Structure- and Event-Driven Frameworks for State Machine Modeling with LLMs**（arXiv:2604.00275）是更接近本文的旁证：其单提示实验中 Claude 3.5 Sonnet precision 0.7931、GPT-4o precision 0.7130，结构/事件 scaffold 对不同模型的作用方向和幅度并不相同；该工作不是当前四款模型的直接成绩，也未替代本实验的固定源状态机协议。

这些材料共同支持的只是：**通用推理、事实可靠性、拒答/犹豫、工具稳定性和格式遵循是部分相关但不等价的维度。** E2 中出现的差异应解释为模型与任务 scaffold 的交互，而不是给模型家族贴一个固定的“幻觉高/低”标签。[完整 benchmark 矩阵](../paper_stm_issue_discover/reports/model_readiness_20260906/2026-09-07-04-30-00-candidate-benchmarks.md)

## 七、论文叙事建议

### 7.1 推荐的主线段落

可以把结果节写成四段连续论证：

1. **先说明配对设计。** 我们不比较不同 LLM 谁更强，而是在每个固定模型—provider 配置内比较 `LLMx` 与 `LLMx + FCSTM + predicates`，让模型能力差异不直接冒充方法增益。
2. **再报告跨配置 coverage。** 四个配置的 hit 点估计均提高；Qwen/Muse 的 cluster bootstrap 对整体 hit 支持正向差异，Sonnet 的 hit 区间较宽，但其 precision 区间稳定为正。
3. **接着报告 precision。** 三个新配置普通和 strict precision 同时提高，且报告量不降、INVALID 比例下降。这支持“方法降低无证据结构报告”的任务内结论；不要把它写成普遍 hallucination suppression。
4. **最后解释异质性。** Sonnet 的 baseline headroom 最大且 strict gap 收窄最多，Qwen 的报告广度和有效产出扩张最大，Muse 的重复稳定性和证据承诺最好，Luna 的历史 baseline precision 较高且主要体现 coverage 增益。模型差异是结果的一部分，不是需要抹平的噪声。

### 7.2 可直接使用的英文核心表述

> We evaluate four fixed model–provider–prompt configurations rather than ranking language models. Within each configuration, adding the FCSTM representation, deterministic inspection facts, typed predicates, and executable evidence changes discovery coverage and report validity. Across the three newly generated backbones, ordinary and D1/D2-only strict precision both increase, while report volume does not decrease. We therefore interpret the result as a task- and configuration-specific effect of evidence-constrained issue generation, not as a universal claim that one model family hallucinates more or less than another.

> The paired gains are heterogeneous. Sonnet 5 has the largest baseline precision headroom and the largest reduction in the ordinary-to-strict gap; Qwen3.8-27B expands report breadth and accepted output the most; Muse Glimmer-30B shows the strongest repeated-round stability and evidence commitment among the newly generated backbones; historical Luna has high baseline precision and most visibly gains in coverage. These profiles are descriptive interactions between model behavior and the task scaffold, not intrinsic rankings of the four models.

### 7.3 A2 选 Sonnet 的论证方式

A2 之前应把 Sonnet 选择登记为 **post-E2 exploratory stress configuration**：

- 选择依据是当前任务中 baseline ordinary/strict precision 最低，且完整方法的 precision 增益最大；不是引用公开 benchmark 断言 Claude 家族最容易幻觉。
- A2 仍保持 Sonnet model ID、provider、输入对、轮次、转换、inspection context、prompt 其余部分、validator 和 judge 固定，只关闭完整 predicate mechanism（词表、路由/绑定、backend、回执）。
- A2 的结果只回答 Sonnet 配置下的谓词机制联合效应，不能与 A1 Luna 的 inspection 差值直接做机制排名，也不能推广到所有模型。
- A2 若出现 hit 上升而 precision 下降，应解释为 coverage/selectivity trade-off，并报告报告量、INVALID、strict precision 和人工确认负担的代理指标；不能只挑 hit 或只挑 precision。

## 八、限制、后续讨论与审稿风险

1. **配置与代次不完全相同。** 新模型使用 12 predicates；历史 Luna 使用 19 predicates。Luna 行是历史参照，不是新连接下的四款同批次重跑。
2. **judge 共享。** 三款新模型全部由 Luna judge 完成，不能据此证明与另一 judge 或人工金标准一致；E2 没有人工确认。
3. **cluster 数量有限。** 只有 9 个自然语言簇，bootstrap 主要用于显示结果对簇组成的敏感性，不能当作大样本总体显著性证明。
4. **公开 benchmark 不同口径。** AA、模型卡和论文使用不同数据集、effort、harness、输出预算和 judge；它们只解释背景，不替代 E2。
5. **结果边界。** 运行诊断和证据缺口均保留在 E2 归档中，但不作为模型能力排名；最终格状态不能抹去语义证据不足，也不能外推为普遍能力。
6. **未测人工工作量。** precision 下降会增加人工确认的理论负担，但本轮没有审查者工时、inter-rater agreement 或真实部署吞吐数据。
7. **A2 尚未完成。** 当前可以提出“谓词机制可能改善选择性”的任务内解释，但不能在没有 A2 的情况下把模板引导和 backend 拦截分开，也不能把完整 E2 差值写成谓词单独的因果效应。

## 十、自审与导师讨论问题

### 学术审阅结论

- **贡献与问题匹配**：主张限定为“固定源状态机 issue discovery 中，方法对不同模型配置的任务内增益”，没有写成最新模型比较或跨语言优越性。
- **实验强度**：E2 有三款新模型的完整双臂 972 格和历史 Luna 只读参照；每个主要数字能回到 statistics/cells/luna history。bootstrap 的九簇限制已经显式写出。
- **指标完整性**：同时报告 hit、普通 precision、strict precision、K/N/I、报告广度、有效产出、novelty share、round stability 和 W2 evidence share，没有用单一报告数替代完整结果。
- **机制边界**：E2 支持完整方法的联合效果和任务内“无依据报告减少”解释；A1/A2 的单组件因果边界没有被越过。
- **文风与可读性**：正文采用“设计—结果—画像—解释—限制”顺序，删去成本和 SOTA 排名叙事；术语、分母、历史版本和失败状态保持原样。
