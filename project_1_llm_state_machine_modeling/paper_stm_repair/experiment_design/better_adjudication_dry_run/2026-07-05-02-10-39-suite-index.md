## 1. 核心结论

R5.7.5 已构造 20 个 protocol dry-run case，用来覆盖 Better STM 裁决协议的主要输出和风险路径；全部 case 均不是真实 repair loop 输出，不能进入 headline 或 repair effectiveness 统计 `[clm-suite-boundary]`。

anti-gaming risk flags 是最小覆盖表的有意超集：同一 case 可以同时标记主风险与次级风险，以便后续 reviewer dry-run 观察误判路径；但每个 case 仍只有一个 `primary_expected_verdict`，不得把次级风险标记外推为真实 repair 发现。
