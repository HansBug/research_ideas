# plan/ — PR-R0 执行记录

## 1. 职责

`plan/` 记录 PR-R0 的输入、产物、review、检查和剩余风险。这里的记录是 PR 执行审计，不是论文方法贡献，也不应进入 manuscript 主文。

## 2. 文件说明

| 文件 | 作用 |
|---|---|
| [progress.md](./progress.md) | 当前 PR 的阶段、输入、产物、自检、剩余风险。 |
| [agent_provenance.md](./agent_provenance.md) | 三路 reviewer、实现侧 subagent 和主 session 的 provenance。 |

## 3. 使用规则

1. 每次实现或 review 后更新 [progress.md](./progress.md)。
2. subagent 参与时更新 [agent_provenance.md](./agent_provenance.md)。
3. 不把 plan 记录写成论文贡献。
