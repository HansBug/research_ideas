# PR-R1.7 broad strict seed survey task packet

## 1. 目标

在 PR-R1.6 bounded snapshot v2 上继续扩展 `<NL, STM_0>` strict seed 文献与 artifact 文库，重点寻找公开、可复查、满足 `NL -> T0 FSM/HSM/EFSM/statechart` 生成关系的论文 / artifact，同时给 PR-R2 提供更透明的 negative evidence 和 manual download handoff。

## 2. 不做什么

- 不冻结最终四例样本。
- 不跑四例真实运行。
- 不调用真实 LLM，不读取 `.env`。
- 不实现转换器、不做修正循环、不改 method runtime。
- 不把 paper-only、private-only、project-constructed、SA-3/SA-4/SA-5 计入 R1.7 主 seed 成功门。

## 4. 证据门

每个新增或升级候选必须至少记录：题名、年份、venue/DOI/URL、输入类型、输出家族、生成关系、PDF/全文状态、artifact/license 状态、SS/SA、priority、风险、后续角色和证据指针。

`SS-A/SS-B/ES-C` 的全文候选原则上必须有单篇目录；若 artifact-only 或无法下载 PDF，需要在 `artifacts.md` 或 `manual_download_queue.md` 中说明例外。

## 5. 完成判据

1. 至少 8 个 R1.7 search round 记录或等价的 source/query/blocker 记录。
2. 至少 20 条新增 / 重判候选、负例或 manual queue 记录。
3. 至少 10 条新增正式候选进入 `candidate_matrix.md` 与 `screening_ledger.md`。
4. 至少 6 个新增或升级 P0/P1/P2 单篇目录。
5. R1.6 legacy manual queue 逐项转为 `downloaded / excluded / still-blocked`，并给 PR-R2 影响说明。
6. 若按 §1.3 可计入的 `SS-A/SS-B + SA-1/SA-2` 仍不足 6 条，则必须在 `seed_selection_candidates.md` 写出 negative evidence 与降级路径。
