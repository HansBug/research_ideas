# PR-R1.6 strict seed 扩展检索任务包

## 1. 目标

在 PR-R1.5 bounded snapshot v1 基础上，继续扩展 $NL \to T0$ `FSM/HSM/EFSM/statechart` strict seed 文献与 artifact 审计，优先补足可交给 PR-R2 的主 seed 候选；若仍不足，则形成可审计 negative evidence 与 blocker handoff。

## 2. 不做什么

- 不冻结最终四例样本。
- 不跑四例真实运行。
- 不调用真实 LLM，不读 `.env`。
- 不把 `fcstm` / `pyfcstm` / DSL 作为论文贡献。
- 不在本 PR 内执行 `sources/`、学生或人工 `STM_0` 构造。

## 4. 证据门

每个新增或升级候选至少要有以下证据中的大部分，且不得只凭摘要结论：

1. 题名、年份、venue、URL/DOI。
2. 输入类型与输出家族。
3. 生成/派生关系。
4. PDF / `paper_content.txt` / BibTeX。
5. artifact / license / code / data 可获取性。
6. SS/SA 分级与排除码。
7. 证据指针（页码、小节、文件路径、URL）。

## 5. 完成判据

二选一：

1. 成功补足 `>=4` 条可计入 PR-R2 的主 seed 候选；或
2. 给出足够强的 negative evidence，明确本轮检索边界内仍无法补足，并把缺口交接给 PR-R2。

## 6. 验证命令

- `git diff --check`
- Markdown 链接检查
- candidate / ledger ID 一致性检查
- search_log 与 search_rounds 交叉检查
