## 简报

这篇论文把下肢外骨骼的坐下、起立和行走控制整理成一个很清楚的 12 状态监督 `FSM`。低层每个髋膝关节使用可变增益 `PD` 控制器，高层则用用户上肢姿态推算得到的 `CoP` 位置来判断何时从 sitting 切到 standing、何时迈步、何时从 walking 回到 standing。

- 形式主义定位：面向截瘫外骨骼的 gait-phase supervisor，把姿态意图、步态阶段和关节轨迹压进同一离散控制器。
- 构造方式简述：高层 `FSM` 维护 4 个静态状态与 8 个过渡状态，低层为各关节下发轨迹和高低增益 `PD` 参数。
- 基础设施与场景简述：依托下肢外骨骼、髋膝编码器、腿段 IMU、拐杖稳定辅助和 host computer，服务坐下、起立、站立、平地步行的自主切换。

```text
用户上身前倾 / 侧倾 -> CoP 估计 -> 12 状态 gait FSM -> 关节轨迹 / PD 增益 -> 外骨骼执行
```

## 形式主义定义与核心对象

### 定义对象

论文中的关键对象包括：

1. 12 状态监督 `FSM`。
2. 4 个静态状态 `S1` 到 `S4`。
3. 8 个过渡状态 `S5` 到 `S12`。
4. 关节参考轨迹与高/低增益 `PD` 参数。
5. 由 IMU 与关节角计算得到的 `CoP` 估计 `X_c`。
6. 由步长 `X_h` 修正的步态触发阈值。

### 核心抽象

按论文结构，可把外骨骼控制器保守整理为：

$$
\mathcal{E} = (S, s_0, \Sigma, \delta, \Theta, K)
$$

上式中的符号逐项解释如下：

1. `S` 是 12 个 gait states 的集合。
2. `s_0` 是初始 sitting 状态。
3. `\Sigma` 是由 `CoP` 估计、前倾/侧倾和时间触发组成的事件集合。
4. `\delta` 是状态转移关系。
5. `\Theta` 是各状态下使用的关节轨迹集合。
6. `K` 是各状态下的 `PD` 增益配置。

论文明确给出了静态与过渡状态的集合，可写成：

$$
S = \{S_1, S_2, S_3, S_4\} \cup \{S_5, S_6, \ldots, S_{12}\}
$$

上式中的符号逐项解释如下：

1. `S_1` 是 sitting。
2. `S_2` 是 standing。
3. `S_3` 与 `S_4` 分别是右脚前与左脚前的双支撑静态状态。
4. `S_5` 到 `S_{12}` 是 sit-to-stand、stand-to-sit、step 与 walk-to-stand 等过渡状态。

论文中的用户意图主要由 `CoP` 触发，因此转移守卫可保守写成：

$$
\delta(s, X_c, X_h) = s' \quad \text{when } X_c \ge \eta(X_h)
$$

上式中的符号逐项解释如下：

1. `s` 是当前 gait state。
2. `X_c` 是估计的中心压力位置。
3. `X_h` 是步长估计。
4. `\eta(X_h)` 是随步长变化的触发阈值。
5. `s'` 是下一状态。

### 一个最小例子与通俗解释

一个最小例子是用户从坐姿起身并开始行走：

1. 初始状态在 `S1` sitting。
2. 用户前倾并向上撑拐杖，`CoP` 超过起立阈值。
3. 状态机进入 `S5` sit-to-stand，并用增益逐渐爬升到高增益模式。
4. 达到 standing 构型后转到 `S2`。
5. 用户继续前倾并向左或向右侧倾，状态机选择下一半步状态。
6. 完成一步后进入 `S3` 或 `S4`，若继续前倾则进入下一步；若暂停过久则回到 `S2` standing。

通俗地说，这个模型像一个“由身体重心驱动的步态开关箱”：用户不用按按钮，只要通过前倾、后仰和左右转移重心，就能触发外骨骼在坐、站、走几个模式之间切换。

### 运行 / 接受 / 转移语义

其运行语义可写成：

$$
(s_t, X_c(t), X_h(t), \theta_t, K_t) \xrightarrow{\delta} (s_{t+1}, u_t)
$$

上式中的符号逐项解释如下：

1. `s_t` 是当前状态。
2. `X_c(t)` 是当前 `CoP` 估计。
3. `X_h(t)` 是当前步长估计。
4. `\theta_t` 是当前关节轨迹模板。
5. `K_t` 是当前 `PD` 增益配置。
6. `u_t` 是下发到髋膝执行器的控制命令。

### 语义边界

这个模型的边界包括：

1. 它服务的是坐、站、平地步行的基本 mobility，而不是复杂地形运动。
2. 高层 `FSM` 依赖 `CoP` 估计和用户配合稳定成立。
3. 它主要是监督控制，不含形式验证、运动规划或复杂环境感知。
4. 论文假设用户借助稳定辅助器具，并且头/躯干可用简化模型估计。

### 关键性质与判定边界

| 问题 / 性质 | 形式化写法 | 原文意义 |
|---|---|---|
| 监督器骨架 | `$\mathcal{E} = (S, s_0, \Sigma, \delta, \Theta, K)$` | 高层状态、低层轨迹和增益分工明确。 |
| 状态集合 | `$S = \{S_1, S_2, S_3, S_4\} \cup \{S_5, \ldots, S_{12}\}$` | 4 个静态相位 + 8 个过渡相位构成完整 gait cycle。 |
| `CoP` 触发守卫 | `$\delta(s, X_c, X_h) = s' \text{ when } X_c \ge \eta(X_h)$` | 用户意图通过上身姿态而不是按钮输入进入状态机。 |
| 增益-轨迹耦合 | `$(\Theta, K)$ per state` | 每个状态都由轨迹模板和增益配置共同定义。 |

## 关键特性

| 维度 | 支持情况 | 说明 |
|---|---|---|
| 状态 / 模式 | 强支持 | sitting、standing、double support、step 等模式清晰。 |
| 事件 / 触发 | 强支持 | `CoP` 前后与左右偏移、时间阈值直接触发状态转移。 |
| 守卫 / 数据 | 强支持 | `CoP`、步长、关节构型、站立完成等条件都进入 guard。 |
| 层次 | 弱支持 | 论文用平铺 `FSM`，未显式层次化。 |
| 并发 / 同步 | 弱支持 | 重点是单个外骨骼 gait phase 切换。 |
| 时间约束 | 中等支持 | 停顿时长会触发从 walking 回到 standing。 |
| 连续动态 / 随机性 | 中等支持 | 关节控制是连续的，但高层是离散监督器。 |
| 可执行 / 可验证性 | 强执行、有限验证 | 实机截瘫用户实验充分，但非形式验证模型。 |

### 形式化问题与性质

1. 论文最有价值的点，是把用户意图检测和 gait phase 切换压成显式 `FSM`。
2. `CoP` 守卫提供了从自然语言“用户前倾开始走”到状态转移条件的直接映射。
3. 每个状态由轨迹和增益共同定义，说明任务状态与控制参数不应分离得过松。
4. 对 `project_1` 来说，这类条目很适合抽取“人体姿态阈值 -> 模式切换 -> 关节输出”模式。

## 构造方式与承载格式

### 建模入口

建模入口主要包括：

1. 用坐、站、步行相位定义离散状态。
2. 用 IMU 与关节角估计 `CoP` 和步长。
3. 用高低增益 `PD` 与轨迹模板定义每个状态的执行方式。
4. 用阈值条件决定状态转移。

### 机器可处理承载方式

原文直接给出的承载方式包括：

1. 12 状态 `FSM` 图。
2. 过渡状态对应的髋膝轨迹曲线。
3. 各状态对应的高/低增益配置。
4. `CoP` 阈值与 step-length 相关的切换逻辑。

### 交换与互操作

互操作重点在：

1. 传感器给监督器提供 `CoP` 与关节构型。
2. 监督器给关节控制器提供轨迹与增益。
3. 用户通过身体姿态而不是按钮与状态机交互。
4. 微控制器与 host computer 共同承担执行与数据采集。

## 适用场景与需求前提

### 适用场景

适合强调坐下、起立、站立和步行基本移动能力的下肢外骨骼或康复辅助设备。

### 需求前提

1. 用户意图可通过 `CoP`、前倾和侧倾可靠估计。
2. 任务主要由有限 gait phases 组成。
3. 低层关节控制可以稳定跟踪模板轨迹。
4. 使用环境是受控平地，且用户具备外部稳定辅助。

### 不适用或高成本场景

若场景涉及复杂地形、快速转向、上下楼梯或强外界扰动，仅用这套 12 状态 `FSM` 会明显不足。

## 与相邻形式主义的关系

它比一般 gait phase `FSM` 更强调用户自主触发，而不是外部按键或操作员控制；相对行为树，它更适合表达严格顺序的步态相位；相对混成自动机，它没有把连续动力学显式形式化，而是把连续关节控制留给 `PD` 层。

## 与本研究的关系

### 对 Project 1 的价值

它很好地展示了如何把“用户想站起来/想走一步”这类需求语句转成可执行的守卫条件和有限模式。

### 作为目标形式主义还是中间表示

对步态辅助控制器来说，它可以直接作为目标形式主义；对更大康复系统来说，它更适合作为上层行为监督器的中间表示。

### 对需求到模型生成的启发

1. 人体姿态与阈值条件适合直接抽成 guard。
2. 状态不必很多，但要把静态相位与过渡相位分开。
3. 轨迹模板和状态语义应同步建模，而不是分散在注释里。
4. “暂停过久则停止行走”这类时间条件应显式转成状态转移。

### 现实限制

这套模型依赖较强的人机耦合假设和 `CoP` 估计精度，推广到更复杂人群或更复杂活动时需要重新设计状态与守卫。

## 重要的相关工作

- 早期 `FES` 与 orthosis 系统：论文将其作为有按钮或外部操作员控制的前例。
- `ReWalk` 与 `Ekso`：作为商业外骨骼对照，但论文指出公开控制细节不足。
- Vanderbilt powered orthosis 系列工作：提供该控制器的硬件平台基础。
- gait phase / mobility assessment 工作：为 TUG 试验和步态阶段划分提供背景。
