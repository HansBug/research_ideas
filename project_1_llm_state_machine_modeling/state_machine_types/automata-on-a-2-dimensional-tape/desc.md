## 简报

这篇早期论文把普通一维 finite automaton 的“沿串扫描”推广成“在有限二维网格上移动扫描”的模式。自动机不能改写 tape，只能读取当前格子的 `0/1/B` 并据此更新状态、再朝 `N/E/S/W` 四个方向移动一步。它关心的不是协议串或控制器状态，而是二维图案、连通区域、矩形/方形等空间对象能否被有限状态扫描者识别。

- 形式主义定位：把有限自动机从线性 tape 扩展到二维离散网格的经典空间自动机分支。
- 构造方式简述：用有限状态集、下一状态函数和移动方向函数描述一个在二维带上游走的只读扫描器。
- 基础设施与场景简述：原文完全是理论模型，没有工程标准，但它给出了二维 pattern-recognition 自动机的最早清晰骨架。

```text
二维图案 / 有限网格 -> 当前格局部读取 -> 状态更新 + 方向移动 -> 接受 / 拒绝 / 循环
```

## 形式主义定义与核心对象

### 定义对象

论文研究的是“在有限二维 tape 上移动的自动机”。tape 是一个有限方形网格，边界格标成 `B`，内部格标成 `0` 或 `1`。自动机每一步只看到当前格的符号，然后依靠有限内部状态决定下一状态和移动方向。

### 核心抽象

原文给出的二维自动机骨架可写成：

$$
U = (S, f, g, s_0, s_Y, s_N)
$$

上式中的符号逐项解释如下：

1. `S` 是有限状态集。
2. `f` 是下一状态函数，按原文写法它由“当前状态 + 当前扫描符号”决定下一状态。
3. `g` 是移动方向函数，按原文写法它把“当前状态 + 当前扫描符号”映射到 `N/E/S/W`。
4. `s_0` 是初始状态。
5. `s_Y` 是接受状态。
6. `s_N` 是拒绝状态。

结合论文文字说明，可以把其一步运行关系保守整理为：

$$
(q_t, p_t) \to (f(q_t, T(p_t)),\ p_t + \mathrm{dir}(g(q_t, T(p_t))))
$$

这里的符号逐项解释如下：

1. `q_t` 是第 `t` 步的内部状态。
2. `p_t` 是第 `t` 步扫描头所在的网格坐标。
3. `T(p_t)` 是当前位置的 tape 符号，取值为 `0`、`1` 或 `B`。
4. `\mathrm{dir}(\cdot)` 把 `N/E/S/W` 解释成对应的坐标位移。
5. `f(q_t, T(p_t))` 是下一状态。
6. `p_t + \mathrm{dir}(g(q_t, T(p_t)))` 是向北、东、南或西移动一步后的新位置。

这条运行式不是原文以公式显式排版给出的定义，而是按照原文“state update + direction of motion”叙述做的保守符号化整理。

### 一个最小例子与通俗解释

原文最简单的可判定例子之一是“tape 上恰好有 `k` 个 `1`”。自动机可以逐格扫描整个网格，每看到一个 `1` 就把内部状态转到“已计数 `i` 个 `1`”对应的状态。若最终到达边界扫描结束时状态恰好是 `k`，就接受，否则拒绝。

通俗地说，这类模型像一个“只能看眼前一格、但能在二维棋盘上四处走动的小机器人”。它没有栈、没有额外内存，也不能给地面做永久标记，所以能否识别一个图案，完全取决于有限状态和扫描路径是否足够。

### 运行 / 接受 / 转移语义

原文的接受语义是：自动机从初始状态 `s_0`、指定起始方格开始扫描，若最终停在 `s_Y` 则接受，若停在 `s_N` 则拒绝；若永远不停止，就视为循环而非决定。

可把这一点整理成：

$$
\mathrm{Acc}(U, T) \iff \exists n \ge 0,\ q_n = s_Y
$$

$$
\mathrm{Rej}(U, T) \iff \exists n \ge 0,\ q_n = s_N
$$

$$
\mathrm{Decides}(U, P) \iff
\forall T,\ T \in P \Rightarrow \mathrm{Acc}(U,T),\quad
T \notin P \Rightarrow \mathrm{Rej}(U,T)
$$

上式中的符号逐项解释如下：

1. `T` 是一个具体二维 tape。
2. `q_n` 是运行到第 `n` 步时的状态。
3. `\mathrm{Acc}(U,T)` 表示 `U` 接受 `T`。
4. `\mathrm{Rej}(U,T)` 表示 `U` 拒绝 `T`。
5. `P` 是某个图案性质类，例如“是否是矩形”“是否连通”等。
6. `\mathrm{Decides}(U, P)` 表示 `U` 对性质 `P` 给出总是停机的接受/拒绝判定。

### 语义边界

这个模型的边界非常鲜明：

1. 输入不是线性词，而是二维离散网格。
2. 自动机是移动式扫描者，不是像 `Cellular Automata` 那样的全局同步更新系统。
3. 基础模型不能在 tape 上留下持久标记，因此很多“需要回访和比较远处结构”的性质会失去可判定性。

### 关键性质与判定边界

原文给出的代表性边界包括：

$$
\exists P_{\mathrm{sym}},\ \neg \exists U\ \mathrm{Decides}(U, P_{\mathrm{sym}})
$$

其中 `P_{\mathrm{sym}}` 可取“关于中央列对称”这类性质。论文明确指出这类图案性质不由基础二维自动机决定。

论文还指出二维自动机的空白带接受问题具有递归不可解性，可保守压缩成：

$$
\text{Given } U,\ \text{decide whether } U \text{ accepts the blank tape}
$$

这是不可判定的。其直觉原因是二维位置坐标可模拟计数器，因此二维扫描模型的能力远高于普通一维有限自动机。

同时，原文也展示了 marker 扩展后能力会显著上升，例如一标记自动机可以判定 pathwise connectedness。这说明二维带自动机天然会分化出“无标记 / 有标记”的后续子分支。

## 关键特性

| 维度 | 支持情况 | 说明 |
|---|---|---|
| 状态 / 模式 | 支持 | 有限内部状态控制扫描行为。 |
| 事件 / 触发 | 不适用 | 触发来自当前格符号而非外部事件流。 |
| 守卫 / 数据 | 很弱 | 只有当前格局部读值，没有一般变量守卫。 |
| 层次 | 不支持 | 原始模型是平坦有限控制。 |
| 并发 / 同步 | 不支持 | 单扫描头串行运行。 |
| 时间约束 | 不支持 | 无显式时钟。 |
| 连续动态 / 随机性 | 不支持 | 纯离散、确定扫描。 |
| 可执行 / 可验证性 | 部分支持 | 基础运行规则清晰，但总体能力边界很快进入不可判定。 |

### 形式化问题与性质

| 问题 / 性质 | 形式化写法 | 原文意义 |

| 模型元组 | `$U=(S,f,g,s_0,s_Y,s_N)$` | 二维扫描自动机由状态更新和方向移动共同定义。 |
| 一步运行 | `$(q_t,p_t)\to(f(q_t,T(p_t)),p_t+\mathrm{dir}(g(q_t,T(p_t))))$` | 每步只读当前位置并移动一格。 |

## 构造方式与承载格式

### 建模入口

建模入口是：

1. 定义二维有限网格及边界符号 `B`。
2. 给出内部状态集。
3. 为每个“状态 + 当前格符号”指定下一状态和移动方向。

### 机器可处理承载方式

原文的机器承载方式本质上就是状态转移表与方向表，而不是 XML/JSON 之类的工程交换格式。

### 交换与互操作

原文没有标准格式，但它和 picture language、maze search、spatial pattern recognition 这些后续理论线天然互操作。

## 适用场景与需求前提

### 适用场景

适合研究网格图案、二维连接性、矩形/方形识别、空间搜索和“对象维度改变后有限状态能力如何变化”这类问题。

### 需求前提

1. 输入对象必须天然是二维离散网格。
2. 需求核心是局部扫描与空间移动，而不是变量守卫、时钟或并发。
3. 可以接受“有限状态 + 单扫描头”的强约束。

### 不适用或高成本场景

若需求对象是协议串、树结构、控制器状态或连续物理过程，这类二维带自动机就不是合适主线。

## 与相邻形式主义的关系

相对普通 `Finite Automata`，它把一维 tape 改成二维网格并引入方向移动；相对 `Cellular Automata`，它不是并行局部更新而是单主体扫描；相对 `Tree Automata`，它描述的是空间图案而不是层次树语言。

## 与本研究的关系

### 对 Project 1 的价值

它不是控制系统状态机自动建模的主流目标，但对“状态机族演化树”的边界完整性很重要，因为它展示了 automata theory 主干如何向空间对象分支扩展。

### 作为目标形式主义还是中间表示

通常不作为 `project_1` 的目标形式主义，更适合作为谱系中的经典边缘分支。

### 对需求到模型生成的启发

它提醒我们：当需求对象从线性事件流变成二维图案时，不能继续用普通 `FSM` 的默认直觉，必须切换到与对象结构匹配的状态机家族。

### 现实限制

缺少工程标准和工具链，而且基础模型没有额外记忆，因此对复杂二维性质的能力边界很快暴露出来。
