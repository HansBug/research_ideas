## 当前收录重心

- 当前阶段仍以**扩充状态机族演化树**为第一目标：每轮优先收能直接挂到主树上的 `🧱` 模型本体节点，而不是继续堆应用侧证。
- 本轮优先补的是 classic acceptance-family / infinite-object 支线：从 `Finite Automata` 母线补出 `Alternating Automata`，从 `\omega`-automata 母线补出 `Bi-Infinite Word Automata`，从 `Infinite-Tree Automata` 母线补出 `Alternating Parity`、`Co-Büchi` 与 `Landweber / Muller-Superset`。
- `Tree Automata -> Infinite-Tree Automata` 现在不再只有 `Rabin / Finite-Tree-on-Infinite-Trees / Weak Alternating` 三个孤点，而是开始形成 `alternating -> co-Büchi` 与 `Muller` 弱化分支两条可继续扩展的 acceptance-family 结构。
- `Weak Alternating Tree Automata` 现在可以稳定回挂到 `Alternating Tree Automata / Alternating Parity Tree Automata` 主线之下，后续继续补 `Muller / parity / full alternating` 时不必再把各 acceptance 条件分散挂接。
- `Bi-Infinite Word Automata` 与 `Alternation` 的补入，让 `Finite automata on infinite objects` 不再只停留在总母节点说明，`word / bi-infinite / tree` 三条 classic infinite-object 语义线也开始被更清楚地区分。
- 下一轮仍优先追 `Thatcher/Wright`、经典 `Muller / parity / full alternating tree automata`、更早的 `McNaughton / one-sided parity`、`biautomata` 近邻母文献，以及少数能直接补树的 weighted / probabilistic / picture-language 经典节点。
- 对 `DSL / runtime / toolchain / application` 这类方向，除非能直接补语言本体或主树挂接依据，否则继续降为次级 backlog，不与 classic automata theory 扩树竞争优先级。

## 待优先补入方向

1. `Finite Automata -> Alternating Automata` 已补出母节点，下一轮优先追更早或更纯的 alternating word / acceptance-family 经典条目，尽量把 word-side alternation 与 complexity-side work 继续分开。
2. `Infinite-Object Automata / ω-Automata -> Büchi / Bi-Infinite Word Automata` 现在已有两条主枝，下一轮优先补 `McNaughton`、one-sided `Muller / parity` 和与双向无限词直接相邻的经典节点。
3. `Tree Acceptors -> Tree Automata -> Thatcher/Wright / recognizable tree sets` 仍是有限树主线最重要的前序缺口。
4. `Tree Automata -> Infinite-Tree Automata -> Rabin / Finite-Tree-on-Infinite-Trees / Alternating Parity / Weak Alternating / Co-Büchi / Landweber-Muller-Superset` 已初步连成 acceptance-family 骨架，下一轮优先补 `Muller / parity / full alternating tree automata` 的经典母文献。
5. `Alternating Tree Automata -> Co-Büchi` 已补出，但 generalized / complement / parity 之间仍可继续细分，后续优先找能直接稳定命名子类的条目。
6. `Finite Automata -> Probabilistic Automata -> cut-point / isolated cut-point / stochastic extensions` 仍值得继续追更系统的经典理论条目。
7. `Finite Automata -> Weighted Automata -> weighted logics / valuation monoid` 继续保留为第二梯队，优先收能直接补主树或统一视角的经典母文献。
8. `Finite Automata -> Two-Dimensional Automata -> marker / pebble / picture-language` 这条空间对象主线已有母节点，下一轮可继续补更纯的 picture-language 条目。
9. `Petri Nets -> Time Petri Nets / ISO-15909 / PNML / High-Level / Nets-within-Nets` 与 `I/O Automata -> Interface / Contract` 继续保留为稳定次级扩树方向。
10. `Timed / Hybrid` 主干最近几轮已密集补树，除非出现能直接闭合 mother-line 缺口的经典本体条目，否则暂时让位于 infinite-word / infinite-tree acceptance-family 主线。
