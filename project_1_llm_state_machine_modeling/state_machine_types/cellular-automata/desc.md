## 形式主义定义与核心对象

### 定义对象

文章把细胞自动机定义成由大量离散、同构、局部相互作用单元组成的格点系统。每个 site 取有限状态值，并按统一局部规则在离散时间步上同步更新。

### 核心抽象

文中的一般定义可以概括为：

1. 一个离散 lattice。
2. 每个 site 取有限值集中的一个值。
3. 更新规则只依赖局部邻域。
4. 所有 site 同步迭代。

文章还给出了典型一维例子：

$$
a_i(t+1) = a_{i-1}(t) + a_{i+1}(t) \bmod 2
$$

这说明 `CA` 的核心不是全局控制状态，而是局部规则反复作用后的整体模式。

### 语义边界

相对 `Two-Dimensional Automata`，细胞自动机没有“移动中的读取头”，而是每个单元同时更新；相对 `Finite Automata`，对象从串变成格点场；相对 `Hybrid Automata`，它不描述连续物理流。

1. 格点维度与拓扑。

## 适用场景与需求前提

### 适用场景

适用于局部相互作用、大量同构单元、空间扩散/生长模式、并行计算和复杂系统行为研究。

### 需求前提

1. 系统由大量局部相互作用单元组成。
2. 更新规则在各单元上同构且局部。
3. 关注点是整体涌现行为而不是单一控制器状态图。

### 不适用或高成本场景

若需求是明确的控制流程、接口契约或带变量守卫的事件驱动逻辑，细胞自动机就不是直接主线。

## 与相邻形式主义的关系

相对 `Two-Dimensional Automata`，它没有移动控制头而是全域同步更新；相对 `Finite Automata`，它处理的是格点阵列而不是单串；相对 `Petri Nets`，它更强调局部空间更新而不是 token 流与并发资源语义。
