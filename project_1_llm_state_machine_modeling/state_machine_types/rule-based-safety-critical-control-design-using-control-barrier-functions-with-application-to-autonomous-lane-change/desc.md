## 简报

这篇论文最重要的点，是把传统“高层行为规划 + 中层轨迹规划 + 低层跟踪控制”的变道链路压缩成一个单一的低层安全关键 planner-controller。作者用一个小型 `FSM` 决定当前属于 `ACC`、左右变道还是回退状态，再让不同状态切换不同的 `CLF-CBF-QP` 约束组，从而在高频下直接做安全关键控制。

- 形式主义定位：面向自动驾驶变道任务的离散-连续混合控制器，其中 `FSM` 负责离散模式切换，`CLF-CBF-QP` 负责连续控制输入求解。
- 构造方式简述：用输入信号 `c/p/e` 驱动状态切换，并在各状态下挂接不同 `CBF` 与 `CLF` 约束。
- 基础设施与场景简述：依托运动学自行车模型、凸二次规划、`CBF/CLF` 约束、`GitHub` 代码与数值仿真，服务高速/城市道路变道控制场景。

```text
高层变道指令 + 交通环境 -> FSM 状态 -> 对应 CLF/CBF 约束组 -> QP 求输入 -> 安全变道 / 回退
```

## 形式主义定义与核心对象

### 定义对象

论文中的关键对象包括：

1. 五个 `FSM` 状态：`ACC`、`L`、`R`、`BL`、`BR`。
2. 三类输入信号：高层命令 `c`、位置信息 `p`、交通环境可行性 `e`。
3. 运动学自行车模型。
4. 控制李雅普诺夫函数 `CLF`。
5. 控制障碍函数 `CBF`。
6. 二次规划求解器 `CLF-CBF-QP`。
7. 周围关键车辆 `fc`、`ft`、`bt`。

### 核心抽象

论文中的离散控制骨架可保守整理为：

$$
\mathcal{F} = (Q, \Sigma, \delta, q_0, \Omega)
$$

上式中的符号逐项解释如下：

1. `Q = \{\mathrm{ACC}, L, R, BL, BR\}` 是离散状态集合。
2. `\Sigma = C \times P \times E` 是输入集合。
3. `\delta` 是状态转移函数。
4. `q_0 = \mathrm{ACC}` 是初始状态。
5. `\Omega` 是输出集合，对应当前启用的控制约束组。

论文把车辆连续动力学简化为非线性仿射模型：

$$
\dot{x} = f(x) + g(x)u
$$

上式中的符号逐项解释如下：

1. `x` 是系统状态，例如车辆位置、姿态、速度。
2. `u` 是控制输入。
3. `f(x)` 是系统自然动力学项。
4. `g(x)` 是输入作用矩阵。

控制器核心优化问题为：

$$
u^\ast = \arg\min_{(u,\delta)}
\frac{1}{2}u^\top H u + p_v \delta_v^2 + p_y \delta_y^2 + p_\psi \delta_\psi^2
$$

并满足：

$$
L_f V_j(x) + L_g V_j(x)u \le -\alpha_j V_j(x) + \delta_j
$$

$$
\frac{\partial h_k(x,t)}{\partial t} + L_f h_k(x,t) + L_g h_k(x,t)u \ge -\gamma_k h_k(x,t)
$$

上式中的符号逐项解释如下：

1. `H` 是正定权重矩阵。
2. `V_j` 是不同控制目标对应的 `CLF`。
3. `h_k` 是不同安全约束对应的 `CBF`。
4. `L_f`、`L_g` 是沿系统动力学的 Lie 导数。
5. `\delta_j` 是 `CLF` 软约束松弛变量。
6. `\alpha_j` 与 `\gamma_k` 分别是稳定性和安全性参数。

一个关键 `CBF` 例子是前车安全距离约束：

$$
h_{fc}(x,t)=
\begin{cases}
\Delta x_{fc} - (1+\epsilon)v - \frac{(v_{fc}-v)^2}{2a_l}, & v \ge v_{fc} \\
\Delta x_{fc} - (1+\epsilon)v, & \text{否则}
\end{cases}
$$

其中：

1. `\Delta x_{fc}` 是自车与当前车道前车的纵向净距离。
2. `v` 是自车速度。
3. `v_{fc}` 是前车速度。
4. `a_l` 是允许减速度界。
5. `\epsilon` 是安全裕量。

### 一个最小例子与通俗解释

最小例子可以这样理解：

1. 高层命令 `c=1`，表示自车想向左变道。
2. `FSM` 在 `ACC` 状态下先检查是否有足够空间，如果没有就继续跟车。
3. 一旦检测到左侧满足安全约束，状态切到 `L`，启用左变道所需的 `CLF/CBF` 约束组。
4. 如果变道过程中突然有车逼近导致约束不可满足，状态会切到 `BL`，控制器把车辆带回原车道。
5. 等待重新安全后，再次尝试进入 `L`。

通俗地说，这个模型像“会看时机的安全驾驶员”：它不直接吐出整条变道轨迹，而是先判断能不能变、变到一半是否要撤回，然后每个阶段都由一个带安全护栏的二次规划控制器算出下一拍控制输入。

### 运行 / 接受 / 转移语义

离散状态推进可概括为：

$$
\delta: Q \times (c,p,e) \rightarrow Q
$$

其中：

1. `c` 表示高层变道命令，`0` 对应保持当前车道，`1/-1` 对应左右变道。
2. `p` 表示车辆是否仍在原车道、跨过车道边界或已进入目标车道。
3. `e` 表示当前 `CLF-CBF-QP` 是否仍可满足安全变道条件。

连续控制则由当前状态选出的约束组驱动：

$$
q_t \xrightarrow{\delta(c,p,e)} q_{t+1}
\xrightarrow{\Omega(q_{t+1})} u^\ast
$$

上式中的符号逐项解释如下：

1. `q_t` 是当前离散状态。
2. `q_{t+1}` 是 `FSM` 切换后的新状态。
3. `\Omega(q_{t+1})` 表示该状态对应的一组 `CLF` 与 `CBF` 约束。
4. `u^\ast` 是当前时刻求得的最优控制输入。

### 语义边界

这个控制器的边界包括：

1. 它是低层安全关键 planner-controller，不是全局路线规划器。
2. 它依赖较准确的周车感知，并假定传感器无明显时延。
3. 它基于小侧偏角近似和运动学自行车模型，因此高横向激烈工况下适用性有限。
4. 它主要关注车道级变道，不覆盖复杂路口决策。

### 关键性质与判定边界

| 问题 / 性质 | 形式化写法 | 原文意义 |
|---|---|---|
| 离散骨架 | `$\mathcal{F} = (Q, \Sigma, \delta, q_0, \Omega)$` | 变道逻辑由有限状态机组织。 |
| 连续动力学 | `$\dot{x} = f(x) + g(x)u$` | 底层连续控制基于非线性仿射模型。 |
| 稳定性约束 | `$L_f V_j + L_g V_j u \le -\alpha_j V_j + \delta_j$` | `CLF` 负责速度、横向位置和航向等控制目标。 |
| 安全约束 | `$\partial_t h_k + L_f h_k + L_g h_k u \ge -\gamma_k h_k$` | `CBF` 保证与前/后/目标车道车辆的安全距离。 |

## 关键特性

| 维度 | 支持情况 | 说明 |
|---|---|---|
| 状态 / 模式 | 强支持 | 论文明确给出 `ACC/L/R/BL/BR` 五种模式。 |
| 事件 / 触发 | 强支持 | 高层命令、车辆横向位置和环境可行性共同驱动转移。 |
| 守卫 / 数据 | 强支持 | 安全距离、车辆速度、可行性判定都是核心守卫。 |
| 层次 | 弱支持 | 不是层次状态机，而是扁平模式机。 |
| 并发 / 同步 | 弱支持 | 重点是单车控制器，不是多主体组合。 |
| 时间约束 | 中等支持 | 高更新频率很关键，但没有显式时钟自动机语义。 |
| 连续动态 / 随机性 | 强支持 | 状态机直接切换连续控制约束组。 |
| 可执行 / 可验证性 | 强执行、较强安全语义 | 有代码和视频，且安全性来自 `CBF` 不变集约束。 |

### 形式化问题与性质

1. 这篇论文把状态机从“中层决策器”下沉为“低层安全控制器的约束切换器”，这是最有价值的地方。
2. `FSM` 的职责不是生成整条轨迹，而是决定当前该启用哪一组 `CBF/CLF` 约束。
3. 因为 `QP` 求解代价低，状态切换可以在高频下运行，适合快速变化环境。
4. 这种设计特别适合需要“可撤回、可重试”的安全关键机动。

## 构造方式与承载格式

### 建模入口

建模入口主要包括：

1. 用运动学自行车模型建立连续动力学。
2. 用 `ACC/L/R/BL/BR` 建立离散模式。
3. 用 `CBF` 定义与关键车辆的安全距离约束。
4. 用 `CLF-CBF-QP` 求当前模式下的最优控制输入。

### 机器可处理承载方式

原文直接给出的承载方式包括：

1. `FSM` 状态图。
2. 车辆动力学方程。
3. `CLF` 与 `CBF` 约束。
4. 二次规划问题。
5. 开源代码实现。

### 交换与互操作

互操作重点在：

1. 高层行为规划器向 `FSM` 发送左右变道命令。
2. 感知系统向 `FSM` 和 `QP` 发送周车位置与速度信息。
3. `FSM` 根据 `c/p/e` 选择当前控制模式。
4. 模式对应的 `CLF-CBF-QP` 输出油门/制动/转向相关控制输入。

## 适用场景与需求前提

### 适用场景

适合高速和城市道路上的安全关键变道控制、需要“发现时机 -> 执行变道 -> 发现威胁就回退”的自动驾驶控制场景。

### 需求前提

1. 周围关键车辆可被稳定感知。
2. 车辆动力学可用运动学自行车模型近似。
3. 问题可接受基于安全距离的 `CBF` 约束建模。
4. 系统需要高频实时求解，而不是低频全局规划。

### 不适用或高成本场景

如果环境感知噪声和时延很大、车辆高侧偏激烈机动频繁、或任务涉及复杂交叉口博弈，仅靠本文的 `FSM + CLF-CBF-QP` 会受到明显限制。

## 与相邻形式主义的关系

相对传统“行为规划器 + 轨迹规划器 + 跟踪控制器”三段式链路，它把中层和低层压到一个安全关键控制器里；相对纯 `MPC` 变道控制，它更强调可解释的离散模式切换；相对纯规则 FSM，它又通过 `CBF/CLF` 获得了连续安全语义。

## 与本研究的关系

### 对 Project 1 的价值

这篇条目说明状态机不仅能选动作，还能选“当前生效的安全约束组”，这对后续做高可信状态机生成非常重要。

### 作为目标形式主义还是中间表示

对安全关键变道控制而言，它可以直接作为目标执行载体；对更大自动驾驶架构来说，它也可作为低层安全控制中间表示。

### 对需求到模型生成的启发

1. 需求里的“允许变道”“撤回变道”“保持跟驰”天然对应离散状态。
2. 生成状态机时，应同步生成每个状态关联的连续安全约束，而不是只生成状态名称。
3. 面向安全关键任务，状态机完全可以成为形式化安全约束的开关。

## 重要的相关工作

- `CLF-CBF-QP` 在自适应巡航上的早期工作：是本文低层安全控制的直接前驱。
- `MPC` 变道与轨迹跟踪路线：是论文明确对比的传统链路。
- `CBF` 车道保持与障碍规避工作：为变道安全约束设计提供基础。
