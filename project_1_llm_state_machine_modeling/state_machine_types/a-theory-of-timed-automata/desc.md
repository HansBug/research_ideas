## 简报

这篇论文为实时系统建模建立了最经典的状态机扩展方式：在离散状态机上加入实值时钟、时钟约束、复位与不变式，并通过 region/untiming 思路把许多实时判定问题重新压回有限分析。它是 `Timed Automata` 以及后续 `UPPAAL` 等工具线的理论起点。

- 形式主义定位：面向实时离散事件系统的时钟状态机。
- 构造方式简述：位置/迁移 + 时钟集合 + 守卫约束 + 时钟复位 + 位置不变式。
- 基础设施与场景简述：原文核心是 region automaton、language emptiness、language inclusion 等算法基础；具体工程 DSL 和工具在后续生态中形成。

```text
实时需求 -> 离散模式 + 时钟约束 -> 时间自动机 -> 可达性/包含性/模型检查
```

## 形式主义定义与核心对象

### 定义对象

论文针对的是需要同时表达“事件顺序”和“时间延迟”的实时系统行为，例如超时、最小/最大等待时间、限时响应等。

### 核心抽象

经典时间自动机通常可写为：

$$
A = (L, l_0, C, \Sigma, E, I)
$$

其中 `L` 是位置集合，`C` 是时钟集合，`E` 给出带时钟守卫和复位的离散迁移，`I` 给出位置不变式。论文的重要理论手段是 region equivalence 与 untiming construction。

### 语义边界

它擅长“有限离散模式 + 有界实时间约束”的系统；但并不直接表达连续微分方程、概率行为或复杂数据变换。超出时钟差约束的更强算术会迅速破坏可判定性。

## 关键特性

| 维度 | 支持情况 | 说明 |

| 状态 / 模式 | 支持 | 仍以有限离散位置为骨架。 |

## 适用场景与需求前提

### 适用场景

适用于协议超时、调度窗口、限时响应、最小/最大间隔等实时行为要求明确的系统。

### 需求前提

1. 需求包含显式时间界限。
2. 系统仍可抽象为有限离散模式。
3. 时间约束主要表现为时钟比较、重置和不变式。

### 不适用或高成本场景

若系统核心在复杂数据运算、连续物理方程或概率分布，原始时间自动机就需要进一步扩展。

## 与相邻形式主义的关系

相对 `FSM`，它增加了时钟和时间守卫；相对 `TIOA`，它更偏自动机语言与区域判定框架；相对 `Hybrid Automata`，它只允许时钟以单位速率流逝，因此可判定性更强；相对 `Timed Petri Net`，它更强调模式状态而非资源流。

### 对 Project 1 的价值

### 现实限制

它对连续物理行为和复杂数据状态不够直接，需要与其他形式主义组合或扩展。
