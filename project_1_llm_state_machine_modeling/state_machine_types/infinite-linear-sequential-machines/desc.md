## 简报

这篇论文把普通 sequential machine 的状态、输入和输出都提升到某个域 `F` 上的向量空间，并要求转移和输出都是线性的。于是它不再只是“有限个离散状态之间切换”，而是“向量状态在每步按线性方程更新”的序列机。论文的重点是：在任意域上研究这种机器的有限性条件、输入/输出关系、realization、等价判定和可达性问题。

- 形式主义定位：顺序机 / 转导器支线上的线性代数化分支。
- 构造方式简述：用矩阵 `A,B,C,D` 描述状态更新和输出生成。
- 基础设施与场景简述：原文没有工程标准，但矩阵语义清晰，天然连接控制理论、线性系统和代数 automata。

```text
输入向量序列 -> 线性状态更新 -> 线性输出序列 -> 顺序关系 / realization / equivalence
```

## 形式主义定义与核心对象

### 定义对象

论文先回顾普通 sequential machine，然后引入其线性特例：状态集、输入字母表、输出字母表都不是任意离散集合，而是域 `F` 上的有限维向量空间。

### 核心抽象

原文给出的 `LSM` 可写成：

$$
M = (Q, \Sigma, \Lambda, \delta, \lambda)
$$

并满足存在某个域 `F` 与非负整数 `n,k,l` 使得：

$$
Q = F^n,\qquad \Sigma = F^k,\qquad \Lambda = F^l
$$

并且存在矩阵 `A,B,C,D` 使得：

$$
\delta(q, a) = Aq + Ba
$$

$$
\lambda(q, a) = Cq + Da
$$

上式中的符号逐项解释如下：

1. `Q` 是状态空间，这里是 `F^n`。
2. `\Sigma` 是输入空间，这里是 `F^k`。
3. `\Lambda` 是输出空间，这里是 `F^l`。
4. `q` 是当前状态向量。
5. `a` 是当前输入向量。
6. `A` 是状态到下一状态的线性变换矩阵。
7. `B` 把当前输入线性注入到下一状态。
8. `C` 把当前状态线性投影到输出。
9. `D` 把当前输入直接馈通到输出。

论文随后也用 `(F,n,k,l,A,B,C,D)` 作为这种机器的记号。

### 一个最小例子与通俗解释

一个最小例子可以取域 `F = GF(2)`、一维状态和一维输入输出，即 `n=k=l=1`。令：

$$
q_{t+1} = q_t + u_t,\qquad y_t = q_t
$$

其中加法都在 `GF(2)` 上进行。这样输入 `1` 会翻转状态，输入 `0` 会保持状态，而输出就是当前状态。

通俗地说，`LSM` 像一个“把 Mealy/Moore 机线性化”的状态机：状态不再是离散标签，而是向量；转移不再是一张枚举表，而是一组矩阵方程。

### 运行 / 接受 / 转移语义

对输入序列 `u_0,u_1,\ldots`，其一步演化可直接写成：

$$
q_{t+1} = Aq_t + Bu_t
$$

$$
y_t = Cq_t + Du_t
$$

由此可以得到整段输入/输出关系：

$$
\mathcal R(M) = \{(u, y) \mid y \text{ is generated from } u \text{ by the above recurrences}\}
$$

上式中的符号逐项解释如下：

1. `q_t` 是第 `t` 步状态向量。
2. `u_t` 是第 `t` 步输入向量。
3. `y_t` 是第 `t` 步输出向量。
4. `\mathcal R(M)` 是机器 `M` 的顺序关系，即所有可能输入/输出对的集合。

论文明确强调：`the set of all input/output pairs characterizes an LSM`，也就是顺序关系足以刻画线性顺序机。

### 语义边界

与普通顺序机相比，它加强的不是存储结构，也不是读头能力，而是把状态、输入和输出的内部结构限制为线性空间，因此模型更适合描述线性离散系统或代数化转导器。

### 关键性质与判定边界

论文围绕几类关键问题展开：

$$
\text{Equiv}(M_1, M_2):\ \mathcal R(M_1) = \mathcal R(M_2)\ ?
$$

$$
\text{Reach}(q, q'):\ q' \text{ is accessible from } q\ ?
$$

$$
\text{Realization}(R):\ \exists M,\ \mathcal R(M) = R\ ?
$$

这些问题中的符号逐项解释如下：

1. `M_1, M_2` 是两个线性顺序机。
2. `\mathcal R(M)` 是其输入/输出关系。
3. `q, q'` 是状态向量。
4. `R` 是某个目标顺序关系。

论文给出的核心结论包括：

1. `LSM` 的等价问题可判定。
2. 输入/输出关系可以刻画 `LSM`。
3. 改变 ground field 会影响 realization。
4. 可达性问题可以在可计算域的前提下被系统讨论。

## 关键特性

| 维度 | 支持情况 | 说明 |
|---|---|---|
| 状态 / 模式 | 支持 | 状态是 `F^n` 上的向量。 |
| 事件 / 触发 | 支持 | 每步读入输入向量并更新。 |
| 守卫 / 数据 | 部分支持 | 没有一般布尔守卫，但状态/输入都自带线性数据结构。 |
| 层次 | 不支持 | 原始模型是平坦顺序机。 |
| 并发 / 同步 | 不支持 | 单机、单序列语义。 |
| 时间约束 | 不支持 | 无显式时钟。 |
| 连续动态 / 随机性 | 不支持 | 纯离散线性更新。 |
| 可执行 / 可验证性 | 强支持 | 矩阵语义、equivalence、reachability、realization 问题都可分析。 |

### 形式化问题与性质

| 问题 / 性质 | 形式化写法 | 原文意义 |
|---|---|---|
| 线性模型骨架 | `$Q=F^n,\ \Sigma=F^k,\ \Lambda=F^l$` | 状态、输入、输出都提升为向量空间。 |
| 状态更新 | `$q_{t+1}=Aq_t+Bu_t$` | 下一状态是当前状态和输入的线性组合。 |
| 输出方程 | `$y_t=Cq_t+Du_t$` | 输出同时依赖当前状态和当前输入。 |
| 顺序关系 | `$\mathcal R(M)$` | 全体输入/输出对刻画整台机器。 |
| 等价判定 | `$\mathcal R(M_1)=\mathcal R(M_2)$?$` | 原文给出可判定程序。 |

## 适用场景与需求前提

### 适用场景

适用于离散时间、线性输入/输出、线性状态更新明显的顺序系统，以及需要从输入/输出关系反推实现的场景。

### 需求前提

1. 状态、输入和输出适合被建模为向量。
2. 每步更新可用线性关系表达。
3. 关注点在顺序关系、realization 或等价性，而不是层次、并发、时间或连续动力学。

### 不适用或高成本场景

若需求依赖复杂布尔分支、显式时钟、并发同步或非线性连续动态，`LSM` 就不是首选。

## 与相邻形式主义的关系

相对 `Mealy/Moore Machine`，它把转移与输出表线性化为矩阵方程；相对 `Weighted Automata`，它更强调状态更新与 realization，而不是词到权值的聚合；相对控制理论中的离散线性系统，它保留了 automata / sequential machine 的语言与等价问题视角。

## 与本研究的关系

### 对 Project 1 的价值

它补出了顺序机 / 转导器主线里非常经典但此前尚未入账的线性分支，使演化树不再只停留在 `Mealy`/`Moore` 的离散表格式定义上。

### 作为目标形式主义还是中间表示

若控制需求天然是离散线性更新，它可以直接作为目标形式主义；否则更适合作为某些代数化子问题的中间表示。

### 对需求到模型生成的启发

它提醒我们：不是所有状态机都必须用枚举状态图表达。若需求本身已经具有线性结构，直接生成矩阵化顺序机往往更自然。

### 现实限制

它对非线性逻辑、层次结构和复杂控制流都不友好，因此只覆盖离散状态机谱系中的一个专门分支。
