Abstract
We survey existing approaches to the formal veriﬁcation of s tatecharts using
model checking. Although the semantics and subset of statec harts used in each
approach varies considerably, along with the model checker s and their speciﬁca-
tion languages, most approaches rely on translating the hie rarchical structure into
the ﬂat representation of the input language of the model che cker. This makes
model checking difﬁcult to scale to industrial models, as th e state space grows
exponentially with ﬂattening. We look at current approache s to model checking
hierarchical structures and ﬁnd that their semantics is sig niﬁcantly different from
statecharts. We propose to address the problem of state spac e explosion using a
combination oftechniques, which are proposed as direction s forfurther research.
