## 简报

这篇论文关心的不是普通字符串自动机，而是“有限自动机在二维和三维空间里到底能干什么”。它把自动机放进 checkerboard / maze / obstructed space 中，允许用有限 pebble 做标记和计数，给出了二维可搜索、三维不可完全搜索的典型边界结果，因此非常适合作为 `Two-Dimensional Automata` 的能力基线条目。

- 形式主义定位：在二维或三维格点空间中移动、观察和标记的空间自动机。
- 构造方式简述：有限状态控制 + 网格方向动作 + 有限 pebble 标记 + 局部感知。
- 基础设施与场景简述：是纯理论空间搜索模型，没有交换标准和工程工具，但把 picture/grid automata 的能力边界讲得非常清楚。

```text
网格 / 迷宫对象 -> 空间自动机 + pebble -> 可搜索性 / 能力边界 / 维度差异分析
```

## 形式主义定义与核心对象

### 定义对象

论文把自动机放在二维或三维离散空间中，让它通过有限内部状态和局部观察执行移动与搜索。对象不再是字符串，而是网格空间中的可达单元与障碍结构。

### 核心抽象

文中核心抽象包括：

1. 自动机具有有限内部状态。
2. 自动机在格点上执行 `N/E/S/W`，三维时还会涉及上下方向。
3. 自动机只能局部观察当前位置或其颜色/障碍信息。
4. pebble 用来做位置标记、计数器或搜索辅助。

论文的重要结论是：

1. 带有限 pebble 的有限自动机可以搜索任意二维阻塞空间。
2. 没有有限自动机集能够搜索所有有限三维迷宫。

### 语义边界

它不是字符串语言识别模型，也不是连续空间机器人控制模型。其核心是“离散网格 + 局部运动 + 有限记忆”下的搜索能力边界。

## 适用场景与需求前提

### 适用场景

适用于网格搜索、maze / picture / checkerboard 一类离散空间对象，以及研究维度变化如何改变有限自动机能力边界。

### 需求前提

1. 需求对象必须是离散空间而非线性串。
2. 行为主要由局部邻域和移动动作决定。
3. 可接受以 pebble 或局部标记来补偿有限记忆。

### 不适用或高成本场景

如果对象是协议、控制器状态或文档结构，这类二维自动机就不是直接主线；它更像空间结构语言和搜索复杂性的理论工具。

## 与相邻形式主义的关系

相对 `Finite Automata`，它把一维 tape 推广到二维/三维空间；相对 `Cellular Automata`，它强调“移动搜索者”，不是全局同步局部更新；相对 `Tree Automata`，它描述的是网格对象而不是层次树。

## 与本研究的关系

### 对 Project 1 的价值

对控制系统状态机本体帮助有限，但它有助于我们认识“对象维度改变会迫使状态机家族改变”。

### 作为目标形式主义还是中间表示

通常不适合作为 `project_1` 的目标输出，更适合作为类型谱系中的边缘但经典分支。

### 对需求到模型生成的启发

当需求对象是空间/图案/栅格而不是控制过程时，不应继续沿普通控制状态机路线前进。

### 现实限制

没有工程标准和主流验证工具链，且与控制系统需求建模的直接相关性较弱。
