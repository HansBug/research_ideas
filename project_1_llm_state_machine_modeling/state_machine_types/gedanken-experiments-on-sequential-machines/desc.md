## 简报

这篇论文把 `Moore Machine` 的核心语义说得非常清楚：机器有有限状态、有限输入和有限输出，**下一状态依赖“前一状态 + 前一输入”，而当前输出只依赖当前状态**。它的重要性不仅在于定义了一类经典顺序机，更在于把“状态可辨识”“黑盒实验能否识别初始状态”“如何把机器化简到 reduced form”这些后续最小化问题放到了统一的行为语义框架里。

- 形式主义定位：输出贴在状态上的有限状态顺序机，适合讨论 black-box behavior 与可辨识性。
- 构造方式简述：给出状态集、输入符号、输出符号、状态转移和状态输出，再通过 simple / multiple experiments 观察外部行为。
- 基础设施与场景简述：原文依赖 transition table、state diagram 与实验区分过程，服务顺序电路、自动机识别与状态最小化。

```text
输入序列 -> 状态迁移 -> 当前状态输出 -> 外部实验观测 -> 可辨识性 / 约简
```

## 形式主义定义与核心对象

### 定义对象

论文明确研究一类 finite sequential machines：

1. 有有限个状态。
2. 有有限个输入符号。
3. 有有限个输出符号。
4. 行为严格确定：当前状态由前一状态和前一输入决定，当前输出只由当前状态决定。

### 核心抽象

可保守归一化为今天标准的 `Moore Machine` 元组：

$$
M = (Q, \Sigma, \Gamma, \delta, \lambda, q_0)
$$

上式中的符号逐项解释如下：

1. `Q` 是有限状态集。
2. `\Sigma` 是输入字母表。
3. `\Gamma` 是输出字母表。
4. `\delta : Q \times \Sigma \to Q` 是状态迁移函数。
5. `\lambda : Q \to \Gamma` 是状态输出函数。
6. `q_0` 是初始状态。

这与原文“present state depends only on its previous input and previous state, and the present output depends only on the present state”的定义完全一致。

### 一个最小例子与通俗解释

一个最小例子是“记录上一拍是否读到 `1` 并把它作为当前输出”。令：

1. `q_0` 表示“上一拍不是 `1`”。
2. `q_1` 表示“上一拍是 `1`”。
3. 读到 `0` 后转到 `q_0`，读到 `1` 后转到 `q_1`。
4. 处于 `q_0` 输出 `0`，处于 `q_1` 输出 `1`。

可写成：

$$
\delta(q_0,0)=q_0,\ \delta(q_0,1)=q_1,\ \delta(q_1,0)=q_0,\ \delta(q_1,1)=q_1
$$

$$
\lambda(q_0)=0,\qquad \lambda(q_1)=1
$$

这些符号逐项解释如下：

1. `0,1` 既可作输入符号，也可作输出符号。
2. 第一式表示当前输入驱动下一状态。
3. 第二式表示输出只看当前状态。

通俗地说，`Moore Machine` 像一个“先站到某个岗位，再按岗位发话”的门卫。门卫说什么只取决于它现在站在哪个岗位，而不直接看这一拍刚来的输入。

### 运行 / 接受 / 转移语义

对输入串 `$a_0 a_1 \cdots a_{k-1}$`，其逐拍语义可写成：

$$
q_{t+1} = \delta(q_t, a_t), \qquad y_t = \lambda(q_t)
$$

这组方程中的符号逐项解释如下：

1. `q_t` 是第 `t` 拍开始时状态。
2. `a_t` 是第 `t` 拍输入。
3. `q_{t+1}` 是输入处理后的下一状态。
4. `y_t` 是由当前状态直接决定的输出。

原文围绕这一语义进一步定义了 `simple experiment` 与 `multiple experiment`：实验者只能通过输入序列和输出序列，间接推断机器的内部状态。

### 语义边界

与 `Mealy Machine` 相比，它不把输出挂在转移边上；与 `Finite Automata` 相比，它不是纯接受器，而是显式输出机；与 `EFSM`、`VPA` 等更强模型相比，它没有变量、栈、层次或时间。

### 关键性质与判定边界

原文最核心的判定对象是状态可辨识性。若记从状态 `q` 出发对输入串 `$w$` 的输出序列为 `$\mathrm{out}(q,w)$`，则状态不可辨识性可写成：

$$
q \sim q' \iff \forall w \in \Sigma^*,\ \mathrm{out}(q,w)=\mathrm{out}(q',w)
$$

也就是说，如果任何实验都不能区分两个状态，它们就属于同一等价类，可在 reduced form 中合并。

论文还给出了经典实验长度上界：对于一个 `(n,m,p)` 机器，若任意两状态都可区分，则存在长度不超过

$$
\frac{n(n-1)}{2}
$$

的实验，可确定机器在实验结束时所处状态。

这里的符号逐项解释如下：

1. `n` 是状态数。
2. `m` 是输入符号数。
3. `p` 是输出符号数。
4. `n(n-1)/2` 是原文 Theorem 8 给出的长度上界。

| 层次 | 不支持 | 状态空间是平坦的。 |

### 形式化问题与性质

| 问题 / 性质 | 形式化写法 | 原文意义 |
|---|---|---|
| 状态更新 | `$q_{t+1}=\delta(q_t,a_t)$` | 当前输入和当前状态决定下一状态。 |
| 状态输出 | `$y_t=\lambda(q_t)$` | 输出只依赖当前状态。 |
| 状态不可辨识 | `$q \sim q' \iff \forall w,\ \mathrm{out}(q,w)=\mathrm{out}(q',w)$` | 定义 reduced form 的合并依据。 |
| 实验长度上界 | `$n(n-1)/2$` | 论文给出识别状态的 simple experiment 上界。 |

## 适用场景与需求前提

### 适用场景

适用于输出稳定地绑定在状态上的控制器、顺序机识别问题和黑盒状态可辨识分析。

### 需求前提

1. 系统可抽成有限状态。
2. 输出更自然地看作“状态标签”而不是“边标签”。
3. 研究重点是外部实验能否识别内部状态。

### 不适用或高成本场景

若需求依赖变量、栈、时间约束或复杂组合条件，仅靠 `Moore Machine` 往往不足。

## 与相邻形式主义的关系

相对 `Mealy Machine`，它把输出从边移回状态；相对 `Finite Automata`，它增加了显式输出语义；相对更强状态机家族，它仍是最简的输出型离散基线。

## 与本研究的关系

### 对 Project 1 的价值

它非常适合作为“需求可观测行为 -> 状态结构”这一链条的最小基线，尤其适合讨论状态可区分、状态合并和输出稳定性。

### 作为目标形式主义还是中间表示

更适合作为中间表示或早期语义对齐对象，而不是复杂控制系统的最终形式。

### 对需求到模型生成的启发

若需求文本强调“系统处于某模式时持续表现出某输出”，`Moore` 风格往往比 `Mealy` 风格更稳。

### 现实限制

一旦需求涉及边触发动作、复杂数据或层次并发，就需要提升到 `Mealy`、`EFSM`、`Statechart` 等更强模型。
