## 简报

这篇论文把步态康复中的三件事压成一套统一监督架构：**外骨骼扭矩场、功能性电刺激 `FES`、肌肉疲劳管理**。核心不是单一控制器，而是两个并行的状态机配合多个底层控制律。`t-FSM` 负责步态相位和左右腿时域协调，`c-FSM` 负责某条腿在 swing 周期内的学习与监测。这样，系统既能逐步学习刺激模式，也能在疲劳出现时重新配置刺激参数。

- 形式主义定位：面向步态康复外骨骼的专用双状态机监督器，用来协同机器人助力、`FES` 刺激和疲劳管理。
- 构造方式简述：上层由 `t-FSM` 管步态相位、`c-FSM` 管学习/监控状态；下层由扭矩场、`ILC` 和疲劳估计器共同驱动。
- 基础设施与场景简述：依托 `Kinesis` 外骨骼、力矩传感器、膝关节参考轨迹和 `FES` 刺激器，服务脊髓损伤患者步态训练。

```text
步态事件 -> t-FSM -> 左/右腿 c-FSM -> ILC / fatigue estimator / torque field -> 外骨骼与 FES 协同输出
```

## 形式主义定义与核心对象

### 定义对象

论文中的关键对象包括：

1. 时域状态机 `t-FSM`，负责步态相位与左右腿协调。
2. 周期域状态机 `c-FSM`，其状态至少包括 `learning` 与 `monitoring`。
3. 膝关节扭矩场控制律。
4. `ILC` 形式的 `FES` 更新规则。
5. 基于 `TTI` 的肌肉疲劳估计器。
6. 交互力矩、膝角轨迹、`NILC` 和步态事件广播。

### 核心抽象

按论文结构，可保守整理为：

$$
\mathcal{K} = (Q_t, Q_c, q_{t,0}, q_{c,0}, X, \delta_t, \delta_c, \Gamma)
$$

上式中的符号逐项解释如下：

1. `Q_t` 是 time-domain `FSM` 的状态集合。
2. `Q_c = \{\mathrm{learning}, \mathrm{monitoring}\}` 是 cycle-domain `FSM` 的状态集合。
3. `q_{t,0}` 是时域初始状态。
4. `q_{c,0}` 是周期域初始状态，默认是 `learning`。
5. `X` 是传感与控制变量集合，如膝角、交互力矩、`TTI`、`NILC` 和 gait event。
6. `\delta_t` 是时域转移函数。
7. `\delta_c` 是周期域转移函数。
8. `\Gamma` 是状态绑定的控制律集合，包括扭矩场、刺激更新与疲劳管理策略。

论文给出的膝关节扭矩场可写成：

$$
\tau_k = K_k(\theta_{\mathrm{ref}} - \theta_k) + C_k \frac{\Delta(\theta_{\mathrm{ref}} - \theta_k)}{\Delta t}
$$

上式中的符号逐项解释如下：

1. `\tau_k` 是外骨骼对膝关节施加的控制力矩。
2. `K_k` 是步态相位相关的等效刚度。
3. `\theta_{\mathrm{ref}}` 是参考膝角轨迹。
4. `\theta_k` 是实际膝角。
5. `C_k` 是阻尼系数。
6. `\Delta t` 是离散控制步长。

论文给出的 `ILC` 更新规律可写成：

$$
u_{n,j+1} = [F] \left(u_{n,j} + [L] e_{n,j}\right)
$$

上式中的符号逐项解释如下：

1. `u_{n,j}` 是第 `j` 次步态周期上第 `n` 个时间帧的刺激控制向量。
2. `u_{n,j+1}` 是下一周期的刺激控制向量。
3. `[F]` 是 forgetting matrix。
4. `[L]` 是 learning matrix。
5. `e_{n,j}` 是由交互力矩形成的学习误差。

按论文判据，`c-FSM` 从 `learning` 进入 `monitoring` 的条件可保守写成：

$$
\frac{|NILC_j - NILC_{j-1}|}{NILC_{j-1}} < 0.05
$$

上式中的符号逐项解释如下：

1. `NILC_j` 是第 `j` 个周期的归一化刺激输出时间积分。
2. 分式表示相邻两周期刺激积分的相对变化。
3. 当该值小于 `5\%` 时，认为学习阶段已经收敛。

肌肉疲劳检测条件则可压缩为：

$$
\frac{TTI_j - TTI_{\mathrm{ref}}}{TTI_{\mathrm{ref}}} \ge 0.19
$$

上式中的符号逐项解释如下：

1. `TTI_j` 是当前 swing 周期的 torque-time integral。
2. `TTI_{\mathrm{ref}}` 是此前稳定刺激配置下的基准积分。
3. `0.19` 对应论文给出的 `19\%` 疲劳判据。

### 一个最小例子与通俗解释

最小例子可以用“一条腿进入 swing 相位”的过程描述：

1. `t-FSM` 检测到左腿进入 swing，相应广播一个新的 step event。
2. 左腿 `c-FSM` 进入 `learning` 状态，先用较高刚度的外骨骼扭矩场保证轨迹。
3. `ILC` 根据本周期测到的交互力矩更新下一周期的刺激输出。
4. 当 `NILC` 的相对变化小于 `5\%` 时，`c-FSM` 进入 `monitoring`。
5. 在 `monitoring` 中，系统重复当前刺激模式，并逐步降低外骨骼刚度，只要膝屈曲仍不低于 `60` 度。
6. 如果 `TTI` 相对基准增长达到 `19\%`，系统判定疲劳出现，调整刺激参数并重新回到学习阶段。

通俗地说，这个模型像“外骨骼教练 + 电刺激助教 + 疲劳裁判”。状态机不是直接算连续控制，而是在合适的时候切换“学习”“监控”“重新学习”这些工作模式。

### 运行 / 接受 / 转移语义

其运行语义可保守写成：

$$
(q_t, q_c, x_t) \xrightarrow{\Gamma(q_t, q_c)} (u_t, \tau_t) \xrightarrow{\delta_t,\delta_c} (q_t', q_c')
$$

上式中的符号逐项解释如下：

1. `q_t` 是当前时域状态。
2. `q_c` 是当前周期域状态。
3. `x_t` 是当前观测量，包括膝角、力矩和步态事件。
4. `\Gamma(q_t, q_c)` 表示由当前双状态决定调用哪组控制律。
5. `u_t` 是刺激输出。
6. `\tau_t` 是外骨骼扭矩输出。
7. `(q_t', q_c')` 是下一时刻状态对。

其中 `t-FSM` 和 `c-FSM` 并不是完全独立的：

$$
\delta_c(q_c, x_t, \mathrm{step\_event})
$$

表示周期域状态机会被时域状态机广播的步态事件驱动。

### 语义边界

这个模型的边界包括：

1. 它只针对特定康复外骨骼与 `FES` 协同架构，不是通用步态建模语言。
2. 连续动力学主要由控制律承担，状态机负责模式切换与协调。
3. 疲劳估计依赖 `TTI` 这一特定指标与实验阈值。
4. 论文重点是执行与实验效果，不是一般性的形式验证或可判定性研究。

### 关键性质与判定边界

| 问题 / 性质 | 形式化写法 | 原文意义 |
|---|---|---|
| 双状态机骨架 | `$\mathcal{K} = (Q_t, Q_c, q_{t,0}, q_{c,0}, X, \delta_t, \delta_c, \Gamma)$` | 时域步态协调和周期域学习/监测被显式分层。 |
| 扭矩场控制律 | `$\tau_k = K_k(\theta_{\mathrm{ref}} - \theta_k) + C_k \frac{\Delta(\theta_{\mathrm{ref}} - \theta_k)}{\Delta t}$` | 外骨骼助力会随步态相位和误差调节。 |
| `ILC` 更新 | `$u_{n,j+1} = [F](u_{n,j} + [L] e_{n,j})$` | 刺激模式按步态周期迭代学习。 |
| 学习收敛条件 | `$\frac{|NILC_j - NILC_{j-1}|}{NILC_{j-1}} < 0.05$` | 当刺激输出变化很小，进入 `monitoring`。 |
| 疲劳触发条件 | `$\frac{TTI_j - TTI_{\mathrm{ref}}}{TTI_{\mathrm{ref}}} \ge 0.19$` | 肌肉疲劳出现时重新配置刺激模式。 |

## 关键特性

| 维度 | 支持情况 | 说明 |
|---|---|---|
| 状态 / 模式 | 强支持 | `t-FSM` 和 `c-FSM` 明确组织步态阶段与学习/监测模式。 |
| 事件 / 触发 | 强支持 | gait event、收敛判据和疲劳判据都会触发转移。 |
| 守卫 / 数据 | 强支持 | 膝角、交互力矩、`NILC`、`TTI` 都直接进入 guard。 |
| 层次 | 中等支持 | 时域与周期域状态机分层协同。 |
| 并发 / 同步 | 中等支持 | 左右腿 `c-FSM` 在 `t-FSM` 协调下并行运行。 |
| 时间约束 | 中等支持 | 状态语义依赖 gait cycle 和离散时间帧，但不是显式 timed automata。 |
| 连续动态 / 随机性 | 强连续、无随机 | 连续控制律很强，未建模随机行为。 |
| 可执行 / 可验证性 | 强执行、有限验证 | 原型外骨骼和受试实验充分，但没有形式模型检验链。 |

### 形式化问题与性质

1. 论文把“何时让外骨骼出力、何时让肌肉主导、何时重新学习刺激”显式结构化了。
2. 双 `FSM` 架构说明应用型状态机也可以管理多种控制器之间的职责边界。
3. `TTI` 和 `NILC` 这类判据为状态转移提供了可量化阈值。
4. 对 `project_1` 来说，它是“生理信号 + 控制阈值 -> guard -> 模式切换”的典型样本。

## 构造方式与承载格式

### 建模入口

建模入口主要包括：

1. 先定义步态相位和左右腿协调逻辑，形成 `t-FSM`。
2. 再把 swing 周期内部的学习/监测机制抽成 `c-FSM`。
3. 为每个状态绑定对应控制律：扭矩场、`ILC` 或疲劳管理。
4. 用 `NILC` 收敛阈值和 `TTI` 疲劳阈值定义转移条件。

### 机器可处理承载方式

原文直接给出的承载方式包括：

1. `Kinesis` 的 `t-FSM` 与 `c-FSM` 结构图。
2. 扭矩场控制方程与 `ILC` 更新式。
3. 基于 `TTI` 的疲劳估计算法。
4. 传感器、参考轨迹和刺激参数组成的嵌入式控制数据流。

### 交换与互操作

互操作重点在：

1. `t-FSM` 广播步态事件给左右腿 `c-FSM`。
2. 力矩传感器把交互误差回送给 `ILC`。
3. `TTI` 估计器把疲劳事件回送给状态机。
4. 状态机再根据当前模式调节 `K_k`、刺激参数和辅助力度。

## 适用场景与需求前提

### 适用场景

适合需要在步态周期中动态平衡机器人辅助与肌肉刺激贡献的康复外骨骼、神经康复训练和人机协同助行系统。

### 需求前提

1. 系统可可靠检测 gait event。
2. 可获得交互力矩、关节角和刺激输出等反馈信号。
3. 任务具有明显的步态相位和周期结构。
4. 控制目标更像模式切换与逐周期学习，而不是单一连续控制律。

### 不适用或高成本场景

如果设备没有稳定的步态事件检测、没有力矩反馈或刺激器参数不可实时修改，这套双 `FSM` 架构很难发挥作用。

## 与相邻形式主义的关系

它比普通 `FSM` 更接近“监督层 + 连续控制层”的混合结构；相对一般 `Hybrid Automata`，它并不追求统一的数学语义，而是把连续控制律嵌入到应用状态机中；相对行为树，它更强调周期相位和阈值触发的严格模式切换。

## 与本研究的关系

### 对 Project 1 的价值

它很好地说明了应用需求中的“学习完成”“疲劳出现”“腿进入 swing”都可以被提炼成正式 guard，而不仅是实现细节。

### 作为目标形式主义还是中间表示

对康复外骨骼来说，这是一种可以直接执行的目标监督器；对更一般的控制系统建模任务，它也可作为“多控制器切换逻辑”的中间表示。

### 对需求到模型生成的启发

1. 需求中的相位词、阈值词和安全下限词特别适合转成 guard。
2. 当系统包含多个连续控制器时，LLM 应优先生成“谁在什么模式下接管”的状态机，而不是直接混写控制方程。
3. 生理性能指标如 `TTI`、`NILC` 可以显式进入状态机变量集合。
4. 左右腿、学习/监测这类多轴结构值得生成成分层或并行状态机，而不是一张扁平图。

### 现实限制

论文中的阈值和控制器设计强依赖具体设备与实验条件，跨平台迁移时需要重新标定。
