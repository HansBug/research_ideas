# Expert Review Designs Guide

## 1. 目录职责

本目录只用于放版本化设计资料。

根层不放具体长文档，只放：

1. `README.md`
2. `GUIDE.md`

## 2. 版本目录规则

设计文档必须落到版本子目录，例如：

1. `v0/`
2. `v1/`

如果以后继续迭代，应新增：

3. `v2/`
4. `v3/`

而不是重新把文档平铺回本目录。

## 3. 文档含义约定

### `v0/`

表示已经存在或已经发生过的系统资料、现状说明、对齐结果与基线整合。

### `v1/`

表示下一轮重构的目标设计。

## 4. 维护原则

1. 历史文档尽量保持可追溯，不随意删减内容。
2. 新版本文档以新增目录为主，不覆盖历史目录。
3. 目录之间通过相对路径链接互相引用。
