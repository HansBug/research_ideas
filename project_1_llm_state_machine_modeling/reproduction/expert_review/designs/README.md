# Expert Review Designs

本目录用于维护 `expert_review` 模块的版本化设计文档。

## 当前分层

- [v0/README.md](./v0/README.md)：当前系统的基线资料与整合说明。
- [v1/README.md](./v1/README.md)：下一轮重构设计稿。

## 设计文档组织原则

1. `designs/` 根层只保留索引与导航文件。
2. 具体版本文档必须放进版本子目录。
3. 不再把不同阶段的设计文档平铺在 `designs/` 根层。

## 推荐阅读顺序

1. [GUIDE.md](./GUIDE.md)
2. [v0/README.md](./v0/README.md)
3. [v1/README.md](./v1/README.md)
