# Expert Review V1 Guide

## 1. 目录职责

本目录只放下一轮设计稿，不放运行结果，不放历史资料整合。

## 2. 文档边界

`v1` 文档应回答：

1. 目标架构是什么
2. 为什么要从 `v0` 演进到这里
3. 需要保留哪些接口兼容性
4. 新系统如何组织 agent、tool、graph、state

但不要求在这里记录已经发生过的实验结果，那些属于：

- [../v0/README.md](../v0/README.md)

## 3. 维护原则

1. `v1` 文档允许持续重写和迭代。
2. 每次较大设计跃迁时，优先新增新版本目录，而不是把 `v1` 无限膨胀。
3. 如果未来实现和 `v1` 明显偏离，应新增新的设计版本，而不是追着实现碎片化修补。
