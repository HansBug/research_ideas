# Expert Review V0 Guide

## 1. 目录职责

本目录是 `expert_review` 当前系统的历史基线资料区。

这里保存的是：

1. 已存在实现的理论依据
2. 已存在实现的架构说明
3. 已完成的对齐实验结果
4. 对这些材料的基线整合文档

## 2. 维护原则

### 保留可追溯性

`v0` 文档优先保留历史信息，不因为后续 `v1` / `v2` 重构而大幅删改。

### 允许修链接和导航

可以修正文档链接、目录说明和引导文件，但不要随意缩减实质内容。

### 不把新设计混进来

新的目标设计应进入：

- [../v1/README.md](../v1/README.md)

而不是回写到 `v0` 长文档里。

## 3. 与代码的关系

`v0` 文档用于描述当前或既有系统，但不作为代码运行依赖。

因此本目录重构时，首要目标是：

1. 保持内容完整
2. 保持链接正确
3. 不破坏代码路径
