# Data Guide

## 1. 职责边界

本目录用于管理复现实验输入数据与派生数据。

### `raw/`

用于保存：

1. 原始下载数据
2. 外部论文附带数据
3. XML / PDF / zip 等原始材料

### `derived/`

用于保存：

1. 清洗后的 parquet
2. 规范化中间表示
3. 供 baseline 与评测统一读取的派生数据

## 2. 不应放在这里的内容

以下内容不应进入本目录：

1. 最终运行结果
2. 专题设计文档
3. 代码实现

## 3. 修改原则

### `raw/`

原则上不要手工改写原始下载内容。

### `derived/`

如需重建，优先通过脚本重算，而不是直接手工改 parquet。
