**缺陷描述**

Off 出边中存在一条无触发迁移，使 Off 不再是稳定等待态：任何没有 start 事件的周期都会不可逆地落入 Terminate 汇态。因此 NL 第 1、2 句要求的 start→Operate 只有在上电后第一个周期立刻给出 start 才成立，而 Operate --keyOff--> Off 之后的再次启动一般不可达。按 UML 完成迁移优先级读则更严重，start 直接不可达。注意 pyfcstm 按声明顺序选边（fcstm 第 24 行 start 边在第 25 行无触发边之前），故同周期竞争由 start 胜出——所以『无触发边吃掉 start 信号』这一说法需要修正为『Off 不可驻留』，不能用 occupancy_after 暴露。
