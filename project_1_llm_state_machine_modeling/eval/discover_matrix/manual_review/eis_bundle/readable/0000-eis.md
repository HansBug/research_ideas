**缺陷描述**

NL 第5句要求运行中的系统在断电时进入终态。生成制品里 Power Off 的源端是顶层伪初始，任何运行态（HumanDrivingMode / AutonomousMode）都没有断电出边；顶层同时存在 `[*] --> HumanDrivingMode : Power On` 和 `[*] --> FinalState : Power Off` 两条初始边，冷启动时给出 Power Off 会直接落到 FinalState（等于没开机就关机）；而 FinalState 只是普通命名状态、无出边，模型永远不会真正 terminate。此外这是**论文自己的语法修复阶段引入**的：workbook 列 I（Phase-I 原始生成）写的是 `HumanDriving --> FinalState : Power Off`（语义正确，但因嵌在 `state HumanDriving { ... }` 体内而结构违法，被记为语法幻觉 "transition does not connect two state"），列 Z（语法检查后）把源端改成 `[*]`，语义随之被破坏；列 AD（语义幻觉）为空、AG 语义 resolved 记 1.0，说明该注入缺陷未被后续语义检查捕获。对照 0030：同一份 NL 下 Phase-I 同样出现 `[*] --> FinalState : Power Off`，论文语义栏把它记为 "missing final state" 并改成 `HumanDriving --> [*] : Power Off`；同一缺陷形状在同一 NL 的两个 case 上一个被抓一个被漏，说明语义检查不可复现。

**缺陷描述**

NL 第5句的三个接管条件被压成**一个不可分解的事件标签**：pyfcstm 投影得到单一事件 `Human_Steering_Cmd_Brake_Pressed_in_AutoFinal`，模型无法对单独的 human steering cmd 或 brake pressed 作出响应；更关键的是 `in (AutoFinal)` 本质是**状态条件**（NL 第2句保证 auto final 是 autonomous mode 的子状态），把它塞进事件名是范畴错误——制品里 AutoFinal 确实存在，但仅凭进入 AutoFinal 不会交还控制权，AutoFinal 除该复合事件外无其他出边。无论按"三选一"还是"合取"读法，单一自由文本标签都不是忠实编码；论文 SysML 语法检查（grammar 12/13、grammar_resolved=1.0）未对此报警。

**⚠️ 本条的判据经主裁定更换** —— 上面的缺陷描述是复核者当时的原话，其中作为归因依据的部分已被撤回并替换。撤回理由与新判据：

> 原判据放弃：它依赖把 NL08 第 4 句读作析取。NL 原文是 'transit to human driving mode when receive human steering cmd, brake pressed, in (auto final)'——逗号列举，既无 any of 也无 and。NL 未授权析取解释，故『缺少可单独触发的事件』不能作为归因依据（这一点由用户在 2026-07-30 的讨论中指出，经复核成立）。；换用不依赖该解释的判据：in (AutoFinal) 是状态测试表达式，其真值由系统当前状态决定；模型把它放在 trigger 位置而非 guard 位置，因此它对迁移不构成任何约束。原始 PlantUML 那条边是组迁移（源为复合态 AutonomousMode），UML 语义下从任何活跃子态均可触发。；后果实测：stays_in(source='...AutonomousMode.AutoNavigating', trigger='...Human_Steering_Cmd_Brake_Pressed_in_AutoFinal') = False，即模型在尚未进入 AutoFinal 时就交还控制权；not occupancy_after(AutoNavigating, 该事件, HumanDrivingMode) = False。；负控有效：occupancy_after(AutoFinal, 该事件, HumanDrivingMode) = True，说明断言不是恒 False——从 AutoFinal 走得通，从 AutoNavigating 也走得通才是缺陷。；层从 nl_named 改为 wellformedness：新判据不以任何 NL 句为前提，只依赖模型自身结构与状态机的形式化语义（状态条件不得充当事件）。对照 0050#4：该 pair 的 AutoFinal 根本不存在，是另一类缺陷，两者不同型。
