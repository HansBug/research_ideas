**两侧对照**

| | 内容 |
| --- | --- |
| 参考侧 | HighwayMode --> UrbanMode : urban_way = true; UrbanMode --> HighwayMode : high_way = true（模式间直接切换，只在两模式之间生效） |
| 生成侧 | 在 AutonomousMode 闭合括号之外写 AutonomousMode --> HighwayMode : high_way=true; AutonomousMode --> UrbanMode : urban_way=true（父复合态指向自身后代） |
