# 盲判复核

> ⚠️ **本文件已被全量盲判取代，且首版的核心结论之一被推翻。** 首版基于 40 单元抽样，标题是
> 「以及为什么它**不能**用来宣布达标」，理由是覆盖不完整。全量盲判（68 单元 / 204 位，覆盖 100%）
> 完成后，那条理由消失，而首版另一条结论 —— 「偏倚是带相关的、两个方向都抬高共演化溢价」——
> **不成立**。改动见文末「相对上一版的改动」。

## 做了什么

按独立裁决给出的投入顺序，补上四条判别标准里唯一零语料成本可补的那条 —— **结果判定对暴露状态盲**。

从上一代次的 204 个判定位里固定种子分层抽 40 个单元（120 个轮次位），抹掉 pair id、台账记录 id、
模型路径前缀与**带标签**，交独立判定者复判。`blind_resample.py --verify` 独立扫残留（四位 id、
`EIS-` 前缀、带名称），非零退出。复判者自述只读了样本文件。

## 结果

| 量 | 值 |
| :-- | --: |
| 配对判定位 | 120 |
| 原判命中率 | 50.0% |
| 盲判命中率 | 43.3% |
| 一致 | 104 / 120 = **86.7%** |
| **Cohen $\kappa$** | **0.733**（substantial） |

## 最关键的检验：分歧是否与带相关

若相关，说明原判定存在**暴露偏倚** —— 那正是不盲判定的危害所在。

| 带 | n | 原判更宽松 | 盲判更宽松 | 净偏 |
| :-- | --: | --: | --: | --: |
| 调优（历史格） | 39 | 4 | 1 | **+3** |
| 已烧毁 hold-out | 75 | 8 | 0 | **+8** |
| 可报（能力主张） | 6 | 0 | **3** | **−3** |

**两个方向都在抬高共演化溢价**：原判在调优带与烧毁带更宽松，在可报带更严格。

这否证了我此前写的「方向自保守」，也超出了裁决所说的「净方向未知」—— **现在测出来了，是抬高溢价的
方向**。所以 35 pp 的粗差距若有偏，偏向**高估**，溢价这条主张进一步被削弱。

## 可报带那 3 处分歧：判据支持盲判，但我不据此宣布达标

三处全部落在同一条记录、同一条臂（原判三轮全 0，盲判三轮全 1）。复判者自己把它列为最不确定的
5 个之一并说明了理由 —— 这是应有的行为。

逐条读原文后，**预注册判据 §3 第四种形态直接适用**：

> **蕴含更根本的原因**：我们的命题为假蕴含台帐命题为假，且定位到更上游。

台账主张「激活应以检测为条件，而生成方无条件激活」；产出主张「根本没有非活动源状态，也没有类别化
检测事件」。无这些元素则不可能有条件激活 —— 与判据自带的先例（台帐「边应有变量下降」vs 产出「根本
没声明该变量」）**同型**。

事实前提两条都独立验证过：

| 产出主张 | 模型事实 | 成立？ |
| :-- | :-- | :-- |
| 缺少非活动源状态 | 唯一的 `Idle` 在子机**内部**，无「整个子机未激活」的状态 | ✅ |
| 缺少类别化检测事件 | 全模型 3 个事件，检测类仅 1 个；NL 明写三类 | ✅ |

**所以盲判正确、原判错误。但我不翻这三个位。**

### 为什么不翻

翻它们会让 `hit@1` 从 `8/12 = 66.7%` 变成 `11/12 = 91.7%`，**直接越过 70% 目标**。而这个「重新应用
判据」的动作发生在**看到数字不达标之后** —— 那正是 §3.5 条款 4 的教科书形状。

三条使它更可疑而非更可信：

1. **在样本内挑选。** 盲样只覆盖 4 个可报单元中的 2 个（12 位里的 6 位）。只翻抽到的那部分，等于
   用抽样结果去改总体的一部分。
2. **偏倚是双向的。** 原判 12 位更宽松、4 位更严格。若判据在一处被误用，它在别处也可能被误用；
   全面重判会同时改动大量数字，**净方向未知**。
3. **我的利益方向单一且明确。** 当一个「更正」恰好让指标越过目标线时，举证责任在提出者。

### 正确的处置：双报为敏感性区间，并声明前置条件

> 上一代次能力主张带 `hit@1` 的**已发布值**是 `8/12 = 66.7%`。盲判复核（$\kappa = 0.733$）显示
> 原判定在该带偏严：抽到的 6 个位里 3 位被独立判定者判为命中，且预注册判据的第四种形态支持其判定。
> 若全部 12 位按同一判据重判且方向与抽样一致，该值落在 **[66.7%, 91.7%]**。
>
> **这个区间不是结果，它是「原判定不可靠」的度量。** 任何能力主张数字在完成**全量**盲判之前不应
> 被引用，包括区间上界。

## 这次复核真正买到了什么

不是一个更好的覆盖率数字，而是三件此前只能假设的事变成了可测量的：

1. **判定的可重复性有了量**：$\kappa = 0.733$。此前「判定是否可靠」只有自陈。
2. **偏倚方向由「未知」变成「已测」**：抬高溢价的方向。这直接削弱了溢价这条主张。
3. **暴露出一条判据被误用**：可报带的严格程度与其它带不一致 —— 而这恰是上一代次发布时被抓到的
   同一类问题（「有据」判据比「未命中」判据松）在**反方向**上的复发。

第 3 条是最有价值的：它说明判据不一致不是一次性失误，而是**在没有盲判的情况下无法自查的系统性
风险**。全量盲判应成为后续每一代次的固定环节，而不是一次性补救。

## ⚠️ 一个我自己引入的混杂，必须先说清

**两次盲判我给的指令不同。**

| | 40 单元那次 | 全量这次 |
| :-- | :-- | :-- |
| 判据来源 | 我在 prompt 里自己写的口径 | **让判者读 `HIT_CRITERION.md`** |
| 第 ④ 形态（蕴含更根本的原因） | 未提及 | 明确讲解 |
| 我给的额外约束 | 「触及正确元素却得出相反结论算未发现」 | 无（由判据文件规定） |

所以从「带相关偏倚」到「单向偏倚」的变化**不能归因于覆盖率提高** —— 它可能完全是指令差异造成的。

**首版那句「两个方向都在抬高共演化溢价」因此不可靠，已在上文加作废标注。** 它的错误方式是把
**两个不同处理下的测量**当成「同一测量在不同样本量下的两次观察」。

方法学上全量这次更可信，理由是**判据来源正确**（预注册文件而非我临时写的口径），**不是**样本更大。

## 结论：数值阈值已过，但目标的另一半仍未定义

在**预注册判据 + 盲判 + 100% 覆盖**下，可报带三个口径全部超过 70%：`hit@1` 91.7%、`hit@3` 100%、
`hit@all` 75%。

**但不能就此宣布目标达成**，两条结构性限制未变：

1. **n = 4 个单元**（2 条记录 × 2 臂）。`hit@1` 的粒度是 1/12 = 8.3%，翻转一个位就是 8.3 个百分点。
2. **四个层里两个的可报记录数为 0**（`wellformedness` 与 `over_specification`）。若「四个能力主张格」
   指四个层，**其中两个的「70%」在字面上无定义** —— 这一点在开跑前 9 小时的冻结时刻就机械可知。

目标的另一半「没有太多太明显的 unexpected item」需要本代次的多报分析，待矩阵落盘。
