# 预注册：用干净装置重判 v24（对**判定装置**的单变量实验）

**写于两位标注者开始之前，结果未知。** 本代次刚因「预测在前」不成立撤销过一次归因，所以这次把预期写死
在数据之前，并指明**哪个观测能证伪它**。

| | v24 原判定 | 本次重判 |
| :-- | :-- | :-- |
| 被判对象 | v24 的 66 格产物 | **同一批，逐字节相同**（冻结在盘上） |
| 样本 | `sample_id = 975ca6a5135cf732` | **同一个** |

**唯一变化是判定装置。** 产物、样本、标注者角色设置全部不变。

## 预注册预期

### 主预期：`hit@1` **下降或不变**

理由：泄漏的形态是**告诉标注者某些命题该判什么**（`HIT_CRITERION.md` §3 的四种形态各配一个真实语料
实例并给出命中裁定；§4.5 逐字引用一条已发布 issue 与对应台账 primary，并列出两读法各自的命中/不命中）。
预装答案的方向是**指向命中**，因为那些实例全是"这算命中"的正例。

去掉它 → 命中判定失去外部支撑 → **`hit@1` 应下降或不变，不应上升**。

### 副预期

| 量 | 预期 | 理由 |
| :-- | :-- | :-- |
| `κ_label` | **下降** | 泄漏是**共享**的外部锚点，两位标注者读同一份实例 → 人为提高一致性 |
| `fabricated` | 不定 | 泄漏的实例是命中正例，与虚构判定无直接关系 |
| `boundary` | 不定 | 同上 |

## 证伪条件（写死，不得事后调整）

| 观测 | 结论 |
| :-- | :-- |
| `hit@1` **上升 > 噪声底** | **主预期被证伪** —— 泄漏的方向与我判断的相反，需重新分析泄漏机制 |
| `hit@1` 变化 ≤ 噪声底 | 泄漏**未实际影响**判定，v24 数字站得住（但装置仍该修，已修） |
| `hit@1` 下降 > 噪声底 | 主预期成立，**v24 报告的覆盖率须就地下调** |
| `κ_label` **上升** | 副预期被证伪 —— 一致性提高不是泄漏造成的 |

**噪声底**：v24 逐轮 `hit@1` 极差 **7.4pp**（v23 为 2.9pp）。按仓库三级判据，取 max = **7.4pp**。

⚠️ 但这里有一个我必须先说明的困难：**噪声底是「同一装置下重复运行」的方差**，而本次是**同一运行、不同
装置**。两者不是同一种波动。严格说这次缺一个"同一装置重判"的对照来测判定方差。

**所以判据放宽为**：变化 ≤ 7.4pp 记「不可归因」；> 7.4pp 记「弱信号」并明确说明缺判定方差对照；
**任何情况下不得记为「效果」**，除非补上同一装置重判的对照。
