# Codex Draft Notes — Case 114

## 1. 设计选择

- mode 列表：`Off` 来自 STM §1 摘录 B / expansion [E5] 的 OFF/Stop；`Ready` 来自 [E5] Start 后系统 active 与 green LED；`EntryGateOpen`、`LotFull` 来自 [E6][E7] proximity 入场与满位互锁；`AlignmentCheck`、`AdjustPosition` 来自 [E8][E9] IR1 ON/OFF；`ParkingSlotSelected`、`ParkingRotating`、`ParkingComplete` 来自 [E10][E11][E12] Parkir Mobil、slot 1-8、OK 与 IR2 停车；`RetrievalSlotSelected`、`RetrievalRotating`、`RetrievalValidation`、`ExitGateOpen` 来自 [E13]-[E19] Ambil Mobil、CW/CCW、BENAR/SALAH、出场 proximity；`EmergencyManual` 来自 [E20]-[E24] DARURAT、CW/CCW、gate open/close、Reset Jumlah、Reset Counter。`EntryCheck`、`ParkCommandCheck`、`ParkStopCheck`、`RetrieveCommandCheck`、`RetrieveStopCheck` 是 routing-only pseudo states，用于把事件和 guard 分离，不作为可停留 mode。
- event 列表：`Start`/`Stop` 来自 [E5]；`ProximityOn`/`CarEntered`/`ExitProximityOn` 来自 [E6][E18][E19]；`Infrared1On`/`Infrared1Off`/`PositionAdjusted` 来自 [E8][E9]；`Parkir Mobil` 流程用 `ParkingSlot1`-`ParkingSlot8`、`OKPark`、`Infrared2SpaceDetected`、`FinishBack` 表达 [E10]-[E12] 和 HMI 返回；`Ambil Mobil` 流程用 `RetrievalSlot1`-`RetrievalSlot8`、`OKRetrieve`、`SelectedSlotBelow`、`BENAR`、`SALAH` 表达 [E13]-[E17]；`DaruratOn`/`DaruratOff`、`CWLower`/`CCWLower`、`GateOpen`/`GateClose`、`ResetJumlah`、`ResetCounter` 来自 [E20]-[E24]。
- variable 列表：`int parked_count = 0` 来自 [E19][E24] 的车辆数量增减和 Reset Jumlah，并在 `EntryCheck` 的满位 guard 中读取；`int selected_slot = 0` 来自 [E10][E11][E13] 的 HMI slot 选择，并在 OK 和旋转停止 guard 中读取；`int movement_counter = 0` 来自 [E20][E24] 的 parking-space movement counting / Reset Counter，并在 per-cycle 旋转期间累加、在停止 guard 中读取。
- transition 设计：`EntryCheck -> EntryGateOpen` guard `parked_count < 8` 和 `EntryCheck -> LotFull` guard `parked_count >= 8` 对应 [E1][E6][E7]；`ParkingSlotSelected -> ParkCommandCheck :: OKPark` 后按 `selected_slot >= 1 && selected_slot <= 8` 决定是否进入旋转，对应 [E10][E11]；`ParkingRotating -> ParkStopCheck :: Infrared2SpaceDetected` 后按 `movement_counter >= selected_slot` 停车并 `parked_count = parked_count + 1`，对应 [E12][E19]；取车侧 `RetrievalRotating -> RetrieveStopCheck :: SelectedSlotBelow` 后进入 `RetrievalValidation`，`BENAR` 开闸、`SALAH` 回到 Ambil Mobil，出场 proximity 后 `parked_count = parked_count - 1`，对应 [E15]-[E19]；应急状态提供 DARURAT ON/OFF、CW/CCW、gate、reset controls，对应 [E20]-[E24]。

## 2. C-axis grounding 使用情况

- **C1 (周期执行)**: 用 — `ParkingRotating` 与 `RetrievalRotating` 的 `during { movement_counter = movement_counter + 1; }` 表达 rotary motor running / lowering 期间车位移动计数持续推进；依据 [E12][E14][E20][E24]。
- **C2 (数值守卫)**: 用 — `parked_count < 8` / `parked_count >= 8` 表达 8 槽满位阈值；`selected_slot >= 1 && selected_slot <= 8` 表达 HMI slot 1-8；`movement_counter >= selected_slot && selected_slot >= 1 && selected_slot <= 8` 表达选定槽位计数到达后停车。变量和阈值来自 [E1][E11][E12][E15][E24]。
- **C3 (forced fault)**: 未用 — 原文支持 HMI emergency/recovery UI，但 expansion 的 axis_coverage 明确不把它表述为任意状态 forced fault；因此没有写 `! * -> Error`，而是从关键运行状态显式进入 `EmergencyManual`。
- **C4 (硬件)**: 用 — `GreenActiveLedOn`、`EntryBarrierOpen`、`BarrierClosedRedLedOn`、`Infrared1OffAdjustCar`、`RotaryParkingMotorOn/Off`、`RelayCwCcwRotaryMotorOn`、`YellowLedOnSelectedSlotBelow`、`ExitBarrierOpen/CloseYellowLedOff`、`EmergencyRotaryGateResetControlsAvailable` 分别对应 [E3]-[E7][E9][E12][E14][E15][E18][E20]-[E24] 的传感器、LED、DC motor、relay、barrier 和 HMI controls。

## 3. 与 NL 的对应关系

- expansion NL [E1]: "prototype vertical rotary parking system with eight slots" → `parked_count < 8` / `parked_count >= 8` guard 与 `ParkingSlot1`-`ParkingSlot8`、`RetrievalSlot1`-`RetrievalSlot8`。
- expansion NL [E2]: "rotary motor for moving parking spaces in and out" → `ParkingRotating` / `RetrievalRotating`。
- expansion NL [E3]: "proximity/infrared sensors, LEDs, and DC motors" → `ProximityOn`、`Infrared1On`、`Infrared2SpaceDetected`、硬件 abstract actions。
- expansion NL [E4]: "relay protects the DC motor and reverses rotation for CW/CCW movement" → `RetrievalRotating` 的 `RelayCwCcwRotaryMotorOn` 与 emergency `CWLower`/`CCWLower`。
- expansion NL [E5]: "ON/Start, OFF/Stop, and green active LED" → `Off -> Ready :: Start`、`Ready -> Off :: Stop`、`Ready.enter abstract GreenActiveLedOn`。
- expansion NL [E6]: "proximity sensor opens the barrier when space is available" → `Ready -> EntryCheck :: ProximityOn`，`EntryCheck -> EntryGateOpen : if [parked_count < 8]`。
- expansion NL [E7]: "full lot guard, closed barrier motor, red LED on" → `EntryCheck -> LotFull : if [parked_count >= 8]`、`LotFull.enter abstract BarrierClosedRedLedOn`。
- expansion NL [E8]: "infrared sensor 1 ON means ready to park" → `AlignmentCheck -> ParkingSlotSelected :: Infrared1On`。
- expansion NL [E9]: "infrared sensor 1 OFF means wrong position" → `AlignmentCheck -> AdjustPosition :: Infrared1Off`、`AdjustPosition -> AlignmentCheck :: PositionAdjusted`。
- expansion NL [E10]-[E12]: Parkir Mobil、slot 1-8、OK、IR2 stop → `ParkingSlotSelected`、slot events、`OKPark`、`ParkingRotating -> ParkStopCheck :: Infrared2SpaceDetected`。
- expansion NL [E13]-[E15]: Ambil Mobil、slot、CW/CCW、selected slot below → `RetrievalSlotSelected`、slot events、`RetrievalRotating`、`SelectedSlotBelow`、`RetrievalValidation`。
- expansion NL [E16]-[E17]: BENAR/SALAH validation → `RetrievalValidation -> ExitGateOpen :: BENAR`、`RetrievalValidation -> RetrievalSlotSelected :: SALAH`。
- expansion NL [E18]-[E19]: exit proximity closes barrier/yellow off/decrements count → `ExitGateOpen -> Ready :: ExitProximityOn effect { parked_count = parked_count - 1; selected_slot = 0; }`。
- expansion NL [E20]-[E24]: emergency and reset recovery → `EmergencyManual`、`DaruratOn`/`DaruratOff`、`CWLower`/`CCWLower`、`GateOpen`/`GateClose`、`ResetJumlah`、`ResetCounter`。

- iter 1: 写出初稿 DSL + scenarios，smoke 通过；scenario 发现 `EntryCheck` 作为叶状态导致 `ProximityOn` 后还未进入 gate/full 分支，`EmergencyManual.enter` 重置 counter 抵消 CW/CCW 自环 effect。
- iter 2: 将 `EntryCheck` 改为 pseudo routing state；将 emergency counter reset 从 `enter` 移到各条 `DaruratOn` transition effect，保留 CW/CCW 自环累计。

- iter 3: 补充 `Stop`、`OKRetrieve` invalid slot 分支、parking/retrieval slot 1-8 button coverage；保持 DSL 不变，仅增强 scenarios。
- iter 3 verify: PARSE_OK → SEM_OK → SIM_OK → 7/7 scenarios pass → LINT_SUMMARY warnings=0 → ALL_OK。

## 5. 与 STM.md 表述的偏差（如有）

- 原文没有给出具体 slot 参数传递语法；DSL 用 `ParkingSlot1`-`ParkingSlot8` 和 `RetrievalSlot1`-`RetrievalSlot8` 展开 HMI 数字按钮，保持与 HMI 表格一致。
- 原文说明 IR2 检测经过的车位、Reset Counter 复位移动计数，但没有给出 PLC 内部计数公式；DSL 用 `movement_counter >= selected_slot` 把“所选槽位到达”形式化为可验证 guard，用于 scenario 覆盖 slot 阈值。
