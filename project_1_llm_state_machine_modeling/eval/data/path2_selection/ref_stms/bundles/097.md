## 1. 英文 NL（含 inline [E] 溯源 markers）

> 这是 codex 评审阶段生成的扩充 NL（commit `259e6ea7`），每条 substantive 信息带 `[En]` 标记。完整 provenance 表见 [expansion JSON](../expansions/097.json)。

The mission controller is a finite-state controller for a UAV mission that searches, follows, and grasps a moving object; initially the UAV is landed with GPS, RTK, and cameras initialized, and START_MISSION is the operator order to start [E1] [E2] [E3] [E4]. In SEARCH, the UAV flies a predefined semiellipse near the long-axis border and middle of that axis, at low altitude and very low speed and acceleration, so both UAV detectors stay active and can obtain sharp images against a uniform sky background [E5] [E6] [E7]. The controller changes from search to long-range following when the Long-Range Detector reaches three detections in five consecutive frames, and each new long-range detection commands fast UAV motion toward a point 5 m toward the detection in the XY plane [E8] [E9]. It then changes to short-range following when the Short-Range Detector reaches two detections in four consecutive frames, keeps about 4 m from the target, and disables the Long-Range UAV Detector so the short-range detector gets the computation power [E10] [E11]. When the ball is detected, the controller enters CATCH_BALL, commands motion toward the ball detection, aligns the ball with the gripper, and continues the planned trajectory after the ball leaves the camera field of view [E12] [E13] [E14]. If no new detections arrive for five consecutive frames, the FSM has a DETECTION_LOST transition event [E15]. A successful catch is declared only when the laser sensor inside the gripper detects the ball, after which the UAV lands at a given position and ends the mission [E16] [E17]. The gripper hardware includes a servomotor controlled through an Arduino Nano for closing and opening when high-level mission components require the catching maneuver [E18].

## 2. 中文 NL 译文（claude 翻译，保留 [En] markers）

任务控制器是一个用于无人机任务的有限状态控制器，负责搜索、跟随并抓取一个移动目标；初始时无人机处于着陆状态，GPS、RTK 和摄像头均已完成初始化，START_MISSION 是操作员发出的启动任务指令 [E1] [E2] [E3] [E4]。在 SEARCH 状态下，无人机沿预先定义的半椭圆轨迹飞行，该轨迹靠近长轴边界并位于该轴的中部，飞行高度较低、速度和加速度极低，使两个无人机检测器都保持激活，并能在均匀天空背景下获取清晰图像 [E5] [E6] [E7]。当长距检测器在连续 5 帧中达到 3 次检测时，控制器从搜索切换到长距跟随，且每一次新的长距检测都会指令无人机在 XY 平面上向检测点方向快速移动 5 m [E8] [E9]。随后当短距检测器在连续 4 帧中达到 2 次检测时，切换到短距跟随，与目标保持约 4 m 的距离，并禁用长距无人机检测器，从而把算力让给短距检测器 [E10] [E11]。当检测到球时，控制器进入 CATCH_BALL，指令无人机朝球的检测位置运动，将球与夹爪对齐，并在球离开摄像头视场之后继续按预定轨迹飞行 [E12] [E13] [E14]。若连续 5 帧没有新的检测到达，FSM 会触发一个 DETECTION_LOST 迁移事件 [E15]。只有当夹爪内部的激光传感器检测到球时，才宣告一次成功抓取，之后无人机在给定位置着陆并结束任务 [E16] [E17]。夹爪硬件包含一个通过 Arduino Nano 控制的伺服电机，用于在高层任务组件需要执行抓取动作时进行闭合与张开 [E18]。

```pyfcstm
def int detection_count = 0;
def int frame_window = 0;
def int no_new_detection_frames = 0;
def int detection_seen_this_frame = 0;

state SearchFollowCatchMissionController {
    event DETECTION_LOST;

    ! * -> SEARCH :: DETECTION_LOST;
    ! * -> SEARCH : if [no_new_detection_frames >= 5];

    [*] -> START_STATE;

    state START_STATE {
        event START_MISSION;
        enter abstract InitializeGpsRtkCameras;
    }

    state SEARCH {
        event LongRangeDetectionFrame;
        event LongRangeMissFrame;
        enter {
            if [no_new_detection_frames >= 5] {
                detection_count = 0;
                frame_window = 0;
                no_new_detection_frames = 0;
                detection_seen_this_frame = 0;
            }
        }
        enter abstract CommandSemiellipseSearchLowAltitude;
        enter abstract ActivateBothUavDetectors;
    }

    state FOLLOW_LONG_RANGE {
        event LongRangeDetectionFrame;
        event ShortRangeDetectionFrame;
        event ShortRangeMissFrame;
        enter abstract CommandFastFiveMeterXyApproach;
        during {
            if [detection_seen_this_frame > 0] {
                no_new_detection_frames = 0;
                detection_seen_this_frame = 0;
            } else {
                no_new_detection_frames = no_new_detection_frames + 1;
            }
        }
    }

    state FOLLOW_SHORT_RANGE {
        event ShortRangeDetectionFrame;
        event BALL_DETECTED;
        enter abstract MaintainFourMeterTargetStandoff;
        enter abstract DisableLongRangeUavDetector;
        during {
            if [detection_seen_this_frame > 0] {
                no_new_detection_frames = 0;
                detection_seen_this_frame = 0;
            } else {
                no_new_detection_frames = no_new_detection_frames + 1;
            }
        }
    }

    state CATCH_BALL {
        event BALL_DETECTED;
        event BALL_LEAVES_CAMERA_FIELD_OF_VIEW;
        event SUCCESSFUL_CATCH;
        enter abstract CommandMotionTowardBallDetection;
        enter abstract AlignBallWithGripper;
        enter abstract CommandArduinoNanoGripperManeuver;
        during {
            if [detection_seen_this_frame > 0] {
                no_new_detection_frames = 0;
                detection_seen_this_frame = 0;
            } else {
                no_new_detection_frames = no_new_detection_frames + 1;
            }
        }
        during abstract ContinuePlannedTrajectoryAfterBallLeavesCameraFieldOfView;
    }

    state LAND {
        enter abstract LandAtGivenPosition;
    }

    START_STATE -> SEARCH :: START_MISSION effect {
        detection_count = 0;
        frame_window = 0;
        no_new_detection_frames = 0;
        detection_seen_this_frame = 0;
    };

    SEARCH -> SEARCH :: LongRangeDetectionFrame effect {
        detection_count = detection_count + 1;
        frame_window = frame_window + 1;
    };
    SEARCH -> SEARCH :: LongRangeMissFrame effect {
        frame_window = frame_window + 1;
    };
    SEARCH -> FOLLOW_LONG_RANGE : if [detection_count >= 3 && frame_window >= 5] effect {
        detection_count = 0;
        frame_window = 0;
        no_new_detection_frames = 0;
        detection_seen_this_frame = 1;
    };
    SEARCH -> SEARCH : if [frame_window >= 5 && detection_count < 3] effect {
        detection_count = 0;
        frame_window = 0;
    };

    FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE :: LongRangeDetectionFrame effect {
        detection_seen_this_frame = 1;
    };
    FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE :: ShortRangeDetectionFrame effect {
        detection_count = detection_count + 1;
        frame_window = frame_window + 1;
        detection_seen_this_frame = 1;
    };
    FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE :: ShortRangeMissFrame effect {
        frame_window = frame_window + 1;
        detection_seen_this_frame = 0;
    };
    FOLLOW_LONG_RANGE -> FOLLOW_SHORT_RANGE : if [detection_count >= 2 && frame_window >= 4] effect {
        detection_count = 0;
        frame_window = 0;
        no_new_detection_frames = 0;
        detection_seen_this_frame = 1;
    };
    FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE : if [frame_window >= 4 && detection_count < 2] effect {
        detection_count = 0;
        frame_window = 0;
    };

    FOLLOW_SHORT_RANGE -> CATCH_BALL :: BALL_DETECTED effect {
        detection_count = 0;
        frame_window = 0;
        no_new_detection_frames = 0;
        detection_seen_this_frame = 1;
    };
    FOLLOW_SHORT_RANGE -> FOLLOW_SHORT_RANGE :: ShortRangeDetectionFrame effect {
        detection_seen_this_frame = 1;
    };

    CATCH_BALL -> LAND :: SUCCESSFUL_CATCH effect {
        detection_count = 0;
        frame_window = 0;
        no_new_detection_frames = 0;
        detection_seen_this_frame = 1;
    };
    CATCH_BALL -> CATCH_BALL :: BALL_DETECTED effect {
        detection_seen_this_frame = 1;
    };
    CATCH_BALL -> CATCH_BALL :: BALL_LEAVES_CAMERA_FIELD_OF_VIEW;
}
```

## 6. Codex 起草笔记

# Codex Revision Notes — Case 097

## 1. 设计选择

- mode 列表：
  - `START_STATE`：来自 STM §1 摘录 B / expansion [E3]，表示 UAV landed，GPS、RTK、cameras initialized。
  - `SEARCH`：来自 STM §1 摘录 B / [E5]-[E7]，表示 low-altitude semiellipse search、very low speed/acceleration、both UAV detectors active。
  - `FOLLOW_LONG_RANGE`：来自 STM §1 摘录 B / [E8]-[E9]，表示 long-range following 和 5 m XY fast approach。
  - `FOLLOW_SHORT_RANGE`：来自 STM §1 摘录 B / [E10]-[E11]，表示 short-range following、4 m target standoff、disable Long-Range UAV Detector。
  - `CATCH_BALL`：来自 STM §1 摘录 B / [E12]-[E14]，表示 move toward ball detection、align ball with gripper，并在 ball leaves camera FOV 后继续 planned trajectory。修订版把该 planned-trajectory 行为保留为 `CATCH_BALL` 内部 during abstract，不再升格为独立 FSM state。
  - `LAND`：来自 STM §1 摘录 B / [E17]，表示 land at a given position and mission ends。
- event 列表：
  - `START_MISSION`：来自 STM §1 摘录 C / [E4]。
  - `LongRangeDetectionFrame` / `LongRangeMissFrame`：编码用 frame-level 占位，原文对应 [E8] 的 "3 detections on 5 consecutive frames" 与 [E9] 的 "new long-range detection"；这些不是论文 Table 1 中的真实 event 名。
  - `ShortRangeDetectionFrame` / `ShortRangeMissFrame`：编码用 frame-level 占位，原文对应 [E10] 的 "2 detections on 4 consecutive frames"；这些不是论文 Table 1 中的真实 event 名。
  - `BALL_DETECTED`：来自 STM §1 摘录 C / [E12]。
  - `BALL_LEAVES_CAMERA_FIELD_OF_VIEW`：来自 STM §1 摘录 B / [E14]，修订版将其建成 `CATCH_BALL -> CATCH_BALL` self-transition。
  - `DETECTION_LOST`：来自 STM §1 摘录 C / [E15]，作为 root-level event 声明并由 `! * -> SEARCH :: DETECTION_LOST` 表达跨 mode recovery。
  - `SUCCESSFUL_CATCH`：来自 STM §1 摘录 C / [E16]。
- variable 列表：
  - `detection_count`: `int = 0`，在 `SEARCH` 中表示 long-range detections，在 `FOLLOW_LONG_RANGE` 中表示 short-range detections；阈值 3/5 来自 [E8]，2/4 来自 [E10]。
  - `frame_window`: `int = 0`，与 `detection_count` 共同表达 consecutive frame window；阈值来源同上。
  - `no_new_detection_frames`: `int = 0`，表达 [E15] 的 five consecutive frames with no new detections。
  - `detection_seen_this_frame`: `int = 0`，用于让 detection event cycle 清零 `no_new_detection_frames`，避免 pyfcstm transition 后 during 立即把该帧误计为 missed frame。
- transition 设计：
  - `START_STATE -> SEARCH :: START_MISSION`：operator order starts mission，来源 [E4]。
  - `SEARCH -> SEARCH :: LongRangeDetectionFrame/MissFrame`：累计 long-range 5-frame window，来源 [E8]。
  - `SEARCH -> FOLLOW_LONG_RANGE : if [detection_count >= 3 && frame_window >= 5]`：Table 1 `LONG_RANGE_UAV_DETECTED` 的数值语义，来源 [E8]；目标 state entry 触发 5 m XY approach，来源 [E9]。
  - `SEARCH -> SEARCH : if [frame_window >= 5 && detection_count < 3]`：未达到 3/5 时重置 long-range window，防止把失败窗口无限累积成成功窗口。
  - `FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE :: LongRangeDetectionFrame`：每个 new long-range detection 重新触发 fast 5 m approach，来源 [E9]。
  - `FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE :: ShortRangeDetectionFrame/MissFrame`：累计 short-range 4-frame window，来源 [E10]。
  - `FOLLOW_LONG_RANGE -> FOLLOW_SHORT_RANGE : if [detection_count >= 2 && frame_window >= 4]`：Table 1 `SHORT_RANGE_UAV_DETECTED` 的数值语义，来源 [E10]；目标 state entry 表达 4 m standoff 和 disable long-range detector，来源 [E11]。
  - `FOLLOW_LONG_RANGE -> FOLLOW_LONG_RANGE : if [frame_window >= 4 && detection_count < 2]`：未达到 2/4 时重置 short-range window。
  - `FOLLOW_SHORT_RANGE -> CATCH_BALL :: BALL_DETECTED`：ball detection triggers catch phase，来源 [E12]-[E13]。
  - `CATCH_BALL -> CATCH_BALL :: BALL_LEAVES_CAMERA_FIELD_OF_VIEW`：ball leaves FOV 后仍处于 `CATCH_BALL`，其 `during abstract ContinuePlannedTrajectoryAfterBallLeavesCameraFieldOfView` 表达继续 planned trajectory，来源 [E14]。
  - `CATCH_BALL -> LAND :: SUCCESSFUL_CATCH`：laser sensor inside gripper detects ball, then land，来源 [E16]-[E17]。
  - `! * -> SEARCH :: DETECTION_LOST` 与 `! * -> SEARCH : if [no_new_detection_frames >= 5]`：用 C3 forced transition 表达 [E15] detection-loss recovery；显式 event 保留 Table 1 event 名，guard forced path 保留 five consecutive frames 的数值阈值语义。由于 pyfcstm 单条 transition 不能同时写 event 和 guard，scenarios 约束显式 event 只在 `no_new_detection_frames >= 5` 时注入。

## 2. C-axis grounding 使用情况

- **C1 (周期执行)**: 用 — 在 `FOLLOW_LONG_RANGE`、`FOLLOW_SHORT_RANGE`、`CATCH_BALL` 的 `during {}` 中把 simulator cycle 作为 frame，累计 [E15] 的 no-new-detection consecutive frames；scenarios 覆盖了 ≥3 cycles 和 5-frame boundary。
- **C2 (数值守卫)**: 用 — `detection_count >= 3 && frame_window >= 5` 对应 [E8]；`detection_count >= 2 && frame_window >= 4` 对应 [E10]；`no_new_detection_frames >= 5` 对应 [E15]。
- **C3 (forced fault)**: 用 — 修订后采用 root-level `! * -> SEARCH` forced transition 表达 [E15] `DETECTION_LOST` recovery，替代上一版 4 处重复局部 guard。
- **C4 (硬件)**: 用 — `InitializeGpsRtkCameras` 对应 [E3]；`CommandSemiellipseSearchLowAltitude` 和 `ActivateBothUavDetectors` 对应 [E5]-[E7]；`CommandFastFiveMeterXyApproach` 对应 [E9]；`MaintainFourMeterTargetStandoff` 和 `DisableLongRangeUavDetector` 对应 [E11]；`CommandMotionTowardBallDetection`、`AlignBallWithGripper`、`CommandArduinoNanoGripperManeuver` 对应 [E13] / [E18]；`ContinuePlannedTrajectoryAfterBallLeavesCameraFieldOfView` 对应 [E14]；`LandAtGivenPosition` 对应 [E17]。

## 5. 与 STM.md 表述的偏差（如有）

- `LongRangeDetectionFrame`、`LongRangeMissFrame`、`ShortRangeDetectionFrame`、`ShortRangeMissFrame` 是为了在 pyfcstm 中显式验证 3/5 与 2/4 阈值而规范化出的 frame-level events；论文 Table 1 的 `LONG_RANGE_UAV_DETECTED` / `SHORT_RANGE_UAV_DETECTED` 被编码为相应 numeric guards。
