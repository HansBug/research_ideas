## 1. 英文 NL（含 inline [E] 溯源 markers）

> 这是 codex 评审阶段生成的扩充 NL（commit `259e6ea7`），每条 substantive 信息带 `[En]` 标记。完整 provenance 表见 [expansion JSON](../expansions/114.json)。

The controller manages a prototype vertical rotary parking system with eight slots, PLC Outseal, Android HMI, proximity/infrared sensors, LEDs, and DC motors, including a rotary motor for moving parking spaces in and out [E1] [E2] [E3]. A relay protects the DC motor and reverses its rotation for CW/CCW movement [E4]. Operation starts with ON/Start and a green active LED; during entry, the proximity sensor opens the barrier when space is available, but the barrier motor remains closed with the red LED on when the lot is full [E5] [E6] [E7]. Infrared sensor 1 is the readiness guard: ON means the car is ready to park, while OFF means the position is wrong and the user must adjust it [E8] [E9]. For parking, the operator uses the HMI Parkir Mobil screen, chooses slot 1-8, presses OK, and the rotary motor runs until infrared sensor 2 detects a passing parking space, then stops [E10] [E11] [E12]. For retrieval, Ambil Mobil plus a slot number and OK makes the rotary motor move the car downward CW/CCW until the selected HMI slot is below, turning the yellow LED on and the rotary motor off [E13] [E14] [E15]. The validation step opens the barrier only after BENAR; SALAH sends the operator back to repeat Ambil Mobil [E16] [E17]. After exit, proximity detection closes the barrier again, turns the yellow LED off, and supports decrementing the parked-vehicle count [E18] [E19]. The HMI also exposes emergency and reset recovery: DARURAT ON/OFF, CW/CCW lowering, gate open/close, Reset Jumlah, and Reset Counter for cancelled parking/retrieval, parking-space movement counting errors, or disasters [E20] [E21] [E22] [E23] [E24].

## 2. 中文 NL 译文（claude 翻译，保留 [En] markers）

该控制器管理一套原型化的立式旋转停车系统，配备八个车位、Outseal PLC、Android HMI、接近/红外传感器、LED 指示灯以及直流电机，其中包含用于将停车位移入和移出的旋转电机 [E1] [E2] [E3]。继电器对直流电机提供保护，并通过反向其旋转方向实现 CW/CCW 运动 [E4]。系统在按下 ON/Start 后启动，绿色工作 LED 点亮；在车辆进入阶段，当有空位时接近传感器会打开闸门，而当车位已满时闸门电机保持关闭状态并点亮红色 LED [E5] [E6] [E7]。红外传感器 1 担任就绪守卫：ON 表示车辆已就绪可停入，OFF 表示位置不正确，用户必须进行调整 [E8] [E9]。停车操作时，操作员使用 HMI 上的 Parkir Mobil 界面，选择 1-8 号车位，按下 OK，旋转电机随即运转，直到红外传感器 2 检测到一个经过的停车位后停止 [E10] [E11] [E12]。取车操作时，选择 Ambil Mobil 并输入车位编号后按下 OK，旋转电机会沿 CW/CCW 方向将车辆向下移动，直到所选 HMI 车位移到下方，此时点亮黄色 LED 并停止旋转电机 [E13] [E14] [E15]。验证步骤仅在 BENAR 之后才打开闸门；SALAH 则会将操作员退回到重新执行 Ambil Mobil [E16] [E17]。车辆驶出后，接近检测会再次关闭闸门、熄灭黄色 LED，并支持对已停车辆计数进行递减 [E18] [E19]。HMI 还提供紧急与复位恢复功能：DARURAT ON/OFF、CW/CCW 下降、闸门开/关、Reset Jumlah 和 Reset Counter，用于处理取消的停车/取车、停车位移动计数错误或灾难情况 [E20] [E21] [E22] [E23] [E24]。

## 6. Codex 起草笔记

# Codex Draft Notes — Case 114

## 1. 设计选择

- mode 列表：`Off` 来自 STM §1 摘录 B / expansion [E5] 的 OFF/Stop；`Ready` 来自 [E5] Start 后系统 active 与 green LED；`EntryGateOpen`、`LotFull` 来自 [E6][E7] proximity 入场与满位互锁；`AlignmentCheck`、`AdjustPosition` 来自 [E8][E9] IR1 ON/OFF；`ParkingSlotSelected`、`ParkingRotating`、`ParkingComplete` 来自 [E10][E11][E12] Parkir Mobil、slot 1-8、OK 与 IR2 停车；`RetrievalSlotSelected`、`RetrievalRotating`、`RetrievalValidation`、`ExitGateOpen` 来自 [E13]-[E19] Ambil Mobil、CW/CCW、BENAR/SALAH、出场 proximity；`EmergencyManual` 来自 [E20]-[E24] DARURAT、CW/CCW、gate open/close、Reset Jumlah、Reset Counter。`EntryCheck`、`ParkCommandCheck`、`ParkStopCheck`、`RetrieveCommandCheck`、`RetrieveStopCheck` 是 routing-only pseudo states，用于把事件和 guard 分离，不作为可停留 mode。
- event 列表：`Start`/`Stop` 来自 [E5]；`ProximityOn`/`CarEntered`/`ExitProximityOn` 来自 [E6][E18][E19]；`Infrared1On`/`Infrared1Off`/`PositionAdjusted` 来自 [E8][E9]；`Parkir Mobil` 流程用 `ParkingSlot1`-`ParkingSlot8`、`OKPark`、`Infrared2SpaceDetected`、`FinishBack` 表达 [E10]-[E12] 和 HMI 返回；`Ambil Mobil` 流程用 `RetrievalSlot1`-`RetrievalSlot8`、`OKRetrieve`、`SelectedSlotBelow`、`BENAR`、`SALAH` 表达 [E13]-[E17]；`DaruratOn`/`DaruratOff`、`CWLower`/`CCWLower`、`GateOpen`/`GateClose`、`ResetJumlah`、`ResetCounter` 来自 [E20]-[E24]。
- variable 列表：`int parked_count = 0` 来自 [E19][E24] 的车辆数量增减和 Reset Jumlah，并在 `EntryCheck` 的满位 guard 中读取；`int selected_slot = 0` 来自 [E10][E11][E13] 的 HMI slot 选择，并在 OK 和旋转停止 guard 中读取；`int movement_counter = 0` 来自 [E20][E24] 的 parking-space movement counting / Reset Counter，并在 per-cycle 旋转期间累加、在停止 guard 中读取。
- transition 设计：`EntryCheck -> EntryGateOpen` guard `parked_count < 8` 和 `EntryCheck -> LotFull` guard `parked_count >= 8` 对应 [E1][E6][E7]；`ParkingSlotSelected -> ParkCommandCheck :: OKPark` 后按 `selected_slot >= 1 && selected_slot <= 8` 决定是否进入旋转，对应 [E10][E11]；`ParkingRotating -> ParkStopCheck :: Infrared2SpaceDetected` 后按 `movement_counter >= selected_slot` 停车并 `parked_count = parked_count + 1`，对应 [E12][E19]；取车侧 `RetrievalRotating -> RetrieveStopCheck :: SelectedSlotBelow` 后进入 `RetrievalValidation`，`BENAR` 开闸、`SALAH` 回到 Ambil Mobil，出场 proximity 后 `parked_count = parked_count - 1`，对应 [E15]-[E19]；应急状态提供 DARURAT ON/OFF、CW/CCW、gate、reset controls，对应 [E20]-[E24]。

## 2. C-axis grounding 使用情况

- **C1 (周期执行)**: 用 — `ParkingRotating` 与 `RetrievalRotating` 的 `during { movement_counter = movement_counter + 1; }` 表达 rotary motor running / lowering 期间车位移动计数持续推进；依据 [E12][E14][E20][E24]。
- **C2 (数值守卫)**: 用 — `parked_count < 8` / `parked_count >= 8` 表达 8 槽满位阈值；`selected_slot >= 1 && selected_slot <= 8` 表达 HMI slot 1-8；`movement_counter >= selected_slot && selected_slot >= 1 && selected_slot <= 8` 表达选定槽位计数到达后停车。变量和阈值来自 [E1][E11][E12][E15][E24]。
- **C3 (forced fault)**: 未用 — 原文支持 HMI emergency/recovery UI，但 expansion 的 axis_coverage 明确不把它表述为任意状态 forced fault；因此没有写 `! * -> Error`，而是从关键运行状态显式进入 `EmergencyManual`。
- **C4 (硬件)**: 用 — `GreenActiveLedOn`、`EntryBarrierOpen`、`BarrierClosedRedLedOn`、`Infrared1OffAdjustCar`、`RotaryParkingMotorOn/Off`、`RelayCwCcwRotaryMotorOn`、`YellowLedOnSelectedSlotBelow`、`ExitBarrierOpen/CloseYellowLedOff`、`EmergencyRotaryGateResetControlsAvailable` 分别对应 [E3]-[E7][E9][E12][E14][E15][E18][E20]-[E24] 的传感器、LED、DC motor、relay、barrier 和 HMI controls。

**Hallucination 检查**:
- `threshold` `movement_counter >= selected_slot`: codex notes §5 自承：原文未给 PLC 计数公式，'IR2 检测经过的车位'被擅自形式化为'数到 selected_slot 才停'，把单次触发改为 N 次阈值
- `event` `CarEntered`: EntryGateOpen→AlignmentCheck 的 CarEntered 在 NL 无对应；原文只提 proximity 开闸→IR1 检查，没有中间 CarEntered 事件
- `event` `PositionAdjusted`: AdjustPosition→AlignmentCheck 的 PositionAdjusted 是发明；NL 只说 'pengguna harus membenarkan posisi'，无显式重检事件
- `event` `FinishBack`: ParkingComplete→Ready 的 FinishBack 在 NL 无对应，原文未描述停车完成后如何回到主循环
- `state` `ParkingComplete`: NL 未描述独立的 ParkingComplete 状态及'green ready off'语义；停车完成后行为原文不明
- `effector` `EmergencyRedIndicatorOn/Off`: NL 提到 DARURAT 控件但未提 emergency 专用红色指示灯，红灯在 NL 中只与 LotFull 绑定 [E7]

**修订建议**:
- 移除 ParkingRotating/RetrievalRotating 的 `during { movement_counter = movement_counter + 1; }` aspect 和所有 `movement_counter >= selected_slot` guard；改为单次 `Infrared2SpaceDetected` 触发 ParkingRotating→ParkingComplete、单次 `SelectedSlotBelow` 触发 RetrievalRotating→RetrievalValidation，符合 [E12][E15] 原文单事件停车语义
- 若仍想保留 movement_counter 变量（因 [E24] Reset Counter 明确提到），仅作为 Reset Counter 触发的可观察变量，不参与 guard，并在 notes 中明确这是 [E24] 显式支持的 'parking-space movement counting' 而非停车判定
- 删除 CarEntered 事件，让 EntryGateOpen→AlignmentCheck 由 Infrared1On/Off 直接驱动（NL 描述就是 proximity 开闸后立即由 IR1 判定），或将 EntryGateOpen 与 AlignmentCheck 合并
- 将 PositionAdjusted 替换为再次 Infrared1On（合理：用户调整后 IR1 重新点亮），减少发明事件
- 删除 ParkingComplete 状态及 FinishBack 事件，让 ParkingRotating 在 Infrared2 时直接回到 Ready 并 `parked_count++`，或在 STM.md §1 摘录中明确补一句完成后行为再保留
- 将 EmergencyManual.enter/exit 的 EmergencyRedIndicatorOn/Off 抽象重命名为 NL 直接支持的 `DaruratIndicatorOn`（仅描述 DARURAT ON 状态），避免暗示 NL 未提的红灯硬件

**缺失 scenarios 建议**:
- ir2_single_trigger_stops_parking: 验证去除 counter 后 IR2 单次触发直接 ParkingRotating→ParkingComplete（修订后必须）
- selected_slot_below_single_trigger: 验证 SelectedSlotBelow 单次触发直接 RetrievalRotating→RetrievalValidation

- reset_counter_in_normal_path: Ready 或 ParkingRotating 中 ResetCounter 是否有定义（当前只在 EmergencyManual 自环），核对 [E24] 是否仅限应急
