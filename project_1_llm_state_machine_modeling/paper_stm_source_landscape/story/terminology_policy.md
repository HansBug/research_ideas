# 术语使用策略

## 1. 推荐术语

| 术语 | 使用方式 |
|---|---|
| `benchmark-source landscape` | 主术语，中文写作时优先写“基准来源景观”；表示可作为基准来源的论文案例全景，不等同最终基准 |
| `retrospective systematic mapping with an audit protocol` | 中文写作时优先写“带审计协议的后验系统映射”；描述 `sources/` 的长期增量来源与后验审计，不声称从零预注册 SLR |
| `state-machine case` | 中文写作时优先写“状态机案例”；指论文中可抽取的状态机、模式切换、门控逻辑或行为模型案例 |
| `sanitized artifact` | 中文写作时优先写“脱敏制品”；只含元数据、标签、转述式派生描述、证据定位符、脚本、编码手册 |

## 2. 禁止或谨慎术语

| 术语 | 处理 |
|---|---|
| 带顺序含义的版本化命名 | 禁止；#85 与 `paper_v1` 并列，不是版本序列 |
| `benchmark` | 除非 G7/G9/G10 完成，只能写“基准来源”或“任务卡小规模试跑” |
| `complete SLR` / `PRISMA-compliant` | 禁止；最多写“受 PRISMA 启发的流程”或“后验系统映射” |
| `first` / `largest` | 禁止，除非直接近邻检索与证据门禁完成 |
