# Terminology Policy

## 1. 推荐术语

| 术语 | 使用方式 |
|---|---|
| `benchmark-source landscape` | 主术语，表示可作为 benchmark 来源的论文案例全景；不等同最终 benchmark |
| `retrospective systematic mapping with an audit protocol` | 描述 `sources/` 的长期增量来源与后验审计，不声称从零预注册 SLR |
| `state-machine case` | 指论文中可抽取的状态机、模式切换、门控逻辑或行为模型案例 |
| `sanitized artifact` | 只含 metadata、labels、paraphrased derived descriptions、evidence locators、scripts、codebook |

## 2. 禁止或谨慎术语

| 术语 | 处理 |
|---|---|
| 带顺序含义的版本化命名 | 禁止；#85 与 `paper_v1` 并列，不是版本序列 |
| `benchmark` | 除非 G7/G9/G10 完成，只能写 `benchmark-source` 或 `task-card pilot` |
| `complete SLR` / `PRISMA-compliant` | 禁止；最多写 PRISMA-inspired flow / retrospective SMS |
| `first` / `largest` | 禁止，除非 direct competitor search 与证据 gate 完成 |
