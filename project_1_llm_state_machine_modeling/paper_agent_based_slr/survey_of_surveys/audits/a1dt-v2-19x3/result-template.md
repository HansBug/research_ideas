# A1-DT v2 单篇审计结果模板

每份 `results/<slug>__<agent>.md` 至少包含：

1. 审计结论卡片：slug、agent、读取文件、是否 PDF 核验、原文类型、样本单位、分母、树型、主统计池资格、总体判定。
2. 审计足迹：读取的本地文件、章节、表 / 图 / 附录；未核验项；timeout / blocked。
3. 样本单位四问：原文如何描述、编码、分类、统计样本单位。
4. 原生样本编码维度树 / 维度森林。
5. 叶子维度表：字段来源、定义、取值空间、取值空间类型、缺失值、统计用途、候选发现用途、迁移边界。
6. 关系边表。
7. 统计观察 / 候选 finding / final finding 边界。
8. 对现有 `review.md` 的 C/I/M 返修建议。
9. A.2 证据账本草案和 A.3 结论-证据映射草案。
10. 技能使用与自我审查记录。
