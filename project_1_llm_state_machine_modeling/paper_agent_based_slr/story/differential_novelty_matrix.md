# 差异化新颖性矩阵：PR-S0-v2 相关工作边界

## 1. 目的与术语口径

本文件冻结当前阶段的差异化新颖性门槛。它不是完整相关工作，也不声称已经排除所有直接竞争工作；它用于防止第二篇论文误写成首次自动化系统综述、首次智能体式系统综述、PRISMA 透明报告框架合规工具、自动综述生成论文或 `sources/` 语料论文。

首次出现的关键术语按“中文术语（英文术语 / 缩写）”定义：系统综述自动化（systematic review automation）、智能体式系统综述（agentic systematic literature review / agentic SLR）、大语言模型辅助筛选 / 抽取 / 综合（LLM-assisted screening / extraction / synthesis）、人在回路（human-in-the-loop）、来源追溯（source tracing / attribution）和可审计性（auditability）。后续正文优先使用中文术语，英文仅保留在论文名、工具名、固定缩写和必要术语锚点中。

PR-B0 已完成 35 篇本地全文文本级基线评审与全 CCF A/B/C 扩展检索。后续主线不能继续写“待 A1 才知道是否有强近邻”；当前已知事实是：多智能体系统综述、临床证据综合、人在回路来源追溯、筛选 / 抽取、综述生成和软件工程大语言模型辅助系统综述方法学风险都已有强近邻。本文差异化不能再用“无人自动综述”来表述，而必须显式体现**研究者定义的综述元模型、可演化维度模式、字段级内容证据、统计分析 / 研究发现分层、研究者质疑 / 裁决、过程证据支撑方法评价**这一组合。

## 3. 差异化主线压缩

PR-S0-v2 后，本文可尝试成立的差异化不再是“智能体也能做系统综述”，也不只是旧口径的“综述元模型 + 证据链”。更安全的差异化组合是：

1. **研究者定义的综述元模型**：使用本文方法的研究者明确主题、研究问题、范围、核心对象、关系和证据类型；大语言模型 / 智能体只能建议，不能决定实际生效的综述元模型。
2. **可演化维度模式**：把综述元模型投影为树状 / 类型化、可版本化、可修订的抽取模式；每次修订都记录变更触发原因、影响分析、受影响论文与回填状态。
3. **字段级内容证据**：每个字段值、统计输入和领域发现都必须回到目标论文中的来源锚点、短引文、表格、制品链接、缺失 / 不确定说明。
4. **统计分析 / 研究发现分层**：统计分析只产生频次、分布、交叉表、趋势、覆盖代理、矛盾信号等统计观察；智能体输出只是候选发现。
5. **研究者质疑 / 最终裁决**：候选发现必须经过证据、反例、范围、主张强度和模式适配性的研究者质疑，才能被接受、降级、拒绝或标为未解决。
6. **过程证据支撑方法评价**：试运行和硕士生人机交互日志用于评价方法可用性、审计性、成本和失败模式，不支撑目标领域发现。
7. **软件工程系统综述 / 系统映射研究场景约束**：上述机制落在软件工程、LLM4Modeling、模型驱动工程等软件工程综述场景中，而不是泛医学、金融或通用综述生成。

这组差异化必须正面对齐 B0 中的强近邻：AgentSLR 与 LatteReview 已经覆盖多阶段工作流；EviSearch 已经覆盖单元格级来源追溯；LR-Robot 已经覆盖专家分类体系 + 大语言模型分类；TrialMind 已经覆盖临床证据综合；WSESE@ICSE 2025 已经讨论软件工程大语言模型辅助系统综述风险。因此本文的安全新颖性应落在“研究者定义模式如何演化、字段证据如何进入统计观察、统计观察如何通过人类质疑变成发现、过程证据如何评价方法”这一组合上。

## 4. 最低相关工作门槛

后续任何主线、大纲或手稿若要写新颖性，必须至少回答：

1. 为什么本文不是首次自动化系统综述 / 首次智能体式系统综述，而是审计优先证据工程方法？
2. 与 AgentSLR 的分阶段隔离评价和专家参考答案有什么差别？
3. 与 LatteReview 的多智能体筛选 / 抽取工作流有什么差别？
4. 与 EviSearch 的单元格级来源追溯 / 人在回路审计有什么差别？
5. 与 LR-Robot 的专家分类体系 + 大语言模型分类 + 下游结构发现有什么差别？这里的“分类体系（taxonomy）”只作为该方向论文名词锚点。
6. 与 TrialMind 的临床证据综合管线有什么差别？
7. 与 WSESE@ICSE 2025 的软件工程大语言模型辅助系统综述困难讨论如何衔接，并把提示敏感性、随机性、透明性转成过程证据与评价义务？
8. 与综述生成 / 自动化文献综述生成的差别是什么？
9. 本文为什么只写类 PRISMA，并禁止写 PRISMA 透明报告框架合规？
10. `sources/` 和 PR #97 是证据来源还是论文主贡献？

## 5. 禁止的新颖性写法

- 禁止写首次自动化系统综述 / 首次智能体式系统综述 / 首次大语言模型系统综述。
- 禁止写已有工作只做人工综述、没有自动化。
- 禁止写已有工作没有多智能体系统综述工作流、人在回路、来源追溯、筛选 / 抽取或证据综合。
- 禁止写 ASReview / RobotReviewer / AgentSLR / LatteReview / EviSearch / LR-Robot / TrialMind 与本文无关。
- 禁止写 PRISMA 透明报告框架合规。
- 禁止把 PR #97 未合入快照当成已合入数据集。
- 禁止把自动综述生成或综述写作作为本文核心贡献。
