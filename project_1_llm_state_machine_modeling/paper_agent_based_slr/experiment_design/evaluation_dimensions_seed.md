# 评价维度种子：S0-v2 审计优先证据工程方法

## 1. 边界

本文件只冻结 PR-S0-v2 阶段的评价维度种子和后续 A5 接口，不冻结指标公式、阈值、统计协议或最终脚本。若某段需要精确公式，应移到 PR-A5。

术语规则沿用 [../story/terminology_policy.md](../story/terminology_policy.md)：同一文档中，关键术语首次出现写作“中文术语（英文术语 / 缩写）”，后续使用中文主称。本文件首次锚定：综述元模型（review meta-model）、维度模式（dimension pattern / extraction schema）、内容证据（field-level content evidence）、候选发现（candidate finding signal）、研究者质疑（researcher challenge）、最终裁决（final adjudication）和过程证据（process evidence / audit trail）。下文除论文名、路径、命令和固定缩写外，均使用中文术语。

S0-v2 后，评价中心从“工作流能否生成证据制品 / 报告”进一步收紧为：**研究者定义的综述元模型、可演化维度模式、内容证据、统计观察、候选发现、研究者质疑 / 最终裁决、以及过程证据是否可审计、可复核、可降级、可评价**。

## 2. 维度种子

| 维度 | PR-S0-v2 定义 | 后续可能证据 | A5 接口 | 证据类型 |
|---|---|---|---|---|
| 综述元模型充分性 | 主题、研究问题、范围和综述元模型是否足以约束后续维度模式与发现启发式。 | 研究者批准记录、范围排除理由、种子论文压力测试。 | A5 冻结综述元模型审计表。 | 过程证据 + 设计审计 |
| 维度模式稳定性 / 演化 | 维度模式是否随新论文、新类别和抽取失败有版本化修订；修订是否有触发原因、影响范围和冻结理由。 | 模式版本、变更触发原因、接受 / 拒绝 / 合并记录。 | A5 冻结模式演化统计与稳定条件。 | 过程证据 |
| 回填完整性 / 成本 | 维度模式变化后是否识别受影响论文并完成或显式豁免回填。 | 受影响论文、是否需要回填、回填状态、回填时间。 | A5 冻结回填完成率与负担统计。 | 过程证据 + 内容证据 |
| 内容证据准确性 | 字段值是否有可定位来源锚点，且来源锚点与字段语义一致。 | 页码、章节、短引文、表格、制品链接、人工核验样本、缺失 / 不确定说明。 | A5 冻结来源锚点准确性、断链率和字段错误分类。 | 内容证据 |
| 缺失 / 不确定性处理 | 缺失字段、不适用字段和证据不足是否被区分，而不是被智能体猜测补齐。 | 缺失原因、不适用、不确定、需要复核标签。 | A5 冻结缺失 / 不确定性审计规则。 | 内容证据 |
| 统计分析正确性 | 频次、分布、交叉表、趋势和覆盖代理是否基于正确字段版本与纳入样本计算。 | 分析协议、字段表版本、统计脚本 / 表格、抽样复核。 | A5 冻结统计正确性检查与版本一致性检查。 | 内容证据 + 分析制品 |
| 候选发现有用性 | 候选发现是否相关、非平凡、可审计，并能引出有效质疑。 | 候选发现台账、发现类型、支持 / 反向证据草案、人工评分。 | A5 冻结相关性、非平凡性和可操作性评分规程。 | 内容证据 + 过程证据 |
| 候选到最终转移质量 | 候选发现是否经过质疑、反向证据、补证、降级、拒绝或未解决裁决。 | 接受 / 降级 / 拒绝 / 未解决比例、质疑日志。 | A5 冻结转移状态机与结果统计。 | 过程证据 + 内容证据 |
| 内容证据 / 过程证据分离 | 领域发现是否只由内容证据支撑，方法发现是否只使用过程证据。 | 主张-证据映射、发现类型标签、证据来源类型。 | A5 冻结跨证据类型误用检查。 | 内容证据 / 过程证据分层 |
| 透明材料完整性 | 是否输出主张-证据映射、排除理由、模式修订记录、审计日志、类 PRISMA 流程与局限。 | 透明材料文件、检查清单、第三方复核。 | A5 冻结透明材料完整性检查清单。 | 混合制品 |
| 研究者质疑负担 | 研究者质疑所需时间、交互轮次、阅读负担、补证请求和裁决成本。 | 时间日志、交互轮次、人工修改、被拒绝建议。 | A5 冻结人机协同成本统计。 | 过程证据 |
| 试运行闭环 / 可行性 | 试运行是否跑通 L0--L7，是否产出所有必要制品并暴露阻塞点。 | 试运行记录、制品完整性、阻塞阶段。 | A5 冻结试运行闭环门；不得评价泛化。 | 过程证据 + 制品审计 |
| 多使用者过程指标 | 多名学生 / 研究者使用时的理解难点、模式分歧、质疑行为和失败模式。 | 匿名化日志、同意 / 脱敏报告、使用者间差异。 | A5 冻结过程数据协议与伦理边界。 | 过程证据 |
| 成本 / 效率 | 调用费用、运行时间、人工审计时间、回填、失败重试和脱敏成本。 | 运行记录、用量、时间日志、脱敏报告。 | A5 冻结成本统计口径；不预设正收益。 | 过程证据 |
| 覆盖代理 | 种子论文恢复、已知条目召回、数据库重叠等覆盖代理。 | 种子集、检索日志、筛选台账。 | A5 冻结覆盖代理计算；不得写完整覆盖。 | 内容 / 检索制品 |


## 2.1 risk-to-metric 评价矩阵

2026-06-28 story 再审查指出：若评价只停留在效率、生成质量或主观满意度，本论文会被既有自动综述、筛选 / 抽取和综述生成工作吞没。后续 A5 必须把近邻威胁和审稿风险转成可测指标。下表只冻结评价方向，不冻结公式、阈值或统计协议。

| 风险 / 威胁 | 必须观察的指标方向 | 可报告制品 | 不能替代的内容 |
|---|---|---|---|
| 字段值无来源或来源不匹配 | 来源锚点准确性、断链率、字段错误分类、缺失 / 不确定标记正确性 | 字段级内容证据表、人工核验样本 | 不能用摘要质量或模型自评替代 |
| 维度模式漂移或平铺化 | 模式修订次数、触发原因分布、影响论文数、回填完成率、回填成本、冻结理由 | 维度模式版本、修订 / 回填日志 | 不能只提交最终字段清单 |
| 统计观察被误写成研究发现 | 统计输入版本一致性、统计脚本 / 表格复核、候选发现是否带支持 / 反向证据 | 统计分析表、候选发现台账 | 不能用频次表直接替代发现裁决 |
| 候选发现无证据或主张过强 | 无支撑 / 过强主张率、反向证据检查率、接受 / 降级 / 拒绝 / 未解决比例 | 候选发现台账、质疑 / 裁决日志 | 不能只看生成文本流畅度 |
| 研究者门控只是末端签字 | 质疑次数、质疑类型、补证次数、质疑拦截错误比例、每个门控耗时 | 人工门控日志、过程证据包 | 不能只报告“人工审核通过” |
| 过程证据与内容证据混用 | 主张-证据类型匹配率、跨证据类型误用数、脱敏 / 访问边界完整性 | 主张-证据映射、过程证据包、脱敏报告 | 不能用学生日志支撑领域发现 |
| 强近邻覆盖自动化环节 | 与 AgentSLR / LatteReview / EviSearch / LR-Robot / TrialMind 等按能力维度对齐后的差异矩阵 | 相关工作矩阵、能力覆盖表 | 不能声称首次或空白 |
| 成本不可控 | token / 时间 / 人工审计 / 回填 / 失败重试 / 脱敏成本 | 运行记录、时间日志、成本表 | 不能只说节省时间 |


### 2.2 A5 优先冻结的核心指标候选

S0 不冻结最终公式和阈值，但为避免 A5 继续停留在指标方向，后续至少应优先冻结以下四个核心指标的正式定义、分母、抽样方式、人工标注协议和分歧处理规则：

| 指标候选 | 草案定义 | A5 必须补充 |
|---|---|---|
| 来源锚点准确性 | 正确定位且语义匹配的字段锚点数 / 抽样核验字段锚点数 | 抽样策略、正确 / 部分正确 / 错误标准、图表和制品链接处理方式 |
| 无支撑 / 过强候选发现率 | 被人工标为无支撑或主张过强的候选发现数 / 候选发现总数 | 标注者、主张强度分级、反向证据检查范围、分歧裁决 |
| 字段级回填完成率 | 已完成或经研究者明确豁免的受影响字段数 / 需要回填的受影响字段数 | 受影响字段定义、豁免是否计入完成、豁免理由、字段级回填成本记录方式 |
| 论文级回填完成率 | 已完成或经研究者明确豁免回填的受影响论文数 / 需要回填的受影响论文数 | 受影响论文定义、豁免是否计入完成、豁免理由、论文级回填成本记录方式 |

这些指标只作为 A5 的优先冻结对象，不表示当前 PR 已完成评价。


## 2.3 PR-A1 种子暴露出的指标义务

PR-A1 的 [A1 种子表](../dataset_selection/a1_seed_papers.md) 暂不冻结公式，但已经暴露出 A5a 必须处理的真实指标压力：

| A1 风险来源 | 对 A5a 的指标义务 | 不能用什么替代 |
|---|---|---|
| 4open / GitHub / Google Drive 等外部制品入口 | 制品入口可达性、断链率、是否已本地冻结、是否有 release / commit / license | 不能只写“有 artifact” |
| 状态机 / SysML / DFSM / Mermaid / Umple / 协议 FSM 多输出谱系 | 输出模型类型分类准确性、混淆矩阵、字段回填触发 | 不能只用“输出为模型”一列概括 |
| 公开数据但代码缺失 | 数据公开性与 pipeline 公开性分离、复现资格等级 | 不能把公开数据集等同于完整复现包 |
| 合成 oracle / repair 样本 | 合成数据外推风险、oracle 依赖、修复主张支撑等级 | 不能把 repair 成功率直接外推到真实需求 |
| 私有工业数据样本 | 受限证据标记、主张降级率、不可复现字段比例 | 不能把主题贴合度当成可复现性 |
| 论文内专家评分 / 表格 / 图 / 外部仓库混合证据 | 来源锚点准确性、锚点类型覆盖、证据定位成本 | 不能用模型自评或摘要质量替代 |

这些义务只说明 A5a 需要冻结什么，不表示当前 A1 已经计算任何指标。

## 3. 领域发现与方法发现的分工

| 发现类型 | 支撑证据 | 可评价内容 | 禁止误用 |
|---|---|---|---|
| 领域发现 | 目标论文内容证据、统计观察、反向证据、研究者裁决 | 字段证据准确性、统计正确性、主张强度、反例处理 | 不能用过程日志或学生交互日志支撑。 |
| 方法发现 | 过程证据、试运行制品、交互日志、成本、脱敏报告 | 可用性、审计性、成本、失败模式、人机协同负担 | 不能当作目标领域文献结论。 |

## 4. PR-S0-v2 不做的事

- 不把上述维度写成已运行结果。
- 不冻结公式、阈值或统计显著性检验。
- 不比较“智能体是否优于人类完成完整系统综述”。
- 不声称质疑闭环必然提高质量。
- 不把统计观察写成最终研究发现。
- 不把过程证据用于领域发现。
- 不声称完整覆盖或 PRISMA 透明报告框架合规。
