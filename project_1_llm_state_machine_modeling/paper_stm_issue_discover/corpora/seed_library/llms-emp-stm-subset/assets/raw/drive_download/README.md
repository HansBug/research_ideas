# Folder contents

There are a total of three contents in the public folder, which are

1. *chatbot* - The python script we wrote to quickly call LLMs api and accept the returned result.
2. *Dataset*  - The dataset we constructed.
3. *Experiment Results* - More detailed experimental and analytical data and graphs.



## Dataset

The file contains only one sheets, which are

1. Dataset - records the dataset we constructed. Model Name is the name of the model, Model Source is the source of the model, Requirements Description is the corresponding requirements description of the model, and PlantUML is the corresponding PlantUML code of the model.



## Experiment Results

Experiment Results records our detailed experimental data and analyses. Among them

1. SysML Grammar & Semantic: We documented the SysML syntax and semantics used in our study, with all content derived from the SysML v1.6 Specification.
2. Visualization: Organize the results of the experiment and present them in a graphical form.
3. Hallucinations Summary: Organize the hallucinations and present them in a graphical form.
4. STM & ACT & SD Results: Record our detailed experience results.
5. Hallucinations: Record detailed hallucinations from the experiment.
