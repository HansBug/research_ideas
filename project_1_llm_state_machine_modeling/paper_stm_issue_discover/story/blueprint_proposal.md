**§3 是承重结构**（原文）：「导师那句『规则一定是从领域分析归纳出来的』——这条论证链是成立的，但它要求领域分析这一节是真的、可复现的。这从『加分项』变成了承重结构：整篇论文的方法合法性挂在它上面。」
- 交付物：一节领域分析 + **一张 19 行映射表**
- 表列：`谓词 | 族(S/B/P) | 归纳自哪类领域来源 | 具体文献/标准锚点 | 在 M=(S,E,V,Tr,A) 上如何实例化 | 该来源类下未实例化的部分`
- 最后一列是 RQ1「表达力边界」的直接输入
- 不做成 SLR；**不要在论文里报「我们调查了 N 篇」**——报锚定关系比报数量有说服力
- 写法四步线性：领域分析 → 归纳谓词语义 → 元模型指导 prompt 设计 → 在 54 案例上应用

**§7 讨论落点**：把 scope gate 作为**方法的组成部分**呈现，而不是实验的免责声明。从「我们排除了打不过的样本」变成「我们提供了一个可先验判定的边界机制，并量化了真实语料落在边界外的比例」。

## ref 翻转率实验（AI 建议，零判定成本）

⚠️ **实验本身没有作废，但标题里「零判定成本」这条立项理由已作废**：【用户明确裁定 2026-08-11】正文不谈人工判定成本，它进正文的理由只能是它回答某个 RQ。现行口径见 [paper_outline.md](./paper_outline.md) §6.6「ref 翻转率实验」，前置实测挂在 `TODO-O6`。

把为 pair X 生成的整套断言，拿去在**同一份 NL 的参考模型**上重新执行。预期：在错误模型上为 False 的断言，应当在参考模型上翻成 True。

| 指标 | 定义 | 说明 |
|---|---|---|
| 翻转率 | False@buggy 中在 ref 上变 True 的比例 | 判别效力 |
| 残留 False | 在 ref 上仍为 False | 要么断言写错，要么参考模型也有该问题 |
| 参考侧误报 | ref 上 False 但 buggy 上 True | 断言方向搞反 |

价值：`EIS-0029-05` 那条改判的理由逐字是「这条在参考模型上同样为 False——一个无法区分合规与不合规制品的断言不构成该缺陷的证据」。人工在 132 个位上发现了 1 例，**这个检查能把它自动化到全部断言上**。

⚠️ 唯一风险：54 个 pair 的参考模型能否都从上游数据表拿到并转换？**需先实测转换成功率。**

## fork/join finding 的四层写法（导师点名要的 finding，零新增实验）

1. **量化边界**：10 份 NL 中 1 份有 11 处并发 + 17 处计时提及，另 8 份 0/0，第 9 份 0 并发 / 3 计时 → 真实语料约 11% 的需求族落在 M 表示能力之外
2. **最有意思的一条**：不排除它会发生什么——`0018` 的 hit@1 = 12/18 = 66.7%，**高于当时全量均值 53.9%**。把超出表示能力的需求族放进来，方法**不会表现差，它会在错的东西上得高分**：可表达的部分照常命中计分，并发义务从未形成、分母里根本没有它们。→ **表达力边界如果不显式声明，评测会系统性高估方法覆盖面，且高估方向与直觉相反。**
3. **机制**：与 wellformedness 那条同源——义务只能从「元模型可表达」与「NL 可绑定」的交集里长出来
4. **设计含义**：这类方法必须显式声明并强制表示能力边界，而不是事后发现
