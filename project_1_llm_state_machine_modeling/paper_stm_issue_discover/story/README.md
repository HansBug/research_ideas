## SANER 十页预算

采用 SANER 2027 Research Track 的 IEEE 双栏 10pt 正文上限：10 页包括题目、摘要、图表、正文和任何内文附录，参考文献另有最多 2 页。模板与政策来源见 [Overleaf 格式依据](../overleaf/GUIDE.md)。下表是英文正文的设计预算；中文大纲长度不能直接换算为最终 PDF 页数。正文安排 9.75 页，预留 0.25 页应对浮动体、标题和换栏。词数是扩写上限，包含题注、表头与表下注释的文字，参考文献不计入。

| 大纲部分 | 总页预算（含图表） | 英文词数上限 | 本节浮动体 | 论证任务 |
| --- | ---: | ---: | --- | --- |
| 题目与摘要 | 0.35 | 180 | 无 | 任务、三个机制、整体及消融发现 |
| §1 引言 | 1.10 | 650 | 无；首次引用图 1 | 问题、差距、C-1/2/3/4 |
| §2 背景与相关工作 | 0.80 | 550 | 无 | L/W 定义及三类工作定位 |
| §3 问题定义与范围 | 0.55 | 350 | 无 | 输入输出、义务、源责任 |
| §4 方法 | 2.30 | 1450 | 图 1：0.40 页 | 三个机制与执行边界 |
| §5 研究设计 | 1.40 | 850 | 表 1：0.22 页 | RQ、样本、干预、评价与指标 |
| §6 结果 | 2.10 | 850 | 表 2：0.32 页；图 2：0.30 页；表 3：0.40 页 | 整体效果及三项干预 |
| §7 讨论 | 0.35 | 230 | 无 | 机制联系及复核意义 |
| §8 有效性威胁 | 0.55 | 400 | 无 | 评价、干预、语义、外部与统计限制 |
| §9 结论 | 0.15 | 110 | 无 | 回应中心主张 |
| §10 数据可得性 | 0.10 | 80 | 无 | 已保存材料与公开状态 |
| **正文合计** | **9.75** | **5700** | **1.64 页已包含在分节预算中** | **另留 0.25 页，不分配新内容** |

方法的 1450 词按总览 180、检查事实 280、中间引导 380、谓词反馈 460、发布与隔离 150 分配。结果的 850 词按 RQ1 280、RQ2 170、RQ3 190、RQ4 210 分配。表中数值不计英文词数，但占用的物理空间已经计入浮动体预算。

写作先按结果及评价边界完成方法和研究设计，再压缩引言与摘要。每个 RQ 保留干预、主要变化、一个解释和适用边界；结果表承载逐模型数字。若排版超页，先外移逐层稳定性表、逐谓词统计、完整 prompt、源 ID 映射及案例展开，再压缩重复结果文字。四个 RQ 的直接答案、A4 标签政策、严格精确率反向结果和分母说明保留在主文。补充材料是研究材料的组织方案，当前不承诺已有可公开的匿名下载包。

## 写作与检查

这是论文架构阶段，使用现有故事、数据和导师意见作为项目上下文，不另建重复的 `project_context.md` 或阶段台账。`academic` 与 ARS 的角色在同一会话中分轮执行，记录为角色审查，不冒称独立模型盲审；正文每次实质修改后重新检查主张、来源与措辞。`shuorenhua` 采用 docs 场景、standard 档和 structural 范围，优先保护数字、术语、条件和观点归属。

[实验依赖表](./experiment_dependent_gates.json) 仅登记尚需新增实验才能写入的主张。其当前 records 为空：主文只使用 A1/E2/A3/A4 的已归档结果及其既有边界；A2 不进入本论文叙事。空表不表示论文已满足匿名制品、人工复核或全文投稿验收。旧实验门可从 Git 历史追溯，冻结协议不改写。R1 的 `check_r1_readiness.py` 固定了旧的 19 谓词及五 RQ 合同，用于历史 R1 复验，不是本版大纲的验收工具。

本版检查包含：主表逐字段对拍、比例及百分点复算、来源与参考文献完整性、正文内部词扫描、页预算与图表清单核对、学术论证与语言两轮审查，以及飞书正文回读。英文全文、双语对应、实际 PDF 页数和匿名制品另由正文阶段的 Overleaf 检查验收。
