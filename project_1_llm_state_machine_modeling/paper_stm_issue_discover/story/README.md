## SANER 十页预算

采用 SANER 2027 Research Track 的 IEEE 双栏 10pt 正文上限：10 页包括题目、摘要、图表、正文和任何内文附录，参考文献另有最多 2 页。模板与政策来源见 [Overleaf 格式依据](../overleaf/GUIDE.md)。下表是英文正文的设计预算；中文论文长度不能直接换算为最终 PDF 页数。正文安排 9.75 页，预留 0.25 页应对浮动体、标题和换栏。词数是英文改写上限，包含题注、表头与表下注释的文字，参考文献不计入。

| 论文部分 | 总页预算（含图表） | 英文词数上限 | 本节图表 |
| --- | ---: | ---: | --- |
| 题目与摘要 | 0.35 | 180 | 无 |
| §1 引言 | 0.95 | 550 | 首次引用 Figure 1 |
| §2 背景与相关工作 | 0.85 | 500 | 无 |
| §3 问题定义与范围 | 0.80 | 500 | FCSTM 定义与语义 |

新增语料表和评价流程图后，预算向研究设计移动，英文词数上限从 5700 收缩至 5060。2026-09-11 第二、三轮批注要求每个 RQ 分表分图、主结果补覆盖与精确率柱状图、语料补分布图、方法节补谓词表，中文稿据此保留九图八表。版面占用已用 IEEEtran 双栏模板实测（过程与数字见 [图表说明](./figure_table_specs.md)）：当前图表约占 5 页多，十页版面只剩约 4000 个英文单词、约 6800 个汉字的正文容量，而当前中文正文为 10454 个汉字，排成英文约 13 页。英文排版阶段需要缩小图幅、删并表格或压缩正文约三分之一，取舍前先与用户确认。上表的词数列是实测前的设计值，以实测为准；该表不代表当前中文稿已通过模板页数验收。压缩时保留五个 RQ 的直接结果、A4 标签政策、严格精确率反向结果和分母；逐层稳定性、完整 prompt、注册身份和展开案例通过来源材料追溯。公开输入/人工参考数据集与匿名审稿包分别描述。

## 写作与检查

这是完整中文稿审阅阶段，使用现有故事、数据和导师意见作为项目上下文，不另建重复的 `project_context.md` 或阶段台账。`academic` 与 ARS 的角色在同一会话中分轮执行；paper-writing 的独立审稿交由未撰写正文的另一代理执行。两者分别记录，不冒称第三方人工或独立模型家族盲审；正文每次实质修改后重新检查主张、来源与措辞。`shuorenhua` 采用 docs 场景、standard 档和 structural 范围，优先保护数字、术语、条件和观点归属。

[实验依赖表](./experiment_dependent_gates.json) 仅登记尚需新增实验才能写入的主张。其当前 records 为空：主文只使用 A1/E2/A3/A4 的已归档结果及其既有边界；A2 不进入本论文叙事。空表不表示论文已满足匿名制品、人工复核或全文投稿验收。旧实验门可从 Git 历史追溯，冻结协议不改写。R1 的 `check_r1_readiness.py` 固定了旧的 19 谓词及另一套五 RQ 合同，用于历史 R1 复验，不是本版大纲的验收工具。

本版检查包含：主表逐字段对拍、比例及百分点复算、来源与参考文献完整性、正文内部词扫描、页预算与图表清单核对、学术论证与语言两轮审查，以及飞书正文回读。英文全文、双语对应、实际 PDF 页数和匿名制品另由正文阶段的 Overleaf 检查验收。
