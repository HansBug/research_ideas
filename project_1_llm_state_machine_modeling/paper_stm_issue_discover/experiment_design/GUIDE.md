# 设计材料使用说明

本目录的文件用于保存历史设计理由和后续研究候选，不是当前实验协议。当前事实应分别回到 [最终归档](../final_results/v60_current_vs_x1v2_baseline/README.md)、[method/](../method/README.md)、[judge/](../judge/README.md)、[evaluation/](../evaluation/README.md) 和 [discover_matrix/docs/protocol/](../discover_matrix/docs/protocol/)。

不要从 `next_round.md` 启动 provider、修改冻结结果或推断已经完成的实验。若未来确有新实验，其设计、事前登记、执行和评测必须在独立任务中重新授权；本目录的历史记录不替代这些步骤。
