## 1. ⛔ 先把利益冲突摊开

⭐ **已知的目标偏好**：用户希望基线的数字更低（逐字：「能拉到 `hit@1` 下 50 那就绝对安全了」）。⛔ **本登记的作者知道这个偏好。**

⚠️ **一个必须写下来的算术事实**（⛔ **它不是判据**）：X1 当前 443 位命中。若其可断言率为 $p$，则

$$\mathrm{assertable\text{-}hit@1}_{X1} = 443p/588$$

⛔ 该值低于 50% 当且仅当 $p < 66.4\%$。

⭐⭐ **把这个数写出来，正是为了让「判据不由它决定」这件事可被检验。** ⛔ §4 的成立条件**不含**任何绝对阈值，只含**两臂之差**——⚠️ 若日后发现判据被改成挂绝对值，那就是舞弊的痕迹。

## 3. ⛔ 双报纪律（不可协商）

1. ⛔ **`hit@1` / `hit@3` / `hit@all` 的原值必须原样保留并置于同一张表内**，⛔ 不得只报新口径、⛔ 不得把新口径写成「修正后的 hit」。
2. ⭐ 新口径的名字必须**自带限定**：`assertable-hit@k`，⛔ 不得简称为 `hit@k`。
3. ⭐ 报告里必须写明：**基线在原口径上更高**（$-14.9$pp），⛔ 这一句不得被新口径的段落挤掉或弱化。
4. ⛔ 不得声称新口径「更正确」——⭐ 只能说它**度量的是另一件事**（可被下游机械消费的发现），且那件事是论文的承重主张。

## 4. ⭐⭐ 成立条件（⛔ 在看到任何结果之前写死）

记 $p_{X1}$ 与 $p_{main}$ 为两臂命中位中可断言的比例。

| 条件 | 判定 |
| :-- | :-- |
| $p_{main} - p_{X1} > 10$pp | ⭐ **论证成立**：两臂输出形态在可机械消费性上确有实质差异，`assertable-hit@k` 是正当的补充口径 |
| $\lvert p_{main} - p_{X1}\rvert \le 10$pp | ⛔ **论证不成立**。⚠️ 必须如实写「两臂的可断言率无实质差异」，⛔ **放弃这条论证线**，⛔ 不得报 `assertable-hit@k` |
| $p_{X1} - p_{main} > 10$pp | ⛔ **论证反向成立**：基线的产出比主臂更可断言。⚠️ 这对方法是**额外的坏消息**，⭐ 必须照报 |

⭐ **10pp 这个阈值的由来**（⛔ 不是为了让结论成立而挑的）：它约等于本仓库已用的可归因阈值 2.0pp 的 5 倍。⚠️ 之所以取得比那个宽得多，是因为本判定的**组间抖动尚未测量**，而三条要件里「可判定」一条含语义判断。⛔ 取宽是对自己不利的方向。

⚠️ **并且**：$p_{main}$ 由**抽样**得到（120/355），故须给出其抽样误差；⛔ 若 $10$pp 落在误差区间内，按「不成立」处理。

## 5. ⭐ 必须同时报告的三件事

1. **逐要件拆分**：`locatable` / `decidable` / `single_direction` 各自的失败率。⚠️ 若差异**只**来自「可判定」这一条（最含语义判断的一条），⛔ 论证的强度要相应下调。
2. **判定组的反对意见**：五个判定组都被明确要求回答「你是否觉得这条判据本身有问题、是否对基线不公平」。⛔ 任何一组提出实质性反对，都必须原文列入报告，⛔ 不得只摘对我方有利的部分。
3. **文献支撑的诚实评级**：另一路在查「评判对散文宽松、对形式化严格」的文献佐证。⛔ 若结论是「只能类比、无直接证据」，报告必须照此写，⛔ 不得把类比证据写成直接证据。

## 6. ⛔ 本口径**不能**用来说的话

1. ⛔ 不得说「所以我们的方法覆盖率更高」——⭐ 覆盖率上基线更高，那个数不变。
2. ⛔ 不得说「基线没有发现这些问题」——⭐ 它发现了，⚠️ 只是其中一部分不能被机械消费。
3. ⛔ 不得说「统计显著」——本语料 8 个独立 NL 簇 < 门槛 10。
4. ⛔ 不得把可断言率的差异归因于**模型能力**——⭐ 它是**输出形态**造成的，而形态是我们指定的（主臂被要求产出断言，基线被要求自由报告）。⚠️ 这一点尤其重要：**这恰恰说明差异来自方法设计，⛔ 而不是说明基线的模型更差。**
