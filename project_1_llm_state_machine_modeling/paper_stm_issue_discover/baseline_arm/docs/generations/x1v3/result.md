## 3. ⛔ 两项越界的解剖

### 3.1 claude 侧的沉默**一格都没有回来**

| 对比 | claude 侧零格 | Fisher 精确检验（双侧） |
| :-- | :-- | :-- |
| v1 vs v2 | $0/162$ vs $8/162$ | $p = 0.0072$ |
| **v1 vs v3** | $0/162$ vs $9/162$ | ⛔ $p = 0.0035$ |
| **v2 vs v3** | $8/162$ vs $9/162$ | ⭐ $p = 1.0000$ |

gpt 侧作为对照：v1 vs v3 为 $9/162$ vs $8/162$（$p = 1.0000$），v2 vs v3 为 $14/162$ vs $8/162$（$p = 0.2693$）——⭐ **gpt 侧的沉默回到了 v1 水平，⛔ claude 侧没有**。

⚠️ 检验把格当作独立单位，⛔ 而同一 pair 的六格显然不独立，⛔ 所以 $p$ 值只作参考量级，⛔ 不作推断依据。

### 3.2 ⭐ 沉默仍然是真的「读完认为没问题」

抽查四格（`run1/0055-claude`、`run2/0015-claude`、`run2/0045-claude`、`run3/0025-claude`）：⭐ 四格全部 `status = ok`、`attempts = 1`、`issues = []`，且 `analysis` 字段是逐条核对的中文正文（形如「逐条核对每个状态迁移后，没有发现明显的不符合项。所有状态（DoorShut、DoorOpen、…）及其触发事件均已建模」）。⛔ 没有一格是空响应、截断或解析失败。⭐ 与 v2 的抽查结论一致。

### 3.3 ⭐⭐ 新加的 `Field(description=...)` **不是**一条死通道

⛔ 「加回去没效果」有一个廉价的逃生解释：**也许模型根本没读到它**。⭐ 这条解释被 gpt 侧直接证伪——同一处改动把 gpt 侧总产出从 $490$ 推到 $561$（$+14.5\%$），⛔ 大到越出了事前区间。⭐ **所以新增的字段说明确实被读取并改变了行为**；⛔ claude 侧的沉默不回来，是「读到了但不因此开口」，⛔ 不是「没读到」。

⚠️ 两侧的方向相反，值得单列：

| 侧 | v1 → v2 | v2 → v3 | v1 → v3 |
| :-- | :-- | :-- | :-- |
| claude 每格均值 | $5.586 \to 5.426$ | $5.426 \to \mathbf{5.278}$ | ⭐ 单调**下降** $-5.5\%$ |
| gpt 每格均值 | $2.840 \to 3.025$ | $3.025 \to \mathbf{3.463}$ | ⭐ 单调**上升** $+22.0\%$ |

### 3.4 ⭐ 沉默格仍高度集中在**台账几乎没有条目**的 pair 上

v3 的 17 个零格分布在 7 个 pair 上，其 `REPORTABLE` 条目数为：`0003` 0 条、`0017` 0 条、`0052` 0 条、`0015` 1 条、`0045` 1 条、`0055` 1 条、`0025` 2 条。⭐ 七个里有三个在台账上**一条期望缺陷都没有**——⛔ 在这些 pair 上「未发现不符」并不是失败。

## 5. ⛔ 判定

### 5.1 按事前登记的判定表

| v3 的零产出格 | 是否命中该行 |

**⇒ 判定表第二行触发。** ⛔ gpt 侧总数 $561 \notin [414, 506]$ 独立地再次触发同一后果。

### 5.2 ⭐ 明确回答：沉默来自「去掉臂身份」，⛔ 不来自「丢失对象说明」

三条直接证据：

1. ⭐ 把对象级说明加回后，claude 侧沉默 $8 \to 9$（$p = 1.0000$），⛔ **没有任何回补**；⛔ 而它与 v1 的 $0$ 之间仍显著（$p = 0.0035$）。
2. ⭐ 新增的字段说明**不是死通道**——它把 gpt 侧产出推高 $14.5\%$ 直至越界（§3.3）。⛔ 故「没读到」这一逃生解释不成立。
3. ⭐ 沉默格是真的读完后判定「无不符」（§3.2），⛔ 不是产出退化。

⚠️ **一条必须写下的削弱**：v3 恢复对象说明用的是**另一条通道**——被删的是顶层 `description`（中文、总括式「一条不符之处」），加回的是**字段级** `description`（英文、中性）。⛔ 所以严格地说，本次证伪的是「**在字段级补一句中性对象说明能让 claude 恢复开口**」，⛔ 而不是「任何形式的对象说明都不能」。⭐ 事前登记的判定表已把这一映射写死为「去掉臂身份」，⛔ 本报告按它裁定，⛔ 但同时把这条削弱如实登记，⛔ 不假装它不存在。

### 5.3 ⛔ 后果

1. ⛔ **v1 的 588 位判定不再自动有效，必须重判。**
2. ⛔ **talk 中所有基于 X1 的数字**（$443/588 = 75.3\%$、$\Delta = -14.9$pp、$\mathrm{hit@3} = 81.6\%$、$\mathrm{hit@all} = 67.3\%$、逐位分解的 269 / 86 / 174 / 59、四池分布）**一律标为待复核**。
3. ⭐ **头条结论的符号大概率不变**：沉默格能解释的 $\mathrm{hit@1}$ 变动至多 $-1.19$pp，⛔ 与 $\Delta = -14.9$pp 不在同一量级。⛔ 但「大概率」不是「已核实」——⛔ 且这个上界**不覆盖** gpt 侧新增的 101 条 issue，⛔ 在重判完成前不得把它写成结论。
4. ⛔⛔ **v3 自己也不是一条「产出体量与 v1 可比」的基线**：gpt 侧总数越界。⭐ 它在**信息内容**上是三版里最干净的（模型知道被要求产出什么、⛔ 不知道自己是对照实验的基线臂），⛔ 但它在**产出体量**上与 v1 不可比。⚠️ **因此「重判对象取 v2 还是 v3」是一个必须单独裁定的问题**，⛔ 本报告不擅自裁定，⭐ 登记为待裁定项并给出两侧理由：
   - 取 **v3**：信息内容最干净，⛔ 但需接受 gpt 侧体量偏高、⛔ 且多报口径要重新校准。
   - 取 **v2**：与 v2 报告已做的机械上界分析衔接，⛔ 但它同时缺失对象说明，⛔ 即拿一个「被要求做什么都没说清」的臂当基线。
5. ⚠️ **不需要第四版来处理「反向过冲」**：判定表第三行（$< 9$）未触发。⛔ 但若后续决定继续追这条线，⚠️ 唯一还没被分离的通道是**顶层 vs 字段级**的位置差异（§5.2），⛔ 而那属于新的问题范围。
