# 多报侧两臂并排：X1 朴素基线 vs 主臂 v46

> **一句话结论**：⛔ **主臂在精度上没有可主张的优势。** 逐条 issue 看 X1 明显更准（被台账认领 59.6% vs **31.4%**）；换成「去重后每命中位要读多少条不同的错」这个单位，主臂只在**过度规定**一项上领先（0.189 vs **0.316** 去重/位），而这点领先被它自己独有的 0.085 去重/位**表示债务**吃掉一大半，且是以 **212 倍 token 成本**换来的。⭐ 用户提的粗口径「命中效率」（**0.325** vs 0.329）⛔ **不成立**——它对「这条 issue 对不对」在数学上完全不敏感。

⚠️ 本文件的每个数字都可复算。X1 侧真源是 [X1-J*.jsonl](./)，派生表由 [rebuild_unexpected_x1.py](../../analysis/rebuild_unexpected_x1.py) 机器生成；主臂侧真源是 [../../../discover_matrix/v46/unexpected_verdicts/](../../../discover_matrix/v46/unexpected_verdicts/)，⛔ **本轮一位未动**。

## 〇、⛔ 先说三条决定一切的口径差

### 0.1 ⭐⭐ 两臂读的不是同一份制品（已登记为不对称 #7）

| 臂 | 模型输入的制品 | 核验 |
| :-- | :-- | :-- |
| 主臂 v46 | `model.fcstm`（R4.5 **有损编译**产物） | run record 的 `input_hashes.stm_text = 3f56e942…` 与 `selected_seed_examples/*/model.fcstm` 的 sha256 逐字符相同 |
| **X1** | `plantuml.puml` | ⭐ 与作者源 `stm0.puml` **逐字节相同**（四个 pair 抽样 `diff` 全等） |

**这一条直接决定了多报侧的类结构**：`REPRESENTATION_DEBT`（表示债务）的定义是「事实在**编译产物**上为真、而作者在 `stm0.puml` 里已逐字表达」。⛔ X1 从未见过编译产物，**结构性不可能**报出一条编译损失。故 X1 该类恒为 0，而主臂该类是**其多报侧最大的一块**（134 条目 / 46.5%）。

⛔ **不得把这个 0 读成「X1 更干净」**，也⛔ **不得读成「主臂多犯了一类错」**——它是两臂输入不同的必然推论。本文件凡涉及该类，一律双向标注。

### 0.2 判「事实成不成立」的基准随输入走

X1 侧一律以**作者源 `stm0.puml`** 为事实基准；主臂侧以 `model.fcstm` 为基准。⛔ 拿编译产物去判 X1 的事实真假，等于拿它没看过的东西问罪。

### 0.3 「认领」与「命中」是两件事，⛔ 本轮只动前者

- **命中判定（588 位）**：要求 issue 的**命题**与台账命题对应。⛔ **两臂各自的 588 位一位未动**（主臂 355、X1 449）。
- **认领判定（本轮统一重做）**：只问 issue 是否**指向**同一处台账记录，不问它说得对不对。

⭐ 于是存在一类 issue：**已认领但不构成命中**——瞄准了一条已记录的缺陷却说错了。它既不是命中证据，也不是多报，⛔ 不进桶。这正是主臂机械匹配器的行为。

### 1.1 ⛔ 原 544 条带口径噪声

### 1.2 ⭐ 选定：**宽口径**。判据是「与主臂机械匹配器最接近」

主臂的 `round_variance.py::_match` 判「这条 issue 有没有被台账认领」时——

> `"""Best ledger entry for one issue... Element overlap decides; the predicate only breaks ties."""`

——**只看元素重合**（与台账记录断言点名的元素重合 ≥2 个；谓词只做 tie-break），**对命题内容完全盲、对方向完全盲**。严口径（必须复述台账命题）恰恰是 `_match` **不做**的那件事。

⛔ **选它与哪个数字好看无关。** 事实上它把 X1 的未认领数从 762 压到 552，即让 X1 的多报侧**变小、看起来更好**——若目标是让主臂好看，应当选严口径。

### 1.3 操作判据（六组统一执行）

1. issue 三段文本点名的元素中，≥2 个出现在某条台账记录的断言点名元素里（忽略大小写与下划线）→ 认领。
2. 或 `where` 指向的作者源行就是某条台账记录所讲的那一行 / 那一批相邻编辑 → 认领。
3. 或只有 1 个元素重合，但那个元素是该台账记录的**核心对象** → 认领。
4. 反向：当前已认领但连一条判据都不满足 → 改判未认领。

## 四、⭐⭐ 判据问题：主臂在精度上有优势吗？

### 4.1 ⛔ 先否掉粗口径「命中效率」

用户提的 0.321 vs 0.329 是 `命中位 / 已发布 issue`。它的代数身份是：

$$\text{命中效率} = \frac{\mathrm{hit@1} \times 588}{\text{issue 数}}$$

- 主臂：$0.604 \times 588 / 1094 = 0.325$（⚠️ 初稿 0.321，⛔ 分母未合并 `matrix-v46r`）
- X1：$0.764 \times 588 / 1365 = 0.329$

⛔ **它不是精度度量**，因为它**从不问一条 issue 对不对**：一个臂发 1000 条正确但重复的 issue 覆盖全部 588 位，与另一个臂发 105 条正确 + 1000 条错误覆盖同样 588 位，**得分完全相同**。

⭐ 两臂近似相等是**两个相反效应刚好抵消**——X1 覆盖高 16.0pp，issue 量也高 **24.8%**——⛔ **不是精度相等**。同一批数据换成真正的精度度量（被认领比例）立刻分开：**31.4% vs 59.6%**。

### 4.2 五个单位，逐个给数（⛔ 不挑有利的那个）

命中位：主臂 355，X1 **443**（⛔ 初稿用了**复核前的 449**；⭐ 复核组 R1 改判后是 443，⚠️ 本节下表全部分母已按 443 更正——⛔ 该 bug 的方向是**压低主臂的领先**）。

| 度量 | 主臂 | X1 | 谁更好 |
| :-- | --: | --: | :-- |
| **被台账认领的 issue 比例** | **31.4%** | **59.6%** | ⭐ X1（**+28.2pp**） |
| 未认领 issue / 命中位 | **2.11** | **1.25** | ⭐ X1（少 41%） |
| 多报**条目** / 命中位 | 0.811 | **0.479** | ⭐ X1（少 41%） |
| 多报**去重** / 命中位 | **0.349** | **0.424** | ⭐ 主臂（**少 18%**） |
| ❌ 假阳性去重 / 命中位 | 0.056 | **0.052** | ⚖️ **打平**（差 0.004） |
| 📄 无 NL 依据去重 / 命中位 | **0.189** | **0.316** | ⭐ 主臂（**少 40%**） |
| ⚙️ 表示债务去重 / 命中位 | 0.085 | **0.000** | ⭐ X1（结构性，见 §0.1） |

### 4.3 ⭐ 读法

**(a) 「事实说错」这一项，两臂无差别。** 假阳性去重/位 0.056 vs **0.052**，绝对量 20 vs 23 处根因。⛔ 主臂的谓词体系、结构门、契约门、归因层**没有**在「不说假话」上买到可测量的优势。⚠️ 这是本次比较里最该被记住的一条。

**(b) 主臂唯一真实的领先是「过度规定」，量级 40%。** 0.189 vs 0.316 去重/位。⭐ 机制上讲得通：主臂的需求拆分把 NL 段落转成正向原子命题，谓词词表是闭合的，越界的索求会被结构门与评审轮打回；X1 一句「找出不符之处」没有任何约束，于是把 NL 没规定的形态、命名、枚举封闭性统统当成义务。

**(c) 但这点领先不是净的。** 主臂另背着 X1 结构性不可能有的 0.085 去重/位表示债务。两项相抵后，总多报去重/位 0.349 vs **0.424**——主臂只领先 **18%**。⭐ 再剔除真漏记则只剩 **13%**（0.344 vs 0.395，见 [metrics.md](../metrics.md) §11.3）。⭐ 而它是用 **11 倍调用 / 302 倍 input token / 212 倍总 token** 换来的。

**(d) 换个单位结论就翻，⛔ 必须同时给。** 若读者的成本是「要读多少条」，X1 明显更省（1.25 vs 2.11 条/位）；若成本是「要裁定多少件不同的事」，主臂略省（0.349 vs 0.424 件/位）。⭐ 差别来自条目/去重比：主臂 2.32、X1 1.13。**主臂把同一件事说了 2.3 遍，X1 几乎不重复。**

**(e) 一个对主臂有利的反事实，⛔ 标明它不可实现。** 若把主臂的表示债务整块剔掉（等价于假设主臂也读作者源），主臂剩 154 条目 / 94 去重，去重/位降到 **0.265**，对 X1 的 0.424 领先 **38%**。⛔ 这个数**不能当作主臂的成绩**：表示债务不是可以一删了之的记账项，若主臂真读作者源，其需求拆分、谓词绑定与门的行为都会改变，分布不可能只是「少了这一块」。⭐ 它只说明**输入差异对结论的杠杆有多大**。

### 4.4 ⛔ 结论

> **「主臂精度更高」这个说法，在本语料上没有得到支持。**
>
> - 逐条 issue 层面 X1 **明显更准**（被认领 59.6% vs **31.4%**），⛔ 方向与「主臂更准」相反。
> - 「说假话」层面两臂**打平**（假阳性去重/位 0.056 vs **0.052**）。
> - 主臂唯一可主张的是**过度规定更少**（0.189 vs **0.316** 去重/位，少 **40%**）；⛔ 但计入它自己独有的表示债务后，总多报去重/位只领先 **18%**，且成本是 212 倍。
> - X1 的**真漏记多于主臂**（13 处 vs 2 处；只按 `V1` 一档也是 3 vs 2）。

⚠️ **可归因性**：登记 §5.1 的噪声底 2.0pp 是 `hit@1` 的代次内极差，⛔ **不适用于多报侧的这些比率**——本节任何一个差都没有对应的噪声底估计。⛔ 故一律只作**描述性**陈述，⛔ 不得写「显著」。

⚠️ **与 §9 不对称清单的关系**：本节结论的方向与 `hit@1` 的 $\Delta = -16.0$pp **同向**（都不利于主臂）。⛔ 故 §9.1 那些「压低 Δ、对我方不利」的不对称若被校正，本节的结论只会**更不利于主臂**，⛔ 不会反转。
