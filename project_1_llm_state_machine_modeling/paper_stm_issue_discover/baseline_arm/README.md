# X1v2 baseline 历史材料

本目录保留 X1v2 早期设计、prompt、旧 Judge 判定和过程性分析。它有助于解释 baseline 的形成，但不提供当前 baseline headline、当前 Judge 口径或可直接运行的实验入口。

当前唯一有效的 baseline 比较在 [v60/current 与 X1v2 baseline 最终归档](../final_results/v60_current_vs_x1v2_baseline/README.md) 中完成：同一 54 pair、3 round、145 expected issue 和 issue #195 two-stage Semantic Judge 下，X1v2 的 overall FULL 为 211/435 = 48.51%。该归档也保存 X1v2 的 162 个 method record、冻结 Judge composite、成本审计和 512 条 finding 的 W 回溯审计。

本目录中的旧 prompt、评测网格和历史百分比使用不同 Judge、输入边界或指标定义。它们只能作为 historical/provenance 材料阅读，不能与 v60/current 结果相减、合并或用于当前论文 headline。X1v2 不等于 method 迭代代次；它是当前比较臂，历史版本关系见 [实验历史索引](../archive/experiment_history/README.md)。
