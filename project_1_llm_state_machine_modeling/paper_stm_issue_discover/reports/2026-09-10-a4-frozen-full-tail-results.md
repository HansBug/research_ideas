# A4：隐藏谓词运行结果后的最终报告选择

本报告按[事前协议](../discover_matrix/docs/generations/a4_20260910/preregistered.md)解释冻结 Full 条件下的末端实验。逐模型完整指标只在所有最终报告分类闭合后列入；未裁定项目不是零发现，也不进入已完成模型的分母。

## 1. 实验估计的是冻结候选条件下的末端变化

A4 检验执行证据在最终报告选择中的作用。Full 已经生成的自然语言需求、状态机、静态检查、契约、候选顺序、来源定位、路由、绑定和执行计划保持不变。实验把每个候选的谓词运行结果统一替换为 unknown，清空执行轨迹、反例和运行理由，再调用原来的最终报告判定 LLM。随后运行原有确定性校验、发布与折叠。契约提取、候选生成和谓词执行均不重跑。

最终报告判定在实现中称为内部 D 阶段。D 阶段回答一个候选是否应当发布为缺陷；外部 Luna judge 则评价已经发布的报告，两者不是同一次判断。A4 保留独立语义拒绝，因此 unknown 不意味着自动发布。它也保留源状态机和静态检查事实，因此隐藏执行结果并不意味着模型失去所有确定性信息。

本次比较以每模型 54 个 pair、3 个 round 为单位，共 162 格。Sonnet、Qwen、Muse 的 Full 来源为 E2 的 ours；Luna 来源为 canonical v61，0045/r1 沿用已登记的 fill0045 替代。两边均使用全部三轮。这个设计估计给定 Full 上游候选时的末端变化，不能替代重新生成候选的端到端移除实验。

## 2. 报告标签按固定优先级核算

令 \(R_{p,r}\) 表示 pair \(p\)、round \(r\) 最终发布的唯一报告集合。折叠前的候选不是报告分母。每个最终报告只走下面一条路径：

1. 报告实际发布了原 true 候选的同一缺陷主张，按用户指定的 oracle 政策直接计 I。若一份报告折叠了多个 true 候选，也只计一个 I。
2. 否则，若报告与该格 Full 报告的实质内容等价，复用原 K/N/I、外部 D 和台账关系。
3. 其余报告才送交原 Luna judge，保持 prompt、schema、双读、仲裁、关系判定与失败恢复规则。

内容等价要求稳定候选身份、源定位与引用、需求、性质与违例方向、expected/observed 和实质子主张集合一致。单纯 reason/basis 改写、内部 D 解释变化、运行 ID 或证据等级变化不强制重判；新增或删除实质子主张不能冒充措辞变化。失去对应输出的 Full 报告退出 A4 分母，零报告格仍计为完成格。

这里的 true→I 是评价政策。谓词 true 有时只证明精确边存在等较窄性质，未必独立裁定候选的完整自然语言主张。因此，oracle-I 数量不能直接解释成已经由完备真值证明的现实误报数。原 false 也不自动记为有效，原 unknown 不自动记为 I。

## 3. 指标以最终报告和台账单元为分母

K 表示与台账有 FULL 或 PARTIAL 关系的有效报告；N 表示有效但无上述台账关系的报告；I 表示无效报告。记 \(V=K+N\)、\(R=K+N+I\)：

\[
P=\frac{V}{R},\qquad P_{\mathrm{strict}}=
\frac{\#\{q:q\in K\cup N,\ D_{\mathrm{external}}(q)\in\{D1,D2\}\}}{R}.
\]

普通 precision 沿用原 relation-first 核算；strict precision 要求有效报告同时具备外部 D1/D2 裁定。两者使用同一个报告分母，不能用内部 method D 替代外部 D。零报告集合的 precision 未定义，不填 0。

三轮 pooled precision 是先合并 K/N/I 再相除，逐轮 precision 均值则是 \((P_1+P_2+P_3)/3\)，二者分开报告。每格无效报告负担为 \(I/162\)，有效报告产出为 \(V\)。这些量一起判断 precision 变化来自无效报告增加还是有效输出变化。

对台账条目 \(e\) 和 round \(r\)，令 \(h_{e,r}=1\) 当且仅当至少一条最终 K 报告与它 FULL 匹配。主 hit 为 \(\sum_{e,r}h_{e,r}/435\)，其中 \(435=145\times3\)。三轮至少一次命中与三轮全部命中的分母均为 145。PARTIAL 只增加 support，不计 hit；多条报告命中同一条目同一轮只计一次。

配对比较保留同一 pair 的三轮。结果给出每个 pair 的两边计数及比率，不把各条报告当作独立样本，也不对单次末端重放给出统计显著性结论。

precision 的量级解释采用固定次序的算术分解：先把 Full 有效产出 \(V_0\) 换成 A4 的 \(V_1\)，保持 \(I_0\)；再把 \(I_0\) 换成 \(I_1\)。两项分别为

\[
\Delta P_V=\frac{V_1}{V_1+I_0}-\frac{V_0}{V_0+I_0},\qquad
\Delta P_I=\frac{V_1}{V_1+I_1}-\frac{V_1}{V_1+I_0}.
\]

两项相加等于实际 precision 差值。这个分解依赖替换次序，只解释计数如何形成比率，不是两个独立机制的因果效应估计。

Luna 的普通 precision 下降 4.03 个百分点，由无效报告增加 43 条和有效报告减少 10 条共同形成。按后文先替换有效产出、再替换无效产出的固定次序，二者算术贡献分别为 -0.18 和 -3.85 个百分点。内容等价映射保留 532 K、190 N、130 I；29 K、8 N、14 I 失去等价对应，另有 17 K、10 N、57 I 属于新增或实质内容变化。这里的失去对应不必然是完全消失，也可能是主张发生变化，因此不能把两侧增减直接解释成根因数量。

Muse 的普通 precision 仅下降 0.72 个百分点；无效报告净增 7 条，有效报告净减 4 条。其内容等价映射保留 517 K、214 N、115 I；27 K、15 N、22 I 失去等价对应，新增或实质变化部分为 15 K、23 N、29 I。旧 I 的减少抵消了部分新增 I，故净变化小于 19 条 oracle-I。固定次序的有效/无效产出算术贡献为 -0.07/-0.65 个百分点，不能把两项分别称为独立因果效应。

两款均没有把原 true 候选一律发布。Luna 的 326 个 true probe 中，321 个 D0 拒绝，5 个参与发布；247 个 true nonprobe 中，184 个 D0 拒绝、4 个 D_UNRESOLVED 未发布、59 个参与发布。共 64 个原 true 候选最终贡献 50 份唯一 oracle-I 报告。Muse 的 93 个 true probe 中，92 个 D0 拒绝、1 个折叠发布；88 个 true nonprobe 中，65 个 D0 拒绝、23 个参与发布。其 24 个 true 候选贡献 19 份 oracle-I 报告。候选到报告不是一一对应，同率外推忽略了语义拒绝与折叠，不能作为实测预期下界。

Luna 共复用 852 份 Full 裁定、直接核销 50 份 oracle-I，仅 34 份进入新增 judge；Muse 对应为 846、19、48。判定报告数不等于调用次数：本次保存的新增 judge 成功格阶段回执分别为 108、127，观测到的 provider model_call_id 分别为 127、156。回执覆盖双读、仲裁和关系闭包，provider 调用还包括纠错等，不以两者之差直接推算重试次数。


Sonnet 的普通 precision 下降 4.01 个百分点，有效报告减少 18 条，无效报告增加 36 条。固定次序的有效/无效产出贡献为 -0.28/-3.73 个百分点。内容等价映射保留 435 K、151 N、74 I；101 K、32 N、30 I 失去等价对应，新增或实质变化部分为 90 K、25 N、66 I。39 份 oracle-I、660 份 Full 复用和 142 份新增 judge 恰好覆盖 841 份最终报告。其普通 precision 下降与 Luna 接近，但内容变化和新增裁定的规模更大，不能把两者解释成完全相同的决策过程。

Qwen 的 162 格 method tail 均已完成并保留 985 份报告，分流为 22 份 oracle-I、882 份 Full 复用、81 份 residual。其中 77 份 residual 已裁定，0003/r1、0042/r2、0043/r3 三格的 4 份报告未闭合。失败节点连续六轮仍同时输出核心主张 REFUTED 与 D1/D2，原校验拒绝，已有反馈逐轮记录在输入审计中。这不是将 unknown 自动判为 I 的理由。因 residual 裁定尚未闭合，本报告不提供其完整 K/N/I、precision 或 hit，也不将未裁定条目排除后计算一个“完整”分数。三模型的结果不能替代四模型 A4 的完整验收。

## 5. 个案解释必须区分语义拒绝和降级

Sonnet 0000/r1 的 `i15` 是 HumanDrivingMode 声明探针。原结果为 true；隐藏执行结果后，保留的精确绑定仍显示该状态存在，内部判定 `grounding=not_established`、D0。该候选不在 unresolved 列表中，是语义拒绝的例子。

Sonnet 0000/r2 的 `i2` 主张根复合状态缺少无条件默认入口。A4 利用保留的条件入口静态诊断建立主张，同时保留事件触发启动的替代解释，判为 D1。最终 `issue:2` 还折叠 `i4/i6/i10` 三个 unknown 候选，只计一条 oracle-I。原 S2 true 证明精确入口边存在，并没有独立裁定更宽的无条件入口问题；该例说明指定政策下的计数路径，不能证明完整缺陷主张已被执行结果证伪。

Sonnet 0000/r1 的 `i0` 原有缺边反例，Full 发布后外部标为 K。A4 移除反例后，“NL 中 it 指整个系统”的反驳解释存活，内部改为 D0，报告不再发布；该例也不在 unresolved 列表中。反例移除与重新采样的解释同时发生，单个例子不能把变化全部归因于反例。

同格 `i2` 的主张内容保持等价，内部解释和 D2/D1 选择发生变化，外部 Full K/D1 与原台账关系仍复用。这说明标签复用不代表模型内部判断没有变化。相对地，0009/r3 的 `i1` 在定向修订后仍 unresolved，D0 来自既有 fallback；报告将这类未发布单列，不能统称为模型独立排除了候选。

### 补充：Luna 与 Muse 的源案例

Muse `0014/r1/i3` 和 `i10` 两个原 S2 true 候选都要求 InMotion 无条件进入 Accelerating，observed 指出初始边携带 `Entry_Accelerate`，保留的检查事实为 `INITIAL_ENTRY_CONDITIONAL`。A4 两者均判 D2，以 `exact-typed-defect-key.v1` 去重为一个 `issue:3`，只计一个 oracle-I。这里是相同 typed identity 去重，不是因果后果折叠；原 true 也只证明精确初始边存在。源 SHA-256 为 `68e2abc393b3801a83e6d3b1691a9d4e8b58db817344ff1cd60010ea97a7d699`。扫描 Muse 全部 162 格未找到“原 false、旧有效主报告、A4 不发布”的对应案例，不为叙述完整而补例。

来源与执行身份由 manifest、源文件 SHA-256、masked-input hash 和实现文件 hash 固定。末端 cache 还绑定提示词、schema、参数和命名空间，只复用该 A4 命名空间内成功的调用。失败尝试保留原件，恢复时不重跑已成功的上游或尾阶段。

外部 judge 按同一 pair/round 合批，原上限为 8 条，并保留输出规模分批规则。每个 batch 两次独立有效性判断，随后按原规则处理仲裁和关系判定；只在原有失败恢复要求下拆批。最新 judge 合计 worker 上限为 8，method 为 16；曾同时启动三个 8-worker 池的执行偏差见[协议记录](../discover_matrix/docs/generations/a4_20260910/preregistered.md)，不把历史并发写成始终合计 8。不能跨不同源状态机拼批以改变原 judge 输入语义。

大体量提示词、原始响应、SSE 和逐调用运行记录仅保留于本地 runs。仓库交付来源 hash、适量派生审计、可复算脚本与报告，不宣称 fresh clone 含全量原始调用。重新审阅逐调用文本须另行取得本地原件；由保存的裁定重算指标不需要再次调用 LLM。

本报告涉及四模型同一末端干预；完整指标仅列出裁定已闭合的模型。Qwen 的统计缺口保留，不以三模型结果宣称四模型验收完成。本实验也不能代替独立的 A3。
