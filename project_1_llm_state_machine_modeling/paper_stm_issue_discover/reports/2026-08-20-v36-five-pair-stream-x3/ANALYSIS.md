末端 D1+D2 产物的 FP 口径为方法 `55/102`、precision `46.08%`，X1v2 `42/56`、precision `25.00%`。方法的绝对 FP 高于 baseline 的主要原因是它发布了更多 D1+D2 issue；按 precision 看方法更好，但仍未达到可直接发布的低噪声状态。

典型语义缺口是性质粒度而非形式执行失败。`0023` 的方法多次发现 PumpState/WaterState/MethaneState 之间某一条具体迁移缺失，但台账要求的是相应状态进入后没有任何出边的非预期终止；judge 因“缺一条边”不能替代“整体无出路”而判未命中。`0053` 也出现同样的单条 PumpState→WaterState 缺边与 wrapper 整体互不可达/无出边台账之间的粒度错位。`0004` 的 false positive 主要是把根入口、动作记法或未指定的结构建议升级为台账中的自指/死锁问题。`0046` 的 false positive 主要是把 Searching 持续动作或额外跨区域流程当成台账缺陷，说明方法仍需加强“冻结 NL 义务是否真的支持该 issue”的 D 过滤。`0029` 同时存在守卫分支重叠、跨层完成路线和稳定终止等不同性质，方法有时把条件分支或目标定义问题错误合并为另一条台账性质。

成本边界：本子集方法 `$0.63995292`、baseline `$0.02260044`、比值 `28.316x`，超过 25x 诊断 gate；该比值不用于宣称全量成本通过。后续优化优先删除重复 grounding/revision、提高缓存命中和减少“单条缺边”候选，再做全量运行；不能通过放宽 D0 或把 W1 冒充 W2 来换取 hit。
