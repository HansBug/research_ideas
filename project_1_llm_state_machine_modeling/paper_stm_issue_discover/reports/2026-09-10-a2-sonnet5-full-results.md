## 消融和可比性边界

A2 删除谓词字段与词汇引导、谓词候选路由和参数绑定、执行专属探针、计划编译、backend 执行、执行回执及 true 回执过滤。保留完整输入与检查事实、需求义务提取和补全、语义 grounding、普通模型引用、部分领域不变量/缺边/guard 候选规则、语义评估及发布归并。因此它是当前实现中谓词相关机制的消融，不能写成删除全部上游引导，也不等于 raw_inspect_direct。

Sonnet A2 使用合并前源码，E2 参照为历史冻结运行；本轮完成后合并带入了 E1/E2 的 transport、输出预算和独立轮次支持，未重跑已有 Sonnet。运行版本、provider 日期、超时和恢复策略的差异必须保留，不宣称严格单因素因果识别。不能由此推断全部语义结构化机制没有作用。

## 为什么没有出现预期的 Precision 下降

以下逐格核对 E2 Sonnet full 的冻结 method 原件与本轮 A2 原件，来源 hash 全部一致；两臂对应 162 格的 `input_hashes` 也全部相同。审计脚本与完整条目保存在本地 run 根的 `mechanism_audit.py` / `mechanism_audit.json`。这些是观察到的执行与发布事实，不把未发布候选反事实地判为外部 judge 的 I。

### 过滤确实发生，但不是 358 条已证实的幻觉

Full 的 2,252 条执行回执中，475 为 violation、358 为 pass、1,419 为 unsupported。后者包含 1,115 条未绑定谓词的候选与 304 条绑定谓词但不受支持的候选，不能全部称为 backend 执行失败。普通语义评估本来就承接了大量不能由谓词独立判定的内容。

358 条 pass 分布在 117 个 pair-round。逐条核对原始 `receipt.terminal_state=completed`、`verdict=true`、`satisfied_obligation_ids`，并确认这些 obligation ID 不在 finding、D 决策或 evidence records 中。即：它们在 D 评估前被过滤，不是“先形成最终 report，然后撤回”。这证明执行结果影响了候选的去向。

但其中 **225 条来自执行专属探针**，只剩 **133 条来自其他已路由候选**。Full 共生成 236 条执行探针，225 条通过；A2 同时删除探针生成和执行过滤，不会把这 225 条原封不动交给 LLM 发布。另 133 条也没有“关闭过滤后会发布且被 judge 判 I”的反事实证据，因此不能把 358 或 133 写成消除的幻觉数量。

A2 生成的候选总数减少 460 条，撤掉 358 条 pass 过滤后，进入 D 的数量仍比 full 少 102 条。与此同时，义务、模型事实、普通 grounding 和语义评估继续保留。两臂各有 665 条 D0/D_UNRESOLVED，这是汇总量相同，不是同一批候选逐项互换。逐条确认两臂方法 D0 的 `issue_emitted` 均为 false。最终 A2 少发布 36 条报告，其中有效报告少 23 条、I 少 13 条，普通 precision 因而略升。

因此，本实验测到的是“去掉当前谓词配套生成与执行机制后的整体净变化”，不能从中单独识别 backend 的拦截收益。它也不支持“上游保留了约束，所以谓词必然无用”的结论；那仍需单独识别。

### 真实例子：通过谓词未必足以证伪整条候选

在 full 的 `0019/r1/i5` 中，候选标题是 “Required entry to InitialState is not the unconditional default for AutonomousMode”。其 reason 指向“没有无条件初始边”，observed 明确说已有匹配边但 `conditional=True`。然而编译结果为 S2 `transition_exists`，形式化语义只是“指定源与目标之间存在迁移”。Backend 找到该迁移后返回 true，该候选随后进入 satisfied 集合，被过滤。

这里“有迁移”不逻辑蕴含“有无条件迁移”。所以这份回执不足以证明原候选的完整语义主张错误，不能把这次过滤列为已确认的幻觉消除。它是否对应真实缺陷，还需要基于原始需求和作者模型独立判读；本轮没有给未发布候选补造 judge 标签。

该例的完整 candidate、plan、receipt 可由 E2 原件路径 `raw/sonnet/ours/r1-first/d055d8e8857f4fad901b367754cd863f/method/0019/round-1.json` 复核，也收录在本地 `mechanism_audit.json`。这不是要在冻结实验中按 case 修规则，而是提示一个一般边界：用于否定候选的谓词，其检查语义必须覆盖被否定的主张。

### 对当前结论的约束

现在可以说“谓词执行对 358 条候选实施了确定性的通过过滤”，不能说“因此消除了 358 条幻觉”或“已证明其提高普通 precision”。Full/A2 的 precision 点估计都高于 baseline，与保留机制仍有作用的解释一致，但本轮不能据此把收益拆给特定模块。

已授权的 Qwen/Muse A2 将检验同一机制在其他 backbone 上的净变化。若后续要单独证明执行过滤降低幻觉，应固定同一上游候选池，再比较有无回执/过滤的下游发布，并审查候选主张与谓词语义是否对应；这属于另一个须事先登记的实验，不能把当前结果改名后当作该证据。本轮未改方法来追求指定效果。
