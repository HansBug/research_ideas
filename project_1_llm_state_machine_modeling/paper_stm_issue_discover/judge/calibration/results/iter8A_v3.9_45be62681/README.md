## A 与 B 的取舍

采纳条件（[../../preregistered.md](../../preregistered.md)）：两侧 P1 差在 ±3 pp 内（B 各高 1.0 pp，满足）；K→K 差 ≤ 2 行（current B 少 3 行，**不满足**）；全量加权不低于 A 超过 2 pp（current 低 2.2、baseline 低 3.4，**不满足**）。B 臂多出的 K 损失集中在 FALSE_POSITIVE：current B 把 34 条 gold NADC 与 7 条 gold D2 判成 FP（A 为 19 与 4），8 条 gold K 因 FP 丢失（A 为 4）——没有派生制品作旁证时，judge 更容易把复合报告的框架陈述当成假事实。**按登记规则采纳 A 臂（全闭包）作为后续基础**；B 臂的类别级仲裁触发在第七轮离线核对里对类别无影响（176 条两读同类的仲裁只改 2 条），单独保留为效率选项。
