# CONTINGENCY_L1.md — L1 轨（技术版图与对照系）五问的梯次配置方案

> **这份文件是什么**：L1 轨的五个必答问题（伞 PR [#179](https://github.com/HansBug/research_ideas/pull/179) §4.5 Q1–Q5），每一问都可能调研回来是好结果、中结果或坏结果。本文件在**调研开跑之前**把每一档长什么样、怎么确认落在这一档、落在这一档之后 story 与 contribution 各要怎么改、以及该档下的禁语，全部预先写死。
>
> **为什么要预先写**：档位是在看到结果**之后**才知道落在哪一档的，但「这一档该怎么办」若也等到看见结果之后再定，就无法区分「按预案处置」与「按结果调措辞」。⛔ 本文件的全部价值来自它写在结果之前，与代码同批 push（口径同根 [CLAUDE.md](../../../CLAUDE.md) §3.5.1「开跑实验前必须先 push」的事前登记纪律）。
>
> ⛔ **本文件不是 GUIDE。** L1 的执行规则（编制、分片、可接受结论形态、不可接受清单）唯一真源是 PR #179 §4，本文件不重述、不覆盖、不改写它，只对「回来之后」预置处置。另写一份 GUIDE 等于建第二真源（#179 §4.4 明令）。
>
> ⛔ **本文件不预设结论。** 每一档都标了先验概率（高 / 中 / 低），那只是排产用的粗估，⛔ **不构成任何一档已经成立的判断**，⛔ 也不授权提前按某一档改 story。改 story 的唯一触发条件是该档的「判据」栏被实际满足。
>
> **配套件**：L2 轨的同类方案在 `CONTINGENCY_L2.md`（另一路在写，本文件不涉及其内容）。L1 的实际产出物落点见 #179 §4.4：`related_work/landscape/`。

## 0.1 五档共用的约定

### 0.1.1 边界门在梯次里怎么用

建模对象是 $M = (S, E, V, Tr, A)$，⛔ 无时钟 $C$、无不变式 $Inv$、无正交区并发（#179 §4.0.2）。这条门约束的是**出处与对照**，因此在本文件里落成三条可执行判据：

1. **界内**：所引段落讲的对象是 FSM / HSM / EFSM 或其上的性质、迁移、事件消费、层次结构。→ 可作对照，可作出处。
2. **界外**：时间自动机（UPPAAL 系全部）、混成自动机、Petri 网、进程代数、正交区并发语义。→ ⛔ 既不作对照也不作出处。
3. **邻域**（本文件新增的一个**待裁定**类别）：对象既非 $M$ 也非上述界外形式主义，而是**另一种制品**——RTL / SVA、源代码、需求文本。它们的**方法形状**可能与本文高度相似（受限词表、形式化反馈回路），但制品不同。⚠️ #179 §4.0.2 字面只区分界内 / 界外，未处置邻域。

⚠️ **邻域涉及两件互不相干的待裁定事，⛔ 不要合成一件**：

| # | 待裁定的是什么 | ⛔ 未裁定时的默认值（**定死，不留悬空**） | 谁裁 |
| :-- | :-- | :-- | :-- |
| **N-1** | 邻域工作可否作为 **Related Work 的定位段**（Q4-B） | 邻域**只在 `paper_story.md` §14 风险表出现一行**，用于应对「这不就是把 SVA 那套搬到状态机上吗」这一质询；⛔ 不进 §10 的对照表、⛔ 不作出处、⛔ 不作 `60.4%` 的参照 | L1 层 3 可按默认值交付；若要突破默认值，写入交给 R1 的待决清单 |
| **N-2** | 邻域的**数值**可否作为 `60.4%` 的**量级背景事实**（Q3-B） | 按现行 §4.0.2 **默认拒绝**；⛔ 但 L1 **不自裁**——必须把「§4.0.2 的边界门是否应当区分『规范性出处 / 对照』与『非规范性量级背景』」写成一条**对 #179 §4.0.2 的修订提案**上报伞 PR，理由与形态见 §3 的「⛔ 关于把邻域数字当量级背景：这是一条修订提案，不是 L1 的裁定」 | 伞 PR / R1；⛔ 不由 L1 裁定 |

⚠️⚠️ **N-3 的来历与它为什么必须有默认值**：⭐ 本条原先**不存在** —— §0.1.1 只给了 Q3-B（N-2）与 Q4-B（N-1）的邻域默认值，⛔ **Q2 的邻域计数是空的**。⚠️ 而 L1 层 1′ 实测撞上了它：**$k_{\text{界内}} = 0$（+1 待裁定），$k_{\text{邻域}} = 2$**（MCeT MODELS 2025 · Requirements Satisfiability with In-Context Learning RE 2024）。⛔⛔ **两条路径落的都是 B 档交付形态，但对 contribution 的后果差一整档**：

- 若邻域**不计入** → $k_{\text{界内}} = 0$ → 按 §2 B 档判据「$k = 0$ → 看两段式是否存在」，⭐ 而两段式**确实存在** → 常规 B 档。
- 若邻域**计入** → $k = 2$ → 落 **B 档专设子情况**（$1 \le k \le 2$）：⭐ 交付形态按 B 档、⛔ **对 contribution 的后果按 A 档执行** —— C-① 上限压到「与既有工作不同」，C-③ 的差异化须从「有没有证据链」改成「证据链的**锚点**与**可求值性**不同」。

⭐ **选「不并入」作默认值的理由**（⛔ 不是因为它对我方有利）：⚠️ §4.0.2 的边界门是**按对象**划的，而 $k$ 是**档位判据**；⭐ 把不同对象的篇数并进同一个计数，等于让边界门在计数处失效。⛔ 但**代价必须付**：那几篇邻域工作在**任务形状上**与本文逐项对应，⚠️ 所以它们不进计数**不等于**不进对照 —— ⭐ 故默认值同时要求「逐篇进对照表 + 形状逐项对应者进 §14」。

⚠️⚠️ **一条必须写下来的事实**：⭐ **MCeT 的存在本身已经使「直接判 NL ↔ 已有行为模型、逐条锚回需求条目、输出 issue 列表」这个形状被人做过了。** ⛔ 它与我们的差别落在**制品类型**上（UML 序列图 vs 状态机），⛔ **不落在任务形状上**。⚠️ 无论 N-3 怎么裁，这句话都成立，⛔ 且它不因「不并入计数」而消失。

⚠️ **为什么要写死默认值**：#179 §11 的 L→R1 关口只查三件事（§4.2 的 8 条、层 4 三路 challenge 完成且反驳有处置、两轨都交了 §4.3 的 story 建议），**⛔ 不检查悬空的待裁定项**；#179 §6 的三项导师议题里也没有邻域。也就是说，一个没有默认值的「待裁定」会**带着交付通过全部关口**，而缺的那一栏正是本文件 §8 第 1 条担心的「在成品上看不出来」的那一栏。写死默认值之后，最差情况也是 §14 里有一行，⛔ 不是没有人看守。

⚠️ **同一篇论文可以部分可用**（#179 §4.0.2）：判据是「我们引的那一段」，不是整篇归属。所以每一档的行动里凡涉及界外系文献，都必须落到具体章节。

### 0.1.3 story 锚点的稳定性声明

本文件对 [paper_story.md](../story/paper_story.md) 的每一处定位都写成 **§号 + 逐字片段**（#179 §9 第 4 条，⛔ 不用行号）。锚点取自 S1 冻结时刻的 `paper_story.md`；若 S1 之后 §号发生位移，以**逐字片段**为准重新定位，⛔ 不得因为 §号对不上就跳过该处修改。

### 0.1.4 档位判定的互斥性与同真取档规则

⚠️ 各档的「情况」栏必须能对任一真实结果给出**恰好一个**归属。为此定死三条：

1. **区间一律半开、不重叠。** 凡以篇数或类目数分档的地方，A / B / C 的计数区间**不得共享端点**；写的时候把端点归给更强的那一档，另一档从下一个整数开始（例如 Q1：A 是「≥5 类」，B 是「恰 4 类」，⛔ 不写「4–5 类」）。
2. **非计数条件同真时，取「对 contribution 后果更重」的那一档。** 计数之外还有资格条件（如 Q1-A 额外要求含类目 ⑤、Q2 的 A 与 B 可能在同一份语料上同时为真）时，按后果取档：**降 contribution 强度更多的那一档为准**，⛔ 不许挑对我方更有利的那一档。⚠️ **但另一档的「该档下的行动」不因此豁免**——取档只决定 story / contribution 的写法，交付物该做的对照表照做。
3. **落档理由必须写下来。** `landscape/SUMMARY.md` 的结论一节必须逐问写一行「本问落 X 档，因为判据栏的第 N 条被满足 / 未被满足」，⛔ 不许只给结论不给判据。

### 0.1.5 检索留痕：空类、空格与「读过正文」的证明格式（全档通用）

⛔ **留痕义务不随档位变化。** 以下三条对 A / B / C / D 一律生效，⛔ 不得因为落在好档就豁免——否则「A 档里的那个 0」会成为全份交付里唯一没人查过的格子（这正是 #179 §4.2 #8 要防的事）。

1. **任何一个「0 篇」或「不足 3 篇」的类目 / 形状，都必须附可复现检索过程**（§4.2 #3 的四要件：关键词簇、检索入口、时间窗、命中数与逐条筛除理由）。⛔ 这条**不再是 C 档专属**。
2. **检索过程的交付格式定死为本文件 §7.2 的表格式**：`| 编号 | 查询串（英文逐字原样） | 检索引擎 / 入口 | 日期 | 返回前 N 条的标题 | 观察 |`。⛔ 「我们检索了 requirements-model consistency 相关关键词」这类概述**不算检索过程**；⛔ 查询串必须是能被别人复制粘贴重跑的那一串。

### 0.1.6 近年下限：2022+ 的计数门槛

⚠️ **起点池 74% 落在 2018 年以前**（#179 §4.0.1），而「近年这一块最弱」恰恰是本文立论的前提。若各档的判据只数篇数不看年份，**最省力的走法就是用 1999–2015 年的老论文凑出一个漂亮的 A 档版图**——那与本轮要回答的问题正好相反。因此定死：

### 0.1.7 ⛔ 空白区只能进 Related Work，不能进 Motivation

#### ⛔ 本问的两条前置纪律（先看这两条，再看档位）

**① 「什么算检查侧工作」与「它具备我们的哪几项」必须分开，⛔ 不得合并成一套判据。**

⚠️ 本轮硬化前，A 档的计数判据里含「能不能逐条回放」一问，而**可重放**正是我方主张的组成部分——它是 §4 `TODO-S2` 候选收窄三元组「**需求侧锚定 + 可机械求值 + 可重放**」的第三项，也是 §7 C-③ 第一段链接（「不信就自己再跑一遍」）的核心。把它写进「什么算同类工作」的定义里，后果是：**任何不可重放的 NL↔模型检查工作都不计入检查侧**，于是被推去 C 档的空集，再由 §4 的 gap 表宣布 gap 成立。⛔ **这是循环论证**——审稿人一句「你们把没有你们那条性质的工作定义成了不是同类工作」就击穿，且这一击同时打掉 §4 的 gap 与 C-③ 的差异化。

因此定死两层：

- **第一层 · 是不是检查侧工作（决定篇数）**，判据只两问，**任务同形即算**：① 输入里有没有一份**别人给的**模型（不是它自己生成的）？② 输出锚不锚在**需求条目**上（不是只锚在性质公式或整模型的一个布尔上）？**两问全「是」即计入检查侧篇数。**
- **第二层 · 它具备我们的哪几项（决定差异化怎么写）**，⛔ **只进对照表的列，不进计数**：义务提取是人工还是自动 / 判据锚定的粒度 / **可否重放** / 覆盖缺口怎么处理。

⭐ 由此，「**LLM 端到端判 NL↔模型、逐条给需求锚点、但不可重放**」这种形态——2024–2026 年最可能存在、也最威胁 C-①/C-③ 的那一种——**必定计入检查侧篇数 $k$**，⛔ 不再被静默扫进 C 档的空集。⚠️ **归属按 $k$ 分流，⛔ 不是一律落 A**：⭐ $k \ge 3$ → A 档；⭐ $1 \le k \le 2$ → **B 档的专设子情况**（见 §2 的 B 档）；$k = 0$ → 看两段式是否存在。⚠️ ⛔ **本句原写「明确落 A 档」，而 A 档要求 $k \ge 3$ —— 两处在 $k \le 2$ 时直接矛盾，2026-08-12 更正**（⭐ 补法与 Q1 / Q4 / Q5 同形）。

**② A 与 B 同时为真时取 A 档**（§0.1.4 第 2 条）。语料里同时存在 ≥3 篇第一层意义上的检查侧工作**和**一条两段式路线，是完全可能的；此时按「后果更重」取 A 档写 story，⛔ 但 B 档「该档下的行动」里的两段式对照表**照做不误**。

#### ⛔ 关于把邻域数字当量级背景：这是一条修订提案，不是 L1 的裁定

⚠️ §0.1.1 的 N-2。**现行 §0.1.1 把「邻域不作 `60.4%` 的参照」写成了一条既定规则，那其实是 L1 在自裁——只不过裁向了更严的一侧。** 本轮硬化把它改回它本来的身份：**一条待上报的修订提案**。

**提案要说的是**：#179 §4.0.2 的理由原文是「**拿界外对象的文献给界内谓词挂出处，本身就不成立**」——它成立，**是因为出处是一条规范性义务**（时间自动机里「必须给每个 location 配 invariant」是关于另一种数学对象的规范，它证明不了我们的 $M$ 上有同样的义务）。⚠️ 但**量级背景事实不主张任何规范性**：它只是「这个任务族历史上报过什么量级的数」，而 B 档**本来就允许三重不可比**（对象、执行者、缺陷集来源）。那么问题就是：**为什么第四种不可比（形式主义不同）必须绝对禁止，而前三种可以逐条写明后放行？** ⚠️ 这条默认拒绝还恰好排掉 §7 的 L-5 / L-6——**邻域（SVA 断言生成、代码侧不变量合成）正是这类数字最可能存在的地方**。

**若提案被采纳，准入条件（三条缺一不可）**：① **四条**不可比性逐条写明（对象、执行者、缺陷集来源、**形式主义**）；② 只出现在 **Discussion**，⛔ 不进 Results / Intro / Abstract / 对比表；③ 出处与对照**仍沿用严格边界门**——⛔ 提案只放宽「量级背景事实」这一种用法，⛔ 不放宽出处、不放宽 Related Work 的对照表。

⛔ **在提案被采纳之前，仍按现行 §4.0.2 执行（默认拒绝）**；但 L1 必须把提案本身与上述理由写进 `landscape/SUMMARY.md` 的结论一节并上报伞 PR，⛔ **不得像原先那样静默自裁**——静默自裁的问题不在于严，而在于它把一个该由伞 PR 回答的问题在交付物里做成了既成事实，而没有任何关口会发现这件事。

#### ⭐ C 档下「空集式交付」长什么样

一份 1–2 页的**参照系检索报告**（落点 `landscape/SUMMARY.md` 的一节，⛔ 不单开文件），含五块：

#### ⭐ 为什么 C 档不是失败

1. **它是一个可复现的否定结果。** §9 第 2 条现在是一句自陈（「本文只报绝对量」）；C 档把它变成有检索证据支撑的陈述。审稿人问「你们查过没有」时，前者答不上来，后者有一张矩阵。
2. ⭐⭐ **它产出「为什么必须自建对照」的唯一答案。** ⚠️ **本条已于 2026-08-12 改写**：原文说「它把导师议题从工程偏好变成被证据逼出来的必要动作」，而那个议题（是否跑）**已经裁定了**——X1 现在就跑。⭐ 但同一份矩阵现在承担一个**更硬的用途**：⛔ 审稿人会问「你们为什么不和已有工作比，而要自己造基线」，⚠️ 而自建对照最脆的地方正是「标准由自己定」。⭐ 「**在本轮覆盖的 venue 族与年份窗内未见同时满足四条门的工作**」就是那个答案——⛔ 没有它，X1 的数字会被读成自己出题自己打分。⚠️ **这句话的形状是被规定死的**：⛔ 不得写成「我们查遍了近年 CCF A/B/C 与 arXiv 也没有可比对象」——「查遍了」正是 §0.1.2 禁语第一行禁止的那种穷尽性断言（#179 §4.2 #8）。⚠️ 本文件是**事前登记文本，它示范的措辞会被执行者照搬**，所以连举例都必须用合法句式。
3. **空集式本来就是三种可接受形态之一**（#179 §4.2 #3）。⛔ 把它读成「这一档就没办法了」是对合同的误读：不可接受的是「未找到但检索过程不可复现」（§4.2 #5），不是「未找到」。

## 8. 判断：最可能崩的一问

⭐ **Q4（断言 / 契约 / 可执行规约）**，理由三条，按分量排序：

1. **它的失败模式是「界内空、界外满」，而这一种最难处理。** Q3 若空，交付形态是清楚的（空集式报告，见 §3），且空集本身对导师议题有正面价值。Q4 不同：外检索大概率**会找到大量形状极像的工作**（受限词表 + 形式化反馈回路 + LLM），⛔ 但它们的对象是 RTL / 源代码，按 #179 §4.0.2 落在门外。于是执行者面临一个**两难**——写进去违反边界门，不写则 §14 会缺一行本该有的审稿风险（「这不就是把那套搬到状态机上吗」）。⛔ 两难本身在成品上看不出来：交出来的东西可能干干净净，缺的那一栏没人会注意。§4-B 档的「分两栏」+ §0.1.1 的 **N-1 默认值**（未裁定时邻域必在 §14 写一行）就是为这个准备的——⚠️ 原先只写「升级为待裁定项」是不够的，#179 §11 的 L→R1 关口**不检查悬空的待裁定项**，一个没有默认值的待裁定会带着交付通过全部关口。

2. **起点池对它的贡献恰好为零，而其余四问都有起点池托底。** 复核见 §7：`baselines/` 0 / 91、`sources/` 0 / 787、`state_machine_types/` 8 / 679 里界内可用上限 **≤ 5** 且全是 contract automata，Dwyer 一系全仓 0 个目录。⛔ 这意味着 Q4 的全部篇数都要靠 §4.1 层 1′ 的定向补近年产出，而层 1′ 是**并行三到五路里最慢的一环**（要下 PDF、提正文、做 bibtex）。在周三一天的窗口里，Q4 是唯一一个**没有免费捞的部分**的问题。

3. **它单独承载 contribution ② 的对照面，而 C-② 的根基同时压在 L2 上。** 若 Q4 落 C 档、L2 的 `predicate_provenance.md` 又挂不满，C-② 会同时**缺对照**与**缺根基**。⚠️ 这个组合的危险在于两轨各自看都只是「这一项弱一点」，合起来才是「这条 contribution 站不住」——⛔ 而两轨是并行的，谁都不会看见对方的弱项。§4-C 档因此明写了「⛔ 两轨的结论不得互相传染」与「必须在 R1 如实报告这个组合」。

**次高风险是 Q2**，但它的失败模式温和得多：Q2 最可能落 B 档（找到功能等价的两段式路线），后果是 §4 `TODO-S2` 的收窄措辞必须重写一栏——那是一次**可预期、可局部完成**的改写，⛔ 不威胁任何一条 contribution 的形状。

⛔ **Q3 不是最可能崩的一问**，尽管它最可能落在最差档：因为 Q3 的最差档**事前已经被定义成一种可接受的交付形态**（#179 §4.2 #3 + §2.5 Fallback「L1 参照系问题到 T+6h 无果 → 立即按空集式交付」）。⭐ 一个已经准备好接住的失败，不是风险；没人准备接的那个才是。
