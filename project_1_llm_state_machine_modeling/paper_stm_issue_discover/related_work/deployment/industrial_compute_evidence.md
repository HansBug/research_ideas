# 工业单位算力基础设施：可引证据

> 本文件核验的目标命题（【导师原话】档的产业判断）：**工业单位（尤其中国的型号研制单位 / 设计所 / 制造业企业）没有专业的算力基础设施，因此没有条件部署大规模开源模型。**

⚠️ **本轮是第二轮攻关。** 第一轮结论记在 [hardware_availability.md](./hardware_availability.md) §5，为「查无严谨来源」。本轮按委托方指定的五个新角度重攻：① 「训推一体机」品类本身作为证据 ② 制造业 / 军工信息化投入的官方统计 ③ 涉密 / 隔离网建设规范里对算力的成文约束 ④ 学术文献里的工业算力约束实证 ⑤ 中文文献（第一轮零覆盖）。本文件服务 [SUMMARY.md](./SUMMARY.md) §17.5 第 2 条。

**证据级别口径（沿用本目录既有约定）**：**M** = 核验员亲自打开官方 / 原文页面并逐字读到；**S** = 仅从检索摘要或第三方转述读到，原文未打开或打不开；**I** = 推断，不是任何来源说的。

**核验日期**：2026-08-13（本文件全部条目）。

## 0. 一句话结论

**这句话本轮仍然不能坐实，而且本轮找到了指向其后半句的反证。**

命题有两个半句，必须分开裁定。

**前半句「没有专业的算力基础设施」——可引强度：仅间接，且存在一处比第一轮更隐蔽的对象错配。** 现有最强的官方支撑是工信部 **工信厅通信〔2026〕14 号**逐字承认「算力获取…难点」（**M**），配信通院「数字化前期投入以自筹为主」（**M**）与电子标准院「79% 的中小企业处于数字化转型初步探索阶段」（**M**）。但这三条的口径全部是**中小企业**，而**型号研制单位 / 设计所多为大型央企院所，恰恰不在「中小企业」这个分母里**。⛔ 拿中小企业口径去说型号研制单位，与第一轮拿全国存量说单位级是同一类错误的变体——只是从「分析单位太大」换成了「分析对象换了一类」。本轮**没有找到任何一条针对院所 / 设计所 / 军工单位算力存量的可引来源**。

**后半句「因此没有条件部署大规模开源模型」——本轮找到反证，该判断在技术可行性层面不成立。** 官方与厂商材料一致宣称**单机即可部署 671B**：浪潮信息官方新闻页给出 NF5868G8「高达 1536GB 显存容量」并可「在 FP16/BF16 精度下单机部署 DeepSeek 671B 模型」（**M**）；华为 FusionCube A3000 训/推超融合一体机 DS 版 Ultra 档用「2 个华为 Atlas 800I A2」适配 671B（**S**）；新华三官方新闻页称其一体机「覆盖 14B 至 671B 规模」、纯享旗舰版为 671B「单机推理」（**M**，见 §1.4）。而这类一体机**正是工信部 14 号文点名推荐给中小企业的算力形态**。因此「没有条件部署大规模开源模型」只可能作为**采购预算判断**成立，而预算那一层**依然无任何可引来源**——第一轮的结论在这一点上没有变化。

**可以对外说的最强版本（不超出证据）**：官方规范性文件已认定「算力获取」是中小企业的难点，并把「训推一体机」「整合本地闲置、分散算力」写进任务；工业场景的落地形态因此是**单机 / 单柜级的专用设施**，而不是可弹性伸缩的集群。⛔ **不能说**「因此装不下大模型」，⛔ 也**不能说**「型号研制单位普遍只有单卡」——两句都没有来源。

## 1. 「训推一体机」品类作为证据（典型规格 + 官方推荐）

### 1.2 委托方的假设与实测结果不符（关键）

委托方的设想是：「一个『一体机』品类存在且被官方推荐，本身就说明目标客户的算力形态是『一台机器』而不是『一个集群』。」

**前半段成立，后半段的推论方向反了。** 实测结果是：**「一台机器」在 2025—2026 年已经足以跑 671B**。所以「一体机」这个品类只能证明**采购单位是整机而非集群**，⛔ 它**不能**证明「跑不了大模型」。

### 1.4 一条独立的、方向对我方有利的发现：官方产品页不公布显存

**M**：华为官方 [Atlas 800I A2 产品页](https://e.huawei.com/cn/products/computing/ascend/atlas-800i-a2)的「技术规格」表逐字含「4U AI服务器」、「4 * 鲲鹏920」、「32个DDR4内存插槽，最高3200 MT/s」、「可选NPU全互联机型，整机互联带宽392GB/s」、「8 * 200GE QSFP接口直出，RoCE协议」、「4个热插拔2.6kW电源模块，支持2+2冗余」，⛔ **但通篇不含 NPU 型号、单卡显存、整机显存与算力数值**，只在概述里泛称「采用8模组高效推理方式」。

**M**：新华三[官方新闻页](https://www.h3c.com/cn/d_202502/2356580_30008_0.htm)给出款型划分（「包含纯享版和使能版两大系列，共计六大款型12款产品」、「覆盖14B至671B规模的DeepSeek大模型」）与并发指标（纯享旗舰版 671B「真实并发数＞32@15 Tokens/s」、纯享经济版 32B「＞16@10 Tokens/s」、纯享标准版「该款可选支持70B模型预装」，两条并发数均限定「在较好体验的上下文长度场景下」），⛔ **同样不给机箱、卡数与显存**。

⭐ **这条本身可以写进论文**：**国产一体机的官方材料普遍以「能跑哪个模型 + 并发 / token/s」为售卖口径，而不公布显存与卡数。** 它的含义是：即使拿到了官方来源，也**无法从官方材料反推某单位买到的具体算力形态**——这是「单位级算力画像不可得」的一条**结构性原因**，而不只是我们检索不力。

### 1.5 本节裁定

- ✅ 「一体机」品类存在且被官方文件点名推荐 —— **成立（M）**。
- ✅ 工业场景的算力形态是「整机 / 整柜」而非「弹性集群」 —— **成立（M + S 组合）**。
- ⛔ 「因此装不下大规模开源模型」 —— **不成立，本轮有官方级反证**。
- ⛔ 「训推一体机的典型显存是 X」 —— **问题本身不成立**，实测是 128 GB 到 1536 GB 的连续谱。

⭐ **两条对本路线有用**：

2. **「垂直小模型」被写进官方政策建议**：「推动通用大模型与面向工业场景的垂直小模型相协同、相融合」——⭐ 这是**官方口径里的「工业场景用小模型」**，可用于论证路线合理性。⛔ 但它是**政策倡导**，不是「工业单位只能用小模型」的实证。

## 3. 涉密 / 隔离网对算力共享的成文约束

### 3.1 核到的两条成文条款（M）

**（1）《中华人民共和国保守国家秘密法》（2024 年第二次修订，主席令第二十号，2024-02-27 由第十四届全国人大常委会第八次会议修订通过，2024-05-01 施行）第三十一条**，六项禁止行为中三项与本命题直接相关：（一）未按照国家保密规定和标准采取有效保密措施，将涉密信息系统、涉密信息设备接入互联网及其他公共信息网络；（二）未按照国家保密规定和标准采取有效保密措施，在涉密信息系统、涉密信息设备与互联网及其他公共信息网络之间进行信息交换；（三）**使用非涉密信息系统、非涉密信息设备存储或者处理国家秘密**。同法**第三十条**规定涉密信息系统按涉密程度实行分级保护，保密设施设备与系统「同步规划、同步建设、同步运行」，且须经检查合格后方可投入使用并定期开展风险评估。核验入口：[商务部政策法规库](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=99900) · [人民网 · 中国共产党新闻网全文](http://cpc.people.com.cn/n1/2024/0228/c64387-40184765.html) · [全国社保基金理事会官方 PDF](https://www.ssf.gov.cn/portal/rootfiles/2024/03/25/1713038527579105-1713038527601412.pdf)。⚠️ 逐字全文因单条超出引用长度限制未整段抄录，以上为条款要点与项次；⚠️ 商务部库自带准确性免责声明，正式引用应回 npc.gov.cn 法律法规数据库标准文本（见 §7.3 第 5 项）。

**（2）《涉及国家秘密的通信、办公自动化和计算机信息系统审批暂行办法》（1998-10-27 中共中央保密委员会办公室、国家保密局发布；第二十五条「本办法自发布之日起施行」）第十六条逐字**：

> 「涉密系统不得直接或间接国际联网，必须实行物理隔离。」

核验入口：[cert.org.cn 全文](https://www.cert.org.cn/publish/main/27/2012/20120330183549481189840/20120330183549481189840_.html)（**M**，核验员打开并逐字读到；⛔ 该页未出现文号）。同办法第十九条第（一）项另有一处相关表述：涉密系统若「完全处于其主管部门（单位）独立使用和管理的封闭建筑群内，可以只采取物理保护措施」——⚠️ 这是对加密传输要求的**豁免条件**，⛔ 不是「系统必须独立建设」的要求。审批条款集中在第七至十三条（地市级以上保密局按行政区域审批、跨区域由上一级审批），⛔ 其中**没有**「独立审批」或禁止共用资源的表述。

### 3.2 ⛔⛔ 关键否定发现：没有任何成文条款讲「算力」

**这两份文件、以及本轮检索到的其它保密法规，都不包含任何关于「计算资源不可共享」「算力必须独立采购」「不可弹性扩展」的条款。** 它们管的是**网络连接**（不得国际联网、必须物理隔离）与**设备用途**（非涉密设备不得处理国家秘密），⛔ **不是算力形态**。

因此委托方设想的三条性质，其地位必须按下表分层：

| 性质 | 地位 | 依据链 |
| :-- | :-- | :-- |
| 不能用公有云 / 不能调用外部 API | ⭐ **有成文依据（M）** | 保密法第三十一条（一）（三）：涉密系统不得接入公共信息网络；非涉密设备不得处理国家秘密 |
| 涉密网段内的算力必须是专用设备（专为该网段采购） | ⭐ **可从成文条款直接导出（M + 一步推理）** | 第三十一条（三）把「使用非涉密信息设备…存储或者处理国家秘密」列为禁止行为，故该网段内的 GPU 服务器必须是按涉密标准配备的专用设备；第三十条要求保密设施设备与系统「同步规划、同步建设、同步运行」并经检查合格 |
| **不可跨网段共享** | ⚠️ **I 级推断，无成文条款** | 由「必须实行物理隔离」+「非涉密设备不得处理国家秘密」导出，⛔ 但**没有一条法规是直接这么写的** |
| **不可弹性扩展** | ⛔ **I 级推断，无任何依据** | 这是采购与审批流程的**现实后果**，⛔ 不是成文要求；「同步规划、同步建设、同步运行」讲的是保密设施与系统同步，⛔ **不是**禁止扩容 |

⛔ **写论文时必须按上表分层。** 把「不可弹性扩展」写成保密法规要求，是可被审稿人一击即破的错误陈述。

### 4.1 本轮新增第 1 篇（M，⭐ 本轮最有价值的学术命中）

**Paloniemi, Setälä, Mikkonen. _Porting an LLM based Application from ChatGPT to an On-Premise Environment_.** [arXiv:2504.07907](https://arxiv.org/abs/2504.07907)（cs.SE，2025-04-10，CC BY 4.0，DOI 10.48550/arXiv.2504.07907）。**venue**：arXiv comments 字段逐字标注「Actual article is a part of the proceedings of the International Conference on Software Reuse (ICSR) 2025」——**ICSR 是真实的 SE 会议**（⚠️ abs 页无独立 journal-ref，故 venue 归属为 comments 自述，该项为 **S**；⛔ abs 页也未列作者机构）。核验员已下载 PDF 全文并逐节阅读。

> "We build on top of this work by considering consumer graphics processing units (GPUs) as affordable business hardware as they are designed to be installed and used by layperson, they are effective with current LLM architectures and are reasonably priced compared to high-end data center GPUs or application specific integrated circuits (ASICs)."

> "as the system was intended for use by small teams or individuals, there was no need for a large scale compute cluster."

> "We had no available resources to fine-tune the larger model and hence found that smaller models are better for applications with constantly changing information baseline as they are also faster to customize."

另有一句可用于「算力可得性影响选型」的一般化表述：

## 6. 分析单位审计：哪些证据只支撑国家级、不能推单位级

⛔⛔ 本节是硬性要求。第一轮曾把「H20 单季在华销售 46 亿美元」当成「某单位有 8 张 H20」的依据，那是**分析单位错位**（unit of analysis fallacy），已撤回（记在 [SUMMARY.md](./SUMMARY.md) §16）。**正确的分析单位是：建模工作实际发生的那个隔离 / 涉密网段或那个设计所。** 该单位内算力有三条性质：专为该网段采购（独立审批）· 不可跨网段共享 · 不可弹性扩展。**全国存量对它不可寻址。**
