## R1 · 「与预算无关」不是免疫，那正是致命伤——可复现性**永远**推不出「小」，真正选中小模型的是「我们只在那儿赢」

| 字段 | 内容 |
| :-- | :-- |
| **反驳** | §3.1 把「复现性与预算无关」写成免疫证明，但那恰恰意味着**这条动机在模型规模这根轴上永久沉默**：它推得出「必须用开放权重」，推不出「必须用 27B」。于是选中 27B 的唯一实际理由，就只剩 §3.2 那句「这类干预的适用区间是弱模型」——**配置是按「我们在哪儿赢」挑的，动机是事后挂上去的。** |
| **建议处置** | **接受并降档**（附一个决定性实验） |

### 为什么它致命

§2.2 的标题是作者自己写的：**「P1 → P2 是纯逻辑跳跃」**。它的正文把这一刀拆成两半——

> ⭐ 本地部署也能跑**大**模型；⛔ 要论证「必须**小**」，⛔ 得再加一个「单卡 / 无 GPU 集群」的前提。

前半句是刀刃（动机推不出「小」），后半句是刀背（补的那个前提与场景矛盾）。而 §3.1 的免疫声明逐字是：

> ⛔ 「守得住的场景不缺 GPU」**打不到它**（⭐ 复现性与预算无关）

**它只挡住了刀背，刀刃原封不动。** 更糟的是这个「挡」是有代价的：保密动机至少还**允许**你补一个单卡预算前提去够到「小」；可复现性与预算无关，等于把那根唯一可能通向「小」的线**主动剪断**了。⛔ **免疫是用「永远到不了小模型」换来的。** 把 counterarguments §5.1 那句逐字换一个词就能看清同构：

| 原版 | 换成新动机后 |
| :-- | :-- |
| 「不能用公有云」推不出「必须用 32B」，只推得出「必须用开放权重」 | 「要可复现」推不出「必须用 27B」，只推得出「必须用开放权重」 |

**同一把刀，一个字没钝。** 而这一次没有补丁可打。

于是问题变成：**既然动机选不出规模，是什么选出了 27B？** 按排除法只剩 §3.2 ——脚手架在弱模型上才生效。也就是说：**我们把实验配置挪到了我们会赢的那一格，然后用一条对这一格毫无偏好的动机去解释这次挪动。** 审稿人的版本只要一句话：*你在大家都在用的模型上输了，所以你换了模型；而你给出的换模型理由（可复现）换成一个你同样会输的开源大模型也完全成立。* 按仓库根 [CLAUDE.md](../../../../CLAUDE.md) §3.5 第 4 条，「评测口径迁就结果」是 **C 级**——这里迁就的不是分母而是**被测模型**，性质相同。⚠️ §3.2 反而把这件事写成了美德（「⭐⭐ 这才真正做到『避开和 SOTA 拼数值』…⭐ 对照组本来就该换」），而「本来就该换」的依据正是 §3.2 自己那条待证的主张——**循环**：我们可以搬到我们赢的地方，因为一篇 preprint 说我们在那儿赢。

### 还有第二刀：那一格**可能根本不是**赢的那一格

⛔ 这一条该文档完全没查。[small_model_papers.md](./small_model_papers.md) §4.6 的 VerIbmc 逐模型消融（**M**，同一套三阶段流水线 Basic vs LLM-Only）：

| Model | Δ（脚手架净收益） |
| :-- | --: |
| Llama-3.1-8B | **+35** |
| Qwen2.5-7B | +24 |
| GPT-OSS-20B | +15 |
| **Qwen2.5-32B** | ⛔ **+2** |
| GPT-OSS-120B | +3 |

**在 30B 档上，脚手架收益已经掉到 +2。** 而 counterarguments §5.7 记录的候选模型是 `Qwen/Qwen3.6-27B`——**2026 年的 27B，比 2024 年的 Qwen2.5-32B 只强不弱**（**I**，a fortiori 推断，非实测）。⟹ 我们准备搬进去的那一格，按现有最贴合的逐模型数据，**大概率已经在收益归零区里**。真正有 +35 的是 7–8B 档，而那个档位上 project_1 的任务（读需求、读模型、构造可求值断言）能不能跑起来，一个数都没有。

### 建议处置：**接受并降档**，并补一个决定性实验

1. **不写**「私域 / 可复现 ⟹ 小模型」的任何形态。诚实形态是**能力区间刻画**：「分解型脚手架的收益随模型能力衰减，本文测出这条曲线与它的拐点」。⚠️ 这把贡献从「方法」降格为「实证刻画」，但它是**唯一站得住的形态**，且 §4.9 记录的文献真空恰好就是这个形状。
2. ⭐ **加第三条臂：大开源权重模型**（`Qwen3.5-397B-A17B` 或 DeepSeek）。这是**分离「开放权重」与「小」的唯一手段**，也是审稿人一定会要的那一格。若方法在大开源模型上照样输，那就实锤了「规模轴才是主因、动机与配置无关」，此时**必须**改写成区间刻画；若真赢了，那才第一次有资格谈部署。
3. **拐点判据事前登记并 push**（§3.5.1）：在跑之前写死「收益归零」的判定，否则事后无论曲线什么形状都能讲成故事。

## R2 · 两处「独立收敛」都不独立；剥掉修辞后，承重主张只由**一篇** n=8 的污染 preprint 撑着——而真能撑它的两条证据被留在分册里没上来

| 字段 | 内容 |
| :-- | :-- |
| **反驳** | §0 的「三条互不相干的调研路径独立收敛」与 §3.2 的「三条独立证据同向」都是**计数虚高**：前者其中一条是空结果 + 作者自己的建议，后者其中一条是待解释项（循环）、另一条是防守性调和（不是正面证据）。**同时**，分册里真正硬的两条量化证据（§4.2 / §4.6）**没有进结论文件**。 |
| **建议处置** | **接受并降档**（就地改措辞 + 把分册证据提上来） |

### 为什么它致命

**这不是措辞问题，是审稿人当场可验的事实主张。** 「三条独立证据」是一个可被核对的断言；核对后发现是一条，整份文档的可信度会被连坐——而这份文档其余部分是诚实且高质量的，为一句修辞赔掉它极不划算。

**第一处（§3 动机侧）。** 三条路径里，「法规族」这一条的实际内容是：查完 9 本标准 + 5 族法规**什么都没查到**，然后**主动建议**改挂可复现性。⛔ **空结果加上研究者自己的备选建议，不构成一条独立证据路径**——它是「证据缺席」被重新贴了「收敛」的标签。剩下两条（MDE/RE 直翻、反方族）观察到的是同一件事：**该社区用开源模型时的标准理由就是可复现性**。而 §3.1 自己已经承认这是「**已被占据的位置**」「**不构成新颖性**」。⟹ 在「可复现性本就是社区默认答案」这个零假设下，**三条路径全都会命中它**；命中它因此不携带任何证据力，只证明这条规范存在——而这一点没人有异议。

**第二处（§3.2 支撑主张侧），更严重。** 逐条看那「三条独立证据」：

| # | §3.2 列的 | 实际是什么 |
| :-: | :-- | :-- |
| 3 | 「我们自己的数据：自我批判吃掉 79% token 而净收益 ≈ 0」 | ⛔ **待解释项，不是证据。** 用你要解释的现象去支持你的解释是**循环**。且它落在**自我批判**这根轴上，对**规模**轴一个字都没说 |
| 2 | 「Huang / Stroebl 与它不矛盾，因为是两类不同干预」 | ⛔ **防守，不是支持。** 它论证的是「一批反向证据不适用于我」，这不增加正向支持。⚠️ 且「自我批判 vs 多阶段分解」这条区分是**作者自造的分类**，恰好切在豁免自己所需的位置上——没有任何外部来源断言「分解对弱模型更好」 |
| 1 | Abdulkarim crossover | ⭐ 唯一的正面证据 |

于是承重的是**一篇**，而这一篇的限定该文档自己列了五条：preprint、$n=8$ 且样本来自本科建模课、只 2 个模型（都是 2024 年的）、单作者人工判定无双人复核、⛔ **作者自陈严格后处理器 "may suppress valid LLM outputs"**。[small_model_papers.md](./small_model_papers.md) §4.1 还多记了一条 SUMMARY 没带上来的：**shot 数不对等**（基线 3-shot、多步 2-shot，且论文内部两处口径自相矛盾）——**基线是被有意加强过的**，这直接放大了 crossover 的幅度。⛔ 文档在 §4 限定 2 承认了「幅度不可信」，转头在 §3.2 仍写「三条独立证据同向」。

### 讽刺的是：解药就在自己抽屉里

[small_model_papers.md](./small_model_papers.md) 有两条比 Abdulkarim 硬得多的证据，**都没进 SUMMARY**：

| 出处 | 内容 | 为什么更硬 |
| :-- | :-- | :-- |
| §4.2 **TOSEM 2025**（DOI [10.1145/3771933](https://dl.acm.org/doi/10.1145/3771933)） | Critique prompting 在代码摘要上 GPT-4o **+**、o1-mini **−**，同一技术符号反转 | ⭐ 正式期刊（非 preprint），⚠️ 数字取自 arXiv v1 需回正式版复核 |
| §4.6 **VerIbmc**（arXiv:2606.16886） | 逐模型消融 +35 / +24 / +15 / +2 / +3 | ⭐⭐ **「收益随能力单调衰减」最干净的一次直接测量**，且任务是形式化验证，与我们高度同构 |

**结论文件比它的分册更弱，同时比分册更敢声称独立性。** 这是本轮文档流程本身的缺陷，不只是这一条主张的缺陷。

### 建议处置：**接受并降档**

1. ⛔ **删掉两处「独立收敛」框法。** §3 改写成：「可复现性是该社区处理开源模型选型的**既有规范**，本轮三路调研均命中它，这确认了规范的存在，**不构成对本文设计的独立支持**。」
2. ⭐ **把 §4.2 与 §4.6 提进 §3.2**，主张改述为：「**一篇**同制品 preprint 给出方向（⛔ 幅度受后处理器与 shot 不对等污染，不可引）+ **两条**跨域量化消融给出趋势。」
3. ⛔ **§3.2 第 3 条（我们自己的数据）必须从证据位挪走**，改列为「本文待解释的观测」。
4. ⚠️ 引 §4.6 时**必须同时引它最不利的那句**：最强↔最弱能力差 **89 题 > 任何策略差（最大 +35）**，且 +35 取自三次运行最好一次（均值 336.0，σ=5.3）。⛔ 只引对己方有利的一半，按 §3.5 属选择性报告。

## R3 · 拆开之后，唯一还承重的卖点是全篇**唯一没被测量过**的那个；它借来的证据全在「可靠性」轴上而非「效度」轴上，而它引以为据的 Baldur 恰好确立了会杀死它的那条标准

| 字段 | 内容 |
| :-- | :-- |
| **反驳** | §4 限定 1 + 建议 3 主张把「可断言可追溯」与「私域部署」拆开各自成立——方向正确，但文档**从未回头清点拆完之后还剩什么**。清点结果：私域降为不承重、可复现自认不是 contribution、打平 SOTA 明令禁写 ⟹ **只剩「可断言可追溯」独自承重**。而它是全篇唯一**没有任何自测数据**的卖点，其借来的外部证据买到的是**可靠性**不是**效度**，且论文用来支撑它的 Baldur 自带成本归一化这条标准——在 ~212× 开销下这条标准会先把它判死。 |
| **建议处置** | **移入 Limitations**；⛔ **作为 contribution 主张：无解，建议放弃**（详见下） |

### 为什么它致命

先做文档自己没做的那次清点：

| 卖点 | 该文档给它的处置 | 还承重吗 |
| :-- | :-- | :-: |
| 私域部署 | §3.3「⛔ 降为顺带的应用价值，⛔ 不承重」 | ✗ |

| 小模型打平 SOTA | 建议 2「⛔ **不要写成 parity**」 | ✗ |
| 弱模型区间 | §3.2 支撑主张；且按 **R1** 只能降为区间刻画 | ⚠️ 半 |
| **可断言可追溯** | 建议 3「拆开，各自独立成立」 | ⭐ **只剩它** |

⚠️ [mde_re_venue_scan.md](./mde_re_venue_scan.md) §6 已经**独立地**走到同一个落点——逐字建议「⭐ 在**可断言、可追溯**这个维度上，⭐ 方法带来的收益不依赖模型规模」「⛔ 后者才是我们真正有数据的那一格」。⛔ **两路都退到这根柱子上，却没有任何一路审过这根柱子。** 现在审：

**(a) 支撑它的证据全是「这一类东西」的证据，不是「这套系统」的证据。** [assertion_output_form_evidence.md](../assertion_output_form_evidence.md) 的 F 行拿到的是：Mäder & Egyed（71 被试，有 traceability 快 **24%**、正确解多 **50%**）、Infer diff-time（同一分析、同一误报率，处置率 ≈0 → **>70%**）、CheckEval（评审者间一致性 α **0.09 → 0.48**）。⛔ **没有一条测的是本方法的产出。**

**(b) 更要命：最强的那条买的是可靠性，不是效度。** 该文件自己逐字写了，还预告了会被抓：

> ⭐ **结构化带来的是可靠性约 5 倍，⛔ 不是效度。** ⚠️ 这个区分若不写清，reviewer 一定会抓。

**可靠性 = 判定可复算；效度 = 判定是不是真缺陷。** 而本方法在效度轴上唯一的数字是 **60.4% vs 76.2%**。⟹ 拆开之后的合成主张，用审稿人的话说就是：**「你把输出形态做得更可复算了，代价是找到的真缺陷更少了，而你没有测量过前者值不值后者。」**

**(c) 那个权衡实验根本不存在。** 要主张「可断言形态值 −15.82pp」，需要一次下游测量：拿 60.4% 的可断言 + 可追溯发现，与 76.2% 的散文式发现，比下游修复或人工复核的产出。⛔ 那是 project_4 / 一次人体实验，**现在一个数都没有**。

**(d) 自己给自己立的标准会先判死它。** 论文支撑「判据必须带证据链」的**关键引文就是 Baldur [14]**，而 Baldur 的决定性一步逐字是：

> it does not surpass the performance of the **generate** model **when normalized for inference cost**

⛔ **引 Baldur 就等于接受「按推理成本归一」这条标准。** 而仓库自记的开销是 **~212.6×**（⚠️ 绑定 X1-v1 口径，同文另给 168×，见 [v46_weakness_anatomy.md](../../discover_matrix/docs/findings/v46_weakness_anatomy.md) §136）。⟹ 在成本归一化下，这根柱子要用**两个数量级的开销**去换一个**为负**的发现率差——**它在被测试之前就已经不满足自己援引的那条标准。** counterarguments §5.3 只把成本预见成「审稿人会要求 cost-normalized comparison」，⛔ **没有发现这条要求是我方主引文自带的**，因此无法用「那不是本领域惯例」挡回去。

### 建议处置：**移入 Limitations**；⛔ 作为 contribution 主张 **无解，建议放弃**

分两半，因为两半的可解性不同：

1. ⛔ **无解的那一半：作为 claim。** 「可断言可追溯有价值」**不可能靠补文献补上**——缺的不是引用而是一次下游效用测量，而借来的所有引用都在错误的轴上（可靠性 ≠ 效度）。⭐ **建议直接放弃把它当 contribution 主张**，改写成**声明式的设计性质**：「本方法的产出形态是可机械求值、可回溯到需求条目的；⛔ 本文**不主张**该形态的下游收益已被验证，⭐ 其价值取决于 project_4 的修复阶段能否利用它，⛔ 这留待后续工作。」——⛔ 一个诚实的设计性质，好过一个测不出来的卖点。
2. ⚠️ **可解但不在 N1a 范围的那一半：成本。** 成本归一化这一刀，在自我批判环还在（79% token、净收益 ≈ 0）的前提下**无法用论证回答**，只能靠砍掉它把倍数打下来——那是 M1 的活。⭐ 在此之前，主结果表必须**与 `hit` 同表**列 token / 墙钟 / 调用次数（counterarguments §5.3 已建议，⭐ 这里加一条理由：**这是我方主引文的标准，不是审稿人的额外要求**）。

## 一句话总结

⛔ **R1 最致命**：替代方案的主动机在模型规模轴上**永久沉默**，而文档把这种沉默当成了免疫证明；真正选出小模型的是「我们只在那儿赢」，且按现有最贴合的逐模型数据，**27B 那一格的脚手架收益可能已经归零**——动机是回填的，而回填的目标格还可能是空的。⛔ **R3 里有一条无解**：「可断言可追溯」作为 contribution 主张补不上，只能降为设计性质。⭐ **R2 最好修**，就地改措辞 + 把分册里更硬的证据提上来即可，但不修会连坐整份文档的可信度。
