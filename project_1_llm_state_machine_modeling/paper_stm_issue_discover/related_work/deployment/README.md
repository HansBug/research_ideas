# `deployment/` · N1a 私域部署动机调研

本目录回答一个问题：**到底是什么工业场景，会让我们在「需求 → 状态机建模」这个阶段不得不使用私域部署的模型？** 并且这个答案必须能被足够的文献或成文依据佐证，不能是断言。

**入口**：结论看 [SUMMARY.md](./SUMMARY.md)；修订过程与已撤回主张看 [revision_log.md](./revision_log.md)；证据分册见 SUMMARY §6。

## 结论摘要

落 **B 档**。原设想的四段链条只有前两段可用：

- 「真实项目材料不外发给第三方托管模型」——可写，依据是观察到的产业实践
- 「我们在单卡 24 GB 级条件下评估」——可写，有 10 篇文献先例、3 篇承重
- ⛔ 「因此必须用小模型」——不可写，膝点置信区间 $[8\mathrm{B}, >120\mathrm{B}]$
- ⛔ 「小模型 + 本方法可打平 SOTA」——不可写，四条证据同向反对

## 它服务于什么

导师 2026-08-13 给的第二条路线是「强调工业应用背景，使用私域部署的小规模模型，达到的效果能和最新的全量 llm 相当」。本目录负责查清该路线的**动机层**能否立住。

结论是：动机层的**前半段**能立住，但**它推不出「必须小模型」**——而后者才是原路线的承重部件。

## 一条必须随结论带走的前提

动机层立住**不等于**路线成立。现状是主臂 `hit@1` 60.4% 而朴素基线 76.2%（Δ = −15.82pp），换成小模型不会让这个差消失。相关裁定见 [../../discover_matrix/docs/findings/route_selection_and_v47_plan.md](../../discover_matrix/docs/findings/route_selection_and_v47_plan.md) §一。

本目录只负责动机层；效果层归 M1 与 N1b。
