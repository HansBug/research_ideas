## 1. ⭐⭐ 起点：L1 的种子表在 LLM 硬门下剩多少

L1 §3.2 有一张 7 例的两段式路线表（[landscape/SUMMARY.md](../landscape/SUMMARY.md) 第 146–153 行）。⭐ 它是本表的**出发点**，⛔ 但先要过 L3 的第一条硬门。

| L1 的行 | 谁决定检查什么（L1 原判） | ⛔ 过 L3 的 LLM 硬门？ |
| :-- | :-- | :-: |
| Identifying and fixing ambiguities（SoSyM 23(6)），NL → FORM-L → 仿真 | ⭐ 规则 + 人（**自陈不可全自动**） | ⛔ **否** |
| Post-Hoc Formal Verification of Automotive Software（RE 2024） | ⭐ **人写** | ⛔ **否** |
| Spacecraft Operational Designs（MODELS 2023 + SoSyM 24(6)） | ⭐ **人写** | ⛔ **否** |
| `pat-agent` / `event-b-agent` / `cir-cvn` / `llm-aided-protocol` | LLM 自动 | ⭐ **是**（⚠️ L1 注「多数界外」） |
| Completion of SysML state machines from GWT（SoSyM 23(6)） | ⭐⭐ **预编的 pattern catalogue** | ⛔ **否** |
| Dwyer 模式族 | ⭐ **人写**（目录只降书写成本） | ⛔ **否** |

⭐⭐ **结论：6 行里只有 1 行过门，⚠️ 而那一行 L1 自己注了「多数界外」。**

⛔⛔ **这意味着 L3 不是在扩写 L1 的表，⭐ 而是在开一块几乎空白的地。** ⚠️ 反过来说也成立：⭐ **「行为模型上的检查侧工作，绝大多数不用 LLM」本身就是一条待验证的观察** —— ⛔ 但 L1 的样本量（6 行）撑不起它，⭐ 要由 L3 的浅层计数池给分母。

### ⚠️ 一处必须标出的计数不一致（⛔ L1 的，⛔ 不在本轨修）

L1 正文写「⭐ **7 例中 4 例人写、2 例 LLM 自由生成、1 例预编 catalogue**」，⛔ 而表里只有 **6 行**，⛔ 且那 1 行 LLM 行**点名了 4 个工具**。⭐ 4 + 2 + 1 = 7 与「6 行 / 4 个工具」两种数法**对不上**。

⭐ **本表不采用 L1 的「7 例」这个数**，⛔ 只采用逐行的定性判断（那部分是可核的）。⚠️ 已记入 [SUMMARY.md](./SUMMARY.md) 的「上交项」，⛔ 由 R1 决定要不要回头修 L1。
