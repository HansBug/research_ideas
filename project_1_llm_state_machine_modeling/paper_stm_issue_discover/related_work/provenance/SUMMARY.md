# 来源档案摘要

当前来源档案服务于冻结 `four-family-19-core.v1` 的 19 个谓词。唯一人读审计入口是 [predicate_provenance.md](predicate_provenance.md)；它给出 19/19 legacy/current crosswalk、外部资格、方法语义、实例 authority、全文引文、chronology 和 publication eligibility。完整 machine-readable catalog 见 [current_source_catalog.json](current_source_catalog.json)，使用与运行时隔离规则见 [README.md](README.md) 和 [CURRENT_SOURCE_AUDIT.md](CURRENT_SOURCE_AUDIT.md)。

本目录仅维护 academic provenance。运行时 evidence、W、D、publication、backend execution 和 Judge 关系分别由 method/evaluation artifact 维护；不得把它们写回来源目录，也不得从来源目录读取为运行时 gate。
