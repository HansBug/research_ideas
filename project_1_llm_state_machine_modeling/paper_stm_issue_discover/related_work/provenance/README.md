# 谓词来源与边界审计

本目录维护当前四类 12 种谓词的用途、来源与执行边界。唯一人读事实源是[谓词来源审计](./predicate_provenance.md)，包含书目、一手引文、页码、方法片段和逐极性资格；[结构化目录](./current_source_catalog.json)保存对应的 source ID、状态与键集。

来源分为三类责任：领域资料说明相关检查的实际动机，形式资料说明精确命题形状，技术资料说明绑定、后端与回执的执行边界。每个实例中的名称、期望值、scope 和界限由当前自然语言描述与源制品绑定给出。

W2 需要受支持片段、精确绑定、完整身份链、可核验的描述／来源／绑定引用，以及终止 Boolean receipt。逐极性资格限定论文能作出的最强主张，不代替实例执行或人工有效性裁定。当前来源目录与 method 内资源按同一版本和谓词集合维护，各自保留本层所需字段。

当前入口见 [SUMMARY.md](./SUMMARY.md) 与 [CURRENT_SOURCE_AUDIT.md](./CURRENT_SOURCE_AUDIT.md)。pre-P1 审计、旧数据编号映射和复现说明见[历史版本记录](./archive/pre_p1_20260905/README.md)；历史运行记录不随当前定义改写。
