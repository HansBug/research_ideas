# 来源、后端与运行统计口径

当前方法固定为四类 12 条谓词。下列检查对应不同对象，分别记录。

| 对象 | 当前范围 | 含义 |
| --- | --- | --- |
| 来源对应 | 12 条谓词 | 每条的来源 ID、用途、引文定位和边界可复核 |
| 后端符合性 | 12 条谓词 | 按当前定义验证类型化输入、执行分支、正反例与不支持片段 |
| 运行使用量 | 指定运行及其 registry 版本 | 统计实际终止回执和报告绑定，不把 prompt 出现或测试 fixture 计为实验执行 |
| W2-on-hits | 已 FULL 命中的预期问题轮次单元 | 统计其中达到 W2 的单元，根报告与含子主张回执口径分别列出 |

来源对应与后端符合性不随单次运行的使用量变化。W2-on-hits 的分母是已 FULL 命中的单元，与使用全部预期问题单元作分母的 W2/expected 不同。历史 15-pair 与 54×3 planned 口径保留在[原覆盖审计](./archive/pre_p1_20260905/coverage_audit.md)，不能用作当前运行结果。
