> 复合态 `PumpState` 整枝进不去。PumpControl 的并发区 0（区分隔符 `--` 首见于 stm0.puml:12，故 :5 的默认入口边与 :7-:10 的 `state PumpState {}` 同属区 0）唯一的默认入口边指向 `InitialState`；而全文 8 条迁移的目标里没有任何一条是 `PumpState`。作者要么漏写了一条把控制交给 `PumpState` 的迁移（如 `InitialState --> PumpState : ...`），要么区 0 的默认入口本应写成 `[*] --> PumpState`。这一处缺失入边直接产生三个下游后果：子态 `RunningState` 不可达；`PumpState` 体内两条边所消费的事件 `Activate Pump` 与 `Deactivate Pump` 的唯一消费源随之永不可触发。
