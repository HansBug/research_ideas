1. **只在 `~~~` 围栏里写。** `<!-- FILL:BEGIN … -->` 与 `<!-- FILL:END … -->` 两行是回收锚点，不许改、不许删。围栏**外**写的字，重跑生成器就没了。

3. **勾完别删掉后面的选项文字。** ⚠️ 取值就是**框后面那段文字**，不是框的位置：只留 `裁决: [x]` 等于**没勾**。
4. **单选就只勾一个。** 勾两个不是「两个都算」，是 [validate.py](../validate.py) 报「该字段是单值」。
5. **自由文本写在 `字段名:` 的冒号后面**（半角 `:` 与全角 `：` 都认），可以换行接着往下写，续行里带冒号也不会被截断。但**别改字段名** —— 改了那一行会被并进上一个字段。
