1. **只在 `~~~` 围栏里写。** `<!-- FILL:BEGIN … -->` 与 `<!-- FILL:END … -->` 两行是回收锚点，不许改、不许删。围栏**外**写的字，重跑生成器就没了。
2. **勾选写 `[x]`。** `[X]`  `[✓]`  `[√]`  `[✔]`  `[☑]` 同样认（大小写都行）。⚠️ 别写 `[v]` `[是]` `[o]` `[1]` `[*]` —— 不认的记号会让**那一个选项连同它的文字一起消失**，看起来就像你没勾。
3. **勾完别删掉后面的选项文字。** ⚠️ 取值就是**框后面那段文字**，不是框的位置：只留 `裁决: [x]` 等于**没勾**。
4. **单选就只勾一个。** 勾两个不是「两个都算」，是 [validate.py](../validate.py) 报「该字段是单值」。
5. **自由文本写在 `字段名:` 的冒号后面**（半角 `:` 与全角 `：` 都认），可以换行接着往下写，续行里带冒号也不会被截断。但**别改字段名** —— 改了那一行会被并进上一个字段。
6. **§4 清单**：勾在行首那个 `[ ]` 里（前面有缩进或 `-` 都行，id 别动），发现写在它下面的 `发现:` 后面 —— 直接写在下一行也收。唯一不回收的是 `·` 开头那行：那是机器给的机械判据。
7. **§5 每条新增以 `### NEW-0019-01` 这样的标题单独起头**，别把两条挤在一个标题下，也别漏掉 `NEW-` 前缀。
8. **不适用就留空**（回收成 `null`）；查过了、结论是「没有」，写 `无`（`none` / `N/A` / `-` 同义）。「留空」与「写 `无`」在校验时是两件事。

### EIS-0019-01 🟠

**问题类型**：`pair`（元素间关系） · `nondeterminism`（非确定性） · `requirement`（需求文本）
- 归类依据（原文逐字）：生成侧对两个不同目标使用逐字相同的条件

**问题描述**：NL 3 虽然把 cruise 与 lane_change 写在同一个条件从句下（本身歧义），但两个目标互斥，模型必须给出可区分依据。生成侧对两个不同目标使用逐字相同的条件，FCSTM 投影中它们共享同一个 event dist_to_front_25_extra_lane_true 且均无守卫，形成不可区分的冲突目标。参考侧靠 cruise 无守卫消歧，0009/0049 靠互补守卫消歧，只有 0019 与 0029 没有消歧。
