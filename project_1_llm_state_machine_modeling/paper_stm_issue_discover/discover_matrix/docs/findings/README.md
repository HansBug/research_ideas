## ⭐ 五条结论（⛔ 若只读五行，读这五行）

1. ⛔ **实验执行没有出错。** 输入逐字节等价、格子无错位、模型与采样一致、324/324 全 `completed`。⭐ 修掉唯一的泄漏后重判，**X1 反而更高**（448/588 = 76.2%）。
2. ⛔ **赤字在两处，⛔ 不是一处**：**67 位「根本没问」**（选题）+ **54 位「问了没答对」**（断言构造）。⛔ 三类 issue 的 Δ 几乎均匀（14.4 / 15.6 / 16.7），⛔ **所以缩小 scope 救不了**。
3. ⛔⛔ **自我批判型 loop 是负收益的。** 逐停点重建显示 review 的**第 3–5 轮增加恰好零位**，⛔ 而修订机器吃掉 **79% 的 token**。⭐ 文献（Huang ICLR 2024）与一条不可能性定理（Stroebl arXiv:2411.17501）独立指向同一结论。
4. ⭐⭐ **我们一直在跟错误的对手比。** 形式化规约的**人类基线是 47–50%**（受训 + pattern 辅助，Czepa $N=215$），⛔ 而我们是 60.4%。
5. ⭐ **v47 最小改动集 < 100 行、预计 +11~17pp 且成本降 19%**——⛔ 但即使全拿到，Δ 仍可能为负。
