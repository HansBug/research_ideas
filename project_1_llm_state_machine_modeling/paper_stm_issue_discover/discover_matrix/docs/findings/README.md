## ⭐ 五条结论（⛔ 若只读五行，读这五行）

1. ⛔ **实验执行没有出错。** 输入逐字节等价、格子无错位、模型与采样一致、324/324 全 `completed`。⭐ 修掉唯一的泄漏后重判，**X1 反而更高**（448/588 = 76.2%）。⚠️ ⛔ **但主臂的逐格统计一度读错了目录**（漏了 `apply_v46r.py` 对 6 个 pair 的整块替换）：已发布 issue 是 **1094** 而非 1105、`excluded_findings` 是 **356** 而非 366、损失阶段 ④⑤ 是 **17 / 13** 而非 14 / 15——⭐ 全部已更正，⛔ **`hit@1` 的 355 与全部判定表数字不受影响**。
2. ⛔ **赤字在两处，⛔ 不是一处**：**69 位「根本没问」**（选题）+ **52 位「问了没答对」**（断言构造）。⚠️ **两个数已更正**（⛔ 初稿 67 / 54，⛔ 那是只读 `matrix-v46-full`、漏了 `apply_v46r.py` 对 6 个 pair 的整块替换；⭐ 见 [talk §0.7](../../../../talks/2026-08-12-实验-为什么主臂比朴素基线低15个点.md)）。⛔ 三类 issue 的 Δ 在 **X1-v1** 口径下几乎均匀（14.4 / 15.6 / 16.7）——⚠️ ⛔ **但在 v2 口径下不成立**（+16.4 / +20.6 / ⛔ **−1.7**，③ 类翻负）；⭐ 「缩小 scope 救不了」两个口径下都成立（① 类占 348/588 位，③ 类无论哪个口径只值 ±1.7pp）。
3. ⛔⛔ **自我批判型 loop 看不到正收益。** ⭐ 修订机器吃掉 **79% 的 token**（**M 级**，读 `telemetry`），⛔ 而覆盖净变化 ≈ 0。⚠️ ⛔ **「第 3–5 轮增加恰好零位」已降为 I 级并撤回其数字**——⛔ 重建脚本与「代理量」判据都不在仓库、⛔ 无法复核（见 [v46_weakness_anatomy.md](./v46_weakness_anatomy.md) §4.1）；⭐ 现有重建只能说**指向**后段增量接近零。⭐ 文献（Huang ICLR 2024）与一条不可能性定理（Stroebl arXiv:2411.17501）独立**指向**同一方向。
4. ⚠️ **参照系值得重新考虑。** 形式化规约的人类基线（受训 + pattern 辅助，Czepa $N=215$，SoSyM 2019，⚠️ 参与者为选修课学生）是 **47–50%**——⭐ 它说明**这个任务本身对人也很难**。⛔⛔ **但不可与我们的 60.4% 直接相减**（⛔ 任务 / 分母 / 人群 / 评分四项均不同），⭐ 四条限定见 [talk §10.5.1](../../../../talks/2026-08-12-实验-为什么主臂比朴素基线低15个点.md)。
5. ⭐ **v47 最小改动集 < 100 行、预计 +11~17pp 且成本降 19%**——⛔ 但即使全拿到，Δ 仍可能为负。
