## 8. ⭐ 判据与护栏（⛔ 跑前必须登记）

### 8.1 ⛔ 绝对阈值不可登记 —— ⭐ 判据须写成「相对结构上限」

⛔ 因为结构上限本身就不是 100%。

| 档 | 判据 | 读法 |
| :-- | :-- | :-- |
| ⭐ **好** | `flip / U ≥ 0.80` **且** `guard_break` 误报 < 20% | ⭐ 可作 C-② 判别效力证据 + C-③ 第一段链接实证 |
| **说不清** | `0.50 ≤ flip / U < 0.80` | ⛔ 只报回归防护工具性质 + 谓词判别力自审 |
| **坏** | `flip / U < 0.50` | ⛔ **不是「断言不行」** —— ⭐ 是绑定脆性主导；⛔ 归因未做完不得下任何结论 |

⭐ **两个阈值的锚**（⛔ 不是拍的）：**0.80** = 结构上限外再留 20% 给人工修复的不确定性，⭐ 而这 20% 有实测参照（依修法而定 11.6% + 耦合确定性打断 7.0%，恰在此量级）；**0.50** = ⭐ 翻转不到一半说明主导因素是绑定脆性而非断言质量，⛔ 此时报任何比率都会误导。

### 8.2 ⛔ 报三个量，不是一个

1. **`flip` = False → True**，⭐ 分母取**扣除结构不可翻之后**的数，⛔ 并同时给未扣除的原始分母（两读法并报）
2. **`unsupported` = False → 不可求值**，单列 —— ⛔ **不得并进「未翻转」**（⚠️ 合并会把空集拒答、horizon 拒答、热启动失败全记成「断言不准」，把翻转率压低约 11.6pp）
3. **`guard_break` = True → False**，逐条判真回归 / 误报

### 8.3 ⛔ 低翻转率不必然是坏消息 —— ⚠️ 但只在一个前提下

| 原因 | ⭐ 怎么与另两种分开 | 实测规模 |
| :-- | :-- | --: |
| ⛔ **(i) 断言锚错** | ⭐ **不需要任何修复就能查**：绑定路径若在任何忠于 NL 的模型上都不存在 → 锚错 | A: ≥5 条 |
| ⚠️ **(ii) 修法不对** | ⛔ 只能由第二判定者独立认定（⛔ 不看断言） | 只能实测 |
| ⛔ **(iii) IR / 谓词承载不了** | ⭐ 纯机械可判 | A: ≥5 / ⭐ B: ≥257 = 12.6%，按 issue 16.8% |

⭐⭐ **操作纪律：(i) 与 (iii) 必须在任何人动模型之前分类完毕并落盘。** ⛔ 它们都不需要修复数据，⚠️ 而事后才分类等于「看到结果再定口径」。⭐ 事前分好之后，实验真正测的只有 (ii)，⭐ 那才是它有信息量的部分。

⭐ **一个「低翻转率反而是好消息」的实测事实**：F3 那 10 条里**有 5 条是 6/6 稳定命中**，⭐ 它们贡献了 37/72 个命中位。⛔ **翻转率会把方法最可靠的一批发现记成失败** —— ⭐ 而那恰恰是「表示债务对称审计」这条方法论主张的正面证据。⛔ **但这个读法只在 (i)/(iii) 事前分类的前提下成立**；⚠️ 事后拿它解释难看的数字就是找台阶。

### 8.4 ⛔ 一并登记的护栏

- ⛔ **修的人不得看断言、不得看 issue、不得看台账。** ⭐ 只给 `nl.txt` 与 `stm0.puml`，任务是「让模型符合需求」。⭐ 修完的模型在重跑前哈希落盘。
- ⛔ **修复是否忠于 NL 必须由第二人判，且判的人也不看断言。** ⭐ 这是唯一能避免「断言变 True 当修好判据」这个循环的办法。⚠️ 单一判定者 + 无一致性系数这个已知弱点会**再犯一次**，⛔ 必须事前声明。
- ⛔ **修复引入的新缺陷单独记账**，⛔ 不计入 `guard_break` 误报。
- ⛔ **588 位与 60.4% 一位不动** —— 本实验是新增臂。

### ⭐⭐ 取消第二判定者的替代方案：**事前书面登记修复意图**

⛔ 第二判定者存在的唯一理由是破掉「断言变 True 当修好判据」这个循环。⭐ **同样效果可以用更便宜的办法达到**：

1. ⭐ 修的人在**动手之前**，只读 `nl.txt` 与 `stm0.puml`，⛔ **写下一段自然语言的「我要改什么、为什么这样就满足了 NL 那一句」**，并 **push 落盘**（⭐ 远端时间戳即证据）。
2. ⭐ 然后才动模型、才跑断言。
3. ⭐ 判定「是否修好」看的是**第 1 步那段文字是否忠于 NL** —— ⛔ 而它写在看到断言结果之前，⭐ **循环因此被破掉**。

⭐ **这比第二判定者更硬**：第二判定者仍是事后判断（⚠️ 且本仓库已登记「单一判定者 + 无一致性系数」这个弱点）；⭐ 而事前登记是**时间戳保证**的。⚠️ ⛔ 代价是它只覆盖「修的人自己想对了没有」，⛔ 不覆盖「他有没有想错但恰好写得像对的」——⭐ 后者须在 Limitations 声明。

### ⭐ 怎么在学术口径扎实的前提下让结果更结实

⭐ **三条都是合法的收紧，⛔ 不是挑好看的**：

| 手段 | ⭐ 为什么合法 | ⛔ 代价（必须显式声明） |
| :-- | :-- | :-- |
| ⭐ **只取单记录 pair** | ⛔ 耦合损失是**评测装置的伪影**，不是断言的缺陷；⭐ 排除它测的才是断言本身 | ⛔ 结论**不外推到耦合情形**；⭐ 且必须报告被排除的 27 个 pair / 83 条的规模 |
