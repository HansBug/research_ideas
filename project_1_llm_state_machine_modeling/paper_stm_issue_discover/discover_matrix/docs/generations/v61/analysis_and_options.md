## 3. L2 命中在 v61 上的深挖

L2 39 条、117 单元。v60 → v61：`hit@1` 100 → 97，`hit@3` 36 = 36，`hit@all` 31 → 28；基线 45 / 25 / 7。逐条看，v61 收回 11 单元、丢 14 单元。

**收回的 11 单元**全部来自源–语义分歧审计直接点名的条目：`EIS-0009-03`（FinishState 首次提及嵌套，1 → 3 轮）、`EIS-0049-02`（同形，1 → 3）、`INS-0056-01`（无标签闭环，0 → 3）、`INS-0012-01`（2 → 3）、`EIS-0010-03`（2 → 3）。它们在 v60 靠语义候选偶然命中，在 v61 由确定性检查稳定命中。

**丢失的 14 单元**分两个机制：

1. **因果折叠的关系粒度代价（9 单元）。** `DIFF-0053-01`（3 → 0）、`EIS-0002-02`（3 → 1）、`INS-0019-01`（3 → 2）、`INS-0046-03`（3 → 2）、`INS-0053-02`（3 → 2）。v60 由 G1「作用域不可达」或事件消费覆盖报告单独命中；v61 把这些症状折成结构根因报告的子主张，judge 对根报告的主主张只给 PARTIAL。子主张里写全了缺陷，但对应关系以根报告为准。
2. **终止前沿不稳定（5 单元）。** `INS-0029-05`（3 → 0）、`INS-0039-04`（3 → 1）、`EIS-0029-05` 在 v60 由「共享终止目标 FinishState」的终止报告命中；v61 去掉 `state_role` 依赖后，这三对里终止契约的目标状态仍未解析成候选，需要与根可达同样的 NL 词元回退锚定。

结论：v61 在 L2 上的能力上界不变（`hit@3` 36 = 36），损失全部是发布层的报告合并与一条前沿的解析稳定性，不是发现能力退化；两项都有确定性修法（第 5 节 B、C）。

## 4. 三个研究问题在 v61 上的状况

### 4.1 RQ1 发现覆盖

整体 +22.6 pp，L0 +21.1 pp，L1 +0.9 pp，L2 +44.4 pp；`hit@all` 82 对 47。逐轮 113 / 98 / 112 对 75 / 71 / 79。L1 由 v60 的落后 14 pp 变为持平（35 条里方法赢 10、基线赢 9、平 16），原因是分歧审计把 v60 里被投影抹平的记法层事实（复合标签、首次提及嵌套、仅 stereotype 子机、无标签边）变成了确定性候选。RQ1 的叙事不需要改方向，只需要把「L1 略低于基线」改成「L1 持平」，把 L2 的差距从 47 pp 改成 44 pp。

### 4.2 RQ2 报告有效性

精确率拉平（84.1% 对 83.4%），报告量 903 对 512。无效报告 144 条的构成：D0 158 条中判 I 的 77 条（其余 81 条 D0 因 FULL/PARTIAL 关联被闭合为 K）、`FALSE_POSITIVE` 52 条、NADC 15 条。NADC 从 v60 的 58 条（同 judge）降到 15 条，即 v60 大纲里的「表示债务」一节在 v61 上基本兑现为可消除的适配器边界，而不是方法的固有上界；论文 §2.3 与 §7.1 的措辞要相应改写。剩余 I 的最大家族是语义候选的迁移端点错目标（33 + 14）、S3 触发集不一致（10 + 11）与 S5 缺守卫余项 12 条，已没有单一确定性规则可拦。N 报告 198 条（D2 114 / D1 84）对基线 134 条（79 / 55）；v60 上做过的台账外 D2 跨臂去重分析没有在 v61 上重做。

judge 的 K 闭合规则是 relation-first：核心事实成立且与台账条目 FULL 或 PARTIAL 关联的报告闭合为 K，即使 D 档为 D0。v61 的 561 条 K 里有 81 条 D0，基线 293 条里有 24 条。只把 D2/D1 计为有效时，报告级有效率为 678/903 = 75.1% 对 403/512 = 78.7%，FULL `hit@1` 为 294/435 对 212/435。方向不变、差距缩小，这个敏感性必须进论文。

### 4.3 RQ3 证据强度与谓词使用

W2 份额下降是 v61 最大的叙事代价。FULL 命中单元 323 个里 137 个达 W2（含折叠子主张的回执；仅看根报告 127），L0 65/153、L1 12/73、L2 60/97；报告级 W2 267/903。v60 同口径为 176/292、L2 82/100。两条原因：

1. **分歧审计报告按构造是 W1。** 九项检查（C1.1–C1.9）是对作者源文本与投影语义的确定性比对，有作者行号锚点，但不经过 19 条谓词、不产生回放回执。50 个 FULL 命中单元只由这类报告承载（L0 12、L1 28、L2 10）。
2. **因果折叠把带回执的症状报告折进了 W1 的结构根报告。** 子主张的回执仍在证据记录里，但根报告的 W 取根自身；按根报告算是 127，把子主张回执算进去是 137。

谓词使用：有终止回执的谓词 12/19（1114 条终止回执，其中 541 条 `violation`、573 条 `pass`），绑定到报告的 8/19（453 条报告），绑定到有效报告的 7/19（S1 的 2 条绑定均为 I）。R2 在带路由令牌的模型上撤回，3 条终止回执、0 条发布；V4 66 条绑定里 61 条有效，G1 60 条里 59 条有效，与 v60 里 R2 32 条绑定全为 I 的局面相比，绑定到无效报告的谓词问题已经消失。W2 报告按谓词：S2 102、S3 66、V4 59、S5 22、G1 12、G2 3、S4 3。

对 C2 主张的影响：v60 大纲写「一半以上的命中从主张变成见证（168/310）」，v61 只能写「四成命中携带可回放回执（137/323），L2 上六成（60/97）」。这句话仍然成立且基线为零，但摘要与结论的措辞要降一档。

## 5. 出路

按学术可辩护性与收益排序。A、B、C 都是确定性改动，不触碰提示词、不看台账。

| 出路 | 改什么 | 预期影响 | 代价与风险 |
| :-- | :-- | :-- | :-- |
| A. 分歧审计注册为带回执的检查族 | 九项检查里八项是纯源级比对（作者文本对投影语义），可注册为「D 族」类型化检查，附作者行号、比对项与布尔结果，走同一份回执与回放合同 | W2 单元约 137 → 187/323，L2 约 60 → 70/97；不改任何命中 | 需要论证它们与 S/G/R/V 四族并列的学术资格（UML 2.5.1 的语义规则与 PlantUML 文法是现成依据）；不能追溯改 v61 已发布的 W |
| B. 收窄因果折叠 | 只折死端 / 终止 / 事件消费这类行为症状，G1 作用域不可达与事件消费覆盖作为独立报告发布 | 收回约 20 单元（L2 约 9），`hit@1` 约 323 → 343 | 报告量约 +60 条，报告级精确率下降 1–2 pp；需要重跑或至少重判 |
| C. 终止前沿的 NL 词元回退锚定 | 与根可达同样的锚定 | 收回 6–8 单元（L2 5） | 无副作用；需要重跑 |
| D. 全称事件义务 | C2.2：描述里「任一状态下事件 X 都应……」类义务的候选生成 | `EIS-0030-02`、`VU-0046-01` 等三轮均未命中的条目 | 新候选源，需要事前登记与泄漏审查 |
| E. 契约抽取轮次上限失败 | 把解析错误定向回灌，不耗尽轮次（0045 r1） | 去掉重采样格 | 工程修复，单格重跑 |
| F. v61 人工裁定 | 对 903 条报告按 v60 协议做人工 D/A 与对应关系 | 把仪器偏移从「v60 上估计」变成「v61 上测得」；投稿前必需 | 约 1271 条 v60 的人工工作量的七成 |
| G. C1 开/关消融 | 大纲 RQ4 的门 `TODO-EXPERIMENT-01` | 分离确定性检查事实的独立作用 | 全量运行 + judge，成本约一次 v61 |

**建议顺序**：先把大纲改到 v61 口径并合并（本轮），再做 A + B + C 一次性重跑（一次 54×3 运行与 judge，约 $7.5 + judge 约 5 小时），随后启动 F。A 不改命中只改 W 的记账方式，B、C 改命中；三者合并重跑后预计 `hit@1` 约 345/435、W2 约 200/345、精确率约 82–83%。

## 6. 仪器偏移与阅读方式

同一 judge 在 v60 全量人工裁定（1271 + 512 条）上的逐报告 K/N/I 一致率为 75.3%（方法侧）与 75.8%（基线侧）；聚合偏移为方法侧精确率 −5.9 pp、`hit@1` −18 单元，基线侧 +2.0 pp、−2 单元（judge 减人工）。偏移方向对方法不利，因此 v61 的两臂差距按人工口径更可能被低估而非高估；但这只是 v60 上的估计，v61 的人工裁定（出路 F）完成前不能写成 v61 的事实。judge 的轮间噪声未单独测量。
