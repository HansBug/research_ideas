### ⭐ 最有力的一条：修订轮数几乎完全不变

    v23   均值 3.71   max 11   分布 {1:12, 2:15, 3:10, 4:10, 5:3, 6:6, 7:5, 8:2, 10:2, 11:1}
    v24   均值 3.76   max 11   分布 {1:13, 2:10, 3:15, 4:5, 5:9, 6:4, 7:5, 8:2, 9:1, 10:1, 11:1}

    差 +0.05；逐格 26 升 / 20 降 / 20 持平（接近对称）

**这比「issue 数不可归因」更有力**，因为 issue 数是**末端产物**（受多重因素影响），而修订轮数是**过程量** —— 它直接反映 reviewer 的判断是否变了。

因果链是：`_occupies` 语义改变 → 断言结果改变 → reviewer 接受/拒绝改变 → 修订轮数改变。**若修复改变了 pipeline 的行为路径，修订轮数最该动 —— 而它没动。**

📌 这个角度我没预期到。它从「过程未变」而非「产出未变」的方向支持了同一结论。
