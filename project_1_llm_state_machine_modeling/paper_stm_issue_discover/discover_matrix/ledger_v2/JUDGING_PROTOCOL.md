## 二、⭐ 命中判据（三条全部满足才算命中）

一格算**命中**，当且仅当该格的产出里**存在至少一条 issue**同时满足：

1. **同一处**：它指认的元素或位置与台账条目指认的是同一处（同一状态 / 同一迁移 / 同一事件 / 同一区域 / 同一表达式）。⚠️ 元素名相同但指的是别处（例如同名状态在不同复合态内）不算。
2. **同一性质**：它主张的毛病与台账条目主张的是同一种（缺失 / 多余 / 错位 / 不可达 / 无出路 / 不终止 / 层次归属 / 记法槽位 / 数量）。⚠️ 指对了元素但说的是另一种毛病不算。
3. **不要求同措辞、不要求同深度**：散文表述、只说后果不说机制、没给出可执行断言 —— ⭐ 都仍算命中。⛔ 本判定测的是**覆盖**，不是表达质量。

## 三、⛔ 五条明确不算命中

1. ⛔ **只说了上位类**：台账说「`AutonomousFinal` 无出边导致永不终止」，产出只说「模型缺少终态」——⚠️ 后者没有指认同一处。
2. ⛔ **方向相反**：台账说「模型多了 NL 未点名的 `InitialState`」，产出说「模型缺少 `InitialState`」。
3. ⛔ **顺带提及**：元素名只出现在另一条 issue 的举例或背景里，该 issue 的主张是别的事。
4. ⛔ **对参考模型或对 NL 的抱怨**：产出指认的对象不是被测的作者制品。
5. ⛔ **同一格内多条 issue 拼起来才凑成台账的主张**：⚠️ 允许一条 issue 覆盖台账的一个合取项（记为命中），⛔ 但不允许把两条不相关的 issue 强行合并。⭐ 判据是「是否存在**一条** issue 指认同一处同一性质」。

## 四、指标口径

- **`hit@1`** = 命中格数 / 总格数（每条 6 格）—— 一次运行的期望产出
- **`hit@3`** = 每个（记录 × 模型）单元中三轮至少命中一次的比例 —— 该缺陷是否在能力范围内
- **`hit@all`** = 三轮全部命中的比例 —— 稳定性

⭐ 三者必须一起给（[CLAUDE.md](../../../../CLAUDE.md) §3.5.2）。按 `L0/L1/L2` 与 `D2/D1` 拆分时口径不变。

## 五、⚠️ 本判定的已知限制（必须随数字一起报）

1. ⚠️ **判定人是本 session 的模型自身，无第二判读者复核，无判定者间一致性系数。** ⛔ 故这批 336 个判定只能读作「一轮全量单人判定」，不是「已证明无误」。
2. ⚠️ **`VU-` 一族（12 条）的命中带构造性**：它们本身就是从各臂**未认领产出**里提取的台账漏记，其中若干条出自 X1 自己。⛔ 报数时必须把 `VU-` 单列，不能与其它族混在一个总数里当独立测量。
3. ⚠️ **`EIS-` 那 89 条沿用他人判定**（J1–J8），与本轮 56 条不是同一判定人。⛔ 两部分的口径差异无法量化，故除合计外必须分别给出。
4. ⭐ **判定只看 `parsed_output.issues`**，不看 `analysis` 自由段 —— 那与既有 588 位判定的口径一致。
