**缺陷描述**

NL 第 5 句 'The system begins in the Accelerating substate' 与第 8 句 'The system enters the Accelerating substate when motion begins' 共同要求进入 InMotion 后默认落到 Accelerating。作者正确建了复合状态与三个子状态，却漏了内部初始伪状态，导致 InMotion 被进入后活动子状态未定义。FCSTM 确认投影出 state UnspecifiedInitial 与 [*] -> UnspecifiedInitial，并额外补了两条 UnspecifiedInitial -> [*] 路由边。这是丢失 NL 明确要求的初始化语义。

**NL 依据（复核者逐字引用）**

> NL 第 5 句逐字含 'The system begins in the Accelerating substate'；NL 第 8 句逐字含 'The system enters the Accelerating substate when motion begins'。
