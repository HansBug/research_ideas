# Superseded Judge-Exposed Witness Review v1

This directory preserves the first X1v2 W-level review material exactly as it
stood before acceptance. Its work items exposed `judge_association`, including
validity and expected-relation linkage. That exposure makes the resulting
labels arithmetically reproducible but insufficient as a Judge-independent
manual witness audit.

The files are retained for provenance only. They are not read by the final
recomputation, report, or acceptance checks. The accepted audit uses the
`paper1.x1v2-witness-review-packet.v2` packet and its blinded decision batches:
those packets contain only the original finding, method-record pointer and
hash, and the hash-verified NL and PlantUML input closure. Judge linkage is
attached only after the two review passes complete, for evaluator-side hit
aggregation.

No frozen method, Judge, or raw artifact was modified when this review material
was superseded.
