## 6. 分类说明

1. `一级总判定` 默认使用：
   - `软件工程`
   - `系统软件`
   - `程序设计语言与形式化基础`
   - `跨域/待判定`
2. `软工纳入判定` 默认使用：
   - `属于软件工程`
   - `跨域但软工主导`
   - `不属于软件工程`
   - `待判定`
3. 对 `跨域/待判定` 条目，应单独判断是否“软工主导”。
4. `判定依据（X1/D1-D4）` 默认用于记录最小可追溯的软工判定依据。
5. 只有 `软工纳入判定` 最终落到 `属于软件工程` 或 `跨域但软工主导` 时，才填写 `软工主路径（x.x.x）` 与 `软工次路径/标签`。
6. 软工主路径与次路径默认参考 [../SOFTWARE_ENGINEERING_FIELD_TREE.md](../SOFTWARE_ENGINEERING_FIELD_TREE.md)。
