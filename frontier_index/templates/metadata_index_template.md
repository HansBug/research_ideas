## 6. 分类说明

1. `一级总判定` 默认使用：
   - `软件工程`
   - `系统软件`
   - `程序设计语言与形式化基础`
   - `跨域/待判定`
2. 对 `跨域/待判定` 条目，应单独判断是否“软工主导”。
3. 若跨域条目最终被判定为“软工主导”，建议把 `一级总判定` 最终记为 `软件工程`，并在 `软工次标签` 或 `备注` 中保留 `跨域` 标记。
4. 只有 `一级总判定` 最终落到 `软件工程` 时，才填写 `软工主标签` 与 `软工次标签`。
5. 软工主标签与次标签默认参考 [../SOFTWARE_ENGINEERING_FIELD_TREE.md](../SOFTWARE_ENGINEERING_FIELD_TREE.md)。
