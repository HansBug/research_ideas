# `paper-intro`

这是母论文 [behrmann03-real-time-data-structures/README.md](../README.md) 的 introduction 拆分稿，对应 thesis 的总入口部分。

## 这一部分主要解决什么

1. 交代 thesis 为什么把 `visualSTATE`、CDD、priced timed automata 和 `UPPAAL` 架构放进同一条主线。
2. 给出 formalism 与 data structures 的总览。
3. 解释 `The Making of Uppaal` 这一层的架构语境。
4. 提供后续 papers A-F 的 thesis 级 summary。

## 什么时候优先读

1. 当你第一次进入这篇 thesis 时，优先读它。
2. 当你只想拿整体地图，再决定读哪篇子论文时，优先读它。
