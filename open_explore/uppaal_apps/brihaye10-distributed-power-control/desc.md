验证收获一句话：论文给出了移动节点空间中的可连接区域图像，揭示了离散功率量化会导致非直觉的“灰环”与空洞区域，并可进一步回放策略解释这些现象。

## 简报

这篇论文验证的不是协议报文本身，而是无线网络里“该把功率调到多大才能维持连接”的策略问题。作者把功率控制视为一个发送端对抗环境的 timed game，因此能在离散功率和异步节点假设下直接综合出获胜策略。

- 系统：`2` 对发射机/接收机组成的无线干扰信道，其中 `Tx1` 为可移动笔记本，`Tx2` 为固定终端。
- 特点：离散功率级、`SINR` 约束、节点可异步开关、环境行为不完全可控。
- 规模：功率离散集为 `{11,14,17,20,23,26,29}` dBm；关键场景为 `1` 个移动发送端 + `1` 个固定发送端 + `2` 个固定接收端。
- 模型：发送端、观测器和环境被翻译为 timed game / automata，目标写成 `TATL` 性质。
- 性质：三类连接保障性质，分别对应短报文可靠发送、持续连接和最强即时连通。
- 方法：`UPPAAL-TiGA` 检查是否存在控制策略，使目标性质无论环境如何变化都成立。
- 结果：得到不同空间位置上的可满足区域图，并发现离散功率会造成非单调连接区与策略空洞。

`无线场景参数 -> timed game -> TATL 连接性质 -> TiGA 策略综合 -> 覆盖区域与解释`

## 论文定位

本文是 `⏱️ + 🌐` 的资源/性能验证案例。被验证对象不是 MAC 协议，而是链路层以下的功率控制策略；虽然论文带有明显的方法学成分，但案例设置具体、性质清晰，因此仍属于应用验证文献。

## 验证对象与问题背景

### 系统与场景

被验证对象是分布式无线功率控制。典型应用场景是无线终端在共享频谱和互扰条件下，自主调节发射功率以维持通信质量。

### 系统组成与运行机制

论文的核心组件包括：

1. `Tx1/Rx1`：移动发送端与固定接入点
2. `Tx2/Rx2`：固定发送端与固定接入点
3. 干扰信道与路径损耗模型
4. 发送端开/关状态与离散功率选择机制

发送端在每个时间片内可以上调、下调或维持功率，并受最小开/关时间、最大 `SINR` 与目标 `SINR` 窗口等约束。

### 验证边界

本文验证的是**离散功率控制层面的连接保障问题**，不是完整多跳网络协议，也不建模更复杂的 MAC/路由协作。

### 核心问题

当发射功率只能离散取值时，很多经典连续优化/Nash equilibrium 结果不再适用；作者更关心的是，在这种现实限制下，是否存在保证连接性质的策略。

### 研究动机

作者想用计算式的 timed game / model checking 方法，替代传统解析证明，以覆盖离散功率和不完全信息等更现实的无线条件。

## 模型与形式化建模

### 建模对象

1. 发射机的开/关状态与功率级切换
2. 观测器对 `SINR` 与时间窗的跟踪
3. 环境发射机的非受控行为
4. 路径损耗下的空间位置变化

### 模型形式

论文把功率控制问题翻译成 timed game。发送端是控制方，环境是对抗方；目标性质用 `TATL` 表达，并交由 `UPPAAL-TiGA` 综合获胜策略。

### 关键抽象

1. 发射功率限定在 `7` 个离散值。
2. 移动终端在二维网格上移动，通过路径损耗公式确定 `h_ij`。
3. 只分析 `2` 对通信对，从而突出干扰与离散功率效应。

## 验证目标与性质

### 待验证问题

作者定义了三条分层性质：

1. 性质 1：在给定时间窗口内能维持一定 `SINR` 水平完成通信。
2. 性质 2：在更严格的设定下保证连接持续保持。
3. 性质 3：在固定信道状态下最终能够可靠发送短报文。

### 性质类型

1. 有界响应
2. 连接保持 / 安全性质
3. 资源控制策略综合

### 性质分组与实际含义

1. 可靠性窗口
   某段时间里是否能把 `SINR` 保持在目标区间。
2. 持续连通性
   通信建立后是否不会很快丢失。
3. 即时连接可达性
   固定场景下是否存在最终可连通的策略。

### 查询表达

论文把这些目标翻译成 `UPPAAL-TiGA` 的 controllability 公式，本质上是：

1. 是否存在策略使观测器始终保持在 `Emit/Emit2` 等成功状态中。
2. 是否能避免进入阻塞状态。

## 核心方法与验证流程

1. 先定义无线干扰信道与离散功率集合。
2. 为每个发送端构造带开/关循环和功率调整动作的 automaton。
3. 引入 observer automaton 监测连接性质是否被满足。
4. 将移动发送端位置参数化，逐点检查三条性质是否可满足。
5. 用 `UPPAAL-TiGA` 输出空间区域图，并通过策略回放解释异常区域。

## 案例与结果

### 案例规模

1. `Tx1` 可移动，`Tx2` 固定，`Rx1/Rx2` 固定。
2. 离散功率级为 `11-29 dBm`，步长 `3 dBm`。
3. 关键参数包括 `γ-=5 dB`、`γmin=10 dB`、`γmax=13 dB`。

### 主要结果

1. 对性质 `I(1,3)`，作者得到以 `Rx1` 为中心的可达区域图。
2. 图中出现了一圈反直觉的灰色环带，表示随着距离增加，连接先失效后又恢复。
3. 通过减小功率量化步长，灰环现象减弱，说明问题与离散功率量化直接相关。
4. 对 `I(2,1)`，作者发现 `Tx1` 的位置会以非单调方式影响 `Tx2/Rx2` 连接，这对仅基于距离的感知算法提出警示。

### 结果解释

这篇论文最有价值的发现不是“能连还是不能连”，而是 `UPPAAL-TiGA` 能帮助解释离散功率导致的非单调空间效应，这种现象用传统解析法并不直观。

## 与本研究的关系

### 相关性分析

本文说明，对于带资源约束和环境对抗的控制问题，性质不必只写成静态公式，还可以写成“存在控制策略使目标总能满足”的形式。

### 可借鉴之处

1. 用 observer 把工程连接要求变成形式化性质。
2. 用参数化空间扫描把验证结果直接映射回实际布局。
3. 用策略回放解释异常区域，而不是只输出真/假。

### 存在的不足与改进空间

1. 案例规模较小，仅 `2` 对链路。
2. 未给出公开模型工程。
3. 更偏链路层功率控制，而非完整控制系统状态机。

### 对本研究的启发

若博士研究后续涉及时间窗、资源级别与环境对抗，则 timed game + observer 的写法值得借鉴，可把“需求是否总能被控制策略保证”直接纳入验证目标。
