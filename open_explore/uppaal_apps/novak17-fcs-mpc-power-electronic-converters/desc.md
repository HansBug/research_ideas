## 简报

这篇论文把 `UPPAAL SMC` 拉进电力电子控制验证流程，目标不是证明一个离散逻辑永不出错，而是回答“控制器在大量随机瞬态下大概率能不能压住误差”。作者用的对象很典型：`UPS` 中的标准两电平 `VSC` 和 `LC` 滤波器，因此它既是具体应用案例，也是后续一整条 power-electronics `SMC` 论文线的起点。

- 系统：`UPS` 用两电平 `VSC`、`LC` 输出滤波器与 `FCS-MPC` 控制器。
- 特点：离散开关控制作用在连续电气系统上，需同时权衡电压误差、`THD` 与平均开关频率。
- 规模：标准 `2-level VSC` 三相拓扑；论文给出多组权重因子、负载变化和参数不确定场景，并辅以 `Simulink` 与实验对照。
- 模型：`UPPAAL SMC` 中的可执行随机模型，结合随机负载变化与参数误差。
- 性质：瞬态电压偏差阈值概率、简单移动平均阈值概率、`THD` 与 `fsw` 折中。
- 方法：`UPPAAL SMC` 统计查询 + `Simulink` 基准模型 + 实验平台三方对照。
- 结果：在 nominal 场景下，若把误差阈值放到 `10%`，模型给出高概率满足；同时论文展示了 `THD` 与平均开关频率可通过权重因子显式折中。

`UPS 变换器与控制器 -> 随机负载/参数不确定 -> UPPAAL SMC 概率查询 -> 误差/THD/fsw 量化结论`

## 验证对象与问题背景

### 系统与场景

被验证对象是 `UPS` 应用中的标准两电平电压源变换器（`VSC`）及其 `FCS-MPC` 控制器。该系统需要在负载变化时仍提供满足标准的输出电压质量。

### 系统组成与运行机制

系统核心包括：

1. 两电平 `VSC` 开关桥。
2. `LC` 输出滤波器。
3. 负载侧电压/电流测量。
4. 以采样周期反复选择电压矢量的 `FCS-MPC` 控制器。

控制器在每个采样步根据预测模型和代价函数选取下一时刻的开关动作，输出质量则通过电压偏差、`THD` 与平均开关频率体现。

### 验证边界

论文验证的是**变换器控制层的动态性能**，不是整套 `UPS` 产品的软件、硬件寿命或电网级交互逻辑。负载变化与参数偏差被建成随机环境，用于测试控制器鲁棒性。

### 核心问题

1. `FCS-MPC` 在电力电子里设计直观，但缺少工程上容易使用的性能验证方法。
2. 单靠有限次仿真或实验，很难对“在各种随机负载变化下是否仍满足要求”形成有置信度的结论。
3. 权重因子会同时影响 `THD` 和开关频率，需要量化折中而不是凭经验选取。

### 研究动机

作者想说明：对 power electronics 而言，`UPPAAL SMC` 不是只适合协议或调度问题，它也能作为控制器性能验证工具，给出带置信区间的概率结论。

## 模型与形式化建模

### 抽象对象

作者把 `VSC`、`LC` 滤波器、负载和 `FCS-MPC` 控制算法抽象为 `UPPAAL SMC` 中的随机可执行模型。离散控制决策与连续电气量演化一起进入模型。

### 模型形式

论文使用的是 `UPPAAL SMC` 的 stochastic timed/hybrid 建模能力。核心不是普通离散自动机，而是能表达采样、连续演化与随机负载变化的可执行统计模型。

### 关键状态与参数

模型重点保留：

1. 输出电压与参考电压的差值。
2. 不同权重因子下的代价函数行为。
3. 负载瞬变。
4. 参数不确定性对预测模型的影响。

### 抽象边界

更细的半导体物理、热模型和复杂电网交互未被展开；论文主要面向“控制器能否在给定误差界下工作”的验证任务。

## 验证目标与性质

### 待验证问题

1. 负载跃迁时输出电压误差能否维持在给定阈值内。
2. 简单移动平均后的误差能否保持在阈值内。
3. 不同权重因子下 `THD` 与平均开关频率如何折中。
4. 参数误差引入后，满足阈值的概率如何变化。

### 性质类型

1. 统计性能性质。
2. 有界误差/有界响应性质。
3. 资源/性能折中性质。
4. 鲁棒性分析性质。

### 性质分组与实际含义

- `diff < θ`：瞬态负载变化后，参考电压与测得输出电压的偏差是否足够小。
- `SMA < θ`：平滑后的误差是否仍处于可接受范围。
- `THD / fsw`：输出波形质量与开关损耗之间的工程折中。
- 参数偏差查询：控制器对模型失配是否敏感。

### 查询表达

正文使用 `UPPAAL SMC` 估计类查询来回答“误差低于某阈值”的概率。例如对 `diff < 8% / 10% / 12% / 15%` 与 `SMA` 阈值分别做估计，再比较 nominal 与参数偏差情形。

### 判定边界与前提

结论建立在论文给定的 `VSC + LC` 结构、负载变化模式、权重因子集合和参数不确定范围之上，不应直接外推到其他功率等级或拓扑。

## 核心方法与验证流程

1. 先建立 `VSC + LC + FCS-MPC` 的 `UPPAAL SMC` 模型。
2. 再建立等价 `MATLAB/Simulink` 基准模型，并使用实验波形做交叉比对。
3. 通过 `UPPAAL SMC` 对误差阈值和参数偏差执行统计查询。
4. 比较不同权重因子下的 `THD` 与平均开关频率。
5. 以概率区间而非单次仿真轨迹来解释控制器性能。

论文真正多做的一步，在于把“多次仿真 + 经验观察”变成“统计查询 + 置信区间 + 跨模型对照”的正式流程。

## 案例与结果

### 案例规模

论文围绕标准两电平 `VSC` `UPS` 案例展开，给出多组权重因子、误差阈值和参数偏差场景，并辅以 `Simulink` 与实验平台波形。

### 主要结果

1. 权重因子 `λsw` 从 `0` 到 `0.5` 变化时，输出电压 `THD` 从约 `1.12%` 上升到 `3.38%`，而平均开关频率从约 `18.3 kHz` 降到 `10.2 kHz`。
2. 论文据此指出，像 `λsw=0.1` 这类取值能在 `THD` 与开关频率之间形成更可接受的工程折中。
3. 对 nominal 场景，论文给出多组 `diff < θ` 与 `SMA < θ` 的概率估计；阈值放宽到 `10%` 或更高时，可获得较高满足概率。
4. 在引入参数偏差后，误差阈值需要相应放宽，才能维持较高满足概率，说明该方法能够量化鲁棒性退化。

### 结果解释

最关键的工程价值不只是“控制器表现不错”，而是作者展示了怎样用 `UPPAAL SMC` 把控制器性能表达成概率结论，使权重选择和鲁棒性判断从经验式调参转成可验证流程。

## 与本研究的关系

### 相关性分析

这篇论文对本研究有代表性价值，因为它把连续物理控制对象压缩成可统计验证的自动机模型，并把性能要求写成可查询的阈值性质。

### 可借鉴之处

1. 将“误差阈值是否满足”写成统计查询，而不是只看仿真曲线。
2. 把环境不确定性显式建模为随机因素。
3. 用多源对照（`UPPAAL`、`Simulink`、实验）提升模型可信度。

### 存在的不足与改进空间

1. 主要关注性能与鲁棒性，不是更强的离散安全规约。
2. 公开工件不足，复现实验仍需手工重建。
3. 案例对象较单一，尚未覆盖更复杂拓扑和多控制目标场景。

### 对本研究的启发

它提醒本研究：控制系统验证不必局限于布尔安全性质，也可以把“误差低于阈值的概率”“参数失配下的满足率”纳入验证剖面。
