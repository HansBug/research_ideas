问题一句话：本文分析的是 `Running.Christel` 纳卫星的电池切换策略，核心问题是在随机任务负载下，控制器该如何在多块电池之间切换，才能尽量延长整机寿命。
方法一句话：作者把电池包、任务负载和切换控制器建成 stochastic hybrid model，并比较解析工具、`modes`、`Simulink` 与强化学习调度器在寿命阈值分析上的表现；同时明确把早期 `UPPAAL` 电池调度工作作为直接前身。
验证收获一句话：论文说明两电池设置下学习到的策略可逼近早期 `UPPAAL` 结果，而在四电池随机负载下 `Simulink` 中的 `DQN` 调度能把“寿命至少 `56 h`”的概率保持在约 `84%`，但 `Q-Learning` 面对大状态空间会明显退化。

## 简报

这篇论文是电池调度应用线中的边界条目。它的直接实验主线已经转向更一般的 stochastic hybrid modeling 与 `RL` 工具比较，但它明确把早期基于 `UPPAAL` 的两电池调度工作作为前身，并沿着同一应用对象继续扩展到更大的电池包和随机负载。因此可以作为 `UPPAAL` 电池调度主线的后续案例收录，但必须明确其边界。

- 系统：纳卫星 `Running.Christel` 的多电池供电系统。
- 特点：非线性 `KiBaM` 电池模型、随机任务负载、多电池切换决策。
- 规模：支持 `2`、`3`、`4` 电池设置；四电池示例使用 `[7, 8.5, 10, 12] Wh` 配置。
- 模型：stochastic hybrid automata / hybrid automata + `RL` 调度器。
- 性质：寿命阈值可达性、最优切换策略、达到给定寿命的概率。
- 方法：比较 `RealySt`、`prohver`、`modes`、`Simulink DQN` 等方案。
- 结果：两电池情形与早期 `UPPAAL` 结果接近；四电池随机负载下可得到较高寿命阈值达成概率。

`电池包与工作负载 -> 随机混合模型 -> 调度器学习电池切换策略 -> 评估寿命阈值可达性与概率`

## 论文定位

严格说，这篇论文的主贡献已经超出 `UPPAAL`，更偏 stochastic hybrid modeling 与工具比较；但案例对象和问题设置直接延续了此前的 `UPPAAL` 电池调度线，因此仍可作为 `🔋` 次轴的边界型后续条目。这里需要显式标注为 `🟡`，避免误读成“本文主实验仍然在 `UPPAAL` 中完成”。

## 验证对象与问题背景

### 系统与场景

案例是 `Running.Christel` 纳卫星。卫星在轨时需要拍摄图像、压缩图像并发送回地面站，因此电池切换策略直接决定整机寿命。

### 系统组成与运行机制

1. 卫星任务被抽象为一系列 jobs。
2. 每个 job 有到达时间、功率需求和服务时间。
3. 控制器在每次 job 到来时选择一块非空电池供电。
4. 若当前电池在服务过程中耗尽，则立即切换到另一块非空电池继续执行。

### 验证边界

论文关注的是**电池调度与寿命分析**，不是完整卫星姿态、通信协议或轨道控制逻辑。充电也被排除在外，只考虑单次放电周期。

### 核心问题

1. `KiBaM` 模型下的非线性恢复效应会让调度策略很敏感。
2. 电池数量增加后，状态空间迅速膨胀。
3. 随机负载下不能再只问“最大寿命是多少”，而要问“达到某个寿命阈值的概率是多少”。

## 模型与形式化建模

### 电池与负载模型

论文使用 `KiBaM` 表示电池内部的 available/bound charge 及 recovery effect。对 `N` 块电池的系统，需要为每块电池维护：

1. available charge `a_i`
2. bounded charge `b_i`
3. 是否已空 `e_i`

此外还需要全局变量跟踪当前寿命 `L`、当前 job、功率需求和剩余服务时间。

### 控制器

控制器根据当前 workload 选择电池。动作空间就是电池 `ID`，观察空间则包含：

1. 当前 lifetime
2. 电池切换次数
3. 当前 job 信息
4. 每块电池的 available / bounded charge
5. 电池是否已空

### 模型边界

论文显式指出，解析工具为了可算性，需要对 `KiBaM` 的 recovery effect 做 over-approximation，因此其结果更像寿命上界而不是真实可执行值。

## 验证目标与性质

### 待验证问题

1. 系统寿命是否能超过阈值 `L`。
2. 哪类调度器能最大化寿命。
3. 在随机 workload 下，达到某个寿命阈值的概率是多少。

### 性质类型

1. 资源寿命分析。
2. 概率阈值性质。
3. 策略学习 / 优化。

### 性质分组与实际含义

- deterministic workload：比较能达到的最大 lifetime。
- stochastic workload：比较 `Pr(lifetime >= L)`。
- analytical over-approximation：给出保守上界。

### 查询表达

原文没有给出 `UPPAAL` 公式；核心问题被表达为“寿命是否超过阈值 `L`”以及统计概率估计。这也说明它与经典 `UPPAAL` 布尔查询论文的写法不同。

## 核心方法与验证流程

1. 建立卫星 job workload 与电池系统模型。
2. 对两电池、三电池和四电池设置分别评估。
3. 用 `RealySt` / `prohver` 求 over-approximate 上界。
4. 用 `modes` 与 `Simulink` 中的 `Q-Learning / DQN` 学习切换策略。
5. 对随机 workload 再用统计方法估计达到不同寿命阈值的概率。

## 案例与结果

### 两电池确定性工作负载

对设置 `(2, 5.5 Wh, 0.166)`：

1. `RealySt` 和 `prohver` 的 over-approximation 都给出 `9.2 h`。
2. `modes` 与 `Simulink` 仿真结果约为 `5.75 h` / `5.73 h`。
3. 作者指出解析上界比仿真寿命高约 `60%`，因为 recovery effect 被放大。

### 两电池与三电池学习结果

对确定性 workload，表 3 给出：

1. 设置 `(i)` 下 `Simulink DQN` 与 `modes Q-Learning` 都达到约 `11.89 h`，接近早期 `UPPAAL` 工作中 `12.04 h` 的结果。
2. 当容量变大时，寿命可上升到 `30.97 h`、`73.23 h`、`224.97 h`。
3. 三电池设置 `(v)` 中，`Simulink DQN` 约 `23.58 h`，而 `modes Q-Learning` 仅 `15.8 h`，说明大状态空间下表格式学习明显退化。

### 随机工作负载与四电池系统

对四电池设置 `(4, [7, 8.5, 10, 12] Wh, 0.5)`：

1. 确定性 workload 下，`Simulink DQN` 学到的寿命约 `71.08 h / 59.01 h / 51.28 h`，与 uniform scheduler 的 `71.2 h / 59.2 h / 52 h` 接近。
2. 随机 workload 下，表 6 显示寿命至少 `56 h` 的概率约为 `84%`。
3. 更高阈值对应更低概率，符合任务服务时间采样带来的随机性。

### 相关性分析

这篇论文对博士研究的价值在于：它展示了“资源寿命 + 调度策略 + 随机负载”如何组织成一套稳定的验证问题，而不仅仅是控制器功能正确性。

3. 明确把上界分析和学习式调度结果分开讨论。
