问题一句话：本文验证的是软组织中的柔性针在线导航系统，核心问题是在存在未知障碍和轨迹偏差时，如何让针安全地避开关键区域并尽可能到达目标区域。
方法一句话：作者用 `UPPAAL Stratego` 建立针、用户、组织环境和状态检查器组成的 timed game 模型，并把它嵌入在线策略综合框架，反复执行“测量-更新模型-重综合-执行”闭环。
验证收获一句话：在虚拟针实验中，已知障碍场景下多数设置可达到 `100%` 目标到达率，真实针实验中虽然到达率下降到 `0%-66.67%`，但所有场景的关键区域命中率都保持 `0%`。

## 简报

这篇论文验证的不是单次离线路径规划，而是一个在线导航系统。模型必须在每一步都足够快，既能证明不会撞进 `CR`，又能随着观测更新重新合成策略。

- 系统：用户决策器 + 可控针 + 组织环境 + 状态检查器。
- 特点：`R^3` 几何运动、在线策略综合、部分未知环境、需要把连续空间压缩成可验证离散模型。
- 规模：样例模型含 `1` 个 `TR`、`1` 个 `CR`、`1` 个 `DR`；单轮最多 `10` 个动作、每轮最多 `2` 次旋转；在线实验含 `5` 类环境、虚拟针 `50` 次/设置、真实针 `5-7` 次/设置。
- 模型：User / Needle / Tissue / StateChecker 网络 + `R^3 -> Z^3` 的几何近似。
- 性质：存在安全到达路径、关键区域不可达、目标是否可达、在线综合是否来得及。
- 方法：离线 `ReachFinalTR` 综合 + 在线 `OSS` 周期重综合。
- 结果：虚拟针在多数已知障碍场景下 `100%` 到达且 `0%` 命中关键区；真实针虽有较多偏差与重规划，但依然保持 `0%` 关键区命中。

`测量初始运动圆 -> 离线综合安全计划 -> 执行中实时匹配 -> 偏差/障碍触发重综合 -> 直到到达或判定不可达`

## 论文定位

这是一个很典型的 `UPPAAL Stratego` 医疗 `CPS` 案例：它关心的不只是“针模型是否存在路径”，而是“在线控制框架能否在安全前提下持续工作”。

## 验证对象与问题背景

### 系统与场景

被验证对象是软组织内的 flexible beveled needle steering。典型场景包括活检和近距离放疗，需要把针送到目标附近，同时避开器官和危险组织。

### 系统组成与运行机制

`Uppaal` 模型包含四类主要组件：

1. **Decision Maker / User**
   - 发起旋转或前推动作。
2. **Controlled Device / Needle**
   - 执行 push / rotate 动作并更新几何状态。
3. **Environment / Tissue**
   - 表示目标区、关键区、检测区和未知区。
4. **State Checker**
   - 每步后检查路径是否有效、目标是否已达、目标是否仍可达、是否命中关键区。

### 验证边界

本文验证的是**几何级别的在线导航安全性与可达性**，而不是高保真组织力学或真实临床影像系统。

### 核心问题

连续 `R^3` 空间、软组织不确定性和实时性能要求天然冲突。过于真实的模型很难在在线场景中及时验证。

### 研究动机

作者希望找到一组可接受的离散化和运动限制，使模型既能被 `Stratego` 及时处理，又与真实针运动保持足够关联。

## 模型与形式化建模

### 状态与动作

模型维护：

1. 针尖位置、姿态、速度和 motion circle；
2. `TR/CR/DR` 的球形区域；
3. 推进与旋转动作序列。

### 关键抽象

1. **值域限制**
   - 把连续值缩放后存成整数，必要时在 `R^3` 与 `Z^3` 间转换。
2. **运动限制**
   - 旋转只允许 `90/180/270` 度；每轮综合最多 `2` 次旋转；两次旋转间必须有最小推进距离。
3. **环境限制**
   - 当前版本的 `TR/CR/DR` 都建成静态球体。

### 查询

论文给出的核心查询是：

1. `E<> Checker.Final_TRReached`
2. `strategy ReachFinalTR = control: A<> Checker.Final_TRReached`

它们分别对应“是否存在可到达路径”和“是否能综合一套面向最终目标的策略”。

## 验证目标与性质

### 待验证问题

1. 是否存在不穿过 `CR` 且能到达 `TR` 的路径；
2. 在线执行中如果轨迹偏差或发现新障碍，能否及时重规划；
3. 整个过程能否避免关键区域命中。

### 性质类型

1. **安全性质**
   - `CR` 不可达。
2. **可达性性质**
   - `TR` 是否可达。
3. **在线性能性质**
   - 局部综合时间与整体执行时间是否在手术场景可接受范围。

### 性质分组与实际含义

1. **局部安全**
   - 当前几何状态是否仍在安全轨迹集合中。
2. **全局可达**
   - 从当前状态继续执行是否还有希望到目标。
3. **在线适配**
   - 当偏差出现时，能否通过 pull-back 和重综合恢复安全。

## 核心方法与验证流程

1. 先推针少量距离测得初始运动圆。
2. 更新 `Uppaal` 模型并离线综合到目标的动作计划。
3. 执行计划的同时实时匹配观测数据。
4. 若发现偏差过大或检测到 `CR`，立即中止并回退。
5. 重新拟合模型、重综合策略并继续执行。

## 案例与结果

### 模型匹配实验

1. 离线轨迹匹配中，正常参考轨迹平均偏差约 `1.32-1.74mm`。
2. 错误轨迹平均偏差约 `1.78-2.60mm`。

### 虚拟针在线实验

在 `5` 类环境中：

1. `NoCR`：`100%` 到达，`0%` `CR` 命中。
2. `Small Mid CR / Surface CRs / Tunnel CRs` 的已知障碍版本：多数为 `100%` 到达。
3. `Large Mid CR` 已知障碍：系统立刻判断不可达，`0%` 到达。
4. 总体平均执行时间在 `5.18s` 到 `88.03s` 间，个别情形到 `120s` 超时阈值。

### 真实针在线实验

1. `NoCR`：目标到达率 `66.67%`。
2. `Small Mid CR`：`40%`。
3. `Surface CRs`：`57.14%`。
4. `Large Mid CR`、`Tunnel CRs`：`0%`。
5. 所有真实针场景 `CR hit` 均为 `0%`，说明安全约束保持住了。

## 与本研究的关系

### 相关性分析

这篇论文与博士研究中的“状态机建模 + 时间/安全验证 + 迭代修正”非常接近，只是对象从工业控制器换成了医疗导航。

### 可借鉴之处

1. 把“发现偏差 -> 重综合”做成显式工作流。
2. 用 `TR/CR/DR` 分层刻画目标、危险和早期预警区域。
3. 先承认连续世界无法直接验证，再设计有边界的离散抽象。

### 存在的不足与改进空间

真实针实验到达率仍有限，且环境模型简化为静态球体；没有公开独立仓库。

### 对本研究的启发

对博士研究而言，这篇论文说明：只要把“异常检测”和“重综合触发条件”显式进模型，就可以把在线修复纳入可验证闭环，而不是纯工程启发式。
