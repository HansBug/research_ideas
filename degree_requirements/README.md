# 博士毕业要求情报库

> 信息更新时间：`2026-06-16 22:05:00`（Asia/Shanghai）

本目录用于保存和整理 2022 级计算机学院**学术型博士**毕业 / 学位申请相关政策、邮件证据、非正式讨论线索和待补问题。它是毕业成果认定的证据库，不是行政最终解释；任何结论都必须能回到政策原文、老师邮件或加密 raw 档案复核。

**本 README 不是单纯入口索引，而是给博士生本人做毕业成果规划时优先阅读的核心决策页。** 读完本页应能初步判断：2014 版和当前新版候选各自要求什么、哪条路径更可能适合当前成果、哪些点必须找老师确认、哪些成果不应作为主路径冒险。

## 1. 一句话结论

1. **两版都可作为候选方案**：学院老师 2026-06-09 邮件已确认，2022 级博士生可在 2014 版与当前新版创新成果要求之间选择参照；因此后续规划必须同时评估 2014 版和新版候选，不应只押一边。
2. **2014 版更像“数量 + 收录源”路径**：计算机学院条款要求论文不少于 3 篇、至少 1 篇外文，并满足 `SCIE 2 篇`，或 `SCIE 1 篇 + EI/CPCI-S 2 篇且至少 1 篇为 EI 收录源期刊论文`。
3. **新版候选更像“高水平锚点 + 组合条件”路径**：对学术型博士，主依据候选是 CS/SE 学术型创新成果要求；核心是 Nature/Science/ESI 高被引，或至少 1 篇 CCF 推荐期刊 / JCR Q1 等重要期刊，再叠加奖励、专著、专利、CCF A 或不少于 2 篇重要期刊/会议论文等条件。
4. **两版共同硬风险很强**：第一作者 / 导师第一作者本人第二作者、第一署名单位北航、与学位论文密切相关、导师审阅、录用 / 刊出状态、证明材料都必须逐篇核对。
5. **当前保守建议**：先对所有候选成果建立逐篇资格审计表，同时按 2014 与新版两套规则分别打勾；在老师确认“能否混用”“新版具体文件”“外部论文例外”“2014 免盲审是否仍有效”之前，不把外部单位论文、多个仅录用论文、共同一作论文作为唯一主路径。

## 2. 2014 版 vs 当前新版候选：博士生最关心的对比

证据等级口径：🟢 = 官方政策 PDF / 老师正式邮件 / 已核原文；🟡 = 非正式讨论或仍需邮件确认。

| 对比维度 | 2014 版口径 | 2024 / 当前新版候选口径 | 对 2022 级学术型博士的含义 | 证据 |
|---|---|---|---|---|
| 是否可选 | 老师邮件确认可选择参照 2014 版 | 老师邮件确认也可选择参照当前新版创新成果要求 | 两版都要认真评估；但“能否混用”尚未确认，当前按“整体选择一版”保守规划 | 🟢/🟡 |
| 主文件 | 2014 版《北京航空航天大学关于申请博士学位发表论文的规定》，含计算机学院条款 | CS/SE 学术型创新成果要求是学术型博士新版候选主依据；实施细则管流程；电子信息文件是专业型对照 | 本用户是学术型博士，不能把电子信息专业型文件当主依据 | 🟢 |
| 基本结构 | 计算机学院要求不少于 3 篇，至少 1 篇外文，并满足两个基本要求之一 | 不是简单篇数要求，而是“高水平锚点 + 组合条件” | 2014 更容易按篇数核算；新版更看重成果层级与组合 | 🟢 |
| 可操作论文门槛 | `SCIE 2 篇`；或 `SCIE 1 篇 + EI/CPCI-S 2 篇且至少 1 篇为 EI 收录源期刊论文` | 路径 1：Nature/Science 及子刊 1 篇，或 ESI 高被引 1 篇；路径 2：至少 1 篇 CCF 推荐期刊 / JCR Q1 等重要期刊，再满足奖励、专著、专利、CCF A，或不少于 2 篇重要期刊/会议论文等条件之一 | 若已有稳定 SCIE/EI/CPCI-S 组合，2014 可能更可计算；若已有 Q1/CCF A/高被引/强主会成果，新版可能更合适 | 🟢 |
| 会议论文 | 2014 计算机基本要求允许 EI/CPCI-S 收录源；免盲审要求含 CCF A 类会议已发表；已核主体条款未明确主会/从会 | 明确会议论文必须为主会，不能是从会 | 若用会议论文，新版主会限制更明确；按 2014 用会议也建议向老师确认主会/从会口径 | 🟢/🟡 |
| 免盲审 / 评阅 | 2014 有“基本要求 / 免盲审要求”结构 | 实施细则写 2020–2023 级博士原则上至少 3 份“双盲制”评阅 | 2022 级若选择 2014，免盲审条款是否仍有实际作用必须问老师，不能自行假设 | 🟢/🟡 |
| 第一作者 / 导师第一作者 | 第一作者；或本人第二作者且导师 / 副导师第一作者 | 同左 | 导师通讯但非第一作者、外部合作复杂作者序都不能直接当合规 | 🟢 |
| 第一署名单位 | 第一作者及申请者第一署名单位只能是北航；国家留学基金委联合培养有最多 1 篇特定例外 | 第一作者及申请者第一署名单位须为北航 | 外部单位论文当前保守不纳入主路径，除非老师邮件确认例外 | 🟢 |
| 与学位论文关系 | 成果须与学位论文密切相关，投稿前导师审阅同意 | 成果须与学位论文密切相关，核心创新成果需在学位论文章节体现，投稿前导师审阅同意 | 弱相关论文即使级别够也有风险，需提前映射到论文章节 | 🟢 |
| 录用 / 刊出 | 仅允许 1 篇期刊论文处于录用状态，且各要求中级别最高的一篇必须正式刊出 | 所有论文成果中仅允许 1 篇处于录用状态，且级别最高一篇需已刊出；会议收录号 / DOI 等状态有细分 | 多篇 accept 未刊出不是安全路径；最高级别论文状态最关键 | 🟢 |
| 共同一作 | 可折算；合计不超过 1 篇；特殊情况需导师认定、共同一作声明、分委员会审核 | 还要求高被引 / JCR Q1 / 中科院 1 区 / CCF 目录等条件；合计不超过 1 篇，且成果不可全部为共同一作 | 共同一作只能做补充，不能作为全部毕业成果主路径 | 🟢 |
| 证明材料 | 图书馆检索证明、来源刊证明、封面、目录、首页；录用通知、版面费收据、底稿、DOI、版权转让等 | 已检索、已刊出未检索、已录用分别有材料要求，并需标注文章名、期刊/会议、本人姓名、第一作者单位、本人所在单位等 | 不能只看论文级别，必须提前按最终选用版本准备材料 | 🟢 |

## 3. 两条可选路径的难度、难点和适配场景

| 路径 | 最适合的成果状态 | 主要难度 | 主要风险 | 初步建议 |
|---|---|---|---|---|
| 2014 版 | 已有不少于 3 篇相关论文且其中至少 2 篇 SCIE；或已有 1 篇 SCIE + 2 篇 EI/CPCI-S，且至少 1 篇 EI 源期刊；署名单位和作者顺序均干净 | 要凑够不少于 3 篇，且每篇的 SCIE/EI/CPCI-S 收录源、EI 源期刊属性、外文篇数、刊出/录用状态都要证明 | 外部单位论文、多个录用未刊出、EI 会议与 EI 源期刊混淆、口语化 SCI/EI 误写成正式结论 | 如果成果更偏传统 SCIE/EI/CPCI-S 组合，优先把 2014 版算清楚；不要忘记至少 1 篇外文和最高级别已刊出 |
| 当前新版候选 | 已有 ESI 高被引、Nature/Science 子刊，或已有 JCR Q1 / CCF 推荐期刊等重要期刊锚点并可叠加 CCF A 主会、奖励、专著、专利等组合成果 | 门槛不只是篇数，必须有高水平锚点；“至少 1 篇重要期刊”和后续“不少于 2 篇重要期刊/会议论文”能否重叠计数仍需确认 | 把新版误解成“2 篇即可”、会议从会不合规、共同一作条件更严、最新版具体文件未被老师点名确认 | 如果已有高水平锚点，或已有重要期刊锚点并能叠加 CCF A / 主会 / 专利等奖励组合，新版值得并行评估；否则不要只按数量乐观估计 |
| 两版共同底线 | 论文都由本人第一作者，或导师第一作者本人第二作者；第一署名单位北航；与学位论文强相关；最多 1 篇录用状态；材料齐全 | 每篇论文都需要同时通过身份、单位、相关性、收录源、发表状态、证明材料六类审计 | 任一论文在单位、作者序、相关性或状态上出问题，都可能导致整条路径不稳 | 建议为每篇候选论文建立“资格审计表”，先排除高风险论文，再决定走 2014 还是新版 |

## 4. 按当前成果形态选择路径的初步策略

| 当前成果形态 | 初步偏向 | 原因 | 必须补证 / 确认 |
|---|---|---|---|
| 已有不少于 3 篇相关论文，其中至少 2 篇 SCIE，且均为北航第一署名单位、作者序合规、与学位论文强相关 | 先核算 2014 | 与 2014 第一条基本要求中的 SCIE 条件匹配，但仍须满足“不少于 3 篇”总量要求 | 是否均为 SCIE 收录源；第三篇是否属于相关国内外重要期刊/会议且材料可证；最高级别是否已刊出；是否满足至少 1 篇外文 |
| 已有 1 篇 SCIE + 2 篇 EI/CPCI-S，其中至少 1 篇 EI 源期刊 | 先核算 2014 | 与 2014 第二条基本要求高度匹配 | EI/CPCI-S 收录源证明；EI 源期刊证明；三篇状态和外文要求 |
| 已有 ESI 高被引 / Nature/Science 子刊，或已有 JCR Q1 / CCF 推荐期刊等重要期刊锚点并可叠加 CCF A 主会、奖励、专著、专利等成果 | 同时评估新版 | 新版可能更能利用高水平锚点或组合条件；单独 CCF A 主会是否足够不能乐观假设 | 老师确认新版具体文件；重要期刊锚点和组合条件是否可重叠计数；会议是否主会 |
| 论文主要来自外部单位或非北航第一署名单位 | 不建议作为主路径 | 两版都有北航第一署名单位约束 | 是否属于联合培养或其他可认定例外，必须邮件确认 |
| 多篇论文只是录用，尚未刊出或未检索 | 高风险，不宜作为唯一主路径 | 两版均限制录用状态，最高级别论文需刊出 | 哪篇是最高级别；是否已有 DOI、网络在线、卷期、收录号、来源刊证明 |
| 主要依赖共同一作 | 只能补充，不能全靠它 | 两版均限制共同一作折算，新版条件更严 | 共同一作人数、贡献声明、导师认定、分委员会审核材料 |

## 5. 不要误判的点

| 易误判 | 正确写法 / 当前结论 |
|---|---|
| “2014 就是 2 SCI 或 1 SCI + 2 EI” | 不要把口语传闻写成正式结论；正式写法是 `SCIE 2 篇` 或 `SCIE 1 篇 + EI/CPCI-S 2 篇且至少 1 篇为 EI 收录源期刊论文`。 |
| “老师说两版都行，所以可以混用条款” | 只能确定两版都可作为候选；能否混用尚未确认，当前保守按整体选择一版规划。 |
| “外部论文只要本人一作就能用” | 当前证据不支持；两版均有北航第一署名单位约束，特殊例外必须邮件确认。 |
| “新版只要 2 篇重要论文” | 新版是高水平锚点 + 组合条件，不是单纯 2 篇论文门槛。 |
| “2014 免盲审要求一定仍能免盲审” | 实施细则写 2020–2023 级博士原则上至少 3 份双盲；2014 免盲审条款对 2022 级是否仍有效需问老师。 |
| “2024 文件一定就是最新版” | 当前只能写作“2024 版 / 当前已取得新版候选”；老师邮件确认的是“最新版创新成果要求”可选，但未点名具体文件。 |

## 7. 当前定位

- 服务对象：2022 级计算机学院学术型博士。
- 核心问题：毕业 / 学位申请创新成果可以按 2014 版还是当前新版执行，论文成果如何认定。
- 当前最高置信结论：2026-06-09 老师邮件确认 2022 级博士生可在 2014 版与当前新版创新成果要求之间选择参照。
- 当前最大缺口：研究生院官方 `.docx` 附件入口已定位但下载仍受验证码/会话限制；当前主依据为自动化学院官方附件 PDF、研究生院 Wayback 快照和用户拍照原文。

## 10. 原始档案入库原则

- 原始邮件与聊天记录必须完整保存。
- 原始档案以 AES-256 加密 zip 入库，密码不写入仓库；本地通过 `.env` 的 `DEGREE_REQUIREMENTS_ARCHIVE_PASSWORD` 配置。
- Markdown 只写语义索引、关键结论、证据等级、SHA256 和 zip 内文件名；不逐字展开邮件/聊天原文。
- 复核原文时先执行 `source .env`，再运行：

```bash
python degree_requirements/scripts/archive_tool.py archives
python degree_requirements/scripts/archive_tool.py list
python degree_requirements/scripts/archive_tool.py test
python degree_requirements/scripts/archive_tool.py show --member MANIFEST.txt
python degree_requirements/scripts/archive_tool.py extract --output /tmp/degree_raw_check
```

当前只有一个加密 zip 时脚本会自动选择；未来有多个 zip 时，使用 `--archive <zip 文件名>` 或本地 `.env` 中的 `DEGREE_REQUIREMENTS_ARCHIVE_FILE` 指定目标档案。仓库文档和 PR comment 不写任何可复制的口令赋值样式。
