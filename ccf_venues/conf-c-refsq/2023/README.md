## 6. 与本仓库 project 的年度相关性观察

- P1：重点关注需求到模型、需求抽取、需求分类、需求质量、traceability 与 LLM / NLP for RE。
- P2：重点关注场景生成、requirements-to-specification、acceptance criteria、property / constraint mining、open science artifact。
- P3：关注 formal requirements、requirements validation、model checking / simulation / safety case 相关论文。
- P4：关注 requirements evolution、change impact、inconsistency detection、requirements repair / refinement 相关论文。
