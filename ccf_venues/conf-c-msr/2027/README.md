## 6. 与本仓库 project 的年度相关性观察

- P1：🟡 中：LLM 从需求到模型可借鉴软件仓库数据和 benchmark。
- P2：🟢 高：场景/性质生成需要真实项目数据、trace、issue、repository mining 证据。
- P3：🟡 中：验证 profile 的数据集构造和可复现实验可借鉴 MSR 数据实践。
- P4：🟢 高：缺陷、修复、维护、commit / issue mining 与模型修复密切相关。
