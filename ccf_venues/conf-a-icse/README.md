## 2. Scope 与方向

- ICSE 是软件工程旗舰会议，覆盖软件工程理论、方法、工具、实证研究与产业实践。
- 与本仓库最相关的方向：需求工程、模型驱动工程、软件验证、测试、程序修复、AI for SE、LLM for SE、软件工程工具评估。
- 明显不属于本仓库重点但仍可能相关的方向：教育、社会影响、会议组织、宽泛人因研究。

## 3. 与本仓库 project 的关系
