## 6. 与本仓库 project 的年度相关性观察

- P1：高相关，可追踪 AI/LLM 辅助建模、需求到模型转换、软件建模工具与评估论文。
- P2：高相关，可追踪测试场景生成、规格/属性生成、需求质量分析与 benchmark 论文。
- P3：高相关，可追踪模型检查、形式化验证、可靠性分析与验证工具论文。
- P4：高相关，可追踪自动修复、缺陷定位、反馈驱动修复、LLM repair 论文。
