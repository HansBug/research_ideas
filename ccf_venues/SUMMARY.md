## 2.5 外部索引与分区核验口径

- `CCF`：只用 `🏆 / 🥈 / 🥉 / ⚪ / ❓` 表示 CCF 三档、未列入、待核验；CCF 官方目录是主证据，镜像只能作发现线索。
- `WoS / CPCI`：`🟢` 表示期刊 WoS collection 行级证据，`🟠` 表示会议卷 / proceedings 级线索，`🟡` 表示部分核验，`⚪` 表示不适用或未查到，`🔴` 表示已检索未获行级证据，`⏳ / ❓` 只用于已检索未获可审计证据或尚未启动场景。
- `JCR` 与 `CAS`：只用 `1️⃣ / 2️⃣ / 3️⃣ / 4️⃣ / ⚪ / ⏳ / 🔴 / ❓`；列名决定 JCR Q1--Q4 或 CAS 1--4 区含义。第三方公开镜像只能作为二级可审计证据，必须在 venue README 标明“非 Clarivate/CAS 官方导出”，且不得把 `索引核验` 升级为 `🟢`。
- `EI / Compendex`：`🟢` 只给 source-level 期刊或等价精确 source 证据；`🟠` 给单年 proceedings；`🟡` 给 LNCS / LNBIP / CCIS 等 book-series 或部分核验；`🔴` 给已检索未获可审计行级证据。
- `索引核验`：`🟢` 仅代表官方证据齐全；`🟡` 代表部分核验或二级证据降权；`🔴` 代表已检索未找到关键证据；`⏳ / ❓` 只允许作为明确阶段状态，不能作为已完成条目的甩锅占位。
