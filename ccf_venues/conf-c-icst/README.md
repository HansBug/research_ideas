## 2. Scope 与方向

ICST 聚焦软件测试、验证、验证与验证确认、tool competition、industry、journal-first 与 workshops；本库必须把 Research track 与 series-wide DBLP 记录分开。

## 3. 与本仓库 project 的关系

| Project | 相关性 | 说明 |
