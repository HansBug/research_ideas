## 6. 与本仓库 project 的年度相关性观察

- P1：若 2022 年 STVR 出现模型驱动测试、状态/行为模型测试或规约驱动测试论文，可回流 project_1 作为邻近文献入口。
- P2：testing / verification 方向与验证场景、待验证性质、oracle 和需求到测试链路强相关。
- P3：verification / reliability 方向与模型检查、验证剖面、形式化验证证据链强相关。
- P4：若论文涉及测试反馈驱动修复、可靠性改善或缺陷定位，可作为 project_4 检索入口。
