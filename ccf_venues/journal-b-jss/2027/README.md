## 6. 与本仓库 project 的年度相关性观察

- P1：JSS 覆盖 requirements、design、architecture、AI for SE 和 model-driven engineering，适合作为状态机结构化建模的综合 SE 投稿/检索入口。
- P2：verification and validation、testing 与 evidence-based software engineering 可支撑验证场景与待验证性质生成。
- P3：当论文包含 formal proof、simulation、model checking 或 reliability evidence 时，可与验证剖面和模型检查主线对齐。
- P4：maintenance、evolution、reliability、dependability 和 fault localization 可支撑模型修复与缺陷闭环。
