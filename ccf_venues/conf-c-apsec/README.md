## 2. Scope 与方向

APSEC 是亚太软件工程综合会议，覆盖 empirical / automated / AI-intensive software engineering、程序修复、测试、需求、软件工程实践等主题。本库将其作为 P2 邻近观察 venue，用于扩展区域性 SE、LLM4SE 和工程实践线索，不作为 P0/P1 主投目标。
