## 6. 与本仓库 project 的年度相关性观察

- P1：关注程序理解、逆向工程、模型抽取、工件理解和 LLM4SE 上下文构造。
- P2：关注维护历史、需求 / 缺陷报告、回归测试和验证场景生成线索。
- P3：关注工具、trace、profile、reproducibility 和验证证据链。
- P4：重点关注缺陷定位、修复、重构、维护、演化、负结果和 empirical repair 证据。
