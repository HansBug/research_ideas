## 2. Scope 与栏目

- Springer scope 摘要：STTT 面向支持计算机系统开发与验证的软件工具，强调 rigorous、semantics-based、formal approaches，并要求工具与真实系统、工作流和工业上下文之间存在 technology-transfer 价值。
- 期刊定位：在学术工具研究与工业实践之间建立 tool-oriented link，尤其适合形式化验证、模型检查、运行时验证、工具链、竞赛 / benchmark、可靠系统工程和 tool paper 的扩展版本。
- 主题栏目：当前 editorial board 中显式维护 `Competitions and Challenges (CoCha)`、`Explanation Paradigms Leveraging Analytic Intuition (ExPLAIn)` 与 `Foundations for Mastering Change (FoMaC)` 等主题方向。
- 投稿模式：常规稿件 rolling submission；Springer submission guidelines 显示 single-blind peer review，并说明 special / guest-edited issue 的论文同样遵循期刊 peer-review 过程。
- 专刊模式：Springer `Special issue guidelines` 要求 special issue proposal 说明 guest editors、CFP、deadline、review / revision / notification 计划，并要求说明是否基于 conference / workshop；因此 STTT 年度论文计数必须显式区分常规论文与 conference-based special issue / invited papers。
