## 6. 与本仓库 project 的年度相关性观察

- P1：关注 TACAS 中与状态机、自动机、形式化规格、建模工具相关的论文。
- P2：关注验证场景、性质生成、counterexample、benchmark 与 specification mining 相关论文。
- P3：重点关注模型检查、时序逻辑、自动化验证工具、artifact evaluation 与 benchmark 论文。
- P4：关注 counterexample-guided repair / refinement、程序或模型修复、验证驱动调试论文。
