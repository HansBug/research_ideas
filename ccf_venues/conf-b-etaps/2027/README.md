## 6. 与本仓库 project 的年度相关性观察

- P1：关注 TACAS 中与状态机、自动机、形式化规格、建模工具相关的论文。
- P2：关注验证场景、性质生成、counterexample、benchmark 与 specification mining 相关论文。
- P3：重点关注模型检查、时序逻辑、自动化验证工具、artifact evaluation 与 benchmark 论文。
- P4：关注 counterexample-guided repair / refinement、程序或模型修复、验证驱动调试论文。
- **投稿视角**：`2026-10-15 AoE` 是 TACAS 与 iFS 共用的 submission deadline。对本仓库 project_1 而言，**iFS 的 scope 契合度高于 TACAS**（前者明列 requirements engineering、MDE、model learning、AI-based systems 的 SE 基础）；iFS 无 rebuttal、artifact 自愿、双盲仅限 regular research paper，且提供 empirical evaluation / NIER / data showcase 三条 short paper 通道。
