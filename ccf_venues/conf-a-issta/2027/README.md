## 6. 与本仓库 project 的年度相关性观察

- P1：中相关，可从测试驱动建模、行为抽象和规格推断角度追踪。
- P2：高相关，可追踪测试 / 场景 / oracle / 性质生成与开放科学评估。
- P3：高相关，ISSTA 包含程序分析、符号执行、验证和测试生成。
- P4：高相关，可追踪调试、缺陷定位、自动修复和 LLM repair。
- 投稿视角：主轨强制 abstract `2027-01-08`、full paper `2027-01-11`，是 P2/P3/P4 当前可行动的 🏆 档窗口。
