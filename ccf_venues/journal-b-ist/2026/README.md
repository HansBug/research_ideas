## 6. 与本仓库 project 的年度相关性观察

- P1：强相关：需求、规约、MBSE、AI-driven architecture 与工具链案例可支撑从需求到模型的经验 / 工具论文。
- P2：强相关：requirements、testing、V&V 与 quality assurance 适合验证场景、oracle、性质生成线索。
- P3：中相关：更偏经验 / 工具链评估，可承载验证剖面方法的工业案例与可靠性证据。
- P4：强相关：software evolution、quality / defect 与 testing feedback 适合修复与缺陷分类。
