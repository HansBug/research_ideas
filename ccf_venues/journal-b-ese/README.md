## 2. Scope 与栏目

- 官方 scope 摘要：Springer [Aims and scope](https://link.springer.com/journal/10664/aims-and-scope) 将 ESE 定位为面向应用软件工程研究、且具有强经验研究成分的论坛。
- 官方 scope 强调经验研究通常包含对软件开发交付物、实践和技术的数据或经验收集与分析，目标是理解、评价并在合适上下文中部署软件工程技术，见 [Aims and scope](https://link.springer.com/journal/10664/aims-and-scope)。
- Research Articles：Springer [Aims and scope](https://link.springer.com/journal/10664/aims-and-scope) 明确接受 original 与 replicated studies，覆盖 controlled experiments、field studies、data-intensive 与 qualitative studies，并偏好可复制或可扩展的研究。
- 相关主题包括 analysis and design、model-driven development、requirements engineering、verification and validation、maintenance and evolution、quality assurance、dependability、project management、predictive models、software economics、AI for SE 与 qualitative analysis。
- 投稿模式：常规稿件按 [submission guidelines](https://link.springer.com/journal/10664/submission-guidelines) 与 [Editorial Manager EMSE](https://www.editorialmanager.com/emse/) rolling submission；带 deadline 的 collections 在本目录年度页记录，并已同步至 [../TIMELINE.md](../TIMELINE.md) 全局时间线；后续若 Springer 更新状态或具体时刻再增量维护。
