## 6. 与本仓库 project 的年度相关性观察

- P1：重点关注 Research / Technical track 中关于 MDE、UML/SysML、建模语言、模型转换和模型生成的论文。

- P3：关注 model checking、formal analysis、verification、validation 和 tool-supported analysis 相关论文。
- P4：关注 model evolution、consistency management、repair、refactoring 和 transformation maintenance 相关论文。
