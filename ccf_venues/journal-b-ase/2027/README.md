## 6. 与本仓库 project 的年度相关性观察

- P1：自动化建模、低代码 / modeling collection、AI-augmented SE workflow 与需求到状态机建模相关。

- P3：若年度文章强调 model-based testing、CPS verification 或 verification workflow，可纳入验证剖面线索。
- P4：program repair、SBSE、quality feedback、genetic improvement 与迭代式修复强相关。
