## 2. Scope 与栏目

- Springer scope 摘要：SoSyM 聚焦软件与系统建模语言、技术、方法的理论和实践问题。
- SoSyM 官方站会使用 International Journal on Software and Systems Modeling 表述，并提供 current calls、online first 和 submission 入口。
- Article types：regular papers、tool papers、expert voice、theme / special section papers 等；不同栏目可能 rolling 或 dated deadline。
- 投稿模式：regular / tool / expert voice 等栏目可 rolling；theme section / special section 若有明确 deadline，应进入 [../TIMELINE.md](../TIMELINE.md)。

## 3. 与本仓库 project 的关系

| Project | 相关性 | 说明 |
