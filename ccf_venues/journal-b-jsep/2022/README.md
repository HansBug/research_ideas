## 6. 与本仓库 project 的年度相关性观察

- P1：关注软件过程、维护历史和演化建模对状态机建模上下文的贡献。
- P2：关注测试、质量、维护过程中的验证场景和 oracle 线索。
- P3：关注质量保障、可靠性与验证 evidence profile。
- P4：重点关注演化、维护、重构、测试、过程改进与修复效果评估。
