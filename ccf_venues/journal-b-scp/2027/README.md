## 6. 与本仓库 project 的年度相关性观察

- P1：中相关：形式化 DSL、状态机建模工具、可执行 artefact 和 MBSE 工具链可进入 Software Track。
- P2：强相关：specification、validation、verification 与程序 / 规约性质直接相关。
- P3：强相关：model checking、formal / semi-formal techniques、CPS verification 与工具 artefact 是核心线索。
- P4：强相关：verification-guided repair、program synthesis、fault localization 与工具化评估适合 SCP。
