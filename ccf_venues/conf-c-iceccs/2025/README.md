## 6. 与本仓库 project 的年度相关性观察

- P1：复杂系统、需求规约、CPS / 控制系统案例可支撑状态机建模样例筛选。
- P2：requirements / specification / V&V 论文可抽取验证场景与性质。
- P3：formal engineering methods、model checking、runtime verification、safety/reliability 是主要关注点。
- P4：修复相关只作二次筛选，不默认强相关。
