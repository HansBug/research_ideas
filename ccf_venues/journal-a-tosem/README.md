## 2. Scope 与栏目

- 官方 scope 摘要：TOSEM 是 ACM 软件工程与方法学方向的 Transactions 期刊；ACM 官方期刊总页说明其 journals 面向 practical 与 theoretical 的计算研究，并强调同行评审与 archival publication。
- TOSEM-specific scope 在当前环境下未能稳定抓取 ACM DL 正文；非 ACM 镜像仅作为发现线索，不作为唯一权威来源。
- Article types：ACM journal article、Just Accepted / accepted manuscript、以及 TOSEM 当前主页列出的栏目；具体以 ACM DL TOSEM 当前页面为准。
- 投稿模式：常规滚动投稿；当前未发现带明确 deadline 的 TOSEM special issue CFP。
