## 6. 与本仓库 project 的年度相关性观察

- P1：若年度论文涉及 requirements quality、model quality、AI/LLM-assisted quality assurance 或 learning-enabled systems，可作为状态机建模质量约束的补充文献。
- P2：testing、verification、validation、oracle、quality assessment 与验证场景 / 待验证性质生成直接相关。
- P3：software quality、formal / empirical validation、quality of autonomous / AI systems 可支撑验证剖面与模型检查证据链。
- P4：quality improvement、fault localization、testing feedback 与 technical debt 可作为模型修复评价和缺陷闭环线索。
