## 2. Scope 与栏目

- 官方 overview 将 SQJ 定位为传播软件系统开发、使用与维护中的 software quality 学术和实践洞见的平台。
- 期刊强调 quality management、methods、tools、products 与 software quality 的国际参考入口，适合作为 P2/P3/P4 的 testing / verification / reliability / quality assurance 交叉期刊。
- 常规投稿按 rolling submission 处理；topical collections / special issues 需按 Springer collections 页面和单独 collection 页面核验 deadline 与 open/closed 状态。

## 4. 与本仓库 project 的关系

| Project | 相关性 | 说明 |
|---|---|---|
| P1 状态机建模 | 中相关 | 若论文涉及 requirements quality、model quality、AI/LLM-assisted quality assurance 或 learning-enabled systems，可回流 P1。 |
| P2 场景与性质生成 | 强相关 | testing、verification、validation、quality assurance 和 oracle 问题与验证场景/性质生成高度相关。 |
