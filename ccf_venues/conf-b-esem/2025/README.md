## 6. 与本仓库 project 的年度相关性观察

- P1：重点关注 LLM / AI for SE、modeling task evaluation、benchmark、human / expert assessment、quality metric 和 qualitative analysis 方法。
- P2：关注 scenario / property generation 的实验设计、评价指标、replication package 与 threat-to-validity 写法。
- P3：关注验证工具链的 user study、empirical comparison、statistical analysis 和 reproducibility 证据。
- P4：关注 repair loop、defect taxonomy、ablation、developer / evaluator study 与修复质量度量。
- project_ex1：重点吸收 rubric、inter-rater agreement、judge reliability、noise floor、provider drift 与 open science practice。
